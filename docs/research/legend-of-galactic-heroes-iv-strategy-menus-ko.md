# 《은하영웅전설 IV》 전략 지도와 메뉴

보스텍의 1994년 PC-9801판 《은하영웅전설 IV》를 기준으로 하고, 일본어 Windows 95판 《IV EX》 화면을 함께 검토했다. 괄호 안 일본어는 화면 또는 명시된 자료에서 확인한 표기이며, 한국어는 설명용 번역이다. 상위 버튼은 두 판본의 실제 게임 캡처에서 판독했다. 하위 명령은 캡처에 나온 명령·대화창과 플레이 기록으로 확인한 범위다. 기본판 레퍼런스 매뉴얼 본문과 각 드롭다운의 전체 목록은 확인하지 못했다. ## 1. 은하 지도에서 확인하는 정보

전략 화면은 항로로 연결된 성계 지도, 상태 표시 영역, 조회 버튼, 명령 버튼으로 구성된다. PC-9801판에서는 버튼이 오른쪽 아래에 모여 있고, Windows EX에서는 위쪽 도구 모음으로 옮겨졌다. 지도에는 소속 세력이 색으로 드러나며, 성계별 함대와 작전 진행 상황을 확인할 수 있다. | 개인 (個人) | 플레이어 장교의 현재 보직·소재·능력·공적·공작 수치 등을 확인하는 개인 정보 진입점. |

## 2. PC-9801 기본판의 전략 명령

PC-9801판 명령 영역은 위에서부터 **인사·군사 / 재정·함대 / 특수·기지 / 정보·환경**의 2열 배열이며, 아래에 **해결** 버튼이 있다. 제독의 직책과 계급에 따라 같은 사안을 상관에게 제안하거나 직접 결정한다. [PC-9801 전략 화면](https://blog-imgs-172-origin.fc2.com/s/a/i/saitamat/20240417055436ade.png) · [D4 복각 발표](https://www.d4e.co.jp/20250718/4838)

| 상위 메뉴 | 기본판에서 확인한 명령·기능 |
| --- | --- |
| 인사 (人事) | **요직 임명 (要職任命)**. 제국 화면에는 군무상서·통수본부총장·우주함대사령장관의 현직자와 후보를 지정하는 항목이 나온다. |
| 군사 (軍事) | **군사작전 (軍事作戦)**으로 점령·방어 목표와 출격 규모를 정한다. **함대출격 (艦隊出撃)**으로 이미 수립된 작전에 참가할 함대를 지정한다. |
| 재정 (財政) | 세율 설정 기능이 기본판 플레이에서 확인된다. 상태창에 군무성 예산·통수본부 예산·국가 경제력이 표시된다. 기본판 재정 하위 목록은 미확인이다. |
| 함대 (艦隊) | **함대 편성** 화면에서 사령관·막료·기함·부대 구성과 함종별 재고를 확인하며, 구성 변경을 제안할 수 있다. 화면에는 **해산 (解散)** 버튼도 있다. |
| 특수 (特殊) | **제안공작 (提案工作)**은 정치공작을 써서 일정 기간 제안의 승인 가능성을 높이는 기능이다. 기본판에도 있다는 점은 EX 플레이 기록의 판본 설명에 근거한다. |
| 기지 (基地) | 상위 버튼 확인. 기본판의 개별 건설 명령은 미확인이다. |
| 정보 (情報) | 상위 버튼 확인. 기본판에는 **조사국장 임명 (調査局長任命)** 대화창이 나오며, 후보와 첩보 소요일이 표시된다. 이 대화창의 상위 메뉴 경로는 미확인이다. |
| 환경 (環境) | 상위 버튼 확인. 하위 설정명은 미확인이다. |
| 해결 (解決) | 입력한 명령을 처리하고 전략 시간을 진행하는 버튼. 진행 중에 함대 이동·교전·점령 등 작전 상황이 보고된다. |

## 3. Windows EX판에서 확인한 메뉴와 명령

Windows EX 전략 도구 모음은 **세력 → 성계 → 함대(조회) → 사관 → 개인 → 해결 → 군사 → 인사 → 함대(명령) → 기지 → 정보 → 특수 → 재정 → 환경** 순이다. 상단 Windows 메뉴 바에는 **파일 (ファイル), 표시 (表示), 전략 (戦略), 메인 (メイン), 전술 (戦術), 도움말 (ヘルプ)**이 표시된다. 전술 메뉴는 전략 화면에서 비활성으로 보인다. [Windows EX 전략 화면](https://blog-imgs-183-origin.fc2.com/s/a/i/saitamat/2026021501524888b.png)

| 메뉴 또는 화면 | EX에서 확인한 명령·기능 |
| --- | --- |
| 군사 | **군사작전 (軍事作戦)**, **함대출격 (艦隊出撃)**, **수송 (輸送)**. 수송은 전선으로 보급을 보내는 명령으로 EX에서 사용 가능해졌다고 플레이 가이드에 기록돼 있다. |
| 인사 | **요직 임명 (要職任命)** 화면에서 현직자를 확인하고 후보를 결정한다. |
| 함대 | **편성·막료** 관리와 **함대주둔 (艦隊駐留)**. 주둔 명령에서 성계·행성, 주둔 한도, 배치할 함대를 선택한다. 주둔도 EX 추가로 설명된다. |
| 기지 | **조병창 건설 (造兵廠建設)** 및 **주둔기지 건설 (駐留基地建設)** 화면. 위치, 비용·유지비, 완공 예정일을 보고, 조병창은 함종별 생산 규모를 지정한다. |
| 재정 | **예산 배분 (予算配分)**에서 군무성·통수본부·사회자본의 배분율과 차관 상환을 관리한다. EX 자료에서 세율 설정과 페잔 차관도 확인된다. |
| 특수 및 관련 공작 | **제안공작 (提案工作)**이 특수 메뉴에 있다. **치안회복 (治安回復)**은 화면에서 대상 성계와 방위사령관의 정치공작 값을 확인할 수 있다. **쿠데타 (クーデター)**는 플레이 가이드에서 전략 단계 공작으로 확인된다. |
| 정보·환경 | 상위 버튼은 확인했다. EX 하위 목록은 미확인이다. |

## 4. 전략 명령에서 전술 화면으로

**군사작전**에서 목표 성계와 작전 목적을 정하고, **함대출격**에서 참가 함대를 정한다. 명령을 처리한 뒤 플레이어가 교전에 참여하면 성계 전술 화면으로 전환된다. Windows EX의 전술 도구 모음에는 **작전 조회 (作戦照会), 함대정보 (艦隊情報), 성계정보 (星系情報), 자함대 (自艦隊), 해결 (解決)**이 표시된다. 화면의 공격 메뉴에는 **공격 지시 (攻撃指示), 함재정 출격 (艦載艇出撃), 총공격 (総攻撃), 공격 개시 (攻撃開始)**가 보인다. 전술 플레이 자료에는 항로·이동, 전투, 점령도 나온다.
