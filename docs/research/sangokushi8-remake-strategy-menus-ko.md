# 《삼국지 8 REMAKE》 전략 지도와 메뉴

코에이 테크모의 《삼국지 8 REMAKE》 기본판을 기준으로 조사했다. 메뉴명은 한국어 공식 Web매뉴얼 표기를 따랐다. 지도 조회, 계절 평정, 월간 도시 행동은 각각 다른 화면에서 이루어진다. [공식 Web매뉴얼](https://www.gamecity.ne.jp/manual/sangokushi8-re/kr/)

## 1. 지도와 공통 메뉴

| 메뉴 | 화면에서 하는 일 |
| --- | --- |
| 지도 | 전체 지도와 권역 확대 지도에서 지방·주·도시 위치를 본다. 전체 지도에서 서북·파촉·하북·중원·형초·오월로 접근한다. |
| 정보 | 도시와 무장 등의 정보를 조회한다. |
| 상관도 | 주인공과 다른 무장 사이의 인간관계를 확인한다. |
| 주인공정보 | 주인공의 능력 등을 확인한다. |
| 기능 | 저장·불러오기, 환경설정, 시나리오설정확인, 데모 플레이, 특전을 연다. |
| 도움말 | 게임 내 설명을 조회한다. |

평정 화면에는 날짜·계절, 소속 세력과 도시, 금·군량·병사와 다음 증감, 주인공 신분과 전략P가 표시된다. Steam 키보드에서 지도는 `M`, 정보는 `I`, 상관도는 `R`, 기능은 `C`, 도움말은 `F1`이다. [평정 화면](https://www.gamecity.ne.jp/manual/sangokushi8-re/kr/4100.html) · [전체지도/확대지도](https://www.gamecity.ne.jp/manual/sangokushi8-re/kr/6100.html) · [Steam 조작](https://www.gamecity.ne.jp/manual/sangokushi8-re/kr/2400.html)

## 2. 평정 → 전략

공식 평정 캡처의 하단 버튼은 **진행 → 인사 → 군사 → 계략 → 외교 → 방침 → 첩보** 순이다. 지도와 정보 등 조회 아이콘은 우측 상단에 있다. [공식 평정 화면 캡처](https://www.gamecity.ne.jp/manual/sangokushi8-re/kr/images/4000/4100_01.png)

평정은 1·4·7·10월에 열린다. 군주·도독·태수는 전략P 범위에서 명령을 실행하고, 군사·일반 무장은 제안한다. 군사·일반 무장이 특권을 사용한 제안은 승인된다. 방랑군에는 임무가 없으며 재야무장에게는 평정이 열리지 않는다. [1년의 흐름](https://www.gamecity.ne.jp/manual/sangokushi8-re/kr/3200.html) · [평정 화면](https://www.gamecity.ne.jp/manual/sangokushi8-re/kr/4100.html)

| 상위 메뉴 | 하위 명령과 역할 |
| --- | --- |
| 인사 | **이동**은 다른 도시로 가거나 휘하 무장을 보낸다. **배정**은 다른 도시에서 무장을 데려온다. **등용**은 무장을 영입한다. **상벌**은 명품을 수여하거나 회수한다. **임면**은 군사·태수·도독을 임명하거나 해임한다. **해고**는 무장을 내보낸다. |
| 군사 | **출진**은 대상 도시를 공격한다. **수송**은 도시 간에 금·군량·병사를 보낸다. **거래**는 군량을 사고판다. **징병**은 금을 써서 병사를 모으며 치안·병역인구와 군량수지가 낮아진다. **기술**은 기술서를 써서 세력의 병종·병기 등을 해금한다. **반란**은 군주나 도시 지배자에게 반기를 들어 독립을 시도한다. **방랑**은 방랑군을 일으킨다. **전지**는 방랑군 본거지를 옮긴다. **거병**은 방랑군이 공백도시를 점유해 세력을 세운다. |
| 계략 | **이간**은 적 무장의 충성을 낮춘다. **파괴**는 도시 방어를 깎는다. **선동**은 도시 치안을 낮춘다. **내통**은 무장에게 전향을 약속받는다. **매복**은 적 부대에 첩자를 넣어 전투에서 공황을 유발할 수 있게 한다. |
| 외교 | **친선**은 우호를 높인다. **동맹**은 상호 공격을 막고 원군 요청을 가능하게 한다. **연합**은 공동 표적을 정해 세력을 모은다. **가맹**은 기존 연합에 합류한다. **파기**는 동맹을, **탈퇴**는 연합 참가를 끝낸다. **요구**는 다음 평정까지의 정전을 조건으로 물자를 요구한다. **권고**는 대상 도시에 항복을 제안한다. |
| 방침 | **군단방침**은 군단의 공략·수송 목표를 지정한다. **도시방침**은 도시의 내정 우선순위·공략·수송 목표를 지정한다. **신설**은 군단을 만들고 도독에게 통치를 맡긴다. **편제**는 군단 소속 도시나 도독을 바꾼다. **해산**은 군단을 없앤다. |
| 첩보 | **첩보**는 대상 도시의 내구·병사·무장 정보를 파악하고 계략의 성공 가능성을 높인다. 조사 정보는 12개월 동안 유효하다. |
| 진행 | 전략 명령 입력을 끝내고 임무 화면으로 넘어간다. |

[평정 커맨드](https://www.gamecity.ne.jp/manual/sangokushi8-re/kr/5100.html) · [평정 화면](https://www.gamecity.ne.jp/manual/sangokushi8-re/kr/4100.html)

## 3. 평정 → 임무 → 도시

임무는 **개간·상업·기술·보수·치안** 중에서 정한다. 군주·도독·태수는 담당 무장을 정하며 **자동**, **계속**(지난 계절 배정 유지), **일괄해제**를 사용할 수 있다. 군사·일반 무장은 수행할 임무에 직접 지원한다. 도시에서 해당 행동을 하면 임무 진척도가 오른다. [평정 임무 화면](https://www.gamecity.ne.jp/manual/sangokushi8-re/kr/4100.html) · [도시 화면](https://www.gamecity.ne.jp/manual/sangokushi8-re/kr/4200.html)

| 도시 시설 | 하위 명령과 역할 |
| --- | --- |
| 자택(여관) | **교류**(담화·기증·등용 또는 천거·대련·토론), **연회**(여러 무장과 친밀 상승), **단련**(능력 경험), **습득**(특기·전법), **하야**(재야 전환), **결성**(재야에서 방랑군 창설), **휴양**(다음 달로 진행하고 행동력 회복). |
| 궁성 | **금고**(금 인출), **사관**(재야에서 세력에 소속), **악연**(소문으로 대상 무장의 충성 하락 시도). |
| 주점 | **청부**(의뢰 수락), **모병**(방랑군 병사 모집). |
| 농촌 | **개간**(농업), **견문**, **소재무장**. |
| 시장 | **상업**(상업), **견문**, **소재무장**, **매매**(명품 매매). |
| 공방 | **기술**(도시 기술), **견문**, **소재무장**. |
| 성문 | **보수**(방어), **견문**, **소재무장**, **약탈**(악명 조건), **외출**(임시 방문), **이주**(재야무장의 자택 이전). |
| 둔영 | **치안**(치안), **견문**, **소재무장**. |

농촌·시장·공방·성문·둔영의 **견문**은 시설 민심을 높이고, **소재무장**은 해당 시설에 있는 무장을 보여준다. 도시 화면에는 실행할 수 있는 **연의전**과 진행 중인 **의뢰**도 표시된다. [도시 커맨드](https://www.gamecity.ne.jp/manual/sangokushi8-re/kr/5200.html) · [도시 화면](https://www.gamecity.ne.jp/manual/sangokushi8-re/kr/4200.html)

## 4. 이름이 비슷한 명령과 화면 전환

| 메뉴 경로 | 차이 |
| --- | --- |
| 공방 → 기술 / 평정 → 군사 → 기술 | 공방은 도시 기술 수치를 높인다. 도시 기술이 1,000·2,000에 도달하면 기술서를 얻고, 평정에서는 그 기술서로 세력 기술을 해금한다. |
| 시장 → 매매 / 평정 → 군사 → 거래 | 시장에서는 명품을, 평정에서는 군량을 사고판다. |
| 주점 → 모병 / 평정 → 군사 → 징병 | 모병은 방랑군 병력을, 징병은 도시 병력을 늘린다. |
| 평정 → 군사 → 출진 → 편제 → 군의 | 출진 후에는 총대장·참군, 참가 부대·병종·장비 등을 정한다. 군의에서 부대 배치·책략·수비 함정·원군을 다룬다. |
