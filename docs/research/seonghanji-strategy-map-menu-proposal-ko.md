# 성한지 전략 맵 메뉴 개편 제안

검토일 2026-11-11. 현재 작업 트리의 Godot 전략 지도와 적벽 전투 진입 경로를 기준으로 작성했다. 비교 대상은 《삼국지 8 REMAKE》 기본판과 《은하영웅전설 IV》 PC-9801 기본판 및 Windows EX판이다. 현재 상태는 소스와 데이터에서 확인했다.

## 1. 권장 배치

첫 개편에서는 **지도 · 작전 · 전과 · 메뉴**를 천하 항로도와 형주·구지 화면에 공통으로 둔다. 하단의 **적벽으로**는 그대로 작전 브리핑을 열고, 브리핑 안에서 출격한다. 성계·행성·요새를 탭하면 선택한 대상의 정보와 바로가기만 보여준다.

| 화면 위치 | 제공할 메뉴와 동작 |
| --- | --- |
| 상단 공통 | **지도**는 조회와 탐색, **작전**은 브리핑과 출격 준비, **전과**는 최근 결산, **메뉴**는 설정·조작법·타이틀 복귀를 맡는다. |
| 지도 위 도구 | 현재 위치와 **전체 항로도**, **확대·축소**, **화면 맞춤**을 둔다. 형주·구지 화면의 축척 이동은 기존 단계 이동을 이용한다. |
| 선택 패널 | 선택한 성계·행성·요새·항로의 정보와 **상세 지도 열기**, **이 지점 확대**, **연결 항로 보기** 같은 바로가기를 둔다. 형주·적벽에서는 **작전 브리핑**을 함께 제공한다. |
| 하단 주 행동 | 항로도에서는 **적벽으로**, 브리핑에서는 선택한 작전의 **출격**을 표시한다. 결산에서는 **천하 보기**와 해당 모드가 지원하는 재도전 동작을 표시한다. |

## 3. 현재 전략 맵에서 옮길 항목

| --- | --- | --- |

| 항성계 상세에서 **정거장으로 이동** 또는 연결 진입로를 선택하면 다른 상세 화면이 열린다. | **지도 → 항로·관문**, 선택 패널 | **정거장 항로 보기**, **연결 성계 보기**처럼 화면에서 일어나는 동작을 라벨로 쓴다. 기존 정거장 경유 흐름을 따른다. |

| 결산 카드에서 **천하 보기**, **같은 판 다시**, **새 판**을 제공하는 흐름이 있다. | **전과 → 최근 결산**, 결산 카드의 재도전 버튼 | 현재 세션의 결산 또는 기존에 복원 가능한 제품 결산을 다시 열 수 있게 한다. 시나리오와 모드에서 지원하는 재도전만 연결한다. |
| 항로도 하단의 **타이틀로**, 타이틀 화면의 **설정** | **메뉴 → 타이틀로 / 설정** | 타이틀 복귀는 기존 경로를 연결한다. 설정은 기존 설정 화면과 적용 로직을 재사용할 수 있도록 지도 진입과 복귀 경로를 추가한다. |
| 개발 인수로 노출되는 가져오기·리플레이 열기와 정면·우회 개발 실행 버튼, 비활성 what-if 카드 | 개발 진입점, 추후 **작전 준비** | 개발 기능은 현재의 개발 인수에서 접근하게 둔다. 일반 작전 메뉴의 리플레이와 what-if는 사용자용 경로와 실제 규칙이 준비될 때 연다. |

천하의 항로도와 적벽 작전 카드에는 서로 다른 지도 데이터가 쓰인다. 항로도의 지점과 작전 대상·소유 정보를 연결할 때는 검증한 ID 대응을 사용한다. 화면 이름이 같아도 매핑이 확인될 때까지 각각의 화면에서 제공하는 정보만 표시한다. [지도 화면 조립](../../view/world/world_map_screen.gd) · [항로도 탐색](../../view/world/navigation_atlas.gd) · [208년 작전 지도 데이터](../../data/scenarios/base/world_208.json)

## 4. 상위 메뉴와 하위 명령

**1차**는 현재 적벽 흐름에 붙이는 메뉴다. **2차**는 기존 데이터에서 확인할 수 있는 조회 화면을 추가한다. **캠페인** 항목은 상태 변경·권한·저장 규칙이 구현된 뒤 제공한다.

| 상위 메뉴 | 하위 명령과 실행 범위 | 도입 |

| **외교** | **세력 관계**, **친선·동맹**, **정전 제안**, **지원 요청**. 세력 정보 화면에서 대상 세력을 선택해 같은 명령을 열 수 있다. | 캠페인 · 관계 및 협정 상태 필요 |
| **첩보** | **성계 정찰**, **첩보 보고서**, **공작**. 보고서는 대상, 관측 시점, 정보의 신뢰 범위를 보여준다. | 캠페인 · 전략 가시성·정찰·공작 상태 필요 |

1차 배치에서는 **지도 · 작전 · 전과 · 메뉴**만 상단에 표시한다. 2차에서는 **함대**를 추가하고, 시설을 자주 찾게 되면 **거점·군수**를 추가한다. 캠페인에서 상위 메뉴가 늘어나면 좁은 화면에서 **인사 · 외교 · 첩보**를 더보기로 접는다. **작전**과 하단의 주 행동은 바로 접근할 수 있게 둔다.

## 5. 구현 순서와 검증 기준

1. **1차 메뉴 재배치.** 공통 메뉴를 `WorldMapScreen`의 항로도·형주·구지 화면에 연결한다. 항로도 탐색에서 지도 조작이 정상 작동하고, 상단 **작전**, 하단 **적벽으로**, 적벽 선택이 같은 브리핑을 여는지 확인한다. Esc·뒤로 가기는 열린 메뉴나 상세 패널을 먼저 닫는다.
2. **작전 및 결산 재진입.** `BattleBrief`와 `WorldLink`를 통해 기존 출격·복귀 경로를 사용한다. 표준·직접 지휘의 첫 작전, 일반 적벽의 직접·자동 진행, Windows 이어하기, 결산 재열기를 각각 확인한다. 출격 연출·자동 해결·복원 중에는 다른 출격 명령을 실행할 수 없게 하고, 해당 작업의 기존 취소·복귀 동작을 제공한다.
3. **읽기 전용 조회.** 지도 목록과 작전 편성 조회부터 추가한다. 선택한 지점·작전과 표시하는 데이터가 일치하고, 같은 명부를 브리핑과 지도에서 열었을 때 내용이 일치하는지 확인한다. 좁은 화면과 터치에서도 지도와 메뉴를 모두 조작할 수 있어야 한다.
4. **캠페인 명령.** 함대 위치·거점 재고·권한·명령 대기열·지속 저장이 갖춰진 항목부터 연다. 예를 들어 **함대 이동**은 목적지 선택, 도착 예상, 명령 취소, 진행 후 위치 반영까지 검증하고 공개한다. 제안형 명령은 승인 상태와 사유를 확인할 수 있게 한다.

우선 적용할 흐름은 **천하 항로도 → 적벽 브리핑 → 작전 선택 → 출격 → 결산 → 천하**다. 여기서 지도 조회, 작전 실행, 결산 재열기의 세 진입점을 먼저 정리하면 기존 전투 경로를 그대로 사용하면서도 각 명령의 위치를 일관되게 만들 수 있다.
