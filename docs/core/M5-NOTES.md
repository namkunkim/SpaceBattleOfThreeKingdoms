# M5 진형과 기동: 구현 메모

2026-10-04, 구현 세션. 브랜치 `claude/trusting-hermann-ef7f1b`. 제안서 §4.2·§4.4·§4.7, §9 M5 행.

## 1. M5 전 후속 처리

| 후속 | 처리 |
|---|---|
| M3 방향 배분 잔여 이월 | 전대 단위 카운터(`loss_total`, `loss_exposed`; `exposed*BP < 6000*(total+1)`)가 이미 소수 잔여를 이월한다. 실제 동작: 이탈 한 척마다 노출 묶음 비중이 60% 미만이면 노출 함종에서, 아니면 나머지에서 뽑는다(첫 척은 노출 묶음). 코드는 그대로, 장기 비율 테스트만 추가(`formation_rules` §6: 이탈 24척, 작은 타격 반복, 노출 몫 60±5%) |
| 지휘 한도 초과 페널티 | **필요 없음.** 적벽 4난이도 모든 전대의 코스트가 한도(`40 + 통솔×2`) 이하다(`formation_rules` §9가 감시). 초과 전대가 생기는 편성이 들어오면 기동·명중·전환 페널티를 구현한다 |
| 제한적 승리 "함대 전체 도달" | 같은 함대에 격침·항복 전대가 있으면 제한적 승리가 안 된다(`victory.gd` `_alliance_escaped`). 탈출한 전대는 도달로 센다. 테스트 `victory_rules` 4a |

## 2. 구현

| 항목 | 내용 |
|---|---|
| 진형 % | 화력·방어·탐지는 M3에서 들어와 있었다. 기동%는 속도에 곱한다(진형이 바뀌면 속도 재계산) |
| 상성 | 학익→어린→방원→봉시→안행→학익, 교전 거리대(결착 아님) ×1.2. 팔진은 양쪽 모두 무효, 장사진 ×0.9 (`salvo.formation_mul`) |
| 전환 | 명령 `formation`(`args.id`). 30초, 통솔이 요구치에 못 미치면 60초, 팔진 조건 충족자(통솔 90 + 특성 "신기묘산")는 절반. 전환 중 피해 ×0.8, 방어%·노출·배치도는 이전 진형, 완료 때 바뀜. 현재 진형을 지정하면 전환 취소. 사유 코드: `formation_terrain`, `formation_master`, `unknown_formation` |
| 지형 제한 | `salvo.terrain_class`(시나리오 `battlefield_class`, 적벽은 개활이라 없음). 기저 항로: 학익·안행 불가, 중회랑: 방원·봉시·장사만, 대회랑: 장사진 강제·변경 불가. 시작 진형이 어긋나면 즉시 보정 |
| 노출표 | 7종 × 정면·측면·후면(`combat.loss.exposure`, 제안값) |
| 선회 | salvo 규칙은 9°/초(180°에 20초, `combat.movement.turn_deg_per_s`). POC 규칙은 `turn_rate` 그대로 |
| 이동 명령 | `move` args: `via`(경유점, 경유+목적지 ≤5), `strafe`(평행 이동, 전진의 60%, 방향 유지), `facing_deg`(도착 방향, 맞출 때까지 자동 조준보다 우선). 정지·공격·돌격·후퇴·집결·강제 퇴각이 지운다 |
| 방어진형 삭제 | salvo 규칙에서 `def`는 거부, `def_on`은 무시. 적 AI는 선체가 줄면 방원진(`formation_rules.defense_id`)으로 전환한다. salvo 쪽 방어태세 곱셈 삭제 |
| 배치도 | 진형 7종 → 기존 모양: 어린·학익·안행·장사 그대로, 방원=원진, 봉시=쐐기진, 팔진=방진(`BattleRules.FORM_SHAPE`). 투영 `formation`이 이 번호 |
| 투영 | `formation_id`, `form_to`, `form_left_s`, `route`, `strafe`, `face_set`, `face_to` |
| 데이터 | `combat.formation_rules`, `combat.movement`, `loss.exposure`. 시나리오 지휘관에 `traits`(제갈량 "신기묘산"). 생성기 `make_combat_m3.py`·`make_red_cliffs_208.py` |

## 3. 화면(UI) 범위

호스트 화면은 아직 POC 프로필이다(M10에서 시나리오 프로필로 교체). 그래서 호스트의 방어진형 버튼과 POC 10종 배치 이름은 그대로고, UI는 `BattleSource.has_command("def")`(규칙 세트 v02에서 숨김)로 이미 준비돼 있다. 진형 탭은 UI 세션이 투영 키(§2)를 읽어 만든다. 코어 쪽 삭제·7종·배치도 재사용은 끝났다.

## 4. 측정 (표준, 200시드, 4개 병렬 청크)

| 정책 | 연합 승률 | 길이 평균(중앙값, p10~p90) | 종료 경로 |
|---|---|---|---|
| none | 81.0% (M4 85.5%) | 1119초 (1122, 1025~1201) (M4 1142) | 조조 사기 붕괴 126, 20분 시계 54(27%, M4 40%), 연합 코스트 11, 조조 코스트 9 |
| attack | 64.0% (M4 63.5%) | 534초 (540, 459~597) (M4 539) | 조조 사기 붕괴 128, 연합 코스트 70% 68, 유비 기함 격침 3, 유비군 코스트 1 |

선회 9°/초가 접근·정렬을 늦춰 none의 20분 시계 종료가 줄었고(조조도 늦게 정렬한다) 나머지는 M4와 오차 범위다. 레버는 건드리지 않았다(M7 기준선).

## 5. 컨셉에 알릴 것

1. 선회가 느려져(97°/초 → 9°/초) 퇴각 전대가 먼저 돌아서는 동안 적 쪽으로 조금 간다. 의도한 결과인지.
2. 적 AI의 방어 반응을 방원진 전환으로 바꿨다(M7에서 다시 설계).
3. 지형 제한은 적벽에서 쓰이지 않는다(데이터·테스트만).
