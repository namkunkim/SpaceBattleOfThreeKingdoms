## 2. 편차·제안값

- **확인 임계 37 → 30** (`combat.detection.confirmed`, 제안값). 37이면 표준에서 조조가 확인 등급을 받은 판이 attack 32.5%, none 0%였다(§3).
- 평가 주기 1초, 관측 센서에 지형 센서%를 진형%와 합산, 사격각 변화는 사격선이 지나는 구역 합, lost 60초, `strength_bands` 4는 모두 제안값이다.
- 추정 사격은 위치 오차 조준 없이 명중 배율만 쓴다(본편 `result_pending`). 놓친 추정 접촉은 실제 위치로 쏜다(사거리·사격각 판정). M7에서 마지막 위치 조준으로 바꿀지 본다.
- 지형 제한(진형 금지 목록)은 적벽에서 쓰이지 않는다(개활). 지형 3구역(성운·잔해·그림자)은 적벽 데이터라 켜져 있다.
