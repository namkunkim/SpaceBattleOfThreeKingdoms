# I01 적벽 v1 일반 출격 진입점 후보

`sortie-entry.review.patch`는 승인된 5파일 제품 후보가 먼저 통합된 기준에서 지도 화면 한 파일만 수정하는 설계 패치다. F의 공유 작업 사본에는 제품 준비기·호스트 연결이 없어 직접 적용 대상으로 삼지 않았다. `manifest.json`에 읽은 E 격리 기준 파일과 SHA를 기록했다.

- 기존 적벽 카드에 `적벽 첫 작전 · 정면`을 명시적으로 선택하는 버튼을 추가한다. 일반 실행의 표준·직접 지휘에서만 사용할 수 있다. 현재 카드 선택값을 바꾸지 않고 승인된 seed 208로 요청한다. 경로 필드는 기존 제품 계약대로 외부 요청에 넣지 않는다.
- 기존 출격·같은 seed 재도전·자동 해결과 개발 정면/우회 버튼은 같은 호출을 유지한다. 일반 출격에서 seed가 208로 일치해도 제품 작전으로 바뀌지 않는다. 제품 작전의 재출격은 카드의 명시적 버튼을 다시 사용한다. 개발 플래그를 켜면 기존 카드 레이아웃과 개발 경로가 유지된다.
- 제품 버튼도 기존 출격 연출, 건너뛰기, `WorldLink.go_battle` 및 실패 시 지도 복원 경로를 공유한다. 제품 요청 준비가 실패하면 기존 실패 화면을 사용한다. Atlas의 표시나 이벤트는 건드리지 않는다.
- 정적 검사로 기존 호출과 Atlas 경계를 확인했다. Godot 4.7.2의 소형 격리 하네스는 패치에서 선택 함수를 추출해 기본·개발·제품 분기와 거부 조건 10개를 실행했다. 카드 배치, 실제 지도 장면과 결산 후 재진입은 이번 F 검증에 포함되지 않았다. 통합 시 새 카드 버튼이 들어가는 화면 높이와 제품 출격의 실패 복귀를 확인할 필요가 있다.

공유 소스 편집, GUI 실행, K6 실행 및 프로젝트 자산 복사는 수행하지 않았다. 하네스는 격리 APPDATA를 사용했다.
