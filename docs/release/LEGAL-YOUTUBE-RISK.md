- 범위: 현재 구현(적벽 3D 전투 POC)을 녹화해 유튜브에 공개하는 경우. 스토어 출시는 범위 밖이다.

## 1. 결론

영상 공개 자체는 가능한 수준이다. 공개 전에 막아야 할 것은 두 가지다.

- ② 사용자 제공 3D 모델과 컨셉 이미지가 어디서 왔는지 확인한다.
- ③·⑤ 제목·태그에 타사 상표를 쓰지 않고, 빌드 다운로드 링크를 걸지 않는다.

① 화면 구성이 VII를 닮은 문제는 촬영 방식과 UI-v2 반영으로 위험을 줄일 수 있다(§3).

**방침 (사용자 결정 2026-10-05): 가능하면 회피한다.** 위험을 줄이는 안보다 위험 요소 자체를 없애는 안을 고른다. 항목별 선택은 §3 "회피 선택"에 적었다.

## 3. 대체 방법

항목마다 비용이 낮은 순서로 적는다. **[즉시]**는 코드 변경이 필요 없는 방법이고, **[구현]**은 구현 세션이 필요한 방법이다.

### ① 화면 구성

| 안 | 내용 | 효과 | 비용 |
|---|---|---|---|
| A [즉시] | 3D 전장 중심으로 촬영·편집한다. HUD 전체 화면은 짧게 보여주고 레이더·명령 격자 클로즈업은 쓰지 않는다. | 공개 증거가 줄어든다. 위험이 없어지지는 않는다. | 없음 |
| B [구현] | HUD 숨김(시네마) 토글을 넣어 HUD 없이 전장만 찍는다. | 영상에서 위험을 거의 없앤다. | 작음 |
| C [구현] | 이미 정해진 §7.1 변경을 먼저 반영한 뒤 공개한다: CP 바 → 군 사기·국면·시계, 명령 8칸 → 태세/진형/무장 탭, 그룹 탭 I~IV → 전대 초상 띠, 정보 층 L0~L3. | VII에서 자연히 멀어진다. 어차피 할 작업이다. | 중간 (UI-v2 일정에 따름) |
| D [구현] | C에 더해 VII와 겹치는 외형을 바꾼다: 원형 레이더 → 사각 전술 지도나 위치 이동, 로마 숫자 탭 표기 폐기, 칸 나뉜 게이지 → 연속 막대·아이콘. | 겹침이 가장 적다. 출시 전 전문가 검토에서도 유리하다. | 중간 |

**회피 선택:** 영상은 B로 찍는다. HUD를 보여줘야 하면 C+D를 반영한 뒤에 공개한다. D의 외형 결정은 컨셉 세션이 맡는다.

### ② 사용자 제공 모델·컨셉의 출처

| 안 | 내용 | 비고 |
|---|---|---|
| A [즉시] | 생성 도구·요금제·생성일을 확인해 `ASSET_NOTES.md`에 적고, 그 라이선스 조건을 지킨다. | 무료 요금제 산출물은 CC BY 4.0(출처 표시 의무)이거나 공개 처리되는 경우가 있다. 이때는 영상 설명란에 출처를 표시한다. 유료 요금제는 보통 상업 이용과 비공개가 허용된다. 구체 조건은 해당 도구의 현행 약관으로 확인한다. |
| B [즉시] | **Hunyuan3D로 만들었다면 사용을 멈춘다.** 커뮤니티 라이선스의 적용 지역이 한국·EU·영국을 제외한다. | 다른 안(C~E)으로 바꾼다. |
| C [구현] | 저장소에 있는 Quaternius CC0 7종으로 촬영한다. | 권리가 가장 명확하다. 다만 ver3로 바꾸면서 Quaternius 런타임 재질 오버라이드를 제거했으므로 되돌리는 작업이 필요하고, 외관 품질은 떨어진다. |
| D [구현] | 다른 CC0 팩(예: Kenney Space Kit)을 쓴다. | 함급 8종을 맞추려면 개조가 필요하다. |
| E | 직접 만들거나(Blender) 외주로 제작한다. 외주는 계약서에 저작재산권 양도를 명시한다. | 상품화하려면 결국 필요하다. 비용이 가장 크다. |
| 컨셉 | 컨셉 이미지를 기존 작품(은영전 함선 등)을 참조해 만들었다면, 그 함형이 그대로 나오는 모델은 C~E로 바꾼다. | 독자 작화라면 A로 충분하다. |

**회피 선택 (Meshy 확인 후):** A로 간다. 요금제가 확인되지 않았으므로 무료 요금제 기준(CC BY 4.0)으로 영상 설명란에 "Model created with Meshy – CC BY 4.0 License"를 넣는다. 유료 요금제였어도 넣어서 손해는 없다. B는 해당하지 않는다. 참조 이미지를 쓰지 않았으므로 교체는 필요 없다.

### ③ 메타데이터

- 쓰지 않는 표현: 제목·태그·썸네일의 "은하영웅전설", "은영전풍", "삼국지 N"(KOEI 시리즈 표기), 타사 로고.
- 대체 표현: "적벽대전 모티프 우주함대 실시간 전술 — 개발 중 프로토타입", 태그 `적벽대전` `삼국` `우주전` `RTS` `인디게임` `Godot`.
- 설명란 예시: "개발 중 프로토타입입니다. 효과음은 자체 합성, 일부 이미지는 AI로 생성했고, 폰트는 SIL OFL(Pretendard, Noto Serif KR)입니다." (②의 출처 표시가 필요하면 여기에 더한다.)

## 4. 공개 전 체크리스트

1. ② 영상 설명란에 "Model created with Meshy – CC BY 4.0 License"를 넣는다.
2. ③ 제목·태그·썸네일에서 타사 상표를 뺀다.
3. ⑤ 빌드 다운로드 링크를 걸지 않는다.
4. ③ 설명란에 프로토타입·자체 합성 효과음·AI 생성 이미지·OFL 폰트를 표기하고, 필요하면 출처도 표시한다.
5. ① HUD 숨김 토글로 촬영한다(3-① B, 구현 필요). 토글이 생기기 전에는 3D 전장 중심으로 찍는다(3-① A).
6. ④ "성한지"를 출원하기 전까지 영상에 노출하지 않는다(타이틀 제외, 전체화면 촬영). KIPRIS 검색과 출원도 검토한다.
7. ⑦ (편집 시) BGM을 넣는다면 라이선스가 명확한 음원만 쓴다.
