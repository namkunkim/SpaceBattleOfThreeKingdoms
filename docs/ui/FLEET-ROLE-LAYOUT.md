# 함종별 진형 배치 (2026-10-18)

요청: 함종의 특징에 맞게 함대를 배치하고, 함선 이미지로 7종 진형을 비교한다.

시각 자료: [7종 진형 배치도 (HTML)](fleet-formations.html). 전체 비교와 진형별 확대 보기, 함종별 이미지·역할 범례를 포함한다. 2026-10-18 설정과 동일 편성 56척을 사용한 기록이며, 설정을 수정하면 배치도도 다시 생성해야 한다. [편집용 원본](fleet-formations.fragment.html)을 함께 보관한다.

Godot 화면: 타이틀 **진형 배치도** 또는 전투 중 **진형 → 배치도 보기**. 7종 진형과 예시 편성·실제 아군 편성을 선택할 수 있다. 실제 렌더러와 같은 배치 함수를 사용하고 열람 중에는 전투가 멈춘다. 돌아가기·Esc로 기존 화면에 복귀한다. 구현은 `hud/ui_kit/formation_guide.gd`, 연결은 `deck_screens.gd`와 `command_deck.gd`, 검증은 `tests/formation_guide_ui.gd`다.

실행 시 읽는 문서 정본은 [data/fleet-role-layout.md](../../data/fleet-role-layout.md)다. `FleetRenderer` 생성 시 해당 문서의 `fleet-role-layout` 설정 블록을 읽어 자리 우선순위와 선호 좌표에 적용한다. 문서 수정은 게임 재실행부터 반영된다. Android 내보내기에도 문서를 포함하며, 누락·오류 시 경고 후 내장 기본값을 사용한다.

`FleetRenderer._role_points`는 기존 진형의 모든 좌표를 유지하면서 함종별 위치를 배정한다. 편성의 실제 척 수와 함종 ID를 유지한다.

| 함종 | 우선 위치 | 목적 |
|---|---|---|
| 전열함 | 전방 중앙 | 정면 교전·돌파 |
| 포격함 | 중후방 양측 | 장거리 화력 지원 |
| 공성함 | 후방 화력선 | 관통 사격 |
| 강습모함 | 중앙 후방 | 보호받으며 강습정 운용 |
| 보급함 | 후방 안쪽 | 수리·보급 |
| 전자전함 | 전열 뒤 양측 | 탐지·교란 |
| 요격함 | 양익 외곽 | 호위·요격 |
| 고속정 | 전방 양익 | 정찰·기습 |

위치는 진형 안의 상대적인 선호 구역이다. 편성 비중과 진형 폭에 따라 가장 가까운 빈자리를 쓴다. 장사진에서도 대열 폭을 늘리지 않는다. 진형 전환 시 같은 함종 역할로 재배치하며 격침 슬롯은 비워 둔다. 이동·피해·사거리·진형 계수 등 전투 규칙 수치는 바꾸지 않는다. 편성이 비공개인 적 접촉과 POC는 기존 표시를 유지한다.

검증: `tests/formation_role_layout.gd`(7종 좌표 보존·중복 없음·결정성·전열/보급 및 정찰/모함 전후 관계), `tests/fleet_follow.gd`(진형 변경 후 역할·추종·격침 빈자리), `tests/formation_display.gd`(전환 시간·표시·정보 경계) 통과.

배치도는 위쪽을 전방으로 표시한다. 동일한 예시 편성 56척(강습모함 6, 공성함 4, 포격함 8, 전열함 14, 보급함 4, 전자전함 4, 요격함 10, 고속정 6)을 사용한다. 게임에서 사용하는 기존 실루엣 PNG를 이용하며 고속정은 요격함 이미지를 작게 쓴다.
