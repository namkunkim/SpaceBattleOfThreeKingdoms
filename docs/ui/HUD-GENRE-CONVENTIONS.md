# 전투 HUD — 장르 공통 관례로 다시 짜기

- 작성: 2026-10-05, 컨셉·리뷰 세션. 코드는 고치지 않았다. 구현은 UI 세션이 맡는다.
- 계기: `docs/release/LEGAL-YOUTUBE-RISK.md` 위험 ①, `docs/battle-core/BATTLE_DECISIONS.md` H3. 사용자 방침은 "가능하면 회피"다.
- 지킨 것: `PROPOSAL-realtime-battle-core.md` §7.1·§7.2, `EXPERIENCE-DESIGN.md` §6(U1~U9, 정보 층 L0~L3), `REVIEW-UI-v2.md` §3, Q18·Q21·Q22.
- **Claude는 변호사가 아니다.** 이 문서는 위험을 줄이는 설계 기준이지 권리 판단이 아니다. 출시 전에 전문가 확인을 받는다.

## 1. 결론

- **자리는 그대로 둔다.** 좌하단 지도, 하단 중앙 선택 패널, 우하단 명령 카드, 상단 상태 바, 좌상단 알림 로그는 1990년대 이후 RTS 대부분이 쓰는 배치다. VII만의 배치가 아니다. 그래서 Q18("POC 배치를 따른다")을 뒤집지 않는다.
- **VII에서 온 외형 다섯 가지는 모두 바꾼다.** 원형 레이더, 초상 정보창의 외형, 그룹 탭 I~IV, 칸 나뉜 게이지, 전대 위 초상 태그다(§3).
- 바꾼 결과는 §7.1에서 이미 정한 변경(CP 폐지, 탭 3개, 전대 띠, 정보 층)과 겹친다. 추가 비용은 지도 모양, 태그 내용, 시각 언어 세 가지뿐이다.

## 2. "관례"와 "특정 게임의 표현"을 가르는 기준

**관례로 본다 (가져와도 된다)**

1. **기능과 대략의 자리**만 같다. 예: "전장 축소 지도가 화면 구석에 있고, 누르면 그곳으로 이동한다."
2. **서로 다른 개발사의 게임 3개 이상**이 같은 기능·자리를 쓴다. 하위 장르가 둘 이상이면 더 좋다(RTS, 실시간 전술, 4X·함대전).
3. 특정 게임 이름을 빼고 한 문장으로 설명할 수 있다.
4. 다른 방식으로 만들기 어렵다. 예: 체력은 막대, 시간은 숫자 시계, 컨트롤 그룹은 숫자 키.

**표현으로 본다 (가져오지 않는다)**

1. 형태: 패널 윤곽, 모서리 처리, 지도 테두리 모양, 버튼 모양과 비율.
2. 장식: 리벳, 금속판 질감, 문양, 테두리 장식, 패널 제목 띠.
3. 배색: 특정 게임을 떠올리게 하는 색 조합과 명암 구성.
4. 아이콘·글리프·글꼴: 그림, 기호 체계, 표기 방식(로마 숫자 탭 같은 것).
5. 움직임: 등장·전환 애니메이션, 효과음과 화면의 짝.
6. **조합:** 개별로는 관례라도, 관례가 아닌 선택 여러 개가 한 게임과 동시에 겹치면 표현으로 본다. 대법원 2017다212095(2019)이 본 것이 이 "선택·배열·조합"이다.

**점검 방법 (구현 뒤 화면 캡처로 한다)**

- 화면 요소마다 위 표의 "관례 근거 게임"을 3개 이상 댈 수 있어야 한다.
- 관례가 아닌 선택(우리 고유 표현)을 목록으로 적는다. 그 목록이 특정 게임 하나와 두 개 이상 겹치면 하나를 바꾼다.
- VII 화면과 나란히 놓고 "VII를 아는 사람이 보면 떠올리는가"를 본다. 떠올리면 그 요소를 바꾼다.

**근거 게임에 대해:** 아래 게임 목록은 일반 지식으로 적었다. 출시 전 전문가 확인 때 각 게임의 스크린샷을 함께 내야 하므로 그때 대조한다.

**한 손 완주(U9):** 오른손만으로 띠(선택) → 태세 탭(방침) → 하단 중앙 결정 카드까지 닿는다. 결정 카드는 중앙에서 오른쪽으로 치우쳐 띄운다.

**PC 보조:** 숫자 키(편성 선택), Ctrl+숫자(편성 저장), 명령 단축키는 탭 구성에 맞춰 다시 배정(§7.2), Space(일시정지), 우클릭 드래그(화면 이동). 배치는 같다.

**터치 크기:** 모든 버튼·카드·지도는 물리 9mm(48dp) 이상(§7.2). 지금 명령 버튼(약 3.6mm, 폰 가로 기준)은 이 기준으로 다시 잡는다.
