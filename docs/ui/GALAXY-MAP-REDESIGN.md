# 적벽 작전 지도(은하맵 홈) 재설계 v1

시안은 두 개다. 작성일은 2026-10-04다.

- `docs/ui/mockup-galaxy-map-v1.html`: 적벽 작전 지도(형주 전역부터 시작, 키 1·2·3)
- `docs/ui/mockup-galaxy-map-full-v1.html`: 전체 은하 지도(천하부터 시작, 키 1·2·3·4). §6

Esc는 패널을 닫는다.

## 1. 범위와 근거

- 본편 은하맵 스펙 중 **성역(도시·행성)만** 참고한다. 내정·경제·시간 진행·함대 이동 명령은 넣지 않는다.
- 시나리오는 적벽 하나다. 지도에는 형주성역과 주변 성역(남양·오회·회남)만 둔다.
- 근거 문서는 본편 `docs/06-tech/map-ux-concept.md` §2~§6(연속 확대, 색 의미, 회랑, 화면 배치), `screens.md` §2(성역 뷰: 권역 노드·★주권역·회랑을 권역에 붙여 그림), `star-map.md` §1·§6.1(태양계권, 208 소유)이다.
- 데이터는 본편 `data/maps/galaxy-map.json`(`route-first-curves-v3`)의 `bodies`·`routes`·`corridors` 좌표와 `regions.json`의 권역·거점·국력을 그대로 쓴다. 지도 원본은 하나만 둔다.

## 2. 설계 원칙

| 원칙 | 적용 |
|---|---|
| 단순 | 연속 확대 대신 **3단계 축척**(전역 → 형주성역 → 구지 궤도). 두 손가락 확대·휠도 되고, 단계는 가장 가까운 단계로 자동 판정한다 |
| 태블릿 편의 | 터치 영역 48dp 이상. 포인터를 올려야 보이는 정보는 없다. 탭하면 오른쪽 패널, 좁은 화면이면 하프 시트가 열린다. 주 행동 버튼은 오른쪽 아래(엄지 영역)에 둔다 |
| 전투와 연결 | 전투 HUD 토큰(`ui_theme.gd`)·세력 기호(`factions.gd`: 촉 청록 사각 蜀, 위 주황 마름모 魏, 오 보라 원 吳)·금장 모서리를 그대로 쓴다. 궤도 단계에서 **전장 판(1600×900)이 실제 전투 레이더와 같은 격자·지형·탈출 지점으로** 구지 궤도 위에 드러난다 |
| SF 비주얼 | 시차 별빛, 낮은 대비의 성운(본편 §4: 밝은 성운으로 채우지 않음), 흐르는 고속항로, 회랑 차단대 해칭, 빛과 그림자가 있는 행성 구체, 스캔선 |
| 색 의미 분리 | 세력은 부드러운 영향권과 기호, 지형은 녹색 차단대와 성운으로 표시한다. 세력 채움이 장애 지대로 보이지 않게 한다(본편 §4) |

## 3. 화면 구성(1280×800 기준)

- **상단 띠**: 赤壁 인장, 날짜, 단계 경로(탭하면 그 단계로 이동), 정보 칩, 설정
- **왼쪽 레일**: 레이어 4종(세력·항로·지형·전장) 켜기·끄기
- **왼쪽 아래**: 축척 단계 전역 / 성역 / 궤도
- **아래 가운데**: 상황 띠 "적벽 교전 임박". 탭하면 전장 패널이 열린다
- **오른쪽 패널**: 선택한 대상의 정보와 행동 버튼. 주 버튼은 **출진 · 브리핑**이다

| 단계 | 보이는 것 | 탭 대상 → 패널 |
|---|---|---|
| 전역 | 성역 이름표 4개(등급·소유 기호), 장강 대항로, 양번관문·합비회랑, 지도 밖 출구(이릉협도·오령회랑·무관회랑), 적벽 표지 | 성역: 권역 목록·상시 연결 / 적벽 |
| 성역 | 권역 노드(★주권역, 분쟁 권역은 두 기호), 거점 점과 이름, 회랑 차단대 | 권역: 소유·국력·방어·거점·경유 항로 |
| 궤도 | 태양계권 천체 7개(태양·수성·금성·구지·태음·형혹·목성)와 궤도, **전장 판**: 지형 3구역, 탈출 지점, 함대 기호 | 천체 설명 / 전장: 양군 편성·지형 효과 |

## 4. 결정과 표시 규칙

- **세력 색은 전투 화면을 따른다**(사용자 확인, 2026-10-04). 본편 `galaxy.json`의 위 파랑·촉 초록·오 빨강은 쓰지 않는다. 연합 내 손권군은 보라 원이다.
- **208 소유**는 `star-map.md` §6.1을 따른다. 남양·북부권(양양)은 위, 강하는 유비·유기, 남부 4군은 유비(임시), 오회는 오, 회남은 위(손권 일부)다. **강릉 = 위는 컨셉 추정**이다(유종 항복 후 조조가 강릉을 얻은 정사 흐름).
- 기저 항로는 본편 규칙대로 상시 표시하지 않는다(이동 명령 때만). 이 화면에는 이동 명령이 없으니 그리지 않는다.
- 궤도 단계 전장 판의 함대 위치는 **시안용 표시**다. 시나리오 JSON에 배치 좌표가 생기면 그것을 쓴다. 전장 1단위는 지도 0.1875단위로 겹쳐 그린다(표시용 축척이며 판정과 무관).
- 화면 흐름은 **타이틀 → 작전 지도 → 브리핑(난이도·편성) → 전투**다. 난이도 선택은 브리핑에 남긴다.

## 5. Godot 구현 메모(대기열)

- 새 화면 `hud/ui_kit/campaign_map.gd`: `Control` + `_draw()`(배경·성운·항로·차단대·궤도·전장 판), 노드는 `Button` 자식(48dp)으로 만든다. 지금 `deck_screens.gd`의 `TitleScreen` 다음에 둔다.
- 데이터는 본편 `galaxy-map.json`에서 필요한 부분만 뽑은 `data/scenarios/base/red-cliffs-theater.json`(스냅숏, MANIFEST 해시)으로 만든다. 1MB 원본을 그대로 싣지 않는다.
- 카메라 확대 기준점은 손가락 중심, 단계 판정은 로그 축척으로 가장 가까운 단계다. 확대·패널은 시간 진행에 영향이 없다.
- 전장 판은 `radar_scope.gd`의 격자·색을 다시 쓴다.

## 6. 전체 은하 지도 판(`mockup-galaxy-map-full-v1.html`)

적벽 작전 지도를 유지한 채 본편 19성역 전체를 보이는 판이다. 화면 틀·패널·궤도 전장 판은 v1과 같고, 축척 단계 앞에 **천하**를 더했다.

| 단계 | 보이는 것 |
|---|---|
| 천하 | 19성역 이름표(작게, 소유 기호만), 권역 경계, 지형(소행성대 녹색·먼지 갈색), 회랑·고속항로 22개, 서역 출구, 적벽 표지 |
| 전역·성역·궤도 | v1과 같다. 성역 단계는 45권역 모두에 권역 노드가 붙는다 |

- **데이터:** `tools/ui/make_galaxy_full_data.py <본편 폴더>`가 본편 `galaxy-map.json`(권역 경계 다각형, 지형 다각형, 항로 곡선, 회랑), `regions.json`, `systems.json`에서 뽑아 HTML 안 `/*DATA*/` 구간을 바꾼다(약 57KB). 본편 데이터가 바뀌면 다시 돌린다.
- **208 소유:** 위(사예·예주·연주·청주·서주·기주·유주·병주·남양·회남·형주 북부와 강릉), 오(오회), 유비(형주 남부, 강하), 전장(태양계권)이다. 적벽 밖 군웅(유장·장로·마등·한수·사섭·공손강)은 **회청 육각 하나**로 묶고 인장 한자만 바꾼다. 전투 3진영 색과 섞이지 않게 하려는 것이다. 남중은 미개척(점선)이다.
- **권역 채움:** 본편 권역 경계는 보로노이라 바깥 권역이 지도 끝까지 늘어난다. 거점에서 멀어질수록 옅어지는 방사형 채움으로 그린다.
- **지형:** 다각형을 한 번만 오프스크린에 흐리게 구워 그린다(매 프레임 비용 없음). 개방 공간(분지·평원)은 검게 둔다(본편 §4).
- **기저 항로:** 본편 규칙대로 기본은 숨긴다. 왼쪽 레일 **기저**로 켤 수 있다(점선).
- **권역 숫자:** 패널은 본편 값을 이름 그대로 쓴다(인구·생산·세입·방어). v1 패널의 "국력"은 실제로는 세입 값이다.

## 7. 전체 맵 확대·축소와 행성계·함대 표현 (2026-10-04)

축척은 다섯 단계이고 그 사이는 연속으로 확대된다. 성역·권역·행성계 버튼은 **화면 가운데에 있는 대상**으로 들어간다. 모든 성역에 똑같이 적용된다.

| 단계 | 축척 | 보이는 것 |
|---|---|---|
| 천하 | 세계 전체 맞춤 | 19성역 이름표, 권역 경계, 지형, 항로 |
| 성역 | 0.075U | 성역 이름표(등급·소유), 회랑 이름 |
| 권역 | 0.2U | 45권역 노드, 거점 이름 |
| 행성계 | 1.6U(행성계 맞춤) | 본편 행성계 22개(항성·내행성·금성형·위성·외행성 1~4)와 식민지 79곳, 관문 정거장 1곳. 궤도선, 소유 고리, 항성 쪽 명암 |
| 전장 | 전장 1600×900 맞춤, 최대 3배 | 적벽 전대 14개를 **전투 화면과 같은 실루엣·진형**으로 그린다 |

U는 화면 짧은 변/650이다. 확대 수단은 두 손가락, 휠(이름표 위에서도), 두 번 탭(2배), +/− 버튼, 키 1~5와 +/−다. 상단 경로는 화면 가운데 위치를 따라 `천하 › 성역 › 권역 › 행성계 › 적벽 전장`으로 바뀌고, 각 칸을 탭하면 그 단계로 간다.

**행성계 표현**
- 천체 종류마다 색을 따로 쓴다. 항성은 seed에 따라 황·백청·적색 3종(태양은 황색 고정), 거주 주행성은 바다·대륙·구름, 식민지는 회록 바탕에 도시 불빛, 외행성은 가스·얼음·암석·청색 가스 4종이다.
- 이름표는 거주 주행성·식민지·항성에만 단다. 동반 행성은 탭하면 이름이 나온다.
- 패널은 소유, 권역 세입, 소속 행성계를 보여 준다. 성역·권역 패널에는 **행성계 보기** 버튼이 있다.

**함대 표현(전장 단계)**
- 데이터는 시나리오 정본 `squadrons[]`이다(`initial_position`, `formation_id`, `composition`, 지휘관·부장·참모, `deploy_delay_s`). 난이도 규모 계수는 반영하지 않았다.
- 함선 실루엣은 전투 시안 `mockup-battle-v2.html`의 `hull`/`shipSprite`와 같은 방식이다. 함종 대응은 강습모함=항모, 공성함·포격함=전함, 전열함·전자전함=순양함, 보급함=수송형, 요격함=호위함, 고속정=소형 쐐기이고 기함 전대의 첫 대형함이 기함이다.
- 세력 색은 촉 청록, 오 보라, 위 주황이다.
- 진형 슬롯은 어린진(쐐기), 학익진(날개 앞), 방원진(동심원), 안행진(V), 봉시진(좁은 화살), 장사진(2열 종대)이다. 큰 함선은 가운데, 소형은 바깥에 둔다. 진형 모양은 시안용 근사이고, 정본 슬롯 좌표는 Godot `fleet_renderer.gd`를 따른다.
- 축척에 따라 표현이 바뀐다. 행성계 단계에서는 전대 기호(세력 모양, 기함은 금테)로, 전장 단계에서는 함선 실루엣과 엔진 불꽃·진형 외곽선으로 보인다. 명패는 전장 전체가 보일 때 지휘관·함선 수만 남기고, 더 확대하면 이름·부장·진형·막대까지 보인다(겹침 방지).
- 전대 명패를 탭하면 전대 패널이 열린다(지휘·편성 표).

**교전 연출(전장·행성계 단계)**
- 각 전대는 가장 가까운 적 전대로 방향을 틀어 다가가고, 주력 사거리(전함 250, 순양 220, 항모 300, 호위 150, 고속정 110, 전장 단위) 안에 들면 멈춘다. 고속정·요격함은 더 빠르다.
- 일제 사격은 1.6~2.4초 주기로, 앞줄부터 물결처럼 나간다(전투 화면 UI-FLEET-VISUALS와 같은 리듬). 항모는 곡선 미사일, 고속정은 짧은 탄, 나머지는 광선이다.
- 명중하면 육각 무늬 방어막 섬광(약 2/3)이나 선체 섬광이 나온다. 격침되면 화구·충격파·불씨가 일고, 타면서 표류하는 잔해가 남는다. 한 전대는 정원의 42% 아래로는 격침되지 않는다.
- 위쪽 교전 띠에서 경과 시간, 양측 잔존 척수, 일시정지, 배속(×1·×2·×4), 처음부터를 다룬다. 한쪽 전력이 절반 아래로 내려가거나 4분이 지나면 6초 뒤 처음부터 다시 돈다.
- **이 연출은 화면용 근사다.** 피해·격침 확률·사거리는 전투 코어 규칙이 아니며 승패를 뜻하지 않는다. Godot 구현에서는 코어 투영(`BattleSource`)의 사건을 받아 같은 연출을 붙인다.

## 8. 외부 세력(제어 불가, 위치만 흐릿하게) (2026-10-04)

본편 스펙의 외부 세력을 천하·성역 단계에서 흐린 안개와 회색 이름표로 보인다. 지휘·명령 대상이 아니어서 탭하면 읽기 전용 패널(설명, 접근 경로, 같은 무리)만 열린다.

| 무리 | 세력 | 접근 경로 | 근거 |
|---|---|---|---|
| 북적(이민족) | 흉노 · 선비 · 오환 | 병주·유주 북방 변경 | design-overview §2.3, region-power(안문권 흉노 접경, 병주 이민족 침입) |

- **위치는 시안용 개략 배치다.** 본편 `star-map.md` §8의 "이역 권역(동이·북적·서융·남만)의 성계 외곽 배치"가 아직 미작성이다. 방위와 접근 경로만 맞췄다. 본편이 배치를 정하면 좌표를 바꾼다.
- **표현:** 무리별로 옅은 색을 쓴다(북적 모래, 서융 황토, 서방 회보라, 동이 회청, 남만 회록). 영역은 흐린 안개와 점선 원, 접근 경로는 회색 점선(해상은 점점선)이다.
- **화면 밖 방향:** 무리가 화면 밖에 있으면 가장자리에 방향 화살표와 무리 이름을 띄운다.
- **드래그 범위:** 외부 세력까지 포함한 범위(x −21000~39500, y −1500~30000) 밖으로는 끌림이 약해지고, 손을 떼면 안쪽으로 돌아온다.
- 산월(오회 예장권 내부)처럼 성역 안에 있는 이민족은 외부 세력이 아니므로 표시하지 않았다.
