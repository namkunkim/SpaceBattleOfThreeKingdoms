# 전투 전 편성 화면 (장수·전함 배치)

2026-10-10. 결정: `BATTLE_DECISIONS.md` §T Q73~Q77. 용어: 조종 단위 = **함대**(전대 개념 없음).

## 1. 흐름
브리핑 → **편성 화면** → (위치 배치, Q70·M10) → 전투(일시정지로 시작).
"정사 편성으로 시작" 버튼으로 편성 화면을 건너뛸 수 있다.

## 2. 화면 구성
| 영역 | 내용 |
|---|---|
| 왼쪽: 함대 목록 | 플레이어 세력(유비군)의 함대만. 칸마다 **출전 켜기/끄기(Q77)**, 이름, 제독 초상, 총 척수, 비용/지휘 한도 막대, 오류 표시 |
| 가운데: 선택 함대 | 직책 칸 5개(제독, 부제독, 참모 강습·공성·보급). 함종별 척수 행(− / + 버튼, 태블릿 48dp) |
| 오른쪽: 대기 풀 | 배치되지 않은 장수(능력치 통·무·지·매, 특성), 미배치 함선(함종별 남은 척수) |
| 아래 | 초기화(정사 편성), 확정. 오류가 있으면 확정 잠금 + 사유 |

조작: 장수를 끌어 칸에 놓기(PC·터치 공통), 칸을 눌러 풀에서 고르기(터치 대안). 함선은 −/+로 풀과 주고받는다.

## 3. 검증 규칙
- 출전 함대 1개 이상. 기함 함대는 끌 수 없다. 끈 함대의 장수·함선은 대기 풀로 간다(Q77).
- 세력 함종별 총 척수 = 시나리오 값(옮기기만, 생성·삭제 없음).
- 함대 비용 합 ≤ `command_limit`. 지휘 한도는 제독 통솔로 다시 계산한다(`40 + 통솔×2` 계열, 시나리오 §2).
- 제독 칸이 빈 함대, 함선 0척 함대는 확정 불가(또는 함대 비활성 — 구현 때 정함).
- 한 장수는 한 칸에만 들어간다. 다른 세력 장수는 쓸 수 없다.
- 기함(승패 기함) 함대는 고정이고 그 제독은 바꿀 수 없다(유비·조조 즉시 결과 조건, 제안서 §4.14).

## 4. 코어 연결
- 결과는 시나리오 프로필의 `squadrons[]` 사본(직책·`composition`만 바뀐 것)이다. `ScenarioProfile` 로드 뒤, `BattleSim.new` 전에 덮어쓴다.
- 결정론: 편성 사본을 `replay` 헤더에 기록한다(틱 명령이 아니다).
- **손권군·조조군은 사용자가 고치지 않는다**(사용자, 2026-10-10). 편성은 미리 정의(시나리오 정사 편성)하거나 AI가 같은 규칙 안에서 구성한다. 1단계는 미리 정의를 쓴다(결정론·1000시드 기준선 유지). AI 구성은 난이도별 변형이 필요할 때 넣는다.

## 5. 열린 것
- 함대 구성 자격(제독 통솔 2급 이상, Q62(b))을 모든 함대에 적용할지.
- 참모 보직 효과 수치, 장수 특기 슬롯 3(Q63)을 이 화면에 같이 둘지.
