# 전투 전 편성 화면 (장수·전함 배치)

2026-10-10. 결정: `BATTLE_DECISIONS.md` §T Q73~Q82, 분해 §T-1. 용어: 조종 단위 = **함대**(전대 개념 없음).

## 1. 흐름
브리핑 → **편성 화면** → (위치 배치, Q70·M10) → 전투(일시정지로 시작).
"정사 편성으로 시작" 버튼으로 편성 화면을 건너뛸 수 있다.

## 2. 화면 구성
| 영역 | 내용 |
|---|---|
| 왼쪽: 함대 목록 | 플레이어 세력(유비군)의 함대만. 칸마다 **출전 켜기/끄기(Q77)**, 이름, 제독 초상, 총 척수, 비용/지휘 한도 막대, 오류 표시 |
| 가운데: 선택 함대 | 직책 칸 5개(제독, 부제독, 참모 강습·공성·보급). 함종 8종 척수 행(− / + 버튼, 태블릿 48dp) |
| 오른쪽: 대기 풀 | 세력의 가용 장수 전원 중 미배치(통솔순, 이름·특성 검색, 통·무·지·정·매) + 남은 세력 예산. 명단 = 시나리오 `factions[].available_officers`(본편 SCN-03 소속 + 시나리오 지휘부, 불참 제외; 유비 58·손권 46·조조 71명) |
| 아래 | 초기화(정사 편성), 확정. 오류가 있으면 확정 잠금 + 사유 |

조작: 장수를 끌어 칸에 놓기(PC·터치 공통), 칸을 눌러 풀에서 고르기(터치 대안). 함선은 8종 모두 −/+로 늘리고 줄인다(예산·지휘 한도 안).

## 3. 검증 규칙
- 출전 함대 1개 이상. 기함 함대는 끌 수 없다. 끈 함대의 장수·함선은 대기 풀로 간다(Q77).
- **함종은 막지 않는다**(Q75). 8종 모두 고를 수 있다. 제약은 비용뿐이다: **함대 예산 = 지휘 한도**(Q80, 세력 예산 없음).
- **지휘 한도는 상한이 아니라 불이익 기준이다**(코어 `command.gd` `limit_tier`). 한도 = `(40 + 제독 통솔×2) × 3`(척 수 3배 결정에 맞춘 배율, `combat_m3.json` `command.limit_base` 120 + `limit_per_command` 6). 넘기면 초과분 ÷ (한도×25%)를 올림한 단계(최대 4)만큼 기동 −5%·명중 −4%·진형 전환 +8%씩. 화면은 경고만 하고 막지 않는다.
- 화면의 +는 한도까지만 채운다(자동 편성도). 한도 초과는 수동으로만 만들 수 있고 경고가 뜬다 — O4에서 막을지 정한다.
- 제독 칸이 빈 함대, 함선 0척 함대는 확정 불가(또는 함대 비활성 — 구현 때 정함).
- 한 장수는 한 칸에만 들어간다. 다른 세력 장수는 쓸 수 없다.
- 기함(승패 기함) 함대는 고정이고 그 제독은 바꿀 수 없다(유비·조조 즉시 결과 조건, 제안서 §4.14).

## 4. 코어 연결
- 결과는 시나리오 프로필의 `squadrons[]` 사본(직책·`composition`만 바뀐 것)이다. `ScenarioProfile` 로드 뒤, `BattleSim.new` 전에 덮어쓴다.
- 결정론: 편성 사본을 `replay` 헤더에 기록한다(틱 명령이 아니다).
- 참모 배열 순서 = 승계 순서(부제독 다음) = 보직 순서 강습 → 공성 → 보급(O1b, 관리 세션 기본값). `Organization.apply`는 검증에 실패한 편성을 적용하지 않는다.
- **손권군·조조군은 사용자가 고치지 않고 AI가 자동 편성한다**(Q81, 같은 함수·결정론). 조조는 난이도별 비율까지 함대 수를 늘린다(Q82).

## 5. 열린 것
- 함대 구성 자격(제독 통솔 2급 이상, Q62(b))을 모든 함대에 적용할지.
- 참모 보직 효과 수치, 장수 특기 슬롯 3(Q63)을 이 화면에 같이 둘지.

## 6. 자동 편성 (사용자, 2026-10-10)
"자동 편성" 버튼이 출전 함대를 꽉 채운다. 목업 규칙(탐욕):
- 장수: 제독 = 남은 장수 중 통솔 최고(기함 제독은 고정), 부제독 = 통솔, 참모 강습 = 무력, 공성 = 지력, 보급 = 정치. 함대 순서대로 돌아가며 뽑는다.
- 함선: 함대마다 지휘 한도까지(Q80), 기본 비율 전열4·포격2·요격2·보급1·강습모함1·전자전1로 채운 뒤 남는 점수는 고속정으로 채운다.
- 시뮬 기반 최적화(상대 편성·진형 상성 반영)는 밸런스 도구가 생기면 교체한다.
