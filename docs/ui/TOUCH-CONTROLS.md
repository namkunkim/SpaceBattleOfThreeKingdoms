# 태블릿 터치 컨트롤 정의 (2026-10-05, 그룹 지정 UI 세션 종료 시점)

새 세션이 터치 컨트롤을 이어서 다룰 때 읽는다. 사용자가 정한 규칙과 코드 현황을 구분해 적는다.
코드: `input/touch/touch_controller.gd`(전장 터치), `input/battle_input.gd`(마우스·`click_at`·`box_select`), `input/selection_set.gd`(선택 집합), `hud/ui_kit/squadron_strip.gd`(전대 띠), `hud/ui_kit/command_deck.gd`(그룹 버튼).
2026-10-06 규칙 4 구현(Q1·Q2·Q6 확정), 태블릿 실기기 확인 후 main 병합.

## 1. 용어

- **선택**: 호스트 `selected`(아군 전대 배열). 전대·함대(기함 전대 포함)가 같은 집합이다. 그룹 [1]~[5]는 저장된 선택이다.
- **선택된 영역**: 선택된 전대의 히트 영역(명패 사각형 ±4px 또는 중심 반경 `max(28, 52·cam_z)`px, `hit_fleet`).
- **다중 모드**: HUD [다중] 토글(`host.multi`). 전투 시작 때 꺼진다.
- 탭 = 이동 14px 이하로 손을 뗌. 끌기 = 14px 초과 이동(`TAP_MOVE`). 길게 누름 = 0.5초(`LONG_PRESS`).

## 2. 사용자가 정한 규칙 (정본)

1. 전대·함대 1개 또는 그룹을 선택한 뒤 **적을 탭하면 공격 지정**이다.
2. 선택한 뒤 **임의 공간을 끌면 이동**이다.
3. 선택한 뒤 **임의 공간을 탭하면 선택 해제**다.
4. 선택이 있을 때 **선택된 전대에서 시작한 끌기만 이동·공격**으로 인정한다. 끝점은 어디든 된다(Q1 확정). 선택 밖(빈 곳·적·미선택 전대)에서 시작한 끌기는 무시하고 힌트도 없다(Q2 (a), 힌트 없음).
5. 화면 이동은 두 손가락이다(한 손가락 팬 없음).
6. 선택이 없을 때 빈 곳 끌기는 범위 선택(그룹 지정용)이다. 선택이 없을 때 아군에서 시작한 끌기는 그 전대를 선택하고 명령한다.

### 3.3 시험 기능 제거 (2026-10-09, 사용자 결정)

함대 조작은 **선택 → 끌어서 이동 위치 지정**까지만이다(적 위에 놓으면 공격, 출발점으로 되돌리면 취소, 이동은 진행 방향으로 선회하며 간다). 태블릿 시험 중 넣었던 다음을 모두 뺐다: 회전 핸들·링 평행 이동, 일시정지/재개 고정 버튼(`G.hold`, 전투 시작 자동 정지, "정지 중에만 명령"), 끌다 멈추면 뜨는 도착 방향 원, 1초 누르면 뜨는 제자리(그룹) 방향 원, 이동 방식 알약(방향 고정/선회). `touch_controller.gd`는 시험 전(`00994ad`) 상태, `tactical_overlay.gd`는 시험 전 상태 + 탐지 원(`_detect_rings`). 코어의 `face` 명령과 `move`의 `strafe`/`facing_deg`는 남아 있지만 입력에서 쓰지 않는다. `tests/pause_button.gd` 삭제.

### 3.6 그룹 조작·전장·탐지 원 (2026-10-09, main 병합 `8e02aeb`, 브랜치 `feature/touch-test-two`)

**상태:** 아래 항목이 main에 들어갔다. 시험 모드는 폐지되어 감속 제거는 기본 동작이다. 방향 원·일시정지 버튼은 §3.3에서 제거했다.

- ~~그룹 제자리 방향 메뉴~~ (§3.3에서 제거)
- **그룹 이동 속도 규칙(코어):** 함대 2개 이상을 한 번에 `move`하면 그중 가장 느린 함대 속도로 가서 같이 도착한다(`FleetState.speed_cap`, `battle_sim.gd` move 처리·이동 분기). 도착·정지·공격 등 다른 명령으로 풀리고 돌격 중에는 적용하지 않는다. **함대를 하나씩 조작하면 각자 속도(B안).** 결정은 `BATTLE_DECISIONS.md` Q60. 배경: 함대 속도 = 편성 함선 중 가장 느린 함선 기준이라(`salvo.gd _speed`) 유비(157.5)와 관우(341.25)가 시험 모드 ×150에서 2배 넘게 차이 났다.
- **이동 목적지 보정:** 손가락 지점이 전장 밖이어도 대형 전체가 전장 안에 들어가도록 중심만 당긴다(`battle_commands.gd _fit_to_field`). 코어는 함대마다 따로 경계에 자르기 때문에 보정이 없으면 경계 밖 지점에서 대형이 한 줄로 뭉쳤다(logcat `[ORDER]`로 확인: 요청 (1900,1200) → 두 함대 모두 (1560,860)).
- **배경판 = 전장 크기:** 3D 배경판(성운 그림)과 격자를 실제 전장(`rig.limit`) 크기로 깐다(`battle_view_3d.gd build_backdrop`, `init_game`이 전장 크기를 정한 뒤 다시 만든다). 이전에는 배경판이 3400×2300 고정이라 전장(1600×900)이 판의 일부인데 경계는 안 보여서, 목적지가 보이지 않는 벽에서 잘리고 레이더(전장 기준)와 위치가 어긋나 보였다. 바깥은 어두운 원경판. 일반 전투(시험 모드 꺼짐)는 시나리오 전장 크기(적벽 1600×900)를 따라 판도 그 크기다.
- **함대별 탐지 범위 원:** 아군 함대마다 항상 그린다(선택 여부 무관, 선택한 함대는 더 진하게). 반지름 = (센서 점수 − 기준 점수) × 25(`distance_units_per_point`). 바깥 점선 = 추정(기준 15), 안쪽 실선 = 확인(기준 30), 기준에 못 미치면 그 원은 없다. 센서 점수는 코어 `Detection.sensor_of`(함선 센서 × 진형·지형 보정 + 지혜 구간 보너스 0/6/12/16/20)라 지혜 레벨이 이미 반영된다. 적 전자전·은폐 지형이 없다고 본 값이라 실제 범위는 이보다 줄어든다. 측정(적벽 아군): 유비 센서 22 → 추정 175·확인 없음, 관우 21 → 150. 코드: `tactical_overlay.gd _detect_rings`.
- **기본 동작(옛 시험 모드, 2026-10-09 폐지):** 전장 1700×1150(`FIELD_SIZE`, 배경판 3400×2300의 가로·세로 1/2)에 아군을 가운데에서 시작, 시작 배율 0.9, 이동 ×150·선회 ×15·제자리 회전 ×4, 선택 감속 끔, 카메라 여유 40%(자동 일시정지·정지 중에만 명령은 §3.3에서 제거). 함대 수 제한과 `sim.endless`는 없다. 로그: logcat `godot` 태그에 `[ORDER] move/face`와 `[TOUCH]`를 항상 남긴다(`adb logcat -d -s godot:I | grep -E "ORDER|TOUCH"`).
- **알려진 미해결:** 손가락 미리보기선은 손가락을 따라가서 경계 밖으로 끌면 실제 목적지와 다르게 보인다(미리보기도 경계 안으로 맞추는 것은 미구현). `tests/boundary.gd`가 `view/fleet_render/battle_source.gd:163`의 `BattleRules` 사용(9b9564b)으로 실패한다 — 이번 변경과 무관한 main의 기존 문제.

## 4. 두 손가락·HUD

- **카메라 여유(2026-10-08):** 시작 배율에서는 전장이 화면에 딱 맞아 두 손가락 이동이 제한(`camera_rig.gd clamp_cam`)에 막혀 안 움직였다. 시험 모드에서 `rig.margin = 0.4`로 화면이 전장 밖으로 40%까지 벗어나게 했다(기본값 0은 종전과 같다).

- **두 손가락 벌리기·모으기**: 확대·축소(`_update_pinch`). 같이 움직이기: 화면 이동. 시작할 때 진행 중이던 끌기·범위 상자는 취소한다.
- **HUD 버튼, 오른쪽 가장자리 세로 열(52×52, 작전 목표 패널 아래)**: [다중] 토글, [1]~[5].
  - 번호 탭 = 그 편성 선택(이미 같은 선택이면 화면을 그 그룹으로). 0.6초 길게 누름 = 현재 선택 저장.
  - 표시는 "번호·인원", 지금 선택과 같으면 강조. 격침·퇴각 전대는 그룹을 읽을 때 빠진다(`SelectionSet.prune`).
  - 키보드 1~9, Ctrl+1~9, "전체 선택" 명령(태세 탭)은 그대로다.
- **전대 띠(하단, 카드 7장)**: 탭 = 선택(다중 모드면 추가/해제), 카드 길게 누름 = 추가/해제, 카드에서 전장으로 끌기 = 명령(전장 끌기와 같은 미리보기), 카드 위 숫자 배지 탭 = 그 편성 선택. 띠 위로 되돌리면 취소.
- HUD 버튼은 Godot 터치→마우스 흉내(`DEVICE_ID_EMULATION`)로 눌린다. 전장에 내려온 흉내 이벤트는 `TouchController`가 소비해 마우스 상자 선택과 겹치지 않게 한다.
