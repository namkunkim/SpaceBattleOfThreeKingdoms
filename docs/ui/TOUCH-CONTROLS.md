# 태블릿 터치 컨트롤 정의 (2026-10-05, 그룹 지정 UI 세션 종료 시점)

새 세션이 터치 컨트롤을 이어서 다룰 때 읽는다. 사용자가 정한 규칙과 코드 현황을 구분해 적는다.
코드: `input/touch/touch_controller.gd`(전장 터치), `input/battle_input.gd`(마우스·`click_at`·`box_select`), `input/selection_set.gd`(선택 집합), `hud/ui_kit/squadron_strip.gd`(전대 띠), `hud/ui_kit/command_deck.gd`(그룹 버튼).
브랜치 `claude/peaceful-blackwell-903f01`의 `cf06443`까지가 구현이다. 태블릿 실기기 확인 전이고 main에는 아직 병합하지 않았다(그룹 UI 1차는 병합됨).

## 1. 용어

- **선택**: 호스트 `selected`(아군 전대 배열). 전대·함대(기함 전대 포함)가 같은 집합이다. 그룹 [1]~[5]는 저장된 선택이다.
- **선택된 영역**: 선택된 전대의 히트 영역(명패 사각형 ±4px 또는 중심 반경 `max(28, 52·cam_z)`px, `hit_fleet`).
- **다중 모드**: HUD [다중] 토글(`host.multi`). 전투 시작 때 꺼진다.
- 탭 = 이동 14px 이하로 손을 뗌. 끌기 = 14px 초과 이동(`TAP_MOVE`). 길게 누름 = 0.5초(`LONG_PRESS`).

## 2. 사용자가 정한 규칙 (정본)

1. 전대·함대 1개 또는 그룹을 선택한 뒤 **적을 탭하면 공격 지정**이다.
2. 선택한 뒤 **임의 공간을 끌면 이동**이다.
3. 선택한 뒤 **임의 공간을 탭하면 선택 해제**다.
4. (마지막 지시) 선택이 있을 때 **선택된 영역에서 시작한 끌기만 의미 있는 끌기**로 인정한다.
5. 화면 이동은 두 손가락이다(한 손가락 팬 없음).
6. 선택이 없을 때 빈 곳 끌기는 범위 선택(그룹 지정용)이다.

규칙 2와 4는 서로 다르다. 2는 "임의 공간 끌기 = 이동"이고 4는 "선택된 영역에서 시작해야 인정"이다. **4가 더 나중 지시이므로 4를 채택한다.** 이때 "임의 공간 끌기 = 이동"은 성립하지 않고 이동은 선택된 전대에서 끌기 시작해야 한다. 새 세션에서 사용자에게 한 번 확인한다(§6 Q1).

## 3. 한 손가락 제스처 표

### 3.1 구현된 것 (`cf06443`)

| 상태 | 조작 | 결과 |
|---|---|---|
| 선택 없음 | 아군 탭 | 그 전대 선택 (400ms 안에 같은 전대 재탭 = 화면을 그 전대로) |
| 선택 없음 | 적 탭 | 정보 보기(`inspect`) |
| 선택 없음 | 빈 곳 탭 | 정보 닫기 |
| 선택 없음 | 빈 곳 끌기 | 범위 선택 상자(기존 선택 대체) |
| 선택 있음 | 아군 탭 | 그 전대만 선택(대체) |
| 선택 있음 | 적 탭 | 선택 전체 공격 지정 |
| 선택 있음 | 빈 곳 탭 | 선택 해제 |
| 선택 있음 | 아군 전대에서 시작한 끌기 | 선택 전체 이동. 적 위에 놓으면 공격. 출발 전대 위로 되돌리면 취소. 미선택 전대에서 시작하면 그 전대로 선택이 바뀐 뒤 명령 |
| 선택 있음 | 빈 곳·적에서 시작한 끌기 | 선택 전체 이동(시작 지점 근처로 되돌리면 취소). 미리보기 선은 선택의 첫 전대에서 그린다 |
| 아군 위 | 길게 누름 0.5초 | 선택에 추가/해제(진동) |
| 다중 모드 | 아군 탭 | 추가/해제 |
| 다중 모드 | 끌기(어디서든) | 범위 선택, 기존 선택에 더함 |
| 다중 모드 | 빈 곳 탭 | 선택 유지 |
| 다중 모드 | 적 탭 | 선택이 있으면 공격 지정 |

### 3.2 목표 (규칙 4 반영, 미구현) — 선택 있음 + 다중 모드 꺼짐 행만 바뀐다

| 조작 | 결과 |
|---|---|
| 선택된 전대 위에서 시작한 끌기 | 선택 전체 이동·공격(위와 같음). 미선택 전대에서 시작하는 경우는 §6 Q2 |
| 선택된 전대 밖(빈 곳·적·미선택 전대)에서 시작한 끌기 | 무시. 명령도 범위 선택도 팬도 아니다. 제안 구현: `mode = "ignore"` |

구현 위치: `touch_controller.gd` `_drag`의 `mode == "pending"` 분기. 이동 미리보기를 빈 곳 시작으로 그리던 `order_from` 보정은 필요 없어지므로 지운다. 테스트는 `tests/selection_groups.gd` 3a 단계를 "선택된 전대에서 시작해야 이동, 밖에서 시작하면 무시"로 바꾼다.

## 4. 두 손가락·HUD

- **두 손가락 벌리기·모으기**: 확대·축소(`_update_pinch`). 같이 움직이기: 화면 이동. 시작할 때 진행 중이던 끌기·범위 상자는 취소한다.
- **HUD 버튼, 오른쪽 가장자리 세로 열(52×52, 작전 목표 패널 아래)**: [다중] 토글, [1]~[5].
  - 번호 탭 = 그 편성 선택(이미 같은 선택이면 화면을 그 그룹으로). 0.6초 길게 누름 = 현재 선택 저장.
  - 표시는 "번호·인원", 지금 선택과 같으면 강조. 격침·퇴각 전대는 그룹을 읽을 때 빠진다(`SelectionSet.prune`).
  - 키보드 1~9, Ctrl+1~9, "전체 선택" 명령(태세 탭)은 그대로다.
- **전대 띠(하단, 카드 7장)**: 탭 = 선택(다중 모드면 추가/해제), 카드 길게 누름 = 추가/해제, 카드에서 전장으로 끌기 = 명령(전장 끌기와 같은 미리보기), 카드 위 숫자 배지 탭 = 그 편성 선택. 띠 위로 되돌리면 취소.
- HUD 버튼은 Godot 터치→마우스 흉내(`DEVICE_ID_EMULATION`)로 눌린다. 전장에 내려온 흉내 이벤트는 `TouchController`가 소비해 마우스 상자 선택과 겹치지 않게 한다.

## 5. 마우스 (PC, 터치와 같은 규칙으로 맞춘 것)

- 왼쪽 클릭: 아군 = 선택(Shift·다중 모드면 추가/해제), 적 = 선택이 있으면 공격·없으면 정보, 빈 곳 = 선택 해제(다중 모드에선 유지).
- 왼쪽 끌기: 범위 선택(Shift면 추가). 오른쪽 클릭: 선택이 있으면 이동(빈 곳)·공격(적). 오른쪽 끌기·방향키: 화면 이동, 휠: 확대.
- 마우스에는 "선택된 영역에서 시작한 끌기" 규칙이 없다. 마우스 왼쪽 끌기는 범위 선택이고 명령은 우클릭이다. 터치와 통일할지는 §6 Q3.

## 6. 새 세션이 사용자에게 확인할 것

- **Q1** 규칙 2(임의 공간 끌기 = 이동)와 규칙 4(선택된 영역에서 시작해야 인정)가 충돌한다. 4를 채택해도 되는가? 되면 "선택된 전대 밖에서 시작한 끌기는 아무 일도 없음"이라 사용자가 반응 없음으로 느낄 수 있어, 짧은 힌트(토스트·미리보기 없음 표시)를 줄지 정한다.
- **Q2** 선택이 있을 때 **미선택 아군 전대**에서 시작한 끌기: (a) 무시 (b) 그 전대로 선택을 바꾸고 이동(현재 구현) (c) 범위 선택. 규칙 4의 문구상 (a)가 가깝다.
- **Q3** 마우스도 터치와 같은 끌기 규칙(선택된 전대에서 끌기 = 명령)으로 맞출지.
- **Q4** 선택이 있을 때 범위 선택(그룹 추가)은 [다중]을 켜거나 빈 곳을 탭해 해제한 뒤 해야 한다. 이 순서가 불편하면 대안: 두 번째 손가락으로 범위 선택, 길게 누른 뒤 끌기 등.
- **Q5** 한 손가락 팬이 없다. 태블릿 실기기에서 두 손가락 팬만으로 충분한지 본다.
- **Q6** 선택 감속(Q31·Q36·Q55)은 `mode == "order"` 또는 포인터 누름 중을 본다. 새 모드(`ignore`)가 생기면 감속에서 어떻게 볼지 정한다(제안: 무시 모드는 감속하지 않음).

## 7. 충돌 점검 결과 (`cf06443` 기준)

- 두 손가락 시작 → 끌기·범위 상자 취소: 확인함.
- 전대 띠 끌기 → `touch.mode = "order"`와 `_update_order/_finish_order`를 공유한다. 빈 곳 시작 명령이 생기기 전·후 모두 영향 없음(테스트 `squadron_strip`).
- 선택 감속: `mode == "order"`일 때 감속 유지(테스트 `pacing`). 범위 선택(`box`)은 포인터 누름만 본다.
- `battle.drag`(범위 상자 표시용)는 터치 범위 선택에서도 `btn = -1`로 채워 마우스 `_input`과 겹치지 않게 했다.
- 끌기 도중 선택 전대가 모두 사라지면 미리보기를 비운다.
