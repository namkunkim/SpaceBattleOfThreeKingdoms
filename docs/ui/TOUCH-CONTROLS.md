# 태블릿 터치 컨트롤 정의 (2026-10-05, 그룹 지정 UI 세션 종료 시점)

새 세션이 터치 컨트롤을 이어서 다룰 때 읽는다. 사용자가 정한 규칙과 코드 현황을 구분해 적는다.
코드: `input/touch/touch_controller.gd`(전장 터치), `input/battle_input.gd`(마우스·`click_at`·`box_select`), `input/selection_set.gd`(선택 집합), `hud/ui_kit/squadron_strip.gd`(전대 띠), `hud/ui_kit/command_deck.gd`(그룹 버튼).
2026-10-06 규칙 4 구현(Q1·Q2·Q6 확정), 태블릿 실기기 확인 후 main 병합.

## 1. 용어

- **선택**: 호스트 `selected`(아군 전대 배열). 전대·함대(기함 전대 포함)가 같은 집합이다. 그룹 [1]~[5]는 저장된 선택이다.
- **선택된 영역**: 선택된 전대의 히트 영역(명패 사각형 ±4px 또는 중심 반경 `max(28, 52·cam_z)`px, `hit_fleet`).
- **다중 모드**: HUD [다중] 토글(`host.multi`). 전투 시작 때 꺼진다.
- 탭 = 이동 14px 이하로 손을 뗌. 끌기 = 14px 초과 이동(`TAP_MOVE`). 길게 누름 = 0.5초(`LONG_PRESS`).

## 2. 사용자가 정한 규칙 (정본)

1. 전대·함대 1개 또는 그룹을 선택한 뒤 **적을 탭하면 공격 지정**이다.
2. 선택한 뒤 **임의 공간을 끌면 이동**이다.
3. 선택한 뒤 **임의 공간을 탭하면 선택 해제**다.
4. 선택이 있을 때 **선택된 전대에서 시작한 끌기만 이동·공격**으로 인정한다. 끝점은 어디든 된다(Q1 확정). 선택 밖(빈 곳·적·미선택 전대)에서 시작한 끌기는 무시하고 힌트도 없다(Q2 (a), 힌트 없음).
5. 화면 이동은 두 손가락이다(한 손가락 팬 없음).
6. 선택이 없을 때 빈 곳 끌기는 범위 선택(그룹 지정용)이다. 선택이 없을 때 아군에서 시작한 끌기는 그 전대를 선택하고 명령한다.

### 3.3 회전 핸들·평행 이동 (2026-10-08, 브랜치 `feature/touch-test-one-fleet`, 태블릿 시험 중)

선택이 함대 1개(다중 꺼짐)일 때 함대 주위에 **링**(반지름 84, 화면 단위 `RING_R`)과 선두 방향 **손잡이**(●)를 그린다. 링과 손잡이에서 시작하는 끌기는 3.1·3.2의 이동·공격보다 먼저 판정한다.

| 시작 위치 | 조작 | 결과 |
|---|---|---|
| 손잡이(반경 40, `HANDLE_HIT`) | 끌기 | **제자리 회전**. 위치·진형 배치는 그대로, 방향만 손가락 쪽으로. 미리보기: 중심→목표 방향 점선과 끝 원 |
| 링 위(손잡이 아님, ±26, `RING_BAND`) | 끌기 | **방향 고정 평행 이동**. 선두 방향을 유지한 채 끝점으로 옆걸음. 미리보기 "평행 이동" |
| 함대 본체 | 끌기 | 기존 이동(진행 방향으로 선회하며 이동) 또는 공격. 중간에 멈추면 도착 방향 메뉴(§3.5) |

- 취소: 회전은 함대 중심 가까이(`CANCEL_R`×0.6), 평행 이동은 중심 `CANCEL_R` 안에서 손을 떼면 취소.
- 링 위 평행 이동은 적 위에 놓아도 공격이 되지 않는다(표적 없음). 공격은 본체 끌기나 적 탭.
- 코어: 새 명령 `face`(`args.facing_deg`, 이동·표적 해제 후 `face_set`/`face_to`로 선회). 평행 이동은 기존 `move`의 `args.strafe`(전진 속도의 60%, `combat_m3.json movement.strafe_speed_bp`). 호스트 `order_face(rad)`, `order_move(w, strafe)`.
- 미해결: 다중 선택에서는 링·손잡이가 없다(함대 1개 선택 전용). 마우스(PC) 대응 없음. 실기기에서 링 크기(48dp)·오조작(링 위 시작이 이동으로 오인되는 정도)을 확인한다.

### 3.4 터치 정지·재개 (2026-10-08, 시험 중, `TOUCH_TEST`일 때만)

선택 감속(×0.2) 대신 쓰는 방식이다. 전장을 짚는 순간 전투 시계가 멈추고(`G.hold`), 명령을 다 내린 뒤 화면 아래 가운데의 **▶ 재개** 버튼을 눌러야 다시 흐른다. 탭·끌기·회전·두 손가락 확대를 가리지 않고 전장 터치 전부가 대상이다. HUD 버튼 터치는 정지시키지 않는다. 정지 중에 내린 명령은 즉시 적용되고 재개 뒤에 함대가 움직인다. 전투 재시작 때 해제된다. 코드: `touch_controller.gd`(`_build_resume`), `FleetBattle3D.gd`(`G.hold`). 정지 중 표시: 화면 호박색 테두리와 "정지 — 명령 입력 중" 문구, 내려 둔 명령(이동·평행 이동 목적지, 공격 표적, 도착 방향 화살표)을 계속 그린다. 재개 버튼은 우측 하단. 두 손가락 카메라 조작은 정지시키지 않는다(첫 손가락이 건 정지를 두 번째 손가락이 닿으면 푼다). 검토 안 중 D(링 크기 고정)·E(모드 칩)·F(각도 표시·스냅)·G(되돌리기 노출)는 미구현.

### 3.5 멈춰서 도착 방향 고르기 (2026-10-08, 시험 중)

본체 끌기 도중 손가락을 0.5초(`DWELL_T`) 가만히(14px 이내) 두면 **그 자리가 목적지**로 정해지고 진동과 함께 **방향 메뉴**가 뜬다. 메뉴: 목적지 둘레 8방향 화살표(↑ = 화면 위, 반지름 100, 항목 반경 40)와 중앙 "자동"(방향 지정 없음). 항목을 탭하면 `move`(`args.facing_deg`)가 나가고 도착 뒤 그 방향으로 돌아선다. 메뉴 밖을 탭하면 닫히고 명령은 취소된다. 멈추지 않고 손을 떼면 종전처럼 즉시 이동. 평행 이동(링 끌기)은 방향이 고정이라 메뉴가 없다. 적 위에서 멈춘 경우(공격)와 취소 반경 안은 메뉴가 뜨지 않는다. 메뉴가 화면 밖으로 나가지 않게 중심을 안쪽으로 당긴다. 메뉴가 열린 동안 전투는 정지 상태다(§3.4).

## 4. 두 손가락·HUD

- **두 손가락 벌리기·모으기**: 확대·축소(`_update_pinch`). 같이 움직이기: 화면 이동. 시작할 때 진행 중이던 끌기·범위 상자는 취소한다.
- **HUD 버튼, 오른쪽 가장자리 세로 열(52×52, 작전 목표 패널 아래)**: [다중] 토글, [1]~[5].
  - 번호 탭 = 그 편성 선택(이미 같은 선택이면 화면을 그 그룹으로). 0.6초 길게 누름 = 현재 선택 저장.
  - 표시는 "번호·인원", 지금 선택과 같으면 강조. 격침·퇴각 전대는 그룹을 읽을 때 빠진다(`SelectionSet.prune`).
  - 키보드 1~9, Ctrl+1~9, "전체 선택" 명령(태세 탭)은 그대로다.
- **전대 띠(하단, 카드 7장)**: 탭 = 선택(다중 모드면 추가/해제), 카드 길게 누름 = 추가/해제, 카드에서 전장으로 끌기 = 명령(전장 끌기와 같은 미리보기), 카드 위 숫자 배지 탭 = 그 편성 선택. 띠 위로 되돌리면 취소.
- HUD 버튼은 Godot 터치→마우스 흉내(`DEVICE_ID_EMULATION`)로 눌린다. 전장에 내려온 흉내 이벤트는 `TouchController`가 소비해 마우스 상자 선택과 겹치지 않게 한다.

## 5. 마우스 (PC, 터치와 같은 규칙으로 맞춘 것)

- 왼쪽 클릭: 아군 = 선택(Shift·다중 모드면 추가/해제), 적 = 선택이 있으면 공격·없으면 정보, 빈 곳 = 선택 해제(다중 모드에선 유지).
- 왼쪽 끌기: 범위 선택(Shift면 추가). 오른쪽 클릭: 선택이 있으면 이동(빈 곳)·공격(적). 오른쪽 끌기·방향키: 화면 이동, 휠: 확대.
- 마우스에는 "선택된 영역에서 시작한 끌기" 규칙이 없다. 마우스 왼쪽 끌기는 범위 선택이고 명령은 우클릭이다. 터치와 통일할지는 §6 Q3.

## 7. 충돌 점검 결과 (`cf06443` 기준)

- 두 손가락 시작 → 끌기·범위 상자 취소: 확인함.
- 전대 띠 끌기 → `touch.mode = "order"`와 `_update_order/_finish_order`를 공유한다. 빈 곳 시작 명령이 생기기 전·후 모두 영향 없음(테스트 `squadron_strip`).
- 선택 감속: `mode == "order"`일 때 감속 유지(테스트 `pacing`). 범위 선택(`box`)은 포인터 누름만 본다.
- `battle.drag`(범위 상자 표시용)는 터치 범위 선택에서도 `btn = -1`로 채워 마우스 `_input`과 겹치지 않게 했다.
- 끌기 도중 선택 전대가 모두 사라지면 미리보기를 비운다.
