# M4 이후 밸런스 재조정 기준 (컨셉 세션, 2026-10-04)

실제 코어가 돌기 시작하면(M4) 어떤 값을 어떤 순서로 무엇을 재면서 맞추는지 정한 문서다. 지금까지의 수치(세트 RX, 탐지 재조정)는 **AI 대 AI 근사 모델**의 결과이고, 이 문서는 그것을 실제 코어와 사람의 플레이로 다시 확인하는 기준이다. 근거는 `EXPERIENCE-DESIGN.md` §8과 제안서 §4.11·§11.

등급: **[확정]** 사용자 결정(Q번호), **[제안]** 컨셉 세션의 목표값. [제안]은 M4 시점 측정과 사람의 플레이를 본 뒤 고친다.

## 1. 원칙

1. 사람의 플레이가 최종이다. AI 대 AI 수치는 기준선일 뿐이다.
2. **한 번에 레버 하나**만 바꾸고 같은 시드 묶음으로 다시 잰다. 수치를 JSON(`realtime_rules`)에서 바꾸고 코드 상수로 박지 않는다.
3. 판정은 M1 개정(제안서 §9.2)과 같은 방식이다: **1000시드**, 승률 표준오차 약 ±1.5%p. 목표 구간 안인지로 보고, 변경 효과는 `|Δ| > 2×표준오차`일 때만 의미를 둔다. 200시드 결과로는 판정하지 않는다.
4. 정본 수치(피해, 선체, 사기 감소, 군 사기 임계 3000, 사격 주기 60초)는 건드리지 않는다(Q45·Q46·Q54 보충). 이것을 바꿔야만 목표가 맞는다면 사용자 결정을 바꾸는 일이므로 **인터뷰로 묻는다**.
5. 조정 사유와 전후 수치를 `BALANCE-LOG`(아래 §7)에 남긴다. `status: "proposed"` 값은 측정 후 `confirmed`로 바꾼다.

AI 대 AI는 양측을 같은 AI 수준 규칙으로 돌린 자동 해결이다(M7 이후 지휘관 AI, M4 시점에는 POC 수준 AI). 사람 플레이는 §5.

| 지표 | 목표 | 등급 | 현재 근거 |
|---|---|---|---|
| 게임 시계 길이(대회전) | 15~20분, 중앙값 15~18분 | [확정] Q51 | RX 표준 15~17분 |

## 3. 코어가 내야 할 측정값

판마다 한 줄 JSON(자동 해결 실행기 `tests/autoresolve.gd` 확장). 사건 목록(`events[]`)에서 뽑는다.

- 공통: 시드, 난이도, 정책(무명령/위임/기본 지휘), 승자, 종료 경로, 게임 시계 길이, 양측 손실(코스트 가중)
- 첫 일제: 판당 같은 진영 둘 이상이 같은 초에 쏜 비율, 첫 일제 결과 편중(REVIEW-M3 후속 1)
- 파도: 첫 명중 시각, 선봉·주력·후군의 교전 합류 시각, 파도 수
- 사기: 30초 간격 전대·군 사기 곡선, 군 사기 3000 도달 시각, 전대 퇴각 순서와 시각, 사건 회복(+300, +1200, +1000) 횟수
- 결정: 결정 카드 발생 시각과 종류, 60초·90초 묶음 수, 놓친 카드(시간 초과) 수
- 화공: 서신 시각, 의심 최댓값과 80 도달 시각, 기류 창 시작·종료 시각, 시도·발동·번짐 횟수, 간파 시각, 차단 요인
- 탐지: 조조 첫 확인 시각, 판 전체 확인 비율, 추정 사격 비율, 안개로 못 쏜 시간
- 연환·역병: 연환 유지 시간, 역병 사기 손실 합, 연환 효과가 걸린 번짐 횟수
- 사람 플레이 추가: 명령 수, 조작 일시 감속 시간(실제 시간), 결정 카드 응답 시간, 중도 일시정지 횟수, 실제 플레이 시간

## 4. 조정 순서와 레버

문제 유형별로 위에서부터 쓴다. 아래 레버가 먼저 소진되기 전에는 위의 규칙 수치로 가지 않는다.

| 우선 | 레버 | 위치 | 주로 맞추는 지표 |
|---|---|---|---|
| 1 | 투입 시차(`deploy_delay_s`), 거리대 일정(포화 12분 → 교전 6분 → 강습) | 시나리오 JSON | 길이, 파도, 결정 횟수 |
| 2 | 난이도별 조조군 규모(`count_factor`), 시작 사기, AI 수준 | `difficulty_profiles` | 난이도별 승률 |
| 3 | 화공 수치: 위력 25/40/50%, 번짐 반경 150·20초·최대 2회, 사기 충격 ×0.5/×0.25, 의심 상승(0.4/0.8/1.5/2.0), 기류 창(첫 명중 뒤 9~10분·3분) | `realtime_rules` | 화공 성공률, 시점 민감도 |
| 4 | 연환 ×0.8, 역병 −40bp/10초, 결집 +1200·30초 ×0.5 | `realtime_rules` | 표준 승률, 역전 가능성 |
| 5 | 탐지: 추정 접촉 시작 신뢰도 7500, 확인 임계 37, 추정 명중 배율 | 데이터 상수 | 조조 확인 비율 |
| — | 건드리지 않음: 피해 식, 선체, 사기 감소량, 3000 임계, 60초 주기 | 정본 | (바꾸려면 인터뷰) |

- 길이가 짧으면 1번(시차)이다. 사기 감소를 줄이는 것은 효과가 없다(Q54 보충).
- 승률이 목표에서 벗어나면 2번(난이도)이 먼저다.

## 5. 사람 플레이 테스트

M4(자동 해결 한 판 완결)와 M7(직접 지휘·위임 완결)에서 네이든이 직접 한다(제안서 §9 수직 슬라이스 기준선).

- **시나리오:** 표준 5판(화공 시도 포함), 입문 3판(무명령 1판 포함), 상급 3판, 극한 1~2판. 판마다 시드를 기록한다.
- **지표:** 승패, 길이, 실제 플레이 시간(목표 8~12분, Q51), 결정 카드를 읽고 응답했는가, 화공 시도 시각과 결과, 막혔거나 지루한 구간.
- **질문(판 끝 5개):** (1) 내가 지휘했다는 느낌이 있었나 (2) 지는 판이 억울했나, 납득됐나 (3) 어디서 시간이 길었나 (4) 결정 카드가 놓쳤거나 부족했던 순간 (5) 다시 하고 싶은가.
- 사람 판 결과가 AI 대 AI와 방향이 다르면(예: 입문 무명령이 100% 승리) **사람 결과를 따라** 2번 레버부터 고친다.
- 목표 승률(숙련 화공 성공 50~60%, 연환 대화재는 그 절반쯤 — `EXPERIENCE-DESIGN.md` §2)은 사람 판 5판 이상 뒤에 처음 판단한다. 3판 미만으로는 조정하지 않는다.

## 6.1 M4 측정 결과 (2026-10-04, 구현 세션)

표준 200시드 기준선과 첫 일제 동기화·P12 변형은 `docs/core/M4-NOTES.md` §4다. 요약: attack 연합 63.5%·길이 9분, none 85.5%·19.5분(20분 시계 40%). 첫 일제 동기화 7% 이하라 엇갈림 후보는 불필요, 주기는 60초 유지. 레버 조정은 M7 기준선에서. 1000시드 판정과 입문·상급·극한은 아직 재지 않았다(`tests/autoresolve.gd --profile red_cliffs --difficulty ... --runs 1000`).

## 7. 기록과 확정

- 조정할 때마다 `tools/scenario/balance_log.md`(새 파일)에 날짜, 바꾼 값, 전후 지표, 시드 수, 판정을 한 줄로 남긴다.
- 값이 목표에 들고 사람 판에서도 문제가 없으면 JSON의 `status`를 `"confirmed"`로 바꾸고, 제안서 §11.2의 해당 P번호를 확정으로 옮긴다.
- 사용자 결정(Q번호)을 바꿔야 하면 `BATTLE_DECISIONS.md`에 새 Q로 남긴다.

## 8. 미해결 위험과 판단 규칙

| 위험 | 결정 규칙 |
|---|---|
| 표준 화공 시도 승률이 기준선에 따라 22~32%로 흔들린다 | M4에서 실제 AI의 첫 명중 시각 분포를 본다. 분포가 넓으면 기류 창 기준을 "첫 명중"이 아니라 "조조 확인 시각"이나 절대 시각으로 바꾸는 안을 비교한다(M9) |
| 상급 화공이 시점에 민감하다(480초 75%, 600초 98%) | 창 범위(9~10분 + 3분)를 넓히는 안과 의심 가감 요인을 늘리는 안을 따로 측정한다 |
| 표준 조조가 확인 등급을 못 받는다(69%) | 지금은 신뢰도 7500으로 덮었다. M6에서 확인 임계 37 하향(30)이나 센서 공식을 비교한다. 본편 데이터 수정이 필요하면 본편에 되돌려 줄 것(A2) |
| 길이가 16분대에서 17~18분으로 늘 수 있다 | Q51(15~20분) 안이면 그대로 둔다. 실제 플레이 8~12분을 넘으면 감속·건너뛰기(Q52) 쪽을 먼저 본다 |

| 결정 4~6번이 실제로 안 나온다 | 카드 발생 조건(`realtime_rules.decision_cards`)을 조정하되, 카드를 늘리려고 임의 카드를 만들지 않는다 |
