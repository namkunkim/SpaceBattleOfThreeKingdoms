## 3. 구조

### 3.1 원칙

현재는 `scripts/FleetBattle3D.gd` 한 파일(약 1,830줄)에 시뮬레이션, 표현, HUD, 입력이 함께 있다. 자동 해결(화면 없는 계산)과 재생이 목표에 들어온 이상 분리는 필수다 [세션 Q9].

본편은 이미 같은 원칙으로 서 있다. 그대로 따른다 [정본 `DECISIONS.md` V-25·V-60·V-72, `s5-02`].

- **코어가 유일한 권위다.** 위치, 피해, 사기, 탐지, 승패는 코어만 계산한다.
- **화면은 공개 투영만 읽는다.** 표현과 HUD는 코어가 내주는 "이 진영이 볼 수 있는 것"만 받는다. 코어 상태를 직접 읽거나 바꾸지 않는다.
- **입력은 명령만 만든다.** 3D 화면에서 끌어서 내린 명령도 코어에는 명령 객체로만 들어간다.
- **고정 스텝이다.** 프레임 시간(delta)에 의존하지 않는다.
- **결정론이다.** 같은 초기 상태와 같은 명령 기록이면 결과가 같다. 저장·재생 뒤 상태 지문(digest)이 일치해야 한다.

### 3.2 계층

| 계층 | 책임 | 금지 |
|---|---|---|
| `core/battle/` 시뮬레이션 | 상태, 고정 틱 진행, 규칙, 승패, 공개 투영 생성, 명령 검증 | `Node` 참조, 렌더링, 입력, 프레임 delta, 전역 난수 |
| `core/battle/ai/` 지휘관 AI | 방침과 성향에 따른 명령 생성. **공개 투영만 입력으로 받는다** | 미탐지 적 정보 사용 (치팅 금지, 정본 `ai-design.md` §1.3) |
| `view/` 표현 | 투영을 3D 노드에 반영, 효과 재생 | 규칙 계산, 코어 상태 변경 |
| `hud/` | 투영을 표시, 버튼 | 규칙 계산 |
| `input/` | 터치·마우스·키를 명령으로 변환 | 코어 상태 변경 |
| `data/` | 함종, 진형, 무기, 사기, 승패 수치 | 코드에 수치를 박아 넣기 |

### 3.3 틱과 난수 [제안값]

- 시뮬레이션 틱: **초당 10틱(100ms)**. 표현은 틱 사이를 보간한다.
- 시간 감속과 2배속은 "실제 1초에 몇 틱을 돌리는가"만 바꾼다. 틱 하나의 내용은 같다.
- 난수는 시드와 `(전투 ID, 틱, 사건 ID)`에서 유도한다. 본편은 `sha256(profile_id|turn|event_id)`의 앞 8자리로 판정한다 [정본 `demo-rc-g8-00`]. 같은 방식에서 `turn`을 `tick`으로 바꿔 쓴다.
- 본편은 정수 연산과 basis point(bp, 1/10000)를 쓴다. 코어의 누적 값(사기, 선체, 명중률)은 정수 bp로 둔다. 위치와 속도는 고정 틱 안에서 결정론이 유지되는 한 실수를 써도 되지만, 플랫폼 간 일치가 필요해지면 고정소수점으로 바꾼다.

### 3.4 명령 기록과 재생

- 모든 명령은 `(틱, 발신 진영, 전대 ID, 명령 종류, 인자)`로 기록한다.
- 자동 해결 = 플레이어 명령 없이 AI 명령만으로 끝까지 틱을 돌리는 것.
- 연출 = 초기 상태와 명령 기록을 다시 돌리며 표현 계층만 붙이는 것.
- 저장 = 초기 상태 + 명령 기록 + 현재 틱. 또는 스냅숏 + 이후 명령 기록.

### 3.5 테스트

현재 POC의 메인 씬에는 전투 규칙 테스트가 없다. 구조 분리와 함께 헤드리스 테스트를 갖춘다.

- 규칙 단위 테스트: 거리대 계수, 방향 보정, 사기 임계, 진형 전환, 승패 경로
- 결정론 테스트: 같은 시드로 두 번 돌려 지문 일치
- 재생 테스트: 명령 기록 재생 뒤 지문 일치
- 정보 경계 테스트: 투영에 미탐지 적이 0건
- 자동 해결 통계: 같은 편성을 여러 시드로 돌려 승률과 전투 길이 분포를 본다

## 4. 전투 규칙

### 4.1 편제와 함종

조종 단위는 전대다. 함종을 따로 조종하지 않는다 [세션 Q5].

| ID | 함종 | 역할 | POC 표기 |
|---|---|---|---|
| `SHP-01`~`06` | 전열함 | 교전의 주력 | 전열 |
| | 포격함 | 포화의 주력, 가까우면 무력 | 화력 |
| | 강습모함 | 강습의 주력, 함재기 | 항모 |
| | 전자전함 | 탐지와 교란 | 전자전 |
| | 공성함 | 요새·궤도 공략 | 공성 |
| | 보급함 | 탄약 보급, 수리, 사기 유지 | 보급 |
| `SHP-07` | 요격함 | 고속 요격, 측후방 공격, 차폐와 호위 | (없음, 추가) |

- 함종과 ID의 정확한 대응은 본편 `data/`에서 확인한다. 위 표의 `SHP-01`~`06` 순서는 확인하지 못했다.
- 전대의 함선 수는 28척 고정이 아니다. 함종별 코스트 합계가 지휘관의 지휘 한도 안에 들어야 하고, 초과하면 불이익이 점진 적용된다 [정본 `demo-rc-requirements-interview.md` §3, `ship-specs.md` §6].
- 편성은 전투 밖(캠페인, 전투 준비 화면)에서 한다 [세션 Q5].
- 전대 데이터는 함종별 현재 척 수를 가진다. 지금의 "함정 수 하나"를 대체한다.

### 4.2 거리대와 국면

국면은 시간이 아니라 거리다 [정본 `ship-specs.md` §2.3, 세션 Q4].

| 국면 | 거리 [정본] | 주 무장 | 유효 함종 |
|---|---|---|---|
| 접적 | 20~12광초 | 없음. 탐지와 교란 | 전자전함 |
| 포화 | 12~4광초 | 미사일, 장포신 광선포 | 포격함 |
| 교전 | 4~1광초 | 주포 광선포 | 전열함 |
| 강습 | 1광초 이내 | 부포, 근접 방어, 함재기, 강습정 | 강습모함 |
| 결착 | 가변 | 추격은 미사일, 퇴각은 부포 | 보급함 |

**축척 [제안값]:** POC 전장 좌표로 **1광초 = 75단위**. POC의 주포 사거리 300단위가 4광초에 대응한다. 이 축척이면 미사일 12광초 = 900단위, 탐지 20광초 = 1,500단위이고, POC 전장(3400×2300)에 들어간다.

**이동 속도는 다시 잡아야 한다.** POC의 속도(약 62단위/초)로는 접적 거리를 30초 안에 건너므로 20분 전투와 맞지 않는다. 전투 길이 목표(§4.12)에 맞춰 낮춘다.

**전투 전체의 국면 표시 [제안값]:** 각 전대의 거리대는 그 전대와 가장 가까운 탐지된 적 사이의 거리로 정한다. 화면에 표시하는 "현재 국면"은 양 진영 코스트의 과반이 들어가 있는 거리대다. 무기의 유효성은 전투 전체 국면이 아니라 각 전대의 실제 거리로 판정한다.

### 4.3 화력

정본의 전투력 식을 그대로 쓴다 [정본 `combat.md` §3.1].

```
전대 전투력 = 유효 함선 수 × 함종 계수(거리대) × 지휘관 보정 × 진형 계수(거리대)
            × 지형 보정 × 특성 보정 × 사기 계수 × 방향 보정
```

**함종 계수 [정본 `combat.md` §4.1]**

| 함종 | 접적 | 포화 | 교전 | 강습 | 결착 |
|---|---|---|---|---|---|
| 전열함 | 0.8 | 1.0 | 1.6 | 0.9 | 1.1 |
| 포격함 | 0.9 | 1.8 | 0.7 | 0.5 | 0.8 |
| 강습모함 | 0.7 | 0.6 | 0.8 | 2.0 | 1.0 |
| 전자전함 | 1.9 | 1.1 | 0.9 | 0.7 | 0.6 |
| 공성함 | 0.5 | 1.2 | 0.6 | 0.8 | 0.5 |
| 보급함 | 0.4 | 0.4 | 0.5 | 0.4 | 사기 유지 |
| 요격함 | 본편 `data/`에서 확인 | | | | |

고정 상성표는 만들지 않는다. 이 거리대별 계수가 상성이다 [세션 Q12].

**지휘관 보정 [정본 `combat.md` §3.2]:** 접적은 지력 ±40%, 포화는 지력 ±30%, 교전은 통솔 ±50%, 강습은 무력 ±50%, 결착은 통솔(퇴각) 또는 무력(추격) ±35%.

**사기 계수 [정본 `combat.md` §3.4]:** `0.6 + 사기/250` (게이지 0~125 기준). 폭이 좁다(0.68~1.10). 사기는 전투력을 조금 깎고 붕괴를 크게 당긴다.

**방향 보정:** POC는 측면 +30%, 배후 +60%다. 본편은 전대의 정면·측면·후면 판정과 보정을 코어가 계산하고 값은 `data/`에 있다 [정본 `demo-rc-g4-04`]. 본편 값이 확인되면 그것을 쓰고, 확인 전에는 POC 값을 유지한다 [제안값].

**지휘 범위:** POC는 기함의 지휘 범위 밖 전대에 화력 −25%를 준다. 본편에서 지휘 범위는 전투 중 함대 편입의 조건으로 쓰인다 [정본 `demo-rc-requirements-interview.md` §3]. 화력 불이익은 POC 규칙을 유지한다 [제안값].

### 4.4 맞는 방향과 함종별 손실

피해는 함종별로 쌓인다. 맞는 방향에 노출된 함종이 먼저 손실된다 [세션 Q5·Q6]. 본편의 "함종 ID 오름차순 배분"을 대체한다.

**배분 규칙 [제안값]**

1. 공격이 들어온 방향을 대상 전대 기준 전면, 측면, 후면으로 판정한다.
2. 그 방향의 **노출 함종**(아래 표)에 손실의 60%를, 나머지 함종에 40%를 준다.
3. 각 묶음 안에서는 현재 척 수에 비례해 나눈다. 나머지는 함종 ID 순으로 처리해 결정론을 지킨다.

**진형별 노출 함종 [제안값]**

| 진형 | 전면 | 측면 | 후면 |
|---|---|---|---|
| 어린진 (중앙 돌파) | 전열함 | 요격함, 포격함 | 보급함, 강습모함 |
| 학익진 (양익 포위) | 전열함, 요격함 | 전열함 | 포격함, 보급함 |
| 방원진 (종심 방어) | 전열함 | 전열함 | 전열함, 요격함 |
| 안행진 (사격 전개) | 포격함, 전열함 | 포격함 | 보급함, 공성함 |
| 봉시진 (축차 투입) | 강습모함, 전열함 | 요격함 | 보급함, 포격함 |
| 장사진 (종렬 항진) | 전열함 | 전 함종 | 보급함 |
| 팔진 | 전열함 | 전열함, 요격함 | 전열함 |

- 방원진과 팔진은 어느 방향에서 맞아도 전열함이 받는다. "약점이 없는 진형"이라는 정본의 성격과 맞춘 것이다.
- 장사진은 측면에서 맞으면 전 함종이 노출된다. 정본에서 장사진은 "싸우기 위한 진형이 아니다".
- 이 표는 전부 제안값이다. POC의 기존 배치 모양 가운데 정본 진형과 맞는 것은 배치도로 재사용한다 [세션 Q10].

**함종 손실의 결과**

- 강습모함이 0척이면 함재기 발진 불가.
- 보급함이 0척이면 전장 보급·수리 불가, 결착의 사기 유지 효과 없음.
- 전자전함이 0척이면 탐지 능력이 선체 기본값으로 떨어짐.

### 4.5 손상 단계 [세션 Q25, 정본 `ship-specs.md` §3.7]

함선은 바로 격침되지 않는다.

| 단계 | 전투력 계수 | 전열 | 비고 |
|---|---|---|---|
| 무손상 | 1.00 | 유지 | |
| 경파 | 0.90 | 유지 | 주포와 기관은 건재 |
| 중파 | 0.65 | 유지 | 주포 또는 기관 하나를 잃음 |
| 대파 | 0.00 | 이탈 | 동력 정지, 표류. 전장에 남아 있고 전투 후 회수 대상 |
| 격침 | | 소멸 | |

- 이탈(대파 + 격침) 가운데 대파의 비중은 거리대의 주 무장이 정한다: 접적 0.80, 포화 0.50, 교전 0.60, 강습 0.75, 결착 0.55 [정본].
- 화공(연쇄 폭발 작전)의 대파 비중은 0.25다. 넷 중 셋이 격침이다 [정본].
- 신규 중파는 경파 함선에서 먼저 나온다 [정본].
- "유효 함선 수"는 단계별 계수를 곱한 합이다.

### 4.6 사기

**두 층이다 [세션 Q3·Q23].**

**전대 사기 [정본 `demo-rc-g8-00`]**

| 상태 | 범위 (bp) | 효과 |
|---|---|---|
| 안정 | 6000 이상 | 없음 |
| 동요 | 3000~5999 | 계략에 잘 걸림. 명령은 수행 |
| 퇴각 | 1~2999 | 공격과 임무 변경 불가. 탈출 지점으로 강제 퇴각 |
| 항복 | 0 | 종결 |

- 판정은 확률이 아니라 고정 임계값이다. 현재 값과 다음 위험 단계를 화면에 보여 준다 [정본 `demo-rc-requirements-interview.md` §9].
- 감소 [정본 `demo-rc-g8-00`]: 일반 명중은 300bp와 `ceil(피해 × 10000 / (최대 선체 × 5))` 가운데 큰 값, 함선 손실 1척마다 200bp, 연쇄 폭발 피격 3500bp.

**눈금 [제안값]:** 전대 사기의 눈금은 데모 계약의 bp(0~10000)를 쓴다. 시험된 수치를 그대로 쓸 수 있기 때문이다. 캠페인의 초기 사기(게이지 45~125, `combat.md` §1.2)는 **×100**으로 옮겨 4500~12500bp에서 시작한다. 천명, 통솔, 보급, 원정 피로가 전대의 출발 사기를 정한다.

**거리대 가중 [제안값]:** 위 감소량에 정본의 국면 계수(접적 0.8, 포화 1.2, 교전 2.0, 강습 1.6, 결착 1.0, `combat.md` §1.3)를 곱한다. 같은 손실이라도 교전에서 더 아프다.

**방향 가중 [제안값]:** 측면에서 맞으면 ×1.3, 후면에서 맞으면 ×1.6. POC의 화력 보정과 같은 배율이다.

**군 사기 [세션 Q23]**

```
군 사기 = Σ(전대 사기 × 전대 코스트) / Σ(전대 코스트)  −  사건 누적
```

- 퇴각·항복·파괴된 전대는 사기 0으로 계산한다 [제안값].
- 사건 감소량 [제안값, 정본 `combat.md` §1.3의 E 표를 ×100]: 전대 붕괴 500bp, 화공 피격 2500bp, 위장 항복 피격 4000bp, 기함 진입 허용 4000bp, 일기토 패배(장수 사망·포로) 4000bp, 매복 피격 1500bp.
- **군 사기가 3000bp 미만이 되면 남은 전대가 모두 퇴각 상태가 된다** [제안값. 전대의 퇴각 임계와 같은 값].
- 연합(유비 + 손권)의 군 사기는 따로 계산하고, 승패는 연합 단위로 판정한다(§4.12).

**보급함의 사기 유지 [정본 `combat.md` §1.3]:** 보급함 비율이 10% 이상이면 결착 국면의 사기 감소를 ×0.6으로 줄인다.

- 지휘관의 통솔이 새 진형의 요구 통솔에 못 미치면 전환 시간이 **60초**가 된다.

### 4.8 무기, 탄약, 열 [세션 Q15·Q21]

커맨드 포인트는 없앤다. 제한은 무기 자체의 자원이 한다.

**무장 [정본 `ship-specs.md` §2.4]**

| 무장 | 사거리 | 탄약 | 비고 |
|---|---|---|---|
| 주포 광선포 | 4광초 | 무한 | 열 축적. 연속 3국면 사격 시 출력 −30% |
| 장포신 광선포 | 6광초 | 무한 | 포격함 전용. 명중률 낮음 |
| 부포 광선포 | 1.5광초 | 무한 | 근거리, 대소형기 |
| 근접 방어 | 0.3광초 | 무한 | 미사일·함재기 요격 |
| 미사일 | 12광초 | 유한 | 유일한 소모품 |
| 관통탄 | 6광초 | 유한 | 공성함 전용 |

광자 어뢰와 기뢰는 기술 해금 대상이라 첫 버전에서 뺀다 [제안값].

**배분 [정본 `demo-rc-g4-05`]**

- 전대마다 가용 무기의 사용 비율을 합계 100%로 정한다. 프리셋을 제공한다: 균형, 근거리 집중, 장거리 집중, 함재기 집중.
- 사거리 밖이거나 탄약이 없는 무기는 0%로 잠긴다.
- "공격 보류"는 비율 0%가 아니라 별도 명령이다.

**실시간 환산 [세션 Q19, 제안값]**

- 정본의 무기 범주별 명중률과 피해(요격 8000bp/70, 전열 사격 7000bp/100, 포격 6500bp/140, 어뢰 6000bp/180, `demo-rc-g8-00`)는 1턴 1회 사격 기준이다. **각 범주가 60초에 한 번 일제사격한다**고 두면 기대값이 정본과 같다.
- 화면이 60초에 한 번만 번쩍이면 밋밋하다. 표현 계층은 한 번의 일제사격을 여러 발의 빔과 미사일로 나눠 보여 주되, 코어의 판정은 60초 주기 한 번으로 둔다. 전대마다 주기의 시작 틱을 전대 ID에서 유도해 엇갈리게 한다.
- 주포의 열: "연속 3국면 사격 시 −30%"를 "연속 180초 사격 시 −30%, 60초 사격 중지로 회복"으로 옮긴다.
- **미사일 탑재량은 두 정본이 다른 단위를 쓴다.** `ship-specs.md` §4는 전 함종이 "대회전 4회분"을 싣는다고 적는다(전열함 48발, 포격함 160발, 강습모함 24발, 공성함 관통탄 80발). 이 단위로는 한 전투 안에서 탄이 떨어지지 않는다. 반면 최신 데모 계약은 전투 중 탄약·에너지·열을 제한 자원으로 소비한다(`demo-rc-g4-06`, 읽지 않음). 실시간 코어는 **전투 안에서 탄이 떨어질 수 있는 최신 데모 계약의 수치**를 본편 `data/`에서 가져온다 [제안값]. 캠페인과 합칠 때 "4회분"과의 환산을 정한다.
- 미사일이 소진되면 포화 거리대 계수가 절반이 된다(포격함 1.8 → 0.9) [정본 `ship-specs.md` §4.2]. 잔탄이 적으면 경고 알림을 낸다.

**함재기:** 강습모함의 탑재 수가 제한이다. POC의 함재기 무리(스웜) 표현을 유지한다. 근접 방어와 요격함이 함재기와 미사일을 요격한다. 요격 수치는 본편 `data/`에서 확인한다.

### 4.9 탐지와 전쟁 안개 [세션 Q15, 정본 `demo-rc-g5-01`·`g5-02`]

- 접촉 상태는 넷이다: 미탐지, 확인, 추정, 상실.
- **미탐지 적은 어디에도 나타나지 않는다.** 전장, 레이더, 태그, 로그 모두.
- **확인** 접촉도 정확한 함종·척 수·선체·사기는 공개하지 않는다. 관측 구간(예: "경미한 손상", "동요")만 보여 준다.
- **추정** 접촉은 마지막 확인 위치, 경과 시간, 신뢰도, 오차 반경만 보여 준다. 화면에는 점선 원과 "실제 좌표 아님"으로 표시한다.
- 추정 접촉에는 추정 사격을 할 수 있다. 명중률에 신뢰도를 곱한다.
- 탐지는 플레이어 명령이 아니라 코어의 자동 판정이다. 함종별 센서, 전자전, 진형, 지휘관의 지력, 거리, 지형이 영향을 준다.
- 접촉 수명 [제안값]: 정본의 "3턴까지 상실 접촉 유지"를 180초로 옮긴다.
- **AI도 같은 안개 속에서 싸운다.** 적 AI와 위임 AI는 자기 진영의 공개 투영만 입력으로 받는다 [정본 `ai-design.md` §1.3, `demo-rc-g5-05`].
- 탐지 수식과 임계값은 본편 코어와 `data/`에 있다. 문서에는 수식이 없으므로 본편 코드에서 가져온다.

### 4.10 지형 [세션 Q15, 정본 `demo-rc-g5-03`·`combat.md` §4.2]

- 전장 지형: 성운, 잔해 지대, 행성 그림자. 이동 비용, 탐지, 은폐, 무기 사거리와 사격각에 영향을 준다.
- 임시 위험 지대: 연쇄 폭발 뒤에 생긴다(§4.11).
- 전략 지형 보정 [정본 `combat.md` §4.2]: 회랑은 포격함 +60%, 강습모함 −40%, 전개 수 제한. 고속항로는 결착의 추격 전과 +40%. 기저 항로는 매복 성공률 +50%.
- 색만으로 구분하지 않는다. 윤곽선과 이름을 함께 표시한다 [정본].
- 적벽 전장의 지형 배치는 본편 `data/`의 적벽 설정에서 가져온다.

### 4.11 계략과 강습 [세션 Q15]

**연쇄 폭발 작전 (화공의 SF판) [정본 `demo-rc-requirements-interview.md` §8, `demo-rc-g5-06`, `demo-rc-g8-00`]**

- 발동 조건 다섯: 폭발정 전대 생존, 조조군 밀집 진형, 목표 탐지, 지정 사거리 진입, 태양풍·성운 흐름 확보.
- 조건이 모두 충족되고 플레이어가 직접 선택하면 **확률 판정 없이 성공한다.**
- 상태: 대기 → 예약 → (방해됨 | 발동). 예약 뒤 발동 시점에 조건을 다시 검사한다. 방해되면 조건을 다시 갖춰 재시도할 수 있다. 발동되면 취소할 수 없다.
- 효과: 대상 최대 선체의 40% 피해, 센서 −40%(정본 2턴 → **120초**), 임시 위험 지대(이동 비용 ×1.5, 관측 센서 −15%, 은폐 +8, 무기 사거리 ×0.85, 사격각 −10°), 사기 −3500bp.
- 위험 지대의 크기는 정본에서 160×160(본편 전장 1600×900 기준)이다. POC 전장으로 옮길 때 축척을 맞춘다.
- 즉시 승리가 아니다. 효과를 적용한 뒤 일반 승패 조건으로 판정한다.
- 조조 AI는 발동 전에 진형 분산, 폭발정 요격, 탐지 교란, 거리 이탈로 조건 성립을 방해할 수 있다.

**그 밖의 계략 [정본 `combat.md` §5.1]:** 매복(접적), 교란(접적·포화), 위장 항복(포화·교전, 황개 전용), 유인(교전·결착). 판정식은 `combat.md` §5.3~§5.5에 있다. 첫 버전은 연쇄 폭발 작전을 먼저 넣고, 나머지는 같은 틀(조건 → 예약 → 발동)로 차례로 더한다 [제안값].

**강습 [정본 `combat.md` §6]**

- 전제: 아군 강습모함 보유, 거리 1광초 이내.
- 적 진형 붕괴도가 임계를 넘으면 **전면 강습**(기함 진입 포함), 못 넘으면 **제한 강습**(부대 강습, 에이스 단기만).
- 무력형 인물이 편성되어 있으면 교전 거리대에서 적 진형 붕괴도가 빨리 쌓인다: 강습형 1인 +20%, 강습형과 파일럿형 +35%, 특급 무력 인물 +50%.
- **강행 돌입:** 진형이 열리지 않아도 시도할 수 있다. 성공률은 통상의 1/3, 실패하면 강습 부대 대량 손실과 아군 사기 −30.
- 강습 유형: 부대 강습(성공 시 적 함선 나포, 사기 −15), 기함 진입(호위 판정 뒤 무력 대결, 성공 시 사기 −40과 지휘 보정 전면 소멸), 에이스 단기(사기 −20), 호위 요격(적 강습 무효화).
- 호위 돌파율은 침입 측 무력에서 방어 측 호위 인물의 무력 보정, 기함 호위 전대 규모, 전열함 잔존 비율을 뺀 값이다. 전열함이 남아 있을수록 기함이 안전하다.
- 위 사기 수치는 게이지(0~125) 기준이다. bp로는 ×100 한다 [제안값 P7].
- "진형 붕괴도"는 `combat.md`의 개념이고 데모 계약에는 없다. 실시간 코어에서는 **전대 사기 상태가 동요 이하이거나 진형 전환 중이면 임계 초과로 본다** [제안값].
- 기함 진입과 에이스 단기는 기동병기 설계가 본편에서 보류 상태다(V-58·V-59). 첫 버전은 **부대 강습과 기함 진입**까지 넣고, 에이스 단기와 일기토 연출은 후속으로 둔다 [제안값].

**성향은 성공률이 아니라 선택에 걸린다 [정본 `combat.md` §5.6]:** 지휘관 AI가 어떤 계략을 고르는지에 성향이 반영되고, 성공 여부에는 반영되지 않는다.

### 4.12 승패

**전투가 끝나는 경로 [세션 Q3·Q19, 정본 `demo-rc-requirements-interview.md` §10, `demo-rc-g8-01`~`03`]**

| 조건 | 결과 |

| 유비 기함 격침 | 즉시 연합 패배 |
| 조조 기함 격침 | 남은 조조군과 관계없이 연합 승리 |
| 조조 기함이 조조군 탈출 지점에 도달 | 연합 승리 |
| 유비 기함과 필수 전대가 연합 탈출 지점에 도달 | 연합 제한적 승리 |
| 유비군이 시작 코스트의 70% 이상 손실, 또는 전 전대 항복 | 연합 패배 |
| 연합(유비 + 손권) 결합 코스트의 70% 이상 손실 | 연합 패배 |
| 조조군이 시작 코스트의 70% 이상 손실, 또는 전 전대 항복 | 연합 승리 |
| 군 사기가 3000bp 미만 [제안값] | 그 진영의 남은 전대가 모두 퇴각. 이후 위 조건으로 종결 |
| 전투 시계 20분 경과 | 시작 대비 잔존 코스트 비율이 높은 쪽 승리 |

- 손권군만 무너져도 유비군이 버티면 전투는 계속된다 [정본].
- 같은 틱에 양쪽 조건이 함께 성립하면 조조군 승리, 20분 비교에서 동률이어도 조조군 승리 [정본].
- 퇴각은 버튼이 아니다. 탈출 지점까지 실제로 이동해야 성공한다 [정본]. "후퇴" 명령은 탈출 지점으로의 이동 명령을 만든다.
- 승패 판정은 매 틱이 아니라 **매 초**(10틱마다) 한다 [제안값].

**시간 [세션 Q19]**

- 소전투는 접적·교전·결착, 중전투는 접적·포화·교전·결착만 쓴다 [정본]. 실시간에서는 "시작 거리를 가깝게 둔다"로 옮긴다 [제안값].

### 4.13 보급과 수리 [세션 Q25, 정본 `demo-rc-requirements-interview.md` §3·§7]

- `combat.md`·`ship-specs.md` §4.3은 "페이즈 사이 재보급 불가, 전투 중 긴급 보급 1회"였다. 최신 데모 계약이 자동 보급 영역으로 대체했으므로 아래는 데모 계약을 따른다.
- 정상 작동하는 보급함을 가진 전대는 자기 위치를 중심으로 **이동식 자동 보급 영역**을 만든다.
- 영역의 반경은 보급함 수와 관계없이 일정하다. 보급함이 많을수록 처리량이 늘어난다.
- 영역 안에 60초 머물면 탄약이 보충된다. 중간에 벗어나면 완료되지 않는다.
- 요청이 처리 한도를 넘으면 남은 탄약이 적은 전대, 먼저 들어온 전대, 전대 ID 순으로 처리한다 [정본의 연료 기준을 탄약으로 옮김, 제안값].
- 보급은 모든 진영에서 사람의 개입 없이 자동으로 처리한다 [정본].
- 보급함의 물자도 유한하다. 전대 단위로 합산하고, 보급함이 파괴되면 그 비율만큼 잃는다 [정본].
- 보급함은 물자를 써서 생존 함선을 수리한다. 격침된 함선은 전투 중 복구하지 않는다 [정본].
- 수리 대상 [제안값]: 경파는 시간이 지우고, 중파는 보급 영역 안에서 수리된다. 대파는 전투 중 수리하지 않는다. 정본의 도크 소요(중파 20분, 대파 60분)는 캠페인 시간 기준이라 전투 안에서는 중파만 다룬다.

### 4.14 지휘 승계 [세션 Q25, 정본 `demo-rc-requirements-interview.md` §3]

- 함대 지휘관이 전사·중상·포로로 지휘 불능이 되면 부함장이 승계한다.
- 부함장이 없으면 소속 전대 지휘관 가운데 레벨이 가장 높은 인물이, 같으면 지휘 능력치가 높은 인물이 승계한다. 그 전대가 새 기함 전대가 된다.
- 승계 뒤 **60초 동안 명령 혼선**: 기동력, 명중률, 진형 전환 속도가 결정론적으로 떨어진다. 무작위 명령 실패는 없다.
- 승계 즉시 새 지휘관의 지휘 한도로 코스트를 다시 계산한다. 초과하면 초과 불이익이 혼선과 겹친다.
- 장수의 부상·전사·포로는 기함 피격, 전대 격파, 퇴각 실패에 따라 조건으로 결정한다. 확률이 아니다 [정본]. 구체 조건은 본편에서도 미결(`G8-04` 경계)이므로 본편의 결정을 기다리거나 제안값을 따로 낸다.
- **유비 기함 격침은 승계가 아니라 즉시 패배다**(§4.12).

### 4.15 기동 명령 [세션 Q25, 정본 `legend-vii-red-cliffs-application-review` §5]

| 명령 | 뜻 |
|---|---|
| 이동 | 목적지까지 가고 도착 방향을 지정한다. 경유점 1~5개 [정본 `demo-rc-g4-02`] |
| 제자리 선회 | 위치는 그대로, 방향만 바꾼다 |
| 평행 이동 | 방향을 유지한 채 옆이나 뒤로 움직인다 |
| 정지 | 위치와 방향 유지 |
| 공격 | 탐지된 적을 표적으로 지정. 사거리까지 접근 |
| 추정 사격 | 추정 접촉의 마지막 확인 위치에 사격 |
| 공격 보류 / 사격 재개 | 사격만 멈춘다. 정지와 별개 |
| 후퇴 | 탈출 지점으로 이동 |
| 집결 | 기함 주위로 이동 (POC 유지) |

- 선회 속도와 평행 이동 속도는 정본에 수치가 없다. VII 검토는 "VII의 50% 속도를 복사하지 말고 기동·요격·사격각을 함께 측정하라"고 적었다. 초기값 [제안값]: 평행 이동은 전진 속도의 60%, 제자리 선회는 180° 회전에 20초.
- 선회와 평행 이동이 생기면 §4.4의 노출 방향을 플레이어가 직접 관리할 수 있다. 이번 설계에서 방향이 갖는 무게가 커진 만큼 꼭 필요하다.

## 5. 지휘 체계

### 5.1 한 체계, 세 가지 쓰임

직접 지휘, 위임, 자동 해결, 적 AI가 모두 같은 지휘관 AI를 쓴다 [정본 `ai-design.md` §7.1, 세션 Q2·Q7·Q20]. 차이는 플레이어가 명령을 덮어쓰는가뿐이다.

```
전대의 다음 행동 = 플레이어의 직접 명령이 있으면 그것
                 없으면 지휘관 AI가 (전투 방침, 성향, 특성, 공개 투영)으로 고른 것
```

### 5.2 전투 방침 [정본 `combat.md` §2.3]

| 방침 | 행동 |
|---|---|
| 적극 | 거리 압축, 돌파, 추격 우선. 전과 최대, 손실 큼 |
| 균형 | 표준 |
| 신중 | 원거리 유지, 방어, 질서 퇴각 우선. 손실 최소 |
| 계략 중시 | 화공, 매복, 교란 우선. 지력형 지휘관에 유리 |
| 인물 위임 (기본값) | 지휘관의 성향과 특성에 따라 자동 |

**인물 위임의 성향 대응 [정본 `dispositions.md` §7.1, `ai-design.md` §7.2]**

| 성향 | 방침 | 선호 |
|---|---|---|
| 절의 | 신중 | 종심 방어, 질서 퇴각 |
| 명사 | 균형 | 표준 |
| 실무 | 균형 | 손실률 임계를 넘으면 퇴각 |
| 야심 | 적극 | 중앙 돌파, 전면 추격 |
| 무뢰 | 적극 | 기함 직격, 전면 추격 |

**전황 반응 [정본 `ai-design.md` §7.3]:** 아군 사기 40 미만이면 방어·퇴각 가중 +0.3, 적 사기 40 미만이면 공세·추격 가중 +0.3, 계략 조건 충족이면 해당 계략 +0.4, 지휘관 특성 조건이면 해당 국면 +0.5. 사기 40은 게이지 기준이므로 4000bp로 옮긴다.

### 5.3 지휘관 AI가 정하는 것 [제안값]

방침은 아래 결정의 가중치를 바꾼다.

- 목표 거리대: 어느 거리에서 싸울 것인가 (포격함 중심이면 포화 거리 유지 등)
- 표적 선택: 가장 가까운 적, 약해진 적, 측면이 열린 적
- 방향 관리: 정면을 적에게 유지, 선회와 평행 이동 사용
- 진형 선택과 전환 시점
- 무기 배분 프리셋
- 퇴각 판단
- 계략 예약

### 5.4 직접 명령과 위임 전환 [세션 Q20·Q27]

- 모든 전대는 기본이 위임이다. 유비군도 손권군도 같다.
- 플레이어가 전대에 직접 명령을 내리면 그 전대는 **직접 지휘** 상태가 된다. 직접 지휘 중에는 AI가 이동과 표적을 바꾸지 않는다.
- "위임으로 돌리기"로 AI에게 다시 맡긴다.
- 직접 지휘 중에도 자동으로 유지되는 것 [제안값]: 사거리 안의 적에 대한 사격(공격 보류가 아니면), 보급, 퇴각 임계에서의 강제 퇴각.
- "전 전대 수동" 설정을 켜면 모든 아군 전대가 직접 지휘로 시작한다 [정본 `combat.md` §2.2 ④의 수동 전환].
- 조조군은 항상 AI다.

### 5.5 부재와 자동 해결 [세션 Q2, 정본 `combat.md` §2.2·§8.1]

| 규모 | 개입 | 길이 목표 |
|---|---|---|
| 소전투 (전대~함대) | 0회. 결과만 통보 | 3~5분 |
| 중전투 (복수 함대) | 0~1회 | 8~15분 |
| 대회전 (방면군 이상) | 1~2회. 수동 전환 시 더 많이 | 15~30분 |

- 전투가 발생하면 알림을 보낸다.
- 중요 분기에서 **최대 10분** 응답을 기다린다. 응답이 없으면 위임으로 처리한다.
- 알림을 보내는 분기 [정본 `combat.md` §2.2 ①]: 계략 기회 개방, 사기 붕괴 위험 진입(아군 또는 적), 일기토 발생 가능, 추격 여부 결정, 예상 외 전개(계략 피격, 지휘관 부상).
- 자동 해결은 화면 없이 틱을 끝까지 돌린다. 결과는 복귀 브리핑에서 재생으로 본다.
- **단기판의 "부재"는 앱 안에서 다른 화면을 보고 있는 경우다.** 단기판은 앱을 끄면 세계가 멈추는 세션 내 연속 시뮬레이션이다 [정본 `DECISIONS.md` V-25]. 앱 밖에서 시간이 흐르는 모델은 장기 목표에서 돌아온다.
- 자동 해결의 실제 계산 시간과 캠페인 시간의 관계(대회전 판정 15~30분)는 본편 캠페인과 합칠 때 정한다.

## 6. 다섯 국면의 화면 흐름 [세션 Q4]

### 6.1 접촉: 배치 단계

전투 시작 전의 별도 단계다. 시간이 흐르지 않는다.

- 바탕은 본편의 전투 준비 화면이다 [정본 `demo-rc-g2-01`, `demo-rc-g3-01`]. 역사 편성 복원, 사용자 편성, 전투 시작을 제공한다.
- 이 단계에서 정하는 것 [제안값]: 전대별 진형, 전대별 전투 방침, 무기 배분 프리셋, 허용 구역 안에서의 초기 위치와 방향, 전대를 함대로 묶기(그룹 탭).
- 편성(함종 구성, 지휘관 배치)은 정본처럼 준비 화면에서 고칠 수 있다. 캠페인과 합친 뒤에는 캠페인의 편성 결과를 받는다.
- 보이는 것: 탐지 범위 안의 적만. 접적 거리 밖의 적은 보이지 않는다.
- 자동 해결에서는 이 단계를 AI가 즉시 처리한다.
- POC에는 없는 새 화면이다.

### 6.2 포화, 교전, 강습: 실시간

- 거리에 따라 자연히 넘어가고, 화면 상단에 현재 국면을 표시한다.
- 타이머로 강제하지 않는다. 거리를 벌리면 포화로 되돌아갈 수 있다 [세션 Q27].
- 국면이 바뀔 때 짧은 표시와 로그 한 줄을 낸다.

### 6.3 결산

전투 종료 조건(§4.12)이 성립하면 들어간다.

- **추격 선택 [정본 `combat.md` §2.2·§7.2-b]:** 전면 추격, 제한 추격, 전열 재편, 질서 퇴각.
- **패주 손실 [정본]:** `붕괴 시점 잔존 함선 × (15% + 추격 계수)`. 제한 추격 +10%p, 전면 추격 +25%p(고속항로에서 ×1.4). 추격하는 쪽은 유인 계략에 취약해진다.
- **대파 함선의 회수 [정본 `ship-specs.md` §3.7.7]:** 결정적 승리와 우세는 자군 대파 전량 회수와 적 대파 나포, 근소 우세와 무승부는 절반 회수, 패주는 0(전량 격침 처리).
- **패주 손실의 추출 순서 [정본]:** 중파 → 경파 → 무손상. 도망칠 때는 깨진 배부터 뒤처진다.
- 승리의 등급 [정본 `combat.md` §7.1-b]: 종료 시 사기 격차 60 이상은 결정적 승리, 30~59는 우세, 10~29는 근소 우세, 10 미만은 무승부. 군 사기의 격차(bp ÷ 100)로 판정한다 [제안값].
- **결과 화면 [정본 `demo-rc-requirements-interview.md` §15]:** 승리 조건과 판정 우선순위, 양측 함선 손실과 잔존 코스트, 생존·부상·전사·포로 장수, 사용한 특수 전술과 주요 기록, 유비군 결과와 연합 판정의 구분, 전투 결과·결착 시점 판세·후일담의 구분.
- 전투 기록 다시 보기를 제공한다. 다섯 국면을 장(章)으로 쓴다.
- 문구는 사관 서술의 어조를 따른다 [정본 `05-narrative/prologue.md`의 집필 지침. 읽지 못했다].

## 7. 화면과 조작

### 7.1 화면 배치 [세션 Q18]

POC의 배치를 따른다. 위치는 그대로 두고 내용을 바꾼다.

| 자리 | POC | 변경 |
|---|---|---|
| 전장 | 3D 원근 카메라(피치 68°), 성운 배경 | 유지. 지형 구역과 탈출 지점 표시 추가 |
| 상단 중앙 | CP 바 | **군 사기(아군·연합 / 적) + 현재 국면 + 전투 시계** [세션 Q21] |
| 좌측 상단 | 로그 | 유지. 국면 전환, 접촉 변화, 알림 분기를 추가 |
| 좌측 하단 | 원형 레이더 | 유지. **미탐지 적은 표시하지 않고**, 추정 접촉은 다른 기호로 |
| 하단 중앙 | 지휘관 초상 정보 패널 | 유지. **함종 7종의 현재 척 수, 손상 단계, 사기 상태와 다음 위험 단계, 탄약, 열, 지휘 상태(직접/위임)** 추가 |
| 우측 하단 | 명령 패널 8칸 | **탭 3개: 태세 / 진형 / 무장** [세션 Q22] |
| 명령 패널 위 | 그룹 탭 I~IV | 유지. **함대 편성**으로 쓴다. 전투 중 편입·제외는 지휘 범위 안에서 |
| 전대 위 | 초상·레벨·병력 바 태그 | 아군: 유지 + **사기 표시, 소유 글리프, 직접/위임 표시**. 적: **관측 구간만** |
| 선택 표시 | 보호막 돔 | 유지 |
| 우측 상단 | 2배속, 일시정지 | 유지 + 감속 상태 표시 |

**명령 패널의 탭 [세션 Q22, 내용은 제안값]**

| 탭 | 내용 |
|---|---|
| 태세 | 전투 방침 5종, 정지, 후퇴, 집결, 위임으로 돌리기 |
| 진형 | 진형 7종. 지형과 통솔로 못 쓰는 진형은 이유와 함께 비활성. 전환 중이면 남은 시간 |
| 무장 | 배분 프리셋 4종, 공격 보류 / 사격 재개, 미사일 일제사격, 함재기 발진, 연쇄 폭발 작전(조건 충족 시) |

- POC의 "전 함대 돌격"은 CP가 없어지면서 사라진다. 대신 태세 탭의 "적극" 방침과 강습 거리대의 계수가 그 역할을 한다 [제안값].
- 이동, 공격, 선회, 평행 이동은 버튼이 아니라 전장에서의 끌기 동작으로 한다(§7.2).

**표현 규칙 [정본 `demo-rc-04`, `preproduction-ship3d-procurement.md` §2.1]**

- 색만으로 상태나 진영을 구분하지 않는다. 아이콘, 문자, 형태를 함께 쓴다.
- 진영 구분의 우선순위: 소유 글리프(● 아군 / ○ 타 세력 / ◌ 중립) + 세력명, 문장 데칼, 도장 패턴, 색.
- 동맹(손권군)은 아군과 다른 글리프와 세력명으로 구분한다.

### 7.2 조작 [세션 Q7·Q13·Q26]

모든 명령이 터치만으로 가능해야 한다. 마우스는 같은 동작의 다른 입력이다.

| 동작 | 터치 | 마우스 (PC 보조) |
|---|---|---|
| 전대 선택 | 탭 | 왼쪽 클릭 |
| 여러 전대 선택 | 전대를 차례로 탭, 또는 그룹 탭 | Shift + 클릭, 빈 곳 왼쪽 드래그로 범위 선택, 숫자 키 |
| 이동 | **전대에서 끌어 빈 곳에 놓기** | 같음, 또는 우클릭 |
| 공격 | **전대에서 끌어 적에 놓기** | 같음, 또는 적 우클릭 |
| 도착 방향 지정 | 놓기 전에 손가락을 머문 채 돌리기 [제안값] | 놓기 전에 휠 또는 드래그 |
| 경유점 추가 | 이동 중인 전대에서 다시 끌기 [제안값] | Shift + 우클릭 |
| 제자리 선회 | 선택 전대의 방향 손잡이를 끌기 [제안값] | 같음 |
| 평행 이동 | 방향 고정 토글을 켠 채 이동 [제안값] | Alt + 이동 |
| 화면 이동 | **빈 곳에서 끌기** | 우클릭 드래그, 방향키 |
| 확대·축소 | 두 손가락 | 휠 |
| 화면 점프 | 레이더 탭 | 레이더 클릭 |
| 일시정지 | 버튼 | Space |

- 끄는 동안 경로, 도착 방향, 예상 도착 시간, 도착 시점의 사거리 원을 미리 보여 준다.
- 터치 목표물의 최소 크기는 44px이다 [정본의 UI 기준].
- POC의 단축키(S/D/M/F/C/R/G/A)는 PC 보조 입력으로 남기되, 탭 구성에 맞춰 다시 배정한다.

### 7.3 시간 감속 [세션 Q7]

- 전대를 선택하거나 끌기 시작하면 전투가 감속된다. 초기값 [제안값]: **×0.2**.
- 선택을 풀거나 명령이 확정되면 원래 속도로 돌아간다.
- 설정에서 "명령 중 정지"(×0)와 "감속 없음"을 고를 수 있게 한다 [제안값].
- 속도: 정지, ×1, ×2. 자동 해결의 연출 재생에는 건너뛰기를 둔다 [정본 `demo-rc-04`의 재생·속도 변경·건너뛰기].
- 감속과 정지는 틱을 돌리는 빈도만 바꾼다. 결정론에 영향이 없다.

### 7.4 성능

- 본편의 3D 증거창은 204개 표시 개체에서 warm p95 33.3ms 이하를 목표로 통과했다(Intel Arc 130V) [정본 `s5-02`]. 204를 넘으면 편성 순서로 결정론적 표본 추출을 한다.
- POC는 전대당 28척을 그린다. 정본 적벽 편성의 전대 수와 척 수에 따라 표시 개체가 수백 개가 될 수 있다. **모바일 실기기 측정은 아직 없다.**
- 런타임 모델은 삼각형 2.5만~6만이다(POC 브리프). 모바일에서는 거리별 LOD와, 먼 거리의 `MultiMesh` 또는 임포스터 전환이 필요할 가능성이 높다. 실기기에서 재기 전에는 척 수를 늘리지 않는다.
- 렌더러는 Compatibility를 기준으로 한다(POC 현재 설정, 모바일 호환).
