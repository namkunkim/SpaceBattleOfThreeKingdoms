## 3. 정보 경계와 불간섭 테스트

**판정: 수용.**
- `CommanderAi`는 적에 대해 `sim.projection(side)`의 접촉 항목만 읽는다. `lost`는 버리고, 추정 접촉은 진영별 신뢰도 하한(4500)을 넘어야 표적이 된다. 자기 편은 `sim.st`에서 직접 읽는다(자기 정보라 정당).
- 테스트 §1: 1800초 동안 5틱마다 (1) AI가 읽은 적이 그 순간 접촉표 안, (2) 적 항목 키가 공개 목록 안, (3) 적 AI 표적이 접촉표 안. 표본 100 이상.
- 테스트 §3 불간섭: 미탐지 아군 한 전대의 위치를 셋으로 바꿔 75초 뒤 적 AI의 (표적, 이동 여부, 목적지)를 비교한다. 미탐지 두 변형은 같고, 탐지권에 넣은 변형은 다르다(양성 대조). 설계가 맞다.
- 남는 틈(낮음): 불간섭은 한 전대·75초·표준 하나만 본다. 결정 카드 추격 효과의 반경 판정이 적의 **실제 위치**를 쓴다(아래 F-4). `first_hit_tick`은 양쪽 공용인데, 맞은 쪽도 맞았다는 사실은 아니 공개 사실로 수용한다.

## 4. 마지막 위치 조준 (M6 F-1 처리)

**판정: 수용, 제안서 정리.**
- `detection.aim_pos`: 확인은 실제 위치, 추정·상실은 접촉표 위치. `salvo.damage_of`·`_pick_target`의 사거리·사격각·지형 사거리가 조준점을 쓴다. `aim_ok`가 조준점과 실제 위치 거리 ≤ `err_r`일 때만 명중을 허용한다. 신뢰도 배율은 그대로.

- 제안서 §4.9에 M7 문장이 이미 들어갔으나 그 아래 "M6 구현은 아직 실제 위치를 써서 후속 F-1" 문장이 남아 서로 어긋났다 → 이 리뷰에서 고쳤다.

## 5. 표준 규모 0.9와 `target_cost_ratio`, 측정값 타당성

**규모 0.9: 수용(잠정).** **`target_cost_ratio`: 정정.**
- `target_cost_ratio`는 코드가 읽지 않는 설명 값이다. 생성기의 실제 조조/연합 비용비는 표준 0.9에서 **1.65**(조조 804 / 연합 486, 5전대 80척)다. 1.24는 규모 0.7일 때 값이라 생성기를 1.65로 고쳤다(`make_red_cliffs_208.py`, JSON 1줄). 입문 1.09·상급·극한 2.14는 실제와 같다.
- 40~80시드 값의 내부 정합: 표준오차가 모두 √(p(1−p)/n)과 맞다(65%@80 ±5.3, 57.5%@40 ±7.8, 입문 92.9%@42 ±4.0, 상급 7.1% ±4.0, 극한 4.8% ±3.3).
- 다만 0.85(57.5%)·0.9(65%)·0.95(65%)는 2×표준오차 안이라 **서로 구분되지 않는다.** 0.9가 "최적"이라는 근거는 없고, 0.7 → 0.85 이상에서 확인 접촉 판이 22% → 98%로 뛰는 계단(조조 센서 합이 확인 임계 30을 넘음)이 효과의 대부분이다. 0.9는 계단 위에 안전하게 있는 값으로 수용한다.
- 목표와 거리(1000시드 전 잠정): 표준 조조 35%(목표 약 60%), 길이 14분(15~18분), 입문 무명령 연합 90%대(50~70%), 극한 4.8%(≤10%, 안), 상급 7%(목표 미정). 입문이 높은 이유는 위임 아군 AI가 방어를 해 주기 때문이라는 구현 판단에 동의한다. "무명령"의 뜻이 M4(아군 정지)에서 M7(위임 AI가 싸움)으로 바뀌었으므로 입문 목표는 위임 AI를 켠 상태 기준으로 다시 읽는다(`BALANCE-PLAN-M4.md` 메모 추가 후보, 1000시드 뒤 판단).
- 레버 순서는 메모 §5-1 후보(조조 시작 사기, `range_band_hold`, 위임 `engage_trigger_r`)에 F-1·F-2 반영을 먼저 넣는다. 성향 정정이 조조군 행동을 바꾸기 때문이다.

## 6. 결정 카드 2종과 직접/위임

**결정 카드: 수용.** 제안서 §5.5와 맞다.
- 예고 3초 → 열림 → `decide` 응답 또는 게임 30초 뒤 추천안("위임 처리", `by = delegate`). `time_left`는 게임 초. 열리기 전 응답 거부(`decision_not_open`), 없는 카드·틀린 선택지 거부. 코어는 멈추지 않고 정지·×0.2는 호스트 몫(§5.5와 일치).
- `morale_crisis`(연합 군 사기 < 위기 4500, 회복 +500에 재무장, 추천 방어)와 `pursuit`(확인 접촉인 조조 전대가 퇴각, 추천은 군 사기 6000 이상이면 추격). 알림 분기 "사기 붕괴 위험", "추격 여부"에 해당. 추격 카드가 확인 접촉만 묻는 것은 정보 경계에 맞다.
- 효과는 위임 전대에만 일시 가중(±0.5, 120초/60초)과 추격 표적. 직접 지휘 전대는 받지 않는다(§5.4와 일치).
- 작은 것: 추격 카드의 반경 500 판정이 응답 시점의 적 실제 위치를 쓴다(F-4). 나중 카드가 앞 카드의 가중을 덮어쓴다(위기 "방어" 중에 추격 "유지"가 오면 가중 0) → F-5.

**직접/위임: 수용.** §5.4와 맞다.
- 플레이어 명령(정지·이동·공격·돌격·퇴각·집결·진형·복구·방어·미사일·함재기·일제)은 그 전대를 `direct`로 바꾸고, AI 명령은 `apply()`를 바로 불러 바꾸지 않는다. `delegate`로 되돌리고, `posture`는 지배를 바꾸지 않는다. "전 전대 수동" 있음. 조조군은 항상 AI.
- 무기 설정(미사일·함재기·일제)도 직접 지휘로 바꾸는 것은 "플레이어가 명령하면"의 넓은 해석이다. 수용하되 UI(M10)가 직접 지휘 전환을 분명히 보여 줘야 한다(F-7).

**전황 반응: 수용, 편차 기록.**
- 제안서 §5.2는 "아군 사기가 동요 구간(6000 미만)"이면 방어 +0.3이다. 구현은 진영 군 사기가 위기 임계(4500) 아래일 때다. 임계가 낮아 반응이 늦다. 제안값끼리라 1000시드 레버 목록에 넣는다(F-6).
- "적 사기 동요 관측 → +0.3"을 전력 구간 ≤ 2로 대신한 것은 수용(적 사기는 투영에 없다).
- 메모는 "연합 군 사기 위기"라 썼으나 코드는 자기 진영 군 사기다(조조 AI는 조조군 위기에 반응). 코드가 맞다.
