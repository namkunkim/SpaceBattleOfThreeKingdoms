## M2b: 본편 기준 데이터 스냅숏 (처리함)

- `tools/scenario/sync_base_data.py`가 본편 `data/`의 `ship-types.json`, `formations.json`, `red-cliffs-demo-setup.json`, `red-cliffs-*-rules.json` 14종을 `data/scenarios/base/`로 **복사만** 한다(값 수정 없음). 출처 커밋과 파일 해시는 `MANIFEST.json`에 남는다.
- 구현 세션은 M3에서 `data/scenarios/base/`를 읽어 프로필에 반영한다. 코어가 직접 읽을지 `data/profiles/`로 변환할지는 구현 세션이 정한다. 본편과 다르게 쓰는 값(세션 결정 Q번호)은 JSON을 고치지 말고 `rule_overrides`나 프로필에서 덮는다.
- `characters.json`(약 190KB)은 복사하지 않는다. 시나리오 JSON이 지휘관 능력치를 이미 담고 있고, 생성기만 본편을 직접 읽는다. 코어가 장수 전체 목록이 필요해지면(M6 탐지 보너스) 그때 알려 달라.
- 본편이 데이터를 바꾸면 스크립트를 다시 돌리고 `MANIFEST.json`의 해시 차이를 본다. 차이는 `UPSTREAM-ISSUES.md`에 적는다.
