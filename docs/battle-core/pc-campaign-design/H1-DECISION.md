2026-10-25 / **방향 선택 2항 기록 완료·세부 정책은 OPEN**.

기록자: D03 소유 실행자. 근거: 조율자가 전달한 사용자의 H1 명시 선택, [작업 분해](../PC-CAMPAIGN-WORK-BREAKDOWN-20261025.md) §4 H1·수용본 계약, [플레이북](../../../워크플로우-플레이북.md)의 0/5/6단계. 계획에 H1 전용 경로가 없어 이 파일을 **H1 사용자 결정의 단일 기록 원본**으로 사용한다. D03 최신 섹션은 요약이다.

## 3. 선행 검토·다음 설계 인계

[REVIEW-D03.md](REVIEW-D03.md)·[REVIEW-D04.md](REVIEW-D04.md)는 evidence_audit가 작성한 **독립 문서 수용**이다. 파일 원문을 확인했다. 두 검토의 ‘H1 대기’ 중 이번 시간/지형 방향 두 항목만 위 선택으로 갱신된다. D04/O07 판단은 대기 상태다. 본 기록자가 검토 판정을 대신하거나 게임 검증 수용으로 확대하지 않는다.

D05/D06에는 이 파일 전체, [D03 계약](D03-SPACE-TIME.md) 최신 §9, [D04 상태 계약](D04-STATE.md), H0 및 두 독립 리뷰를 전달한다. 임무/정보·점령/사기 설계는 **효과 지형으로 작전 기본을 먼저 확인하고 이후 본체 차폐를 비교할 구조**를 고려한다. 차폐 후보와 연결 슬롯은 계속 설계하되 아직 물리 차폐가 구현돼 있다고 전제하지 않는다. 시간 사건은 단일 게임 논리 시계에서 구동하고 실제 측정 로그는 게임 판정 입력과 분리한다. 저장/동일 틱/회복/종료 정책은 해당 소유자에게 open으로 남긴다.

**비승인:** 게임 코드/데이터·게임/통행/저장/1000시드/사람 플레이 테스트 실행, 브랜치 변경·병합·커밋·푸시. 이번 선택은 비교·제작 방향을 정했으며 실제 실험 실행이나 성공을 뜻하지 않는다.
