## 유지하는 미결과 검증 상태

- O04: 초기/최대 재고, 유입률·총예산, 서비스/정비 안전·중단 상세, 회복량·가격·상한·측정 범위.
- O05: 보급 완료·소유 전이·피해·배송·유입·종료의 같은 틱 순서와 사건 일정. 목표 점령/지휘 상실 동시 실패 우선 외의 순서를 임의 확정하지 않는다.
- O07: 저장 형식·원자적 커밋·호환 정책. D08의 설계 검토 진행과 실제 게임 구현 착수 게이트를 구별한다.

이번 검토는 문서·정적 코드 대조에 한정한다. **게임·AI·저장·성능·1000시드·사람 플레이 시험은 미실행**이며 미래 반례가 통과했다고 판정하지 않았다. D07 본문·공통 문서·코드·브랜치는 수정하지 않았고 본 독립 기록만 작성했다. 문서 수용은 게임 구현 또는 전체 설계의 최종 사용자 수용을 대신하지 않는다.
