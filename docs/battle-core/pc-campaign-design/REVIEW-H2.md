# H2 사용자 결정·설계 인계 기록 독립 검토

2026-10-26 / final_independent_review / **기록 수용·조건부 설계 검토 루프의 인계 마무리 가능**.

대상은 [H2-DECISION.md](H2-DECISION.md), [D10 최신 §9](D10-INTEGRATED-REVIEW.md), [체크리스트의 PC 맵·캠페인 블록](../CHECKLIST-OPEN.md)이다. 검토자는 해당 기록·D01~D10·후속 구현 스펙 작성에 참여하지 않았다. 사용자 명시 선택 3항, [플레이북](../../../워크플로우-플레이북.md), [D10 독립 판정](REVIEW-D10.md), [R18 완료 기준](../PC-CAMPAIGN-REVIEW-SPEC-20261025.md), [D10/H2 계약](../PC-CAMPAIGN-WORK-BREAKDOWN-20261025.md)을 대조했다.

## 1. 판정

실질적인 전달 오류·선택 누락·승인 확대는 발견하지 못했다. H2 기록과 요약을 수용한다. 기존 REVIEW-D10의 조건부 설계 수용, 사용자 H2 판단, 이번 기록의 독립 대조 및 0번 되먹임 기록이 모였으므로 **R18의 설계 검토 루프는 미정표를 보존한 조건부 인계로 마무리할 수 있다.** 조율자는 이 결과를 사용자에게 인계한다.

이는 후속 구현 스펙·측정 계획의 독립 검토 결과가 아니며 게임 구현·실행 시험·밸런스·성능·병합의 완료/승인이 아니다.

| 사용자 선택 | 독립 대조 결과 |
|---|---|
| H2-01 조건부 설계 수용·후속 준비 | 미정표를 유지하고 구현 스펙·측정 계획 준비만 승인한다. H2 §1/3/4와 D10 §9·체크리스트가 이를 보존하며 게임 코드·테스트·병합 승인으로 확대하지 않는다. |
| H2-02 상태+후속 명령·동일 규칙 버전 | 지원 방향만 채택한다. 커서·원자 커밋·필드·호환 검사 등 O07 상세는 남고, 관람 UI나 모든 과거 기록의 재생을 보장하지 않는다. 업데이트 뒤 옛 저장 계속 재개는 첫 범위에서 제외된다. |
| H2-03 제한 정보·필수 일정 | 자기 시설 상실 보고, 상대 마지막 확인, 적 재고 비공개, 임무 필수 일정/시한 공지를 반영한다. IP1 방향은 채택하되 갱신/투영 기술은 후속이다. |

## 2. 미정과 되먹임의 보존

- O02의 범위와 기존 H0/H1/작전·사건 선택은 유지된다. 과거 초안의 대기 문구는 선택 전 이력이며 새 원본을 전역 치환하지 않는다.
- O01/O08의 사전 측정 조건·기기·표본·제외 기준과 합격 임계, O03의 치수/진형/서비스/퇴로, O04/O05의 수치·예산·전체 동일시각 처리, O06의 최신 통합·미커밋 소유, O07의 필드·커서·원자성·호환 계약은 실제 관련 구현/시험 게이트로 남는다.
- 기존 45초/15초·증원 8/10/16/20/24분·지연 2분·생환 50%·6800×4600/이동30은 측정 전 후보다. 약20분도 게임시간 비교 가설이지 합격 판정값이 아니다.
- Q67의 적용 범위를 판단하고, 적용 시 B항+1000시드 재측정을 유지하며, 비적용 시 근거를 남기는 조건이 유지된다. 새 플레이 표본으로 이를 대체하지 않는다.
- H2 §4는 최신 결정 원본 우선, 자체검사/독립검토/사람 판단 분리, 구 실험의 일반화 방지, 저장 방향/세부 계약 구분, 도구 중단 후 실제 파일 확인과 제한된 UTF-8 복구를 다음 루프의 0번 맥락으로 남긴다. 권한·승인 거부 우회는 허용하지 않는다.

## 3. 다음 루프와 검토 범위

후속 구현 스펙·측정 계획 준비는 사용자 승인 범위다. 다만 그 문서 자체의 5-a와 작성 비참여 독립 리뷰를 별도로 거쳐야 하며, 이 기록으로 미리 수용하지 않는다. 게임 코드 작업이나 실제 시험 착수는 해당 미정과 승인 경계를 확인한 후의 별도 단계다.

이번에는 문서 전달 정확성·현재 승인 범위·인계 완결성만 검토했다. 게임·AI·UI·저장·통행·성능·1000시드·사람 플레이 시험은 실행하지 않았다. 본 독립 기록만 작성했으며 대상 본문·공통 스펙·코드·브랜치·커밋은 변경하지 않았다.
