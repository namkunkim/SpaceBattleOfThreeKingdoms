## 5. Q67 범위 대조 패킷 — R17

확정 근거: `docs/battle-core/BATTLE_DECISIONS.md:665`는 적벽 기본3구역 불변, 신규 종류 활성화 전에 **차이 목록 B항 등재+1000시드 재측정**을 요구한다. `:681`은 통과 불가가 이동·AI·화공에 영향을 준다고 지적하며 `:779`는 기존3구역 표시 우선 결정을 확인한다. `CHECKLIST-OPEN.md`의 「전장 지형·장애물」 원문(약271~273행)도 적벽 기존3구역 유지·B항 등재와 경로/화공 영향의 근거다. 일반 과거 기준선 보류 기록(같은 파일140행)을 신규 종류 활성화 게이트의 자동 면제로 해석하지 않는다.

| 제안 변경 | 기존 규칙과 맞닿는 근거 | 이번 적용 상태·필요한 후속 판정 |
|---|---|---|
| 적벽 일반 전장에 본체 장애물·무기 제한을 켬 | Q67 신규 종류, 현재 terrain/이동/탐지/화공 영향 | Q67 적용 대상으로 볼 직접 근거가 있음. 실제 범위 확정 시 B항+1000시드 유지. 이번 활성화·등재·측정은 하지 않음 |
| 별도 PC opt-in의 기존 효과3종을10구역으로 재배치 | PC configure는 기존 템플릿 재사용, 본체 false. Q67 신규 종류 문구와 ‘종류/배치’ 구분 필요 | 신규 종류와 동일하다고 단정하지 않음. 배치·축척·편성 영향은 별도 회귀/기준선 검토 대상. PC 실험15판을 Q67 1000시드 충족으로 간주하지 않음 |
| 별도 신규 작전 프로필에만 본체/특수 구역, 적벽 기본은 보존 | Q67 적벽 불변·확장 종류의 적용 범위와 공유 코어 수정 범위를 함께 대조해야 함 | **범위 밖 자동 면제 금지.** D03에서 프로필 경계·공유 코어 영향·적벽 비활성 보장을 근거로 적용/비적용 판단. 비적용이면 근거·제외 이유 기록 |
| 작전 목표·보급·사기·사건만 추가하고 지형 규칙은 그대로 | Q67은 지형 확장 규칙. 다른 회귀 위험은 별개 | 목표/사기 변경까지 Q67이 자동 적용된다고 단정하지 않음. 신규 종류 활성화 여부와 공유 규칙 영향에 따라 판정하고 별도 기능/기준선 검증은 유지 |

**인계 산출물:** 위 대조표의 변경 단위·근거·미결을 D03에 전달한다. 최종 Q67 적용 판정은 후보 범위·변경 파일을 확정한 뒤 기록해야 한다. 적용 시 B항+1000시드는 기존 확정 기준이고, O08의 새 사람 플레이 표본 미정으로 바꾸지 않는다. 비적용 사유를 기록하지 못하면 면제 결론을 낼 수 없다.
