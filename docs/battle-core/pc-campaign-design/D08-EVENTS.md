## 2. 공통 사건 상태

각 사건은 작전/사건 인스턴스ID, 정의/규칙 버전, 단계, 예정/출발/진입/도착 시각, 부대/화물/목표 참조, 완료키·취소 사유를 갖는 후보 계약이다. 검사는 `현재시각>=예정 && 미처리`이며 단계/효과는1회 적용한다. 저장 재개는 시작시각·완료키를 초기화하지 않는다.

| 단계 | 전이와 의미 |
|---|---|
| S1 예정/대기 | 정해진 일정/조건을 기다림. 플레이어 단계 완료와 별개 |
| S2 출발 | 부대/화물·경로·출발 사실 확정. 지도 밖 이동이면 아직 투입 아님 |
| S3 진입 대기/지도 진입 | R 유효 공간/조건 검사 후 생성·투입 원장에1회 등록. 막히면 대기/명시 대안, 후방 순간 생성 금지 |
| S4 이동/목표 도착 | 실제 위치·생존·허용 목표로 이동. ETA는 추정이며 강제 도착 보장 아님 |
| S5 수행/완료 | 점령은 D06, 배송 효과는 D07에 요청. 도착과 점령/배송 완료는 다름 |
| S6 중지/취소/실패 | 사유·잔여화물/예약 보존. 취소로 편성/물량/완료키 재생 금지 |

시계는 D03/D04 누적 논리시각이다. 정지는 사건도 멈추고 배속은 같은 진행을 압축한다. 바깥 tick×고정폭·벽시계 복원은 금지한다. UI·경보·대사는 사건의 허용 공개 투영 하나를 읽는다. 본대 공개 예고는 상세 편성/위치의 확인 접촉이 아니다.

## 5. 같은 시각 중재 후보와 사용자 패킷

후보: **동일 시각 사실 수집→소유/지휘/피해의 최종 사실·결과 후보→종료면 미완료 새 효과 차단→계속이면 D지연/출발/진입/임무→최종 소유epoch로 배송/유입/서비스→투영**. 실제 코드 순서가 아닌 D06/D07/O07·D10 정합화 제안이다. 서로 다른 하위 시각을 바깥 tick 하나로 뭉치지 않는다. 거래는 같은 유효 커밋을 참조하고 소유·물자를 함께 확정해야 한다.

| 패킷 | 권고·영향 | 대안·잔여 미정 |
|---|---|---|
| P1 D 경계 | 출발과 같은 논리시각에 D 가동 완료면 지연 인정, 출발 뒤 소급 없음 | 출발 우선으로 동시 완료 무효. 지연량/표시·전체 순서 미정 |

둘은 미채택 사용자 판단 후보다. 어느 안도 채택된 지휘 상실 동시 실패·명시 철수 성과만 판정을 뒤집지 않는다. 기술 정렬키마다 질문하지 않는다. O05 미결은 사건/종료 구현 스펙 확정을 막지만 대안/후속 UX 검토는 가능하다.

## 7. 자체 5-a·검토 상태

R08은 채택 목표/철수와 E07~09, R11은 E01~09·§2~5·X01~11, O05는 P1/P2·잔여 일정/편성·진입/시한/비율로 추적한다. 문서 K=3, 5-a 실패는 본 조각 재시도·초과 보고, 독립 5-b 반려는 2단계 스펙 복귀다. Q67 적용 시 B항+1000시드/비적용 근거, O06 통합 재확인·O07 저장/커밋 게이트 유지.

저장 도구 apply_patch 1회는 212초 후 중단되어 파일이 없음을 확인했다. 같은 도구를 반복하지 않고 지정 경로 일반 UTF-8 쓰기로 복구했다. 이는 승인/권한 거부 우회가 아니다. 문서 개수·링크·후보/미실행 표시는 자체5-a 후 인계하며 독립 검토는 REVIEW-D08.md가 소유한다. **게임·저장·AI·통행·성능·1000시드·사람 플레이 시험 모두 미실행**. 현재 상태는 초안·독립5-b 대기다.

자체 5-a 결과(1회): 상태6·사건9·정책패킷2·반례11, R08/R11/O05 추적 존재, 링크 누락0·행말공백0. 현행 증원 함수·하위걸음 시각 갱신도 읽기 대조했다. 게임 시험을 실행하지 않았으며 독립 검토 인계 가능하다.
