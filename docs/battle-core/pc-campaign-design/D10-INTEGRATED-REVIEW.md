# D10 PC 맵·캠페인 통합 판정·인계

2026-10-25 / **설계 검토 통합 초안·최종 독립 검토/H2 대기** / 문서 K=3.

## 1. 결론·범위·판정의 뜻

권고는 **단일 성계에서 정면/우회를 선택하고 조우·교전·점령·유한 보급을 이어가는 보급로 개방 작전**이다. 호송 차단·통신소 지연·재점령도 설계에 포함하고 제작을 나눈다. 기존 효과 지형으로 기본 흐름을 먼저 확인한 뒤 물리 장애물1~2개와 우회/엄폐를 비교한다. 약20분은 게임시간 비교 가설이며 실제 플레이·정지·배속은 별도 측정한다.

이 문서는 [플레이북](../../../워크플로우-플레이북.md), [D10 카드·공통 계약](../PC-CAMPAIGN-WORK-BREAKDOWN-20261025.md), [스펙 R01~18/O01~08](../PC-CAMPAIGN-REVIEW-SPEC-20261025.md)에 따른 설계 통합이다. D01~09 및 REVIEW-D01~09를 입력으로 삼고, 마지막 [D09 독립 수용](REVIEW-D09.md)을 확인한 뒤 작성했다. 각 리뷰의 수용은 **문서·정적 근거의 수용**이며 실제 기능 검증이 아니다.

아래 PASS는 요구하는 설계 근거·대안·반례·검증 계획이 존재한다는 통합 작성자의 자체 판정이다. OPEN은 최종 판단 또는 정량·정책이 남았다는 뜻이다. **최종 독립 5-b와 H2를 대신하지 않으며 게임 코드 구현·실험 실행·병합 승인이 아니다.** 수치/스키마/통합·정량평가의 미정 때문에 권고는 설계 결과의 조건부 인계 범위로 제한한다.

## 9. H2 최신 사용자 결정·설계 인계 (2026-10-26)

[H2 단일 결정 원본](H2-DECISION.md)에 사용자 선택 3항을 기록했다. 설계 결과는 미정표를 유지한 조건부 수용이며 후속 구현 스펙·측정 계획 준비가 승인됐다. 게임 코드·테스트·병합 승인은 아니다.

- 저장: 전체 상태+후속 명령 보존, 초기 동일 규칙 버전 재개, 관람과 실제 논리 재생 구분. 업데이트 뒤 옛 저장의 계속 재개 지원은 첫 범위에서 제외한다. O07은 지원 방향만 부분 해소하며 필드·커서·원자 커밋·호환 검사 상세는 남는다.
- 정보: 자기 시설 상실 보고·상대 마지막 확인·적 재고 비공개·필수 일정 공지 방향을 채택했다. §3/5/7의 IP1 미채택·H2 대기는 선택 전 이력이다.
- O03/O04/O05 수치·전체 동시 처리, O06 최신 코드 통합, O01/O08 사전 측정 기준은 여전히 게이트다. Q67 적용 판정 및 적용 시 B항+1000시드/비적용 근거를 유지한다.
