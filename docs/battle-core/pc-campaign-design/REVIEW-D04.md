# D04 독립 검토

2026-10-25 / evidence_audit / **문서 수용·O07/H1 사용자 판단 대기**.

대상: [D04-STATE.md](D04-STATE.md). 정확한 담당 기준은 작업 분해 D04와 검토 스펙 **R13/R14·O07**이다. H0·D01/D02 및 D03 후보와 교차 대조했다. 검토자는 대상 문서를 작성·수정하지 않았다.

| 검토 범위 | 원문 대조·판정 근거 |
|---|---|
| 현재 사실/후보 | §1의 `battle_state.gd`, `battle_rng.gd`, `battle_sim.gd`의 issue/queue/replay 및 하위걸음 코드를 읽었다. 가변 난수 상태가 없는 RNG와 사건 카운터, tick/clock 분리, 즉시 명령 적용 커서의 정적 근거가 일치한다. 설계 클래스·필드명은 구현된 것으로 주장하지 않는다. |
| R13 지속 상태 | ST01~18은 정본·ID·함대/손상/자원/사기·명령·진행 중 공격·효과/타이머·점령/재고/보급·항로·임무/접촉·호송/증원·종료/원장을 포함한다. 각 수명·소유·보존/재구성 미결이 있다. 모듈 밖 캐시와 묘비 기록, 지문 제외값의 무조건 누락 금지도 명시한다. |
| 검증 구분 | T01~T05는 연속 상태 유지/저장 왕복/재실행/명령 재생/결산·효과 1회성의 입력·비교·실패를 분리한다. 미래 진행 상태 비교까지 요구하고 기존 해시 일치를 완전 복원 증거로 과장하지 않는다. 모두 미래 검사로 표시한다. |
| O07 대안·정책 | V01~V05는 저장 전략·버전·정본 표현·원자성/복구·재생 호환의 대안과 비용을 제시한다. 권고는 후보이며 H1 선택 및 첫 게임 구현 전 게이트를 유지한다. |
| 분야 미결 | 같은 틱 통신소/출발, 최종 목표/지휘 상실/시한/철수, 재점령/배송/보급, 증원/사기 평가의 슬롯을 열되 의미와 순서는 D06/D08·O04/O05에 남긴다. |
| R14·교차 | 초기 계약→D03/D05~D08 요청→D10 충돌 색인→소유자 수정 요청 구조다. 단독 파일 소유와 DAG를 보존한다. D03의 시계·노드/항로·규칙/지형/경로 버전·실제시간 평가로그 분리는 D04와 충돌하지 않는다. |

실질 누락·정적 근거 오류·문서 간 의미 충돌은 발견하지 못했다. H0 확장 3사건은 상태 슬롯에 포함됐으나 정책값은 확정되지 않았다. **O07/H1은 사용자 판단 대기**이며 코드 통합 관련 O06, 치수/페이싱/동시 틱/정량 기준의 다른 open도 유지한다.

이번은 기초 상태 계약 문서의 독립 5-b 수용이다. **저장/재생·게임·성능·1000시드·사람 플레이는 실행하지 않았다.** 대상 본문·공통 문서·코드·브랜치를 수정하지 않았으며 게임 구현 또는 전체 설계 최종 검증 통과를 뜻하지 않는다.
