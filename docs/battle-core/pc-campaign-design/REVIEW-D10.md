# D10 최종 독립 검토

## 1. 독립 판정

실질적인 요구 누락·근거 오류·선행 사용자 선택의 무단 변경·구현 완료 오인을 발견하지 못했다. **이 문서가 제안한 조건부 설계 인계 범위에 한정하여 수용**한다. 미정이 해소된 구현 스펙 또는 게임의 실제 기능·재미·성능 수용이 아니다.

| 원래 사용자 목표 / R01~R02 | D10 §2는 임무 분리→정면/우회 이동→접촉/교전→점령/가동→유한 보급→목표 또는 철수→시간 증원을 연결한다. D02 §2~3의 단일/다중/적벽 대안과 반대 근거를 거쳐 H0 선택을 반영한다. 기존 AI의 거리 유지 등이 있다는 D01 반대 근거도 보존한다. |

## 2. 남아 있는 실제 차단

- O03: 최종 배치·치수·속도·진형/서비스/퇴로·진입 접근의 구현 범위와 측정.
- O04/O05: 재고·유입/총예산·회복량/가격·안전, 사기 집계, 편성/일정·지연량·시한·생환비율/비용 상세·지휘 승계와 미선택 전역 동시 순서. 선택된 방향과 별도로 구현 인수 계약에 필요하다.
- O06: 실제 구현 직전 최신 기준 커밋·브랜치 차이·미커밋 소유/청결·통합 가능성 재확인.
- O07: 저장 지원 방향을 선택해도 필드별 단위/정본·파생/기본값·커서·복원/지문·버전·원자 커밋 정합화는 별도다. 상태 기반 첫 게임 구현을 아직 시작할 수 없다.
- O01/O08: 실제 측정 전에 기기·표본·조건/제외규칙·가설·정량 합격 기준을 정하고 사람 플레이/성능을 확인해야 한다. 현재는 시간 비교 방향과 계획만 수용 가능하다.

이 open들은 관련 구현 스펙·시험의 확정을 막지만, 선택과 미결을 포함한 설계 결과의 조건부 인계를 자동 반려하는 사유는 아니다. Q67의 기존 게이트는 유지한다.

## 3. H2 최소 판단 패킷

1. **조건부 설계 인계:** 현재 확정한 작전과 정책, 미결표를 함께 설계 결과로 수용할지 판단한다. 권고는 수용 후 구현 스펙·측정 계획을 준비하는 것이다. 이는 코드·시험·병합 승인이나 모든 open 해소가 아니다. 보류 시 책임 D와 재검토 범위를 지정한다.
2. **저장·과거 기록 방향:** 권고는 저장 시점 상태와 이후 명령을 보존하는 방향, 초기에는 같은 규칙/스키마/시나리오/프로필 등 호환 조건만 재개, 관람과 실제 로직 재생을 별도로 취급하는 것이다. 업데이트 전 저장의 계속 재개를 약속하면 변환/옛 규칙·회귀 범위가 추가된다. 방향 선택 후에도 O07 상세는 남는다.
3. **시설 정보 방향:** 권고는 자기 시설 상실 보고, 상대/중립은 마지막 확인·관측, 실제 적 재고 비공개·필수 일정 공개다. 모든 시설 소유 상시 공개는 정찰/재점령 판단을 바꾸는 대안이다. 여기서 방향을 고를 수 있으며 구체 투영·보고 갱신은 후속 계약으로 정한다.

기술 로그 필드·정렬키·개별 수치마다 추가 질문을 만들지 않는다. H2-C를 보류해도 문서 인계는 가능하지만 해당 정보/AI 구현 정책 고정 전에는 선택이 필요하다.

## 4. 검토 실행 범위

이번은 문서·기존 정적 코드/원시 자료·선행 독립 기록을 대조한 최종 독립 5-b다. **게임·AI·UI·저장·통행·성능·1000시드·사람 플레이 시험은 모두 미실행**이다. D10 본문·공통 스펙·다른 산출물·코드·브랜치를 수정하지 않았고 본 독립 기록만 작성했다. 전체 설계의 최종 사람 수용 및 게임 구현 승인을 대신하지 않는다.
