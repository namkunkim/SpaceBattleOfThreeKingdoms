# D02 — 작전 범위·레퍼런스 대안

2026-10-25 / 4단계 설계 문서 실행 / **자체 5-a 후 독립 5-b·H0 사용자 판단 대기**.

담당: D02 작전 기획 실행자. 재시도 상한 K=3. 게임 기능은 미구현·미실행이며 이 문서는 범위 선택을 위한 대안 검토다. D01과 병렬로 작성했으므로 D01 결과·현재 코드 통합 가능성을 확정 입력으로 사용하지 않았다. 지정 산출물은 본 파일 하나다.

## 1. 범위와 근거

사용자 목표는 **함대 이동 → 조우·교전 → 항성계 행성 점령 → 보급**이 이어지고, 지연하면 적 증원이 도착하는 전략 작전이다. PC 맵 확장과 함께 판단하되 은영전 각 작전의 완전 재현·국가 경영·생산·정치·연료·신조함 생산은 첫 샘플의 필수가 아니다.

**사실:** 위 원문에 비교 대상과 제안이 기재되어 있다. S1 §2는 보급·탐지·전투 코어 기반 및 영속 상태 확장의 필요성을 보고한다. 이번 D02에서 코드를 실행하거나 최신 구현 여부를 재검증하지 않았다. 최신 기준·미커밋 변경·PC 브랜치 채택 가능성은 D01/O06의 소유다.

**가설:** 작전 중 서로 다른 항로·적 임무·유한 보급이 선택을 늘릴 것이다. 단일 연속 지도가 상태 인계 경계를 줄일 것이다. 실제 재미·제작 기간·성능 개선은 검증하지 않았다.

**결정:** 사용자는 워크플로우를 지시하고 이번 설계 실행을 승인했다. **미결:** O02의 작전 단위·첫 유형·A/B 채택, O01의 목표 시간 등. S1의 ‘첫 구현은’, S2 §7의 ‘고정한다’는 당시 작성자 권고이며 사용자 확정으로 사용하지 않는다.

용어상 조종 단위는 S4 Q5 및 Q73~Q76의 **함대**를 따른다. 아래 ‘그룹’은 여러 함대의 조작 묶음 제안이고 새로운 편제 계층이 아니다. S1의 ‘정찰 전대’ 표현을 별도 정찰 전대 신설로 읽지 않는다(S4 R5/P10). 행성 점령은 군사 통제권·시설 운용의 작전적 표현이며 실제 천문 축척 지도나 지상전 구현을 요구하지 않는다.

## 2. H0 범위 대안 3개

모든 대안은 사용자 5요소를 충족하도록 설계할 수 있지만, **화면·시간·잔존 상태의 경계**가 다르다. 새 기능이 적다는 추정과 실제 개발 공수는 구분한다.

| 비교 축 | A안: 단일 성계 연속작전 **권고** | B안: 여러 국지전 연결 | C안: 기존 적벽 전장 확장 |
|---|---|---|---|
| 첫 샘플 | 추상화된 한 성계에서 출발·거점·최종 목표·증원 접근을 연속 지휘 | 작전 지도에서 이동·조우하고 전술 전투 화면들을 연결 | 적벽의 넓힌 한 전장에 거점·항로·점령·보급 부임무 추가 |
| 이동 | 실제 기동으로 우회·회항·분견대 합류 | 작전 지도 이동과 국지 전술 이동을 별도로 정의 | 기존 전장 안의 기동. 성계 이동은 추상 거점으로 표현 |
| 조우·교전 | 접촉을 피하거나 교전·이탈 가능. 다른 구역도 동시에 진행 | 조우가 전투 진입을 촉발. 다른 전투/호송이 어떻게 진행되는지 별도 필요 | 적벽 주공과 지역 수비가 공존. 기존 전군 접근을 임무별로 수정해야 함 |
| 행성 점령 | 수비와 점령/시설 가동을 분리하고 이후 재점령 가능 | 국지전 종료 결과를 작전 지도의 소유·진행에 전달 | 기존 적벽 목표와 별도로 점령을 추가. 행성 표시는 설정 정합성 검토 필요 |
| 보급 | 같은 잔존 함대가 가동 거점으로 이동, 유한 재고 사용 | 교전 잔존 상태를 가져온 뒤 거점에서 정비. 결과 비율만 인계하면 부족 | 기존 공급 기반 활용 후보. 점령 소유 변경·유한 재고는 여전히 신규 |
| 시간 경과 증원 | 같은 작전 시계로 예정→출발→외곽 진입→목표 접근 | 전략/전술 두 시간의 환산·정지/배속과 다른 화면의 동시 사건 필요 | 기존 지연 투입과 신규 외부 증원 구별. 적벽 일정/1200초 종료와 충돌 위험 |
| 기존 기반 활용 | S1 §2의 이동·탐지·보급·전술 전투 재사용 후보 | 전투 화면·세계 지도 진입 흐름 재사용 후보. 기존 결과만으로 잔존 인계 충분하다는 근거 없음 | 기존 적벽 배치·승패·표시와 가장 가깝게 시작 가능. 이를 작전 목표로 바꾸는 비용은 별도 |
| 주요 신규 요구 | 임무 AI·점령·유한 기지·사건·작전 목표·상태 저장. 넓은 공간의 조작/가시성 | A안 기능에 더해 장면 전환·양방향 상태 인계·지도 추상화·시간 환산 | 지역 임무·거점·유한 기지·외부 증원. 기존 적벽 규칙을 유지하는 모드/프로필 경계 |

| 저장·사기·승패 | 한 인스턴스 내부 상태 지속. 지역 패퇴와 작전 종료의 분리 필요 | 국지전 사기/결과와 작전 사기/승패를 분리하고 함대 ID별 인계 필요 | 기존 적벽 사기·기함·철수·시간 종료가 새 목표를 덮지 않게 격리 필요 |
| 리스크 | 동시 임무 수·UI·공간/성능 부담. 전투 분산이 산만할 수 있음 | 저장/재생/사건 중복과 시간 불일치. 국지전 로딩으로 사실상 자동회복될 위험 | 회귀 표면과 설정 부담. 이미 끝난 적벽에 ‘작전 계속’이 부자연스러울 수 있음 |

**A안 권고 이유:** 사용자 의도의 이동과 점령 후 보급을 같은 공간에서 직접 확인할 수 있고, 후방 거점 위협을 전방 교전과 동시에 판단할 수 있다. B안의 화면 간 상태 인계와 두 시간의 변환을 첫 실험 필수에서 줄이고, C안의 적벽 결말·고정 시한과 신규 작전 목표가 경합하는 범위를 피할 수 있다. 이는 설계상 복잡도 비교이며 A안의 구현이 이미 준비됐거나 더 빠르다는 측정 결과는 아니다.

**A안에 반대할 근거:** 넓은 지도에서 현재 입력·표시·성능이 감당하지 못하거나 이동 중 판단이 없다면 연속성의 장점이 대기로 바뀐다. 큰 공간을 작은 화면에 압축하면 전술 정보가 읽히지 않을 수 있다. D01 조사나 미래 승인 실험에서 이런 문제가 확인되고, 이동 자체보다 여러 전투의 잔존 전력 운영을 우선한다면 B안이 타당하다. 사용자가 기존 적벽 개선을 최우선으로 정하면 C안을 먼저 검토할 수 있다.

**공통 경계:** 어느 안도 기존 전투 10분에 작전 20분을 더하는 목표가 아니다. 20분 전후는 O01 후보다. 게임 시각·정지 제외 실제 경과·정지 포함 총 경과·배속 체류를 구분하고 병행 활동·조기 달성을 허용한다. S2 §2의 3판·단일 정책·구편성 실험은 새 작전의 길이·난이도·원인을 입증하지 않는다. D02는 그 수치를 새 성능 기준으로 재사용하지 않는다.

## 3. 첫 샘플 후보와 기존 8유형의 대조

추천 첫 유형은 **보급로 개방**이다. 가칭 「강하 보급로 개방」·정면/우회 A/B·선택 통신소 D·호송 차단은 S1 §5~6의 후보이며 아직 지명·노드·시각·필수 기능으로 채택되지 않았다.

| 기존 유형(S1 §5) | 첫 실험에 대한 판단 | 이유·반대 사례 |
|---|---|---|
| 보급로 개방 | 첫 유형 권고 | 이동·조우·점령·보급·증원을 모두 자연스럽게 검증. 단, ‘탄약 떨어져 강제로 보급’만 남으면 선택이 약함 |
| 합류 저지 | 차선 | 적의 일정·임무와 각개 대응을 검증하기 좋음. 행성 점령·보급을 끼워 넣으면 본래 목표와 경합하므로 첫 통합 실험 적합성은 낮음 |
| 수송선단 호위 | 후속 | 움직이는 우선 목표로 전군 추격 관행을 바꾸기 좋음. 수송선 AI·생환 판정이 추가되고 행성 점령의 필요성이 약함 |
| 보급창 급습 | 축소 대안 | 짧은 임무의 출격→타격→생환을 시험하기 좋음. 파괴 후 철수가 중심이면 점령 뒤 보급을 확인하지 못함 |
| 우회 침공 | 보급로 개방의 항로 선택 참고 | 정면전 회피와 관제 목표의 의미가 큼. 우회로가 항상 안전하고 이득이면 정답 경로가 됨 |
| 원정 철수 | 후속 | 손실 지속·보급·철수에 적합. 첫 플레이부터 자원 부족을 강제하면 전투를 배우기 전 실패 가능 |
| 협로 지연 | 후속 | 적을 전멸시키지 않고 시간을 버는 행동을 검증. 시간이 지날수록 아군에 유리해 사용자 요청의 ‘지연 시 적 증원’과 다른 압박 축 |
| 지휘부 급습 | 후속 | 전멸 대신 목표 우선의 가치. 점령·보급을 생략한 속공만 최적이 될 수 있음 |

첫 범위의 **최소 경험 후보**는 출발 → 항로 판단 → 임무 중인 적과 조우/교전 → 보급 거점 점령·가동 → 유한 보급 → 최종 목표이며, 늦으면 외곽에서 증원이 접근한다. 점령·보급을 단순 미션 체크가 아니라 다음 교전 준비에 연결한다. 물리 장애물·전자전·강습 전용 지형·호위·생산은 모두를 한 번에 선행 조건으로 만들지 않는다.

**선택 깊이 후보:** 정면로는 짧지만 수비 부담, 우회로는 길지만 다른 정비/접근 이점. 두 경로 동시 분견·회항·합류를 허용하고 경계 좌표 통과만으로 선택을 잠그지 않는다. 이 차이의 크기·보급량·지연 효과는 D03/D07/D08 및 측정 책임이다. 처음부터 정면/우회가 반드시 필요한지는 H0에서 선택한다.

**단계적 제작 제안:** 먼저 호송·D 효과 없이 위 최소 경험의 상태·계약을 설계하고, 같은 샘플에 선택 호송·통신소·재점령을 연결하는 순서를 비교한다. 이는 기능을 삭제한 최종 범위 확정이 아니다. H0에서 포함을 고르면 D08 설계에 처음부터 반영하고 실제 제작 순서만 나눈다. 저장 필드·사건 ID는 D04부터 설계한다.

## 4. 제미나이 제안의 반영 판단

아래는 S1 §3의 기존 검토를 이번 범위 판단으로 재분류한 **D02 권고**다. 첨부 원문을 이번에 새로 감사했다는 주장이 아니며 정확한 상충 문구 판단은 S1의 검토 기록 범위다.

## 5. 레퍼런스의 경계와 우리 게임 재해석

이번에는 새 외부 사실을 추가하지 않았다. 아래 작품 요소는 **S1 §4·9 또는 S7 §1~3이 이전 조사에서 보고한 범위**이며 D02가 원작 전 캠페인·게임 현행 버전을 직접 검증했다는 뜻이 아니다. 구체 일정·전력비·보급량·A/B·재고 유입·통신소 지연은 전부 우리 게임의 독자 후보다.

레퍼런스의 핵심 활용은 사건 이름의 복제가 아니라 **적이 왜 그 장소에 있으며 무엇을 지키고 언제 떠나는지**다. 이를 첫 유형에서는 순찰·거점 수비·증원 접근으로 좁힌다. 호송·구원·재점령을 포함할지는 H0 범위와 D05/D08의 계약으로 명시한다.

## 7. H0 결정 패킷과 D03~D10 인계

**O02 = OPEN. 권고 패킷:** A안 단일 성계 연속작전 + 첫 유형 보급로 개방. A/B를 핵심 선택 후보로 놓고 호송 차단·통신소 지연·재점령의 포함은 묶어서 사용자 판단을 받는다. 가칭 강하와 20분 전후는 별도 미확정이다. B안은 긴 이동 압축/전투별 집중을 우선할 때, C안은 적벽 자체 개선을 우선할 때의 실질 대안이다.

H0에서 필요한 최소 선택은 **① A/B/C 작전 단위, ② 보급로 개방 첫 유형 채택, ③ 정면/우회와 선택 호송·통신소·재점령의 첫 샘플 포함 범위**다. 이때 구체 좌표·속도·재고·사기·시한까지 결정하도록 요구하지 않는다. 그런 정책은 H1/H2 소유다.

| 후속 | A안 선택 시 검토 입력 | B안이면 달라지는 것 | C안이면 달라지는 것 |
|---|---|---|---|
| D03 | 한 작전 그래프·단일 시계·기동 접근 | 작전/전술 그래프·시간 환산·화면 밖 진행 | 기존 적벽 지도·효과 구역·주공 일정과 확장 연결 |
| D04 | 같은 함대 ID·위치·명령·거점·사건 지속 | 전투별 상태 수출/수입·중복 결산·전환 중 저장 계약 추가 | 기존 적벽 저장/재생과 확장 프로필의 버전 경계 |

| D07 | 가동 거점의 유한 재고·접근/연결 | 전투 밖 보급·전투 재진입 탄약/손상 인계 | 기존 공급원 소유·무한 재고와 새 거점 격리 |
| D08 | 같은 공간의 호송/증원 접근·재점령/철수 | 화면 밖 진행·화면 진입 중 사건 처리/시계 일치 | 기존 지연 투입·한 번 증원과 신규 사건의 병존 |

공통 기준은 SPEC과 PLAN이며 H0 결과를 기록한 D02 수용본을 후속 입력으로 사용한다. D01 기반 제약과 충돌하면 충돌 ID와 영향 후손을 반환한다. D02는 그 제약을 추정해 해소하지 않는다. Q67은 신규 작전이라는 이름으로 자동 면제되지 않으며 D01/D03이 적용 범위를 대조하고 적용 시 B항 등재·1000시드 게이트를 보존한다.

**H0 이전 차단:** O02 미선택 상태에서 D03~D10을 하나의 확정 구조로 설계하지 않는다. 이 문서는 후보별 차이 조사까지의 인계다. H0 선택 후에도 O01/O03~O08은 담당 문서에서 open과 차단 조건을 유지한다. 선택이 코드 구현·테스트·브랜치 작업 승인이 되는 것은 아니다.

사용자가 **A안 단일 성계 연속작전·첫 보급로 개방·정면/우회 선택**을 채택했다. 기본 시간 경과 증원을 포함하며, **호송 차단·통신소 지연·재점령까지 이번 설계에 포함하고 제작 순서는 분리**한다. 단일 기록 원본은 [H0-DECISION.md](H0-DECISION.md)다. 조율자가 전달한 명시 선택을 기록했으며 §1~8의 ‘H0 대기/O02 OPEN/사용자 미선택’은 선택 전 이력이다.

**O02의 H0 범위 항목은 해소**됐다. 20분·좌표·속도·노드 수·재고·점령/사기 정책·같은 틱 순서·증원 편성/일정·철수 분모·스키마는 미정이다. O01/O03~O08 및 H1/H2 게이트를 유지한다. 기존 제안 전체 승인이나 게임 코드·테스트·브랜치·병합·커밋·푸시 승인이 아니다.

D03에는 단일 작전 그래프·정면/우회와 확장 3요소/증원의 공간·시계 요구를, D04에는 같은 함대의 잔존 상태와 호송/통신소/재점령/증원 상태 확장 자리를 인계한다. 정확한 입력과 착수 경계는 H0 기록 §3을 따른다. evidence_audit의 [D01 독립 검토](REVIEW-D01.md)·[D02 독립 검토](REVIEW-D02.md) 파일에서 문서 수용을 확인했다. **사용자 선택과 독립 5-b 수용을 구분**하며 작성자가 자기 문서를 판정하지 않는다. O06의 통합 가능성 미확인은 읽기 기반 설계 조사 자체를 차단하지 않고 코드 통합·최신 통합 가능성 확정을 차단한다.

현재 위치: **D01/D02 독립 문서 수용 및 H0 범위 선택 기록 확인 완료. 기반 제약을 유지한 D03/D04 읽기 기반 설계 인계 가능. 게임 구현·테스트 미착수.**
