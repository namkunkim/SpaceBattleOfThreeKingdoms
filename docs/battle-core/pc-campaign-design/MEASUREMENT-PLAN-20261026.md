# PC 캠페인 사전 측정 계획 준비

2026-10-26 / **문서 초안·독립 검토 대기 / 측정 실행·정량 수용 미승인** / 문서 K=3.

## 1. 목적·입력·가설

[H2](H2-DECISION.md)와 [구현 스펙](IMPLEMENTATION-SPEC-20261026.md)의 후속 준비다. 입력은 [D01 기존 근거](D01-BASELINE.md), [D03 공간/시계](D03-SPACE-TIME.md), [D04 상태](D04-STATE.md), [D09 평가 계약](D09-UX-EVALUATION.md), [D10 통합](D10-INTEGRATED-REVIEW.md)과 각 독립 리뷰·결정 원본이다. 이번에는 문서만 작성하며 게임·로그 수집·성능/저장/사람 시험을 실행하지 않는다.

게임약20분은 비교 가설이다. 실제 플레이·정지·배속을 따로 기록하고 조기 성공/명백한 조기 패배를 허용한다. 임무·A/B·유한 보급이 판단을 늘리는지, 후방 방어와 정비가 의미 있는지, 증원 예고가 대응 여유를 주는지 검증한다. 성공률/시간/프레임 예산·표본 수는 아직 합격값이 아니다.

옛 PC 실험은 5조건×3시드·단일 공격 정책·구편성·게임시간이다. large_slow 중앙값8:50/terrain5:41·3패와 단일시드3프리셋 재생은 새 캠페인의 최신 밸런스·재미·저장 증거가 아니다. 새 기준 커밋·실효 프로필/편성·측정 조건을 확보하기 전 이를 대조군의 현재 결과로 쓰지 않는다.

## 3. 현재 기록과 추가 수집 요구

2026-10-26 정적 열람: `scripts/battle_trace.gd`의 `start/write/sample/event`는 profile/seed/hz/world·시작 편성, mono_ms/tick/sim_ms, UI 상태/선택/배속/감속/포커스, 일부 상태 변화·snapshot·전투 사건을 기록한다. 파일 기록은 코어 상태를 바꾸지 않는 로컬 진단이라고 명시돼 있다. 이 읽기는 로그를 새로 수집하거나 명령 적용·작전 거래의 완전 계측을 검증한 것이 아니다.

시간 계산: 동일 플레이 경계에서 `Ttotal=Ta+Tp`, 배속별 진행 구간 합은 Ta다. 로딩/브리핑/앱이탈은 별도 외부구간이며 포함/제외 기준을 PR03/04에서 명시한다. 정찰+이동+보급이 겹치면 활동별 시간을 총시간에 합산하지 않고 구간 합집합을 쓴다. 지연·재경로·서비스를 제외한 ETA는 근사치임을 표시한다. 사람 판단 주석의 불명 비중도 보고한다.

## 4. 단계별 비교 설계와 미래 시험

모든 arm은 동일 버전·실효 설정·시드/편성/정책을 기준으로 비교하며 바꾸는 변수와 고정하는 변수를 명시한다. 아래 검사 이름은 **미작성 후보**이고 결과는 없다.

| E | 단계·검사 이름 후보 | 입력·비교와 최소 판정 계약 |
|---|---|---|
| E01 | P1 `profile_and_access_baseline` | 현재 승인 기준 vs opt-in 실효 설정. A01~06과 진형/서비스/E-R 접근을 검사. 기존 적벽 입력이 바뀌면 차이 원인을 먼저 보고 |
| E02 | P2 `route_choice_resource_tradeoff` | A/B를 같은 시드 묶음·동일 초기 편성으로 비교. 이동/점령/대기/손실·사용 자원·목표/철수/실패를 기록. 양쪽 완주 가능성은 검증할 요구이지 기정사실 아님 |
| E03 | P2 `control_supply_morale_boundaries` | 경합/중단·재점령·빈 재고/고립·예약취소·피해/이동·결집/정비·지역패퇴. 자원/사기 변화의 원인과 1회 적용, 파괴함 재생 부재 검사 |
| E04 | P3 `optional_missions_timing` | D 확보 여부와 호송 차단 여부를 분리 비교. 다변수 전부 변경한 조합만으로 각각의 인과를 단정하지 않음. 후방 재점령 접근·대응 여유 기록 |
| E05 | P3 `event_time_boundary_matrix` | D완료가 출발 직전/동일/직후, 유효 지연·시한 동시 목표/탈출/지휘상실·종료후 사건·R봉쇄·화물 재경로. 사용자 선택과 표시/원장/결과 일치 |

| E07 | 후속지형 `effect_then_body_comparison` | 먼저 효과만 있는 기본 작전, 이후 본체1~2개. 가능하면 같은 효과/배치에 본체만 추가해 영향 분리. 우회·탐지/사격·지속공격·임무/미니맵·퇴로와 성능 확인 |
| E08 | 사람 `first_play_replay_observation` | 같은 설명 조건에서 초회와 재도전의 학습을 분리, A/B/선택 임무 순서·배속/정지 기록. 목표 이해·예고/철수 이해·대기와 판단·불공정 패배 체감을 원자료와 함께 보고 |

## 5. 결과 수용·반대 증거·기록물

| 분류 | 수용 준비 기준 | 아직 정하지 않은 값 |
|---|---|---|
| 기능 불변식 | 숨은 정보 누설·중복 생성/배송/결산·파괴함 재생·장애물 관통 등은 허용되지 않는 반례. 각 검사 입력/기대 상태를 먼저 확정 | 검사할 상태 공간/동시 경계·수치 표현은 해당 스펙 선행 |
| 페이싱·선택 | Tg와 Ta/Tp를 별도 분포, 이정표·판단/대기·조기성공/실패·양쪽 경로를 함께 봄 | 20분 허용범위·성공/철수 비율·대기/판단 임계 |
| 자원·정비 | 소비·서비스·손실·정비·기회비용과 무한회복/교착의 반례를 함께 봄 | 재고·유입·시간/물자 가격·회복량·상한 |
| 성능·품질 | 같은 기기·해상도·부하에서 프레임/틱 분포와 극단구간, 정보 가림·ETA·경보 반복 | 기기/화질·목표FPS·프레임/틱 예산·새 표본 |

E별 기록물은 실행 명세·원시 로그/관찰주석·체크포인트/결과·분석식·오류/제외 사유·변경 전후 대조와 독립 판정이다. 로컬 진단자료의 경로만 인계하고 개인 원본을 자동 업로드하지 않는다. 결과가 목표와 다르면 인과를 좁힐 분리 비교를 계획하며 합격값을 사후 조절하지 않는다.

Q67 적용 시 차이 목록 B항+1000시드 재측정은 기존 게이트다. E08의 사람 표본이나 옛 15판으로 대체하지 않는다. 비적용이면 변경 범위와 제외 근거가 필요하다. 효과 우선·새 성계·동일 버전 저장 선택만으로 자동 면제하지 않는다.

## 6. 현재 게이트와 독립 인계

O06 최신 기준·소유, O03 공간 입력, O04/05 물량·일정/동시 경계, O07 필드/커밋·복원, O01/O08 수용 기준은 해당 실행 전에 해소해야 한다. 지금은 문서의 완결성과 추적성을 점검하는 단계이며 모든 E01~09는 미실행이다.

자체 5-a: PR6/M8/E9·단위·참조 링크·기존trace 사실/추가 요구·후보/확정·Q67·허용2문서만 검사한다. 문서 K=3. 독립 검토자는 원문과 반대 근거를 대조해 수용/조건부/반려를 기록한다. 반려는 2단계 스펙으로 복귀하고 실행자는 자기 5-b를 선언하지 않는다. 코드·게임/AI/UI·저장·통행·성능·1000시드·사람 시험은 모두 미실행이다.

자체5-a 1회: PR6/M8/E9행, 상대링크 누락0·행말공백0, 시간 구간·기존trace/추가계측·Q67/새표본·미실행 경계를 확인했다. 검사한 두 문서의 공백 검사 오류는 없었다. 이는 문서 완결성 점검이며 실행 결과 또는 독립 수용이 아니다.
