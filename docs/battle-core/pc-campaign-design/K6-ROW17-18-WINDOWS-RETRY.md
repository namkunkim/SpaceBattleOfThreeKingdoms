## 정식 실행 재개 조건

1. 현재 기준의 Windows 실행본과 비교 실행본을 격리된 프로필에 묶고, 실행본·오버레이·검증기 해시 및 비교 매니페스트를 다시 동결한다. 관찰 오버레이는 게임 로직과 출격 타이머를 바꾸지 않는다. 기존 실행 묶음은 증거로 보존한다.
2. Windows 1600×900에서 공개 EntryBoot와 지도 경로로 양양 상세 → 적벽 모의전 → 기존 카드 → 자동 해결 → 표준을 선택한다. 출격 전에 관찰기, 다음 입력의 화면 캡처·요청 준비, 대상 창과 입력 담당을 확인한다.
3. 출격 후에는 실제 건너뛰기 버튼이 보이고 활성화된 상태에서 새 캡처와 입력 요청을 연결한다. 관찰기의 요청 수신과 버튼 대상이 확인되면 한 번 클릭한다. 현행 제품 코드의 연출 종료는 6.6초다. 클릭 상관 기록에서 버튼의 다운·업이 자동 시작보다 앞서야 한다. 이미 자동결산이 시작됐거나 포커스를 잃었으면 해당 회차를 종료하고 증거를 보존한다.
4. 17행은 고정 seed 350157의 종결값, 작업자 합류·해제 및 결과 재조회 불변을 기존 판정으로 대조한다. 18행은 진행 확인 뒤 Stop, 카드·지역 소유자 복구, 재출격 후 두 번째 Stop을 확인한다. 서로 다른 두 작업자가 합류·해제됐고 결산이 생성되지 않았는지 확인한다.
5. 비교 전후 각 회차는 실제 입력 기록과 의미 검증을 모두 통과해야 한다. 이 준비 기록의 오프라인 대조에는 새 Windows 실입력 결과가 포함되지 않는다.
