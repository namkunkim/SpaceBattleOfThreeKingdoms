**렌더 근거.** 편성이 알려진 적벽 함대는 렌더러가 실제 척수만큼 명목 슬롯을 만든다. 함종별 역할 배치는 좌표 집합의 순열이다. 길이와 폭은 PC가 실제로 사용하는 실루엣 평면에서 읽었다. 선체 구간은 앞쪽 길이 `MODEL_LEN=1.9`이고 나머지 평면 길이는 항적이다. 폭 `SHIP_WIDTH=0.48`, 길이 축 `HULL_STRETCH.x=0.75`, 함종별 `CLASS_LEN`, 기함 1.8배를 적용한다. 아래 사각형은 이 렌더러의 **명목 선체 실루엣 구간을 덮는 사각형**이다. GLB 3D 자산의 실제 메시 외곽, 선미 항적·엔진광·잔해의 외곽, 실제 움직이는 화면에서의 추종 위치는 측정 대상에서 제외했다. 월드 투영에서 `S=0.05`는 슬롯에 곱했다가 전술 평면으로 돌아오므로 슬롯 수치는 유지되고 선체의 3D 길이/폭은 `S`로 나눈다. ## 2. 수치가 있는 명목 외곽 계약 후보

계약 후보 `p05-layout-disks-v1`은 전체 함선의 명목 슬롯과 평면 선체를 사용하고, 각 선체를 자세에 관계없이 포함하는 원으로 감싼다. 함선별 반경 `h_i = hypot(0.75 L_i, 0.48 L_i / 1.9) × f_i / (2 × 0.05)`이다. `L_i`는 renderer CLASS_LEN이며 `f_i`는 기함이면 1.8, 일반이면 1이다. 함대별 `max_i(||p_i||+h_i)`는 함종 배정까지 반영한 보수적 상계다. 배치에서 동점/반올림이 달라져 함종 슬롯이 바뀔 가능성에 대비해 **`max_i ||p_i|| + max_i h_i`**도 함께 계산했다. 두 번째 수치는 기함이 있는 LIU01에서 가장 큰 함종이 기함인 경우까지 덮는다. 아래 숫자는 전술 단위, 표의 표시는 가장 가까운 소수점 6자리이며 경계 판정에는 스크립트의 반올림 전 값을 사용한다.

**회전·전환 상계.** 임의 heading의 강체 회전·점대칭은 슬롯 거리와 선체 외접원의 반경을 보존한다. 명목 슬롯이 양끝 위치 사이를 선형으로 움직이면, 각 함선의 중간 슬롯 거리는 `||(1−t)p0+t·p1|| ≤ max(||p0||,||p1||)`이다. 전환 방향을 바꿔도 상계는 동일하다. 이 후보의 선형·회전 계약에서는 LIU01의 01↔03 전환 중 최대 상계가 **75.457852**, LIU02는 **50.059254**다. 배정 반영 시 각각 68.176921, 50.059254다. 전환 도중 동일한 두 끝점으로 다시 전환하더라도 중간점이 그 볼록집합 안에 있으면 이 상계를 유지한다. 증원·수비의 고정 진형은 표의 회전 상계를 그대로 사용한다. 이 상계는 전환 시간이나 진행 중 세계 좌표의 실제 이동 거리를 의미하지 않는다.

렌더러의 `_form_progress`는 명목 슬롯을 선형 보간하지만, `_follow`는 이전 선체 위치와 함대 속도를 이용해 별도로 추종하고 개별 yaw도 제한한다. 이 때문에 화면에 움직이는 개별 선체의 실제 중심 상대 거리가 명목 슬롯 상계를 넘을 수 있다. 코어의 이동 중 선회 궤적, 명령 재경로, 슬롯 추종 편차, 안전 여유와 다중 함대 회랑을 계약하려면 소유자가 각 편차의 상계나 상태 전이 규칙을 제공해야 한다. 중심이 이동하는 경우에는 중심 경로 전체를 해당 원으로 팽창시킨 swept 영역을 사용하고, 경로 추종 편차까지 추가한다. ## 3. 후보 지도에 적용할 수 있는 조건

`m_i`를 각 함대의 독립 안전 여유, `g`를 두 외곽 사이 추가 간격으로 둔다. LIU01과 LIU02가 동시에 전환/회전하면서 명목 외곽을 분리하려면 중심 간 거리가 **125.517106 + m1 + m2 + g 이상**이면 충분하다. 두 원의 중심 거리가 `d`일 때 양 원을 포함하는 최소 원의 반경은 `max(r1,r2,(d+r1+r2)/2)`다. 여기서 `r_i`는 위 배정 독립 상계에 해당 여유를 더한 값이다. 여유 0, 중심 이격 125.517106 조건에서 중심을 최적으로 고르면 합성 반경은 125.517106, 두 함대 중심의 산술 중점을 쓰면 138.216405다. 제품 그룹 명령의 실제 시작 오프셋·회전 축은 고정되지 않았으므로 이 수치는 그 명시적 배치 조건의 예다. 실제 그룹 중심과 각 함대 오프셋 `o_i(t)`가 정해지면 `max_{t,i}(||o_i(t)||+r_i)`로 재산정한다. 기존 다중 이동은 현재 상대 배치를 목표점에 반영하므로 개별 함대 간 이격을 보장하는 계약은 따로 필요하다. [그룹 이동](../../../core/battle/battle_sim.gd#L685).

표의 차감은 **직선 중심선이 지켜지고 후보 원형 외곽이 적용될 때의 벽 대조**다. E·R의 배치 영역이 전체 선체를 담는 원으로 정의된다면 각 함대·합성 외곽과 해당 여유 이상의 반경이 필요하다. A/B 서비스와 E 철수가 중심 도착 조건이면 서비스/철수 유효 영역과 벽·회랑을 침식한 자유중심공간의 교집합, 정지·이탈 및 접근 연결을 검증한다. 미승인 영역 크기를 표에서 역으로 확정하지 않는다. [후보 좌표와 벽거리](P05-PC-MAP-INPUT-EVIDENCE-20261109.md) · [F12/A04](I01-ACCEPTANCE-PREREG-20261026.md).
