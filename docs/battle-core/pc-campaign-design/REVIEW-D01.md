## 남은 조건과 승인 시점

- **O06은 open:** 로컬 기준은 부분 확인됐지만 PC 미커밋 청결·변경 소유·최신 원격·실제 통합 가능성은 미확정이다. 코드 구현 직전 재확인이 필요하다.
- 최초 수용 보고 당시 O02/H0는 사용자 판단 대기였다. 이후 조율자가 전달한 사용자 선택은 **단일 성계 연속작전·보급로 개방·정면/우회, 기본 시간 증원, 호송/통신소/재점령 포함 설계와 제작 순서 분리**다. 이는 검토자가 대신 결정한 내용이 아니며 별도 H0 기록에서 관리한다.
- H0 선택은 20분·좌표·속도·재고·세부 스키마·동시 틱 정책이나 게임 구현 승인이 아니다. 해당 open과 후속 차단은 유지한다.
- 검토 중 문서/코드/기존 JSON과 Git 정보를 읽었으며 **게임·테스트·1000시드·사람 플레이는 실행하지 않았다.** 브랜치 변경도 하지 않았다.

이번 수용은 D01 설계 근거 문서의 독립 5-b 판정이다. 전체 설계 또는 게임 구현의 최종 검증 통과를 뜻하지 않는다. D01 본문은 수정하지 않았다.
