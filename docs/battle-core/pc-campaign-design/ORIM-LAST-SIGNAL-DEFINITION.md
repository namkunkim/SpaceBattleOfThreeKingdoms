# 〈오림의 마지막 신호〉 동결 작전 정의

정의 1판, 시드 20826, 표준·직접 지휘. 논리 틱은 100ms이며 1200틱까지 진행한다. 전장의 좌표 범위는 (0, 0)부터 (1700, 1150)까지다.

| 편성 | 함종 | 시작 또는 출현 위치 | 행동 |
| --- | --- | --- | --- |
| 감녕 지휘 전대 | SHP-03 6척, SHP-04 12척 | (300, 570), 0틱 | 플레이어 이동·정지 |
| 노숙 지원 전대 | SHP-03 4척, SHP-04 8척 | (260, 770), 0틱 | 플레이어 이동·정지 |
| 위군 접근 편성 | SHP-03 3척, SHP-04 6척 | (1300, 570), 0틱 | 북쪽 접근로를 따라 통신소로 진격해 정지 |
| 위군 예비 편성 | SHP-03 4척, SHP-04 8척 | (1500, 850), 500틱 | 남동쪽 접근로를 따라 통신소로 진격해 정지 |

- 통신소는 (850, 570), 반경 90이다. 수리 지점은 (420, 810), 반경 70이다. 반경의 경계에 닿은 편성을 범위에 포함한다.
- 편성 ID는 감녕 `gan-ning`, 노숙 `lu-su`, 위군 접근 `wei-advance`, 위군 예비 `wei-reserve`다. 피해는 SHP-03, SHP-04 순으로 각 함종의 함선 명단을 따라 적용한다. 경유점에 도착한 틱의 남은 이동량은 이월하지 않는다. 예비대는 500틱에 출현해 같은 틱의 포격에 참여할 수 있으며 501틱부터 이동한다.
- 아군의 권장 접근로는 (300, 570) → (570, 570) → (850, 570)이다. 정비를 거치는 접근로는 (260, 770) → (420, 810) → (660, 760) → (850, 570)이다. 아군은 전장 안의 지점을 직접 지정한다.
- 위군 접근 편성은 (1170, 350) → (1030, 450) → (878, 570), 예비 편성은 (1240, 800) → (1050, 675) → (878, 600)을 순서대로 따라간다.
- 전술판의 함대 단위 전투를 사용한다. 각 함선의 최대 체력은 30, 아군 속도는 초당 100, 적은 초당 45다. 사거리는 아군 180·적 140이고, 10틱부터 10틱마다 사거리 안 최단 거리에 있는 상대 전대에 살아 있는 함선 수만큼 피해를 준다. 같은 거리에서는 편성 ID 순서로 고른다. 각 틱에 명령과 이동을 반영한 뒤 전대 중심에서 포격 사거리와 시설 반경을 측정한다. 포격 피해와 파괴를 확정한 뒤 시설 상태를 평가한다. 포격은 표적과 피해를 먼저 확정해 동시에 처리한다. 피해는 해당 전대의 고정 함선 순서대로 소진한다. 정비는 살아 있는 함선 한 척당 최대 6 체력을 회복한다.
- 경합 판단에는 이동 중인 적도 포함한다. 진행을 맡을 정지 아군이 여러 전대면 기존 담당자를 우선하고, 새로 시작할 때는 편성 ID 순서로 고른다. 점유 완료 다음 틱부터 송신을 센다. 포기 명령을 적용한 틱은 다른 전투·시설 처리 전에 실패로 확정한다.
- 최초 결산에는 작전 ID, 부모 결산 ID로 연결되는 영수증, 결과와 사유, 종료 틱과 시각을 기록한다. 원본 입출력과 부모 결산은 같은 Windows 캠페인 프로필의 권위를 사용한다.
