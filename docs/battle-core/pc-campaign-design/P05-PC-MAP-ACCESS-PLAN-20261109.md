## 3. 후속 구현용 세 조각

### 1. 지도와 편성 측정 입력 동결

**소유** P05 지도·시나리오 담당과 전투/편성 담당. 작전 설계 소유자가 난이도·지원 편성/진형, A/B 서비스와 C/E/R 영역의 사용 조건을 승인한다. 지도 담당은 commit, 입력 SHA, 프로필/규칙/편성/진형·기하·변환 버전, 실제 로드된 배치·함종별 척수, 영역 ID/역할/형상/단위와 경로 ID를 동결한다. 소스 정본과 유효 manifest를 별도 기록한다.

**배치 후보 근거** 적벽의 아군 서쪽, 적 동쪽 배치와 효과 지형을 기준으로 서쪽 안쪽에 E, E 동쪽에 선회·분기 공간 J, A를 C 방향의 짧은 축에, B와 D를 다른 효과 노출을 가진 축에 놓는다. D에는 통신 시설 영역 밖 통과 공간을 둔다. C는 두 갈래에서 합류할 회전·정지 공간, R은 C 쪽 외곽 안쪽에 배치하고 A/B/E와 거리를 둔다. 이 배치는 지형 노출과 보급·접근 시간을 실제로 다르게 만들 수 있는 탐색 순서다. 두 항로의 게임 시간 길이와 R→목표 및 C→A/B/E 시간을 비교한 뒤 좌표를 제안한다. R의 첫 유효 배치가 A/B에 즉시 영향 주는지 규칙 반경과 대조한다. 기존 기지·탈출 좌표는 검토 기준점이며 제품 배치 승인은 남아 있다.

**측정** 실제 제품 진입점에서 적용될 후보 프로필의 모든 허용 조합을 열거한다. 함대 중심 상대 위치·방향의 논리 슬롯 전부와 함종별 선체 외곽으로 hull union을 얻는다. 정지 진형, 느슨한 상태, 허용 전환·회전의 연속 구간, 이동 및 그룹 보정에서 최대 거리 `R_form`과 발생 자세/시각을 기록한다. 샘플만 사용한다면 사이 구간의 최대 추가 변위를 보수적으로 덮는 오차 상계를 붙인다. 현 코드에 함대 간 밀어내기가 없으므로 그룹 간격/추후 분리 보정이 작전에서 필요한 경우 명시적으로 모델링한다. 배치·철수·증원의 허용 자세나 상한을 모르면 해당 행은 NOT_READY다. 최종 외곽은 유효 전술 좌표계의 길이로 측정하고, 오차·추가 안전 여유의 출처와 중복 여부를 기록한다.

**통과 증거** source/effective 필드 대응표에 경계·노드·회랑·영역·rect·초기/증원 위치를 포함한다. 생성 경계는 원점 (0,0)의 source만 받아 스케일 또는 identity를 한 번 적용한다. 원점이 0이 아닌 입력은 거부한다. 제품 소비자는 준비된 effective만 읽으며, effective를 source로 다시 제출하면 활성 상태를 보존하고 거부한다. 재시작은 변경되지 않은 원본 source를 새로 읽어 effective를 한 번 재구축한다. 동결 입력의 기준점·길이·rect를 수계산과 대조하고, 새 시작과 동일 입력의 재시작에서 같은 source/effective manifest 식별자를 기록한다. 이 사전 인수 기준의 제품 예외는 별도 승인 전 NOT_READY다. ### 2. 실제 최대 외곽으로 A04 판정

**소유** P05 검증 실행자. 1번의 동결 입력을 사용한다. 각 경로의 승인 함대별로 `M = R_form + safety`를 적용한다. 경계·회랑은 외곽을 포함할 수 있도록 침식하고, 실제 차단 영역이 있다면 M만큼 팽창시킨다. 코어 중심 제한을 유지하면 그 실효 범위를 외곽 침식 후 자유공간과 교차한다. legacy의 `edge=40`이라면 중심이 허용되는 범위는 `[40,W−40] × [40,H−40]`이며, 40을 M에 합산하지 않는다. 첫 효과 지형은 비용만 반영한다. 여러 구간이 만나는 곳은 단일 회랑의 선폭 합산으로 판정하지 않고 회전 공간과 경계의 실제 연결을 검사한다. 허용 방향·선회 반경·정지 조건 및 틱 사이 이동·전환 swept 외곽을 확인한다. 원형 상계가 지나치게 커 판정이 모호하면 방향/진형별 보수 외곽으로 재검증하고, 그때까지 접근 불가를 단정하지 않는다. | 우회 양성 | 같은 지도에서 E–J–B–D–C를 연속 통과한다. B의 서비스 접근/정지/이탈, D 시설 가동이나 점령 없이 D 접근 구간 통과, C 접근을 확인한다. 두 가지 route ID 및 다른 경유·노출을 기록한다. |
| 복귀·증원 양성 | 두 갈래 각각의 전방·보급 위치에서 E 철수 도착 영역까지 유효 복귀 경로가 있다. R은 승인 최대 증원 외곽 전체를 수용하고 선택된 R→C 또는 R→D 접속에서 선회·출구가 이어진다. 보급 중인 함대가 유일 퇴로를 막으면 대기/양보 공간 또는 배치를 재설계한다. |
| 기하 단절 음성 | 같은 지도 사본에서 필수 분기 회랑의 폭이나 배치를 바꿔 실제 최대 외곽+여유가 해당 목을 통과할 수 없게 한다. 중심선과 edge는 유지한다. 다른 갈래는 양성을 유지하고 표적 갈래는 목의 ID와 방향·폭·실패 여유를 내보낸다. 안내 전용 회랑이면 검증 회랑 안의 기하 단절로 기록한다. 실제 이동 경계가 적용되는 경우에만 제품 통행 차단으로 채점한다. |
| 항로 정의 음성 | 별도 사본에서 필수 분기 edge를 제거하고 해당 route의 연결 실패와 다른 route의 연결 유지를 확인한다. 안내 전용 edge 삭제는 항로 정의 실패로 집계한다. 자동 재경로를 시험한다면 표적 항로 실패와 우회 가능을 각각 기록한다. |
| 서비스 접근 불가 음성 | 경로·편성을 고정하고 지도 사본에서 서비스 영역 하나를 해당 route의 도달 가능한 자유공간 밖으로 옮긴다. 중심 경로나 서비스 영역 자체는 여전히 존재하되 정지 가능한 교집합이 비어 있거나 도달 성분이 분리됨을 보인다. 정지 가능한 교집합의 공간/경로 ID와 이유를 내고 다른 서비스의 양성은 유지한다. |

양성의 경로 witness와 음성의 실패 경계를 독립 재계산할 수 있도록 버전·입력 SHA, 허용 자세, 원인, 최소 여유, 사용 정밀도와 경계 접촉 정책을 함께 저장한다. 전 항목의 원천과 실제 최대 외곽이 있어야 제품 A04를 채점한다. 누락은 NOT_READY, 완전한 입력에서 기대와 다른 판정은 FAIL, 입력 훼손/잘못된 실행 환경은 INVALID로 구분한다. 효과 지형 비용 차이는 별도 시간 자료로 남긴다. Q67은 실제 변경 범위로 판정하고 적용 시 차이 목록 B와 1000시드 게이트를 별도로 연다.

## 4. 문서 인계 게이트

5-a는 지정 원문과 값·단위·경로·상태 대조, 문서 링크, 허용 파일 범위, 정/부 판정 및 소유자 대조다. K=3 이내로 문서 결함만 고친다. 다른 모델의 5-b는 이 문서 작성과 제품 구현에 참여하지 않은 심사자가 맡고, 정적 관측과 승인/측정 필요 입력의 구분, 양성/음성 재현성, 선행 게이트와 P02/P03 소유권을 판정한다. 심사 결과는 조율자가 별도로 전달한다.
