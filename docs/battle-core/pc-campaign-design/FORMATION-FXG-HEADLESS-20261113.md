# P05 렌더러 틱과 A05/A06 FX-G 재시작 검증

Windows Godot 4.7.2 헤드리스, 제품 소스 기준 bd5afc4a.

- **P05 44/44** — 39척·21척의 양방향 FRM-01↔FRM-03 전환을 선택형 시뮬레이션 틱으로 표시한다. 중복·과거·다른 작전 스냅샷, 일시정지와 잘못된 입력에서 위치 유지, 틱 건너뛰기 뒤 안전한 이동을 확인했다. 지연된 자세가 최종 배치에 도달하려면 이후 틱이 증가해야 한다. 일시정지나 종료로 마지막 틱이 유지되면 지연된 자세도 유지된다. 공개 명령 연결과 제품 가속도 상한은 남아 있다. [렌더러 테스트](../../../tests/p05_formation_renderer.gd)
- **제한 FX-G** — Windows 한 대에서 독립 Godot 프로세스의 저장 11/11, 재개 13/13. 100ms 상태를 저장하고 새 프로세스에서 복원했다. 150ms 종결 상태·표시·이벤트는 연속 실행과 동일했으며 입력과 슬롯 바이트는 보존됐다. 단일 프로세스 회귀도 16/16을 통과했다. 이 결과는 정상 종료 후 제한 호스트 복원에 해당한다. 전체 A05/A06 인수는 남아 있다. [체크포인트 테스트](../../../tests/restricted_operation_fxg_checkpoint.gd)
