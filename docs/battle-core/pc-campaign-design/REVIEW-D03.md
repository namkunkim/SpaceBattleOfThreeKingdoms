# D03 독립 검토

2026-10-25 / evidence_audit / **문서 수용·H1 사용자 판단 대기**.

대상: [D03-SPACE-TIME.md](D03-SPACE-TIME.md). 기준은 작업 분해 D03·공통 계약, 검토 스펙 R03/R04/R05/R17·O01/O03, H0 결정, D01/D02 수용 근거다. 검토자는 대상 문서를 작성·수정하지 않았다. 실제 공간·기능·밸런스의 검증 통과 판정이 아니다.

| 검토 범위 | 원문 대조·판정 근거 |
|---|---|
| H0·승인 경계 | D03 §1은 단일 성계·보급로·정면/우회·기본 증원·확장 3사건 설계를 포함하고 수치/게임 구현 승인과 구분한다. |
| R03 시계·예산 | §3은 실제 누적 하위걸음의 게임 시계, 진행/정지/총 실제 경과와 배속 체류를 구분한다. 기존 S2 예산 2+3+3+3+2+5+2=20을 후보로 유지하고 병행 합집합·조기 성공을 허용한다. `battle_sim.gd:923~951`의 tick 선증가·하위걸음 clock 증가·조기 종료를 읽어 tick×dt만으로 복원하지 않는 근거를 대조했다. |
| R04 그래프·접근 | §2의 후보 노드 7개는 시설4/출입2/분기1이며 항로9개와 정면/우회 경로가 일치한다. D 통행/점령 분리, 후방 이동, R 진입과 목표 접근 구분이 있다. §4는 논리 진형 외곽·통로·서비스 자유공간·교대·E 퇴로를 미래 측정 대상으로 두어 통행 성공을 선행 주장하지 않는다. |
| R05 지형 | §5는 효과/본체/병기 제한, 직접 가시/공유 관측/사격선, 진행 중 공격, 이동/강습을 구분한다. S6/S7의 제안 상태와 원본 T 식별자 차이를 보존한다. 모든 특수 지형을 필수 선행으로 두지 않는다. |
| R17·Q67 | §6은 D01 및 기존 결정 Q67의 범위 판단·적용 시 B항/1000시드·비적용 근거·공유 코어 회귀를 유지한다. O06의 청결/통합 가능성 미확인을 해소하지 않는다. |
| D04 교차 | D03 §7 요청과 D04 §2~3/§7의 논리 시계·노드/항로·기하/통행/규칙 버전·경로 재구성·관측·사건 슬롯은 의미가 일치한다. D03이 저장 형식이나 D06/D08의 같은 틱 우선순위를 임의 확정하지 않는다. |

실질 수정 요구는 발견하지 못했다. O01/O03은 OPEN이며 P1/P2·S-A/S-B는 사용자 미선택 정책 대안이다. H1의 방향 선택도 20분의 정량 수용·실제 치수/좌표·속도·스키마·Q67 면제 또는 게임 구현 승인을 대신하지 않는다.

문서와 기존 코드/원문을 읽어 판정했다. **게임·통행·저장·성능·1000시드·사람 플레이 시험은 실행하지 않았다.** 본문·공통 문서·코드·브랜치는 수정하지 않았다. 이 기록은 문서의 독립 5-b이며 전체 설계/게임 구현 최종 검증이 아니다.
