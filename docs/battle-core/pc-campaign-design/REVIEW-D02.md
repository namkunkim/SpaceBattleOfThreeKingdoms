# D02 독립 검토 기록

2026-10-25 / 검토자: evidence_audit / 판정: **문서 수용**.

대상: [D02-SCOPE.md](D02-SCOPE.md). 기준: [작업 분해](../PC-CAMPAIGN-WORK-BREAKDOWN-20261025.md)의 공통 계약·D02 카드·H0, [검토 스펙](../PC-CAMPAIGN-REVIEW-SPEC-20261025.md)의 R01/R02/R15·O02. 검토자는 D02 작성·수정에 참여하지 않았다. 이미 보고한 독립 검토의 감사 기록 보강이며 새 실험 또는 새 판정이 아니다.

## 완료한 근거 대조와 판정

| 검토 | 이미 수행한 독립 대조·결론 |
|---|---|
| 사용자 범위·승인 | D02 9~27행과 사용자 요구·기존 결정 기록을 대조했다. 이동·조우/교전·행성 점령·보급·시간 증원의 5요소가 있고, 함대 조종 단위·첫 샘플 비목표·승인 수준을 구분한다. |
| 대안의 공정성 | 33~50행의 A 단일 연속/B 국지전 연결/C 적벽 확장을 대조했다. 각 안의 상태·시계·UI·회귀 비용과 반대 근거가 있으며 A 권고를 구현 속도나 성능의 실측 결론으로 쓰지 않는다. |
| 첫 유형·선택 사건 | 56~73행은 기존 8유형의 이유·반례를 비교하고 보급로 개방·A/B·호송·통신소·재점령을 사용자 미채택 후보로 유지했다. 최소 범위에서도 기본 시간 증원을 제외하지 않는다. |
| 제미나이·레퍼런스 | 기존 캠페인 제안 §3~5·9와 SF 지형 리뷰의 출처 한계를 대조했다. 채택/수정/보류/제외의 판단을 권고로 표현하고 원작·게임 버전·독자 규칙을 구분한다. 새 외부 사실을 직접 검증했다고 주장하지 않는다. |
| H0 패킷·후속 | 122~139행은 작전 단위·첫 유형·선택 사건 범위와 D03~D10의 영향을 구분한다. 미선택 시 확정 설계 차단, 구체 수치/상태 정책의 H1/H2 인계, Q67 자동 면제 금지가 있다. |
| D01 교차 일관성 | 현재 기반은 재사용 후보이며 단일/다중 모두 신규 목표·상태·보급·사건 계약이 필요하다는 D01과 충돌하지 않는다. 현재 결과 요약만으로 상태 인계가 완료됐다고 주장하지 않는다. |

R01/R02/R15의 문서 합격 조건을 충족하며 실질 수정 요구는 발견하지 못했다. 당시 O02를 해소한 판정은 아니었다.

## 사용자 판단과 남은 조건

- 최초 독립 수용 보고 당시 **O02/H0는 사용자 판단 대기**였다. 수용은 선택 가능한 근거 문서라는 뜻이었다.
- 이후 조율자가 전달한 사용자의 H0 선택은 **A 단일 성계 연속작전 + 보급로 개방 + 정면/우회 + 기본 시간 증원**, **호송/통신소/재점령까지 설계에 포함하되 제작 순서를 분리**하는 범위다. 선택은 별도 H0 기록의 소유이며 검토자가 대신 승인하지 않았다.
- D01의 **O06 청결·소유·통합 가능성 open**과 O01/O03~O08의 수치·정책·측정 차단은 유지한다. H0가 최신 브랜치의 병합 가능성을 보장하지 않는다.
- 이번 독립 검토는 원문·D01의 확인 근거와 D02 내용을 대조했다. **게임·테스트·1000시드·사람 플레이는 실행하지 않았고 브랜치도 변경하지 않았다.**

이번 수용은 D02 범위 대안 문서의 독립 5-b 판정이며, 전체 설계 최종 수용이나 게임 구현 검증 통과가 아니다. D02 본문은 수정하지 않았다.
