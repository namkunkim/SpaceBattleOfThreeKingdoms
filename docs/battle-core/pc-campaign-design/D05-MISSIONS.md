## 2. 공통 임무 계층과 정보 입력 — R06/R07

**설계 권고:** 임무는 `목적/유지구역/경유지/추격한계/복귀지점/지원조건/실패·완료조건`을 소유한다. 전술 계층은 그 제약 안의 표적·거리·기동·사격을 고른다. 약한 적/보급 역할 가중치나 진영 집중 사격이 임무 경계를 자동 변경하지 않는다. 명령을 같은 코어 경로로 전달하는 기존 기반을 활용할 후보이며 새 클래스 구현 주장이 아니다.

공통 상태 후보는 `assigned → transit/perform → contact_response → return/replan`, 위험 시 `safety_withdrawal`, 종료/취소 시 `complete/cancelled`다. 모든 임무가 모든 상태를 쓰는 것은 아니다. 논리 전이는 단일 게임 시계와 안정 ID로 기록하고 스케줄러/거점 전이와 같은 틱의 우선순위는 D06/D08/O05에 남긴다.

**의사결정 순서 후보:** 작전 종료·강제 이탈/함대 운용 가능 상태를 읽음 → 자기 임무의 필수 유지/화물 보호/지원 예약 확인 → 진영에 허용된 접촉과 보고만 갱신 → 허용 경로/거리/추격시간의 후보 행동 필터 → 전술 표적 가중 → 명령·보고 기록. 사기 정책 자체를 D05가 정하지 않는다. 강제 퇴각을 표적 선택으로 덮어쓰지 않는다.

**추격 공통 한계:** 거리만이 아니라 임무 기준점까지 유효 복귀 경로·복귀 ETA·화물/목표와의 분리·허용 추격 시간·알려진 위협·자기 잔존 전력/무기 가용을 검사하는 후보를 권고한다. 신뢰도/위협이 불명확하면 낮은 HP라 가정하지 않는다. 최대 추격반경·유지시간·재평가 주기·지원 규모·위협 허용값은 **측정 전 후보/O03·후속 실험**이며 새 수치를 만들지 않는다.

**전군 쏠림 방지:** 거점별 필수 수비/가용 예비·지원 배정·수락 상태를 임무 관점에서 구별한다. 한 요청을 모든 함대가 독립 수락하지 않도록 지원 배정자가 가용 역할·우선순위·이동비용을 대조하고 유한한 배정 결과를 기록하는 안을 권고한다. 임무 수락/취소·순서 동점은 안정 ID로 재현하되 게임 경험을 바꾸는 자원 배정 수치는 D09 실험 전 후보다. 수비를 잃을 정도의 재배치는 명시적 임무 변경이어야 하며 전술 `_focus`가 전군 이동을 지시하지 않는다.

## 3. 임무별 상태 계약 — R06

### M01 순찰

- **목표·접촉 전:** 지정 항로/경유지를 왕복하며 J/A/B 주변 접근을 감시한다. 플레이어가 오지 않아도 일정/경유 진행. 거점 통제권 확보나 새 적 전멸이 자동 목표가 아님.
- **접촉 반응:** 확인은 보고하고 허용 교전 판단. 추정은 마지막 위치/오차영역에 안전한 확인 기동을 검토. 상실은 실제 좌표로 추격하지 않고 제한된 마지막 관측 확인 후 경유 임무 복귀.
- **유지·추격·우선순위:** 다음 경유/복귀 지점과 순찰 임무의 커버리지를 보존하는 범위만 추격. 약한 미끼를 보고 A 수비 범위를 넘어 끝까지 추격하지 않음. 표적 교체도 추격 예산을 무한 초기화하지 않음.
- **지원·퇴각·재계획:** 자기 손상/무기 가용·관측된 위협으로 불리하면 아는 아군 수비/안전지점까지 실제 경로로 이탈하며 보고. 지원 요청은 알려진 위험/마지막 위치·시각 포함. 복귀 경로가 막히면 유효 대체 경로/대기·재평가. 적의 미탐지 우회 위치를 사용하지 않음.
- **완료/연계:** 순찰 지속/교대/상급 취소로 상태 종료. 적 하나 격파가 작전 종료를 뜻하지 않음. 순찰 경유·추격 소비·보고는 ST13/14 요청.

### M02 거점 수비

- **목표·접촉 전:** 맡은 A/B/C/D와 접근/서비스 구역을 지킨다. 허용 범위 안의 진형·감시 위치를 유지하고 모든 수비가 접촉 전 Idle인 것으로 표현하지 않음.
- **접촉 반응:** 확인 위협은 거점 위협/접근 시간을 평가해 요격, 추정은 거점 내부/접근로의 확인 배치, 상실은 마지막 위치 경계와 본래 방어로 복귀. 추정 항적 하나가 시설 포기를 정당화하지 않음.
- **유지·추격·우선순위:** 시설 접근을 막을 수 있는 유효 복귀 경로와 최소 수비 역할을 먼저 보존. 관측된 보급 역할/약한 전력 가중보다 거점 보호 우선. 고정 반경 밖 미끼를 따라 전원 이탈하지 않음.
- **지원·퇴각·재계획:** 알려진 다축 공격에 가용 예비 지원 요청. 감당 불가 시 지역 안전지점/후위 방어 후보로 이동하되 무적 버티기·자살 돌격을 강제하지 않음. 시설 상실을 실제로 보고받으면 지연/봉쇄/재점령 지원 등 임무 변경을 요청하며 소유권을 자체 조작하지 않음.
- **완료/연계:** 교대·시설 상실 보고·명시 임무 변경/취소. 수비대 패퇴=즉시 점령은 아님(D06). 최소 수비 규모·추격 폭은 미정.

### M03 호송

- **목표·접촉 전:** 화물과 호송 구성 함대가 지정 목적지로 이동. 출발 일정/예비 항로/배송 조건은 D08이 소유하고 D07이 화물 재고 효과를 소유. 플레이어 단계 완료를 기다리지 않음.
- **접촉 반응:** 확인 위협이 알려진 항로를 막으면 엄호 요청·허용 대체 경로/대기/이탈 검토. 추정은 불확실성 반영한 경로 확인, 상실은 마지막 위험 구역을 경계하며 유효 경로로 진행. 상실 순간 실제 적 위치가 없는 ‘최단 안전길’을 계산하지 않음.
- **유지·추격·우선순위:** 화물의 목적지/보존을 전술 표적 격파보다 우선. 화물은 미끼를 추격하지 않고 엄호 함대도 화물에서 분리/복귀 가능한 범위만 요격. 호송과 화물에 같은 돌격 명령을 일괄 발행하지 않음.
- **지원·퇴각·재계획:** 엄호가 부족하거나 알려진 봉쇄가 강하면 진행 강제 대신 대기/허용 우회/지역 이탈 후보. 경로 변경 횟수·출발과 상실의 같은 틱·목적지 점령 변경은 D08 미정이므로 D05가 우회를 반복 승인하지 않음.
- **완료/연계:** 도착 판정 후 D08/D07의 배송 전이 요청만 보내고 임무 계층에서 재고를 지급하지 않음. 화물 상실/취소 시 결과 보고. 접촉 목록에 노출된 역할만으로 적의 실제 남은 화물량을 알 수 없음.

### M04 구원·예비

- **목표·접촉 전:** 예비는 지정 집결/중요 목표를 유지한다. 외부 구원은 D08의 출발→R 진입 이후 목표로 실제 이동. ‘예비 가용’과 ‘아직 지도에 없는 예약 증원’을 구분해 이중 배정하지 않음.
- **접촉 반응:** 확인/시각 있는 지원 보고·자기 시설 상실 보고로 대상 검토. 추정 위협은 곧바로 전군 파견하지 않고 확인/제한 지원. 상실 보고만 남으면 지원 목적·도착까지 남는 필요를 재평가.
- **유지·추격·우선순위:** 배정받은 수비 구원/길목 확보가 근처 약한 적 추격보다 우선. 임무가 바뀌지 않으면 도중 미끼에 전체 이탈하지 않음. 남겨야 할 예비/수비 역할과 지원 수락을 기록.
- **지원·퇴각·재계획:** 요청 중복은 요청 ID/대상/보고 버전으로 정리. 대상이 이미 안전/상실됐거나 접근 불가면 복귀/새 지원 배정을 요청하고 알아서 모든 다른 적을 추격하지 않음. 열세 시 집결/지원 대기, 무조건적인 목표 정면 돌파는 금지 후보.
- **완료/연계:** 현지 도착만으로 구원 성공이라 하지 않고 수비 임무 인계/위협 해소/취소를 구분. 실제 출발/진입 지연·편성 생성은 D08 소유.

### M05 재점령

- **목표·접촉 전:** 보고된 상실 거점/확인된 적 통제 시설 중 작전 가치·접근비용·가용 역할로 후보를 선택하고 실제 항로로 접근. 적이 차지한 정확한 재고량·숨은 방어 병력을 읽지 않음.
- **접촉 반응:** 확인 수비는 알려진 전력 구간·접근 상황으로 평가. 추정이면 접근 정찰/봉쇄 위치 검토, 상실이면 마지막 위협/거점 보고 시각으로 재평가. 거점 도착 시 정보를 갱신하고 예상대로 비어 있다고 가정하지 않음.
- **유지·추격·우선순위:** 대상 거점 압박이 목적. 보급함/약한 함대가 보이더라도 허용 접근/복귀 범위 밖으로 전군 추격하지 않음. 현재 공격이 어려우면 항로 압박/지원 대기가 대안이며 매 틱 순간적인 취약 표적으로 목표를 바꾸지 않음.
- **지원·퇴각·재계획:** 관측된 수비가 강하거나 경로가 위험하면 봉쇄/구원 요청·집결. 대상 상실 보고가 취소/갱신되거나 접근 불능이면 유지시간·전환 사유를 기록해 재계획. 추격 대상 변경이 재계획 대기/예산을 무한 리셋하지 않음.
- **완료/연계:** 거점 반경 진입은 점령 완료가 아님. 경합/수비 무력화/점령/가동·재상실 진행은 D06이 판정, 공급원 소유/유한 재고는 D07. 임무는 그 상태 보고를 읽어 완료/주둔 전환 요청만 수행.

### I02 공유와 사격·지형 단계

- 같은 진영의 공유 관측은 다른 관측자의 확인/추정 기록을 임무에 전달할 수 있다. **알게 됨**과 **사격자가 쏠 수 있음**을 분리하여 사거리·사격선·공개 접촉/오차·무기 가용을 코어에서 다시 판정한다.
- H1 기본 단계는 기존 효과 구역이다. 성운의 센서/은폐·감속 효과를 물리 벽/무적으로 바꾸지 않는다. `Detection.in_view()`는 현재 거리/진형외곽 기반이며 본체 차폐가 이미 붙었다고 하지 않는다.
- 후속 본체 비교에서는 직접 가시 경로·점수 탐지·공유 관측·직접/진행 공격의 차폐가 같은 코어 경계를 따라야 한다. 다른 아군이 보더라도 벽 너머 사격은 안 된다. 임무 AI는 사격 가능한 유효 위치를 찾되 숨은 표적의 실제 좌표를 사용하지 않는다.
- 거점 수비/추격 범위의 미리보기는 실제 명령 가능한 공간 계약을 읽으며 시각 충돌체만 따로 적용하지 않는다. 지형/관측 계약이 서로 모순되면 해당 임무 확정은 중단하고 R06/R07·O03의 영향으로 반환한다.

**기존 문서와 차이 C05-01:** S1 §6.6의 ‘확인된 적’은 현재 `Detection.can_target`의 확인/추정 허용 및 CommanderAi의 신뢰도 필터보다 단순하다. D05는 기존 추정 사격 가능성을 전역에서 제거하지 않는 후보를 권고한다. 임무는 추정 기록/오차/신뢰도만 사용하고 실제 명중·허용 여부는 기존 무기/탐지 판정이 결정한다. 상실에는 사격하지 않는다. 확인만 허용하는 새 모드는 게임 경험 변경이므로 별도 사용자 정책 채택 없이는 추가하지 않는다.

## 5. 정보 정책 패킷·미정 수치

**게임 경험에 영향을 주는 선택 한 묶음(IP1):** (권고) 자기 시설 통제 상실은 알려주고 상대/중립의 소유·재고는 관측/마지막 확인으로 제한하며, 본대 예고 같은 필수 공지는 별도 공개한다. 대안은 모든 시설 소유를 항상 공개하되 재고/함대는 탐지로 제한하는 방식이다. 전자는 정찰·재점령의 불확실성을 살리지만 보고/오래된 표시가 필요하고, 후자는 상황 파악이 쉽지만 상대 목표 선택의 정보가 더 많이 열린다. **현재 미선택**이며 D05 자체 구현 규칙으로 확정하지 않는다. 어느 안도 상대 HP/재고/실제 좌표의 무조건 접근을 허용하지 않는다.

추격반경·반응/재계획 주기·지원 역할 수/잔류 수비·확인 기동 예산·위협 평가 가중은 기존 프로필과 비교하는 실험 후보이며 사용자에게 숫자별 결정을 요청하지 않는다. 의미/단위·관측 항목을 먼저 정의하고 후속 승인 실험에서 조정한다. 반면 임무를 무조건 포기하는 행동·완전 공개 지도처럼 경험을 바꾸는 정책은 위 결정 패킷으로 분리한다. H0/H1 범위를 다시 묻지 않는다.

**지역 이탈:** D06 실행자와 메시지로 교환한 후보는 같은 함대가 지도 안 안전지점까지 실제 이동하는 `safety_withdrawal`이며 `out=escaped/dead`를 재사용하지 않는다. ID·손상·탄약·사기를 유지하고 집결로 무적/순간이동/자동회복을 부여하지 않는다. E를 통한 작전 탈출은 D06/D08의 별도 결과다. 재투입 자격·회복량/비용·강제 이탈 우선순위는 D06/D07 미정이며 D05가 승인하지 않는다.
