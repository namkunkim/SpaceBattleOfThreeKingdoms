## 2. 추상 지도·항로·후방 압박 — R04

단위는 실제 광년/천문 거리 대신 **전술 좌표 단위**다. 장식 천체의 시각 크기와 전술 충돌 단면은 구분하되 실제 차단 경계는 화면·미니맵에서 일치시킨다. 편제는 S4 Q73~Q76의 **함대**이며 ‘그룹’은 함대들의 명령 묶음 후보다. 정찰은 기존 함대 편성/탐지를 활용하며 별도 정찰 전대를 신설하지 않는다.

**그래프 G-OP1 후보:** 노드 7개 = 시설 4개 + 출입점 2개 + 분기점 1개. 모두 점령 거점인 것은 아니다. 노드 수/정확한 배치는 H0에서 확정되지 않았다.

| 노드 | 유형 | 역할과 접근 조건의 검토 |
|---|---|---|
| E | 아군 진입/탈출점 | 초기 배치·회항 종점. 점령/가동 시설 아님. 지도 밖 이탈은 D06 종료 계약과 연결 |
| J | 항로 분기점 | 정면/우회 선택·재합류의 기준. 시설/재고/점령 상태 없음 |
| A | 정면 보급 시설/행성 | 수비 무력화·점령·가동·보급의 후보 위치. 짧은 진출과 전투 부담의 교환 |
| B | 우회 보급 시설/행성 | 다른 보급 조합·D 접근을 제공하는 후보. ‘약한 수비’가 필승/무손실을 뜻하지 않음 |

| R | 적 증원 진입점 | 외곽의 유효 배치 영역. 예정/출발과 지도 진입/목표 도착을 분리. 점령 시설 아님 |

**후보 항로 9개:** `E–J`, `J–A`, `A–C`, `J–B`, `B–D`, `D–C`, `A–B`, `R–C`, `R–D`.

- 정면 경로 `E–J–A–C`, 우회 경로 `E–J–B–D–C`. D를 지나기 위해 D 점령을 강제하지 않는다. D 점령 여부와 우회 통행 가능 여부를 분리한다.
- A–B는 보급 거점 간 회항·전력 합류·후방 방어 이동을 제공한다. D–B–A와 C–A 경유로 적 재점령 부대도 실제 접근할 수 있다. 최단 경로가 항상 동일한 거점을 공격하게 되는지는 D05/D08에서 알려진 정보·임무로 검토한다.
- R–C/R–D의 진입 방향 차이가 전방 구원과 후방 우회를 만든다. R은 A/B/E와 같은 위치에 두지 않는다. R 진입 후 B/A로 접근하는 구간과 아군의 회항 구간을 모두 측정하여 ‘등장 즉시 보급소 타격’이 되지 않게 한다.
- 호송은 A–C 및 A 상실 시의 R–C 예비 경로를 S1 후보로 검토한다. 경로 변경 조건/횟수는 D08 소유이며 본 문서가 확정하지 않는다. 호송 이동은 아군 점령 완료를 기다리는 단계 타이머가 아니다.
- 항로는 공개 지형상의 **이동 회랑 후보**이며 노드 소유권만으로 통행을 잠그지 않는 안을 권고한다. 적 수비·차폐·교전 위험과 이동 불가 본체를 구분한다. 공급 연결은 D07의 별도 통제/차단 판정이며 ‘선이 그어짐=안전한 보급’으로 계산하지 않는다.
- 초기 배치·R 진입 영역에는 대상 최대 진형이 들어가야 하며 인접 경로도 열려 있어야 한다. 적이 입구를 차단한 경우의 배치 대기/위치 선택은 D08 미정이다. 충돌 무시·무적 생성·갑작스런 위치 보정은 암묵적으로 추가하지 않는다.

**배치 대안:** G-OP1처럼 D를 우회로의 경유 위치로 두면 D 위협과 우회 이동이 연계된다. 별도 가지로 D를 배치하면 통신소 방문의 추가 이동비가 뚜렷하지만 노드/항로 재검토가 필요하다. 첫 좌표 설계는 G-OP1을 권고하며 D 시설 반경 밖으로 지나 C에 갈 수 있어야 한다. 그래프는 연결성 가설이지 물리 통행/목표 완주를 보장한 결과가 아니다.

## 3. 시계·시간 예산·ETA — R03

| 시간·단위 | 정의 후보 | 사용하는 곳/한계 |
|---|---|---|
| 게임 시각 `Tg` [시뮬레이션 초] | 실제 수행된 논리 하위걸음의 누적 시간. 일시정지는 논리 진행을 멈추고 배속은 실제 시간당 처리량을 변경 | 호송/증원·점령·보급·이동의 단일 권위 시계 후보. 브리핑/메뉴·로그/렌더 프레임/벽시계로 진행하지 않음 |
| 정지 제외 실제 경과 `Ta` [실제 초] | 작전 플레이 세션에서 시뮬레이션 진행 상태였던 실제 구간 합 | 성능 저하/배속·생각하는 시간이 반영됨. 게임 결과를 바꾸는 입력이 아님 |
| 정지 시간 `Tp` [실제 초] | 같은 측정 경계 안의 일시정지 구간 합 | 명령 검토/정지 사용 기록. 브리핑/메뉴 포함 여부는 별도 태그로 기록 |
| 정지 포함 총 경과 `Ttotal` [실제 초] | 동일 플레이 측정 경계의 `Ta+Tp` | 플레이 시작→결산의 세션 시간. 로딩·브리핑·메뉴·앱 이탈은 별도 로그로 분리하며 추후 D09 수용 기준에 경계 명시 |
| 배속별 체류 `T(speed)` [실제 초] | 진행 중 배속 구간별 실제 체류 합 | `ΣT(speed)=Ta`. 일시정지는 별도 Tp. 로딩/오프라인은 포함하지 않음 |

고정 dt 값은 미래 기준 프로필에 명시하며 과거 실험 10Hz를 신규 규칙 확정으로 쓰지 않는다. **현재 코드 정적 대조:** `core/battle/battle_sim.gd:923~951`은 바깥 tick을 먼저 증가시키고 dt를 하위걸음으로 나눈 뒤 실제 수행마다 clock_ms를 증가시키며, 조기 종료 시 나머지 하위걸음을 수행하지 않는다. 따라서 `Tg=바깥 tick×고정 dt`만으로 복원하는 계약은 채택하지 않는다. 정수 ms 누적/하위걸음 반올림·저장 커밋 경계와 tick의 정본/파생 관계는 D04/O07/H1에서 대조해 확정한다. 신규 실행 결과가 아닌 코드 읽기 근거다. 성능이 충분하고 배속 전환 경계가 정렬된 이상적 경우에만 `ΔTg ≈ Σ speed×T(speed)`로 교차 점검할 수 있다. 처리 지연이 있으면 수행된 논리 시간 합을 권위로 삼으며 시뮬레이션을 벽시계에 억지로 맞춰 사건을 건너뛰지 않는다. 저장 후 오프라인 시간을 증원 경과로 더하지 않는 안을 권고한다. 저장/재생 지원 범위는 D04/O07 소유다.

**20분 후보 예산:** S2 §4.1의 `2+3+3+3+2+5+2=20` 시뮬레이션 분을 재계산한 설계 예산이며 단계 최소 대기시간이 아니다.

| 활동 | 후보 게임 분 | 병행·관측할 것 |
|---|---:|---|
| 정찰·항로 판단 | 2 | 이동과 항적 관측을 병행. 첫 정보/첫 선택 시각 |
| 교전 밖 이동 | 3 | 순수 대기와 재배치 판단을 구분 |
| 전초 거점 조우전 | 3 | 다른 그룹의 정찰/우회가 동시에 가능한가 |
| 점령·보급·정비 | 3 | 점령 뒤 공급 가능/함대별 대기/호송 추격 병행 |
| 선택 임무·주공 재배치 | 2 | D 확보·호송 차단·후방 대응의 기회비용 |
| 최종 공방·점령 | 5 | 중간 교전과 별도 전투 10분을 추가하지 않음 |
| 대응 여유 | 2 | 증원 대응·회항·실수 복구 |

위 합은 설명을 위한 직렬 배분이다. 실제 총 게임시간은 활동 구간의 합집합/임계 경로이므로 병행을 이중 합산하지 않는다. 보급이 3분 지나야 끝나는 규칙이 아니며 주목표 달성은 즉시 판정할 수 있어야 한다. 증원 전에 반드시 20분을 채우거나 숙련자의 성공을 기다리게 하지 않는다. 사건 시각·결산 시한은 D06/D08 미정이며 예산과 자동으로 같게 놓지 않는다.

**O01/H1 시간기준 대안:** (P1 권고) 우선 ‘시뮬레이션 20분 전후’를 비교용 가설로 사용하고 실제 경과·정지·배속·유휴를 별도 측정한다. (P2) ‘실제 PC 20분 전후’ 경험을 우선 목표로 두되 증원은 여전히 게임 틱 시계로 돌리고 허용 배속/정지 및 표준 측정 조건을 먼저 정한다. P2에서도 벽시계 증원으로 바꾸지 않는다. P1은 결정론/사건 설계를 단순하게 비교할 수 있지만 실제 플레이가 길어질 수 있고, P2는 체감 길이를 직접 다루지만 같은 게임시간의 서로 다른 정지 습관을 어떻게 비교할지 D09에서 먼저 정해야 한다. **둘 다 미선택**, 목표 범위/표본은 O01/O08이다.

**ETA 계약 후보:** 아군 선택 함대의 알려진 편성·현재 진형·유효 경로 길이·선회/효과 구역 비용·현재 속도로 게임 초 ETA를 계산한다. 선회·재탐색·교전 정지·보급 대기가 빠졌으면 ‘근사/이동만’ 표시하고 서비스 완료 ETA와 분리한다. 그룹 ETA는 함대별 값 또는 마지막 함대 도착 추정으로 표시하여 선두 도착을 전체 도착으로 쓰지 않는다. 실제 초 변환은 현재 배속을 가정한 참고치다. 적 ETA는 공지 일정과 마지막 관측/추정만 사용하고 미탐지 실제 좌표·속도·재고를 읽지 않는다. D 확보 후 일정 UI 갱신 원천은 D08 사건 상태이며 별도 UI 타이머를 두지 않는다.

## 4. 진형 외곽·서비스 접근·치수 측정 — R04/O03

S4 Q5/Q73~Q76의 함대 단위, Q82/Q83 최신 보충의 역할별 편성·비용 기준으로 측정해야 한다. D01 §1 G07이 지적한 실험 후 편성 변화를 반영한다. 과거 척수 추정·원래 배치의 비례 확대 결과·6800×4600/이동배율30만으로 통행을 판정하지 않는다. 현재 미커밋 `bundle_layout.gd` 등은 소유 미확인이므로 무단 수정/통합하지 않는다.

**기하 권고:** `R_form`은 함대 중심에서 모든 **논리 함선 외곽**까지의 보수적 반경이다. 화면상 생략 함선·선체 반폭·진형 전환/회전 과정·느슨한 진형·함대 간 분리 보정을 포함한다. 장식 메시의 꼬리/광원과 논리 경계를 혼동하지 않는다. 원형 외곽을 우선 후보로 쓰되 너무 보수적으로 통로를 막으면 방향별 외곽 대안과 비용을 비교한다. R 진입점과 기호가 겹치지 않도록 반경은 R_form으로 표기한다.

| 측정 대상 | 미래 측정 방법·합격 근거 | 미정/차단 |
|---|---|---|
| 운용 편성/진형 외곽 | 최신 기준 커밋·프로필·함대별 구성/척수·비용·진형 버전을 기록. 모든 허용 진형/자세의 외곽과 전환 중 최대를 산출 | O03: 숫자 반경 확정 전 필요. 보이는 소수 함선 반경만 측정 금지 |

통행 유지 후보는 S6의 `최소 폭 ≥ 2×(R_form+safety)+additional_clearance`와 두 함대 폭 합을 출발식으로 사용하되 숫자를 새 확정으로 만들지 않는다. 병행 통행을 지원하지 않는 곳은 대기/양보가 가능해야 하며 막연히 폭만 합쳐 완료라고 하지 않는다. 진형을 줄이면 필수 목표에 도달하는 안은 사용자에게 전환 가능 위치·기회비용을 보여야 한다. **최대 운용 진형으로 필수 경로 하나 이상 확보**를 우선하고, 강제 자동 진형 변경·함선 분리·순간 이동으로 통행 실패를 감추지 않는다.

O03는 현재 **OPEN**이다. 실제 측정이 필요한 맵 크기·폭·좌표·속도 확정은 중단하고 위 측정/배치 계약까지만 인계한다. 미래 승인 측정에서 막히면 장애물 위치·크기/시설 위치/입구 폭부터 조정하며 현재 문서가 통행 성공을 주장하지 않는다.

## 5. 지형 판정의 세 층과 도입 대안 — R05

권위 판정은 렌더 물리와 별개인 코어 데이터에서 읽고 UI·미니맵·수동/AI·후퇴·돌격·집결·보급 복귀·증원 배치가 공유해야 한다. 경로 탐색 알고리즘/격자·동점 순서·epsilon은 후보 구현 스펙에서 고정한다. 사용자 경유점 수와 내부 우회 노드 수를 구분한다. 유효 경로가 없으면 사유를 표시하고 기존 유효 명령을 유지하는 후보이며 아직 게임에 구현되지 않았다.

| 지형 층/예 | 이동·퇴각 | 사격·지속 공격 | 탐지 | 상태/도입 후보 |
|---|---|---|---|---|
| 효과 구역: 성운·성긴 잔해·그림자 | 통과·기존 비용 | 기존 사거리/사격각 보정 | 센서/은폐 보정 | D01 확인 기반. 개수/배치가 적절한지는 미측정 |
| 물리 본체: 행성 단면·밀집 암반·난파선 | 전부 차단·외곽 포함 우회 | 모든 병기의 직선 차단 | 본체 관통 직접 관측 차단 | 신규 코어·미구현. 배경 행성과 효과 그림자 구분 |
| 병기 제한: 이온화 먼지 | 통과 후보 | beam 태그 차단, 다른 태그는 별도 판정 | 자동 탐지 차단으로 간주하지 않음 | S7 독자 후보. artillery 역할 전체를 레이저로 분류 금지 |
| 병기 제한: 유도 교란 | 통과 후보 | guided 제한 후보 | 별도 센서 정책 | 레이저 차단과 별개. 모든 무기 일괄 약화로 뭉치지 않음 |
| 강습 전용 효과 구역 | 일반 이동/퇴각 허용 | 원거리 금지, 자격/유효경로/사거리 만족 강습만 후보 | 별도 정책 | 신규·후속 비교. 돌격 이동=강습 공격으로 혼동 금지 |

공통 반례 계약:

- 물리 본체는 미사일·함재기·돌격·강습에도 관통 불가. 실제 우회 비행 시스템을 별도 구현하기 전 직선 공격 허용으로 엄폐를 무효화하지 않는다. 진행 중 공격도 피해 틱마다 차폐 재검사하는 S6 후보를 권고하며 소모 자원 환급/복귀 정책은 해당 기능 계약으로 명시한다.
- 공유 탐지는 관측자의 차단 없는 관측을 제공할 수 있지만 공격자의 막힌 사격선을 열지 않는다. 직접 가시 경로도 차폐를 확인해야 한다(D01 탐지 정적 근거). 차폐 뒤 표적은 기존 마지막 접촉/추정 만료로 처리하며 AI가 숨은 위치를 읽어 우회하지 않는다. 특기 공개 예외는 D05와 기존 규칙 충돌 검토 후 명시한다.
- 본체와 효과 구역이 겹치면 본체 차단을 먼저 적용하며, 병기 허용 구역이 다른 금지 조건을 무효화하지 않는 후보를 권고한다. 선분·공격자/표적·경계의 검사 범위는 공통 데이터로 명시한다.
- 공격 AI는 차폐 뒤에서 반복 사격하지 않고 알려진 적에 대해 유효 경로/사격 위치를 검토한다. 수비 거점 유지/추격 제한은 D05 소유다. 지형만 넣으면 적 임무 문제가 해결된다고 주장하지 않는다.

**식별자 충돌 방지:** S2의 T0~T4는 제작 단계, S7의 T0~T4는 비교군이다. D03은 어느 쪽도 덮어쓰지 않고 `SPACE-BASE`, `SPACE-BODY`, `SPACE-WEAPON`, `SPACE-ASSAULT`, `SPACE-TAG`라는 문서 후보 이름을 사용한다. 원본 T ID를 실행 데이터에 새 의미로 재사용하지 않는다.

**O03/H1 도입 대안:** (S-A 권고) 효과 구역으로 작전 기본 루프를 먼저 구현할 후속 분해를 만들고, 본체 1~2개와 우회/탐지/사격 차폐를 별도 비교 후 추가한다. 병기/강습/태그 제한은 선택 비교 단계다. (S-B) 처음부터 최소 본체 차폐까지 공간 기반의 수용 조건으로 둔다. S-A는 임무·점령/보급과 물리 지형 실패 원인을 나누기 쉽지만 초기 항로 분기가 물리적으로 강제되지 않을 수 있다. S-B는 항로/엄폐를 일찍 확인하지만 경로·직접 탐지·지속 공격·AI/표시까지 모두 선행된다. **둘 다 사용자 미선택**이며 확장 호송/통신소/재점령을 설계에서 제외하는 안은 아니다. 어느 안도 6장애물·10효과 구역 또는 모든 특수 지형을 첫 샘플 필수로 만들지 않는다.

## 6. Q67 적용 범위와 회귀 게이트 — R17

S4 Q67(결정 기록 665·681행, S-1 D7 779행)과 D01 §5를 대조했다. 신규 종류 활성화 전 **차이 목록 B항 등재+1000시드 재측정**은 적용 시 유지할 기존 게이트다. O08의 새 표본 미정으로 대체하지 않는다.

|---|---|---|

**적용/비적용 결정이 남는 이유:** 실제 변경 파일·프로필 활성 경계는 아직 구현하지 않았다. O03의 H1 지형 선택 뒤 구현 스펙에서 범위를 다시 대조한다. 범위 밖 근거를 기록하지 못하면 면제로 진행하지 않는다. PC 과거 15판은 1000시드 충족이 아니다.

기존 적벽 기본3구역·승패/사기·화공 접근, 기존 명령 재생의 경로/탐지/피해 지문, 코어와 화면/미니맵 경계, PC 성능·태블릿 적용 범위가 회귀 영향 목록이다. 전장 밖 코어 변경은 PC 전용 표시와 달리 태블릿 계산에도 영향을 줄 수 있다. 구현 직전 O06의 최신 커밋·PC diff·미커밋 소유/청결·실제 통합 가능성을 재확인해야 하며 이 문서가 병합을 승인하지 않는다.

**D04에 요청한 상태 슬롯 후보:** 작전 틱/고정 dt/규칙 버전, 정적 맵/기하·진형·통행/병기태그 버전, 함대 위치/진형·경로/경유점/명령·재계산 기준, 시설/출입점 역할, 알려진 접촉 last_seen, 사건의 예정/출발/진입/목표접근과 D 지연 적용 여부. 경로 캐시 저장 또는 결정론 재계산 선택은 D04/O07 소유다. 실제시간/배속체류는 평가 로그로 분리하며 게임 판정 시계로 쓰지 않는다. 메시지로 전달했으며 D04 파일을 수정하지 않았다.

D05에는 항로·공개 지형·차폐/공유 관측과 사격선 분리 후보를, D06/D07에는 필수 목표/보급/E 접근과 반경 미정·공급 연결 분리 요구를, D08에는 R 진입/목표 접근 경로·실제시간과 구별한 사건 시계를, D09에는 ETA의 근사 항목·정지/배속/대기/판단 측정 후보를 인계한다. 정책 충돌은 해당 문서 소유자에게 반환하고 D10이 교차 색인한다.

**H1에 제시할 최소 질문 패킷:** 시간은 P1(게임20분 가설+실제 로그) 또는 P2(실제20분 경험+측정조건 우선), 지형은 S-A(효과 기반 작전 후 본체 비교) 또는 S-B(초기부터 최소 본체 차폐)다. 권고는 P1+S-A이며 20분/노드/속도/좌표·특수지형의 숫자 승인은 포함하지 않는다. 선택에 따라 시간 실험의 기준과 공간기반의 필수 선행 기능이 달라진다. D04/O07와 후속 O04/O05/O08 미정도 유지한다.

자체 5-a 1차 검사 완료: PowerShell 문서 정규식 검사에서 R03/R04/R05/R17/O01/O03 판정표 각1행, 노드7(시설4/출입2/분기1)·항로9, 예산 `2+3+3+3+2+5+2=20`분, 참조 MD 누락0개를 확인했다. 정지/배속·O07·조기 종료, 지형 후보 식별자5개·B항/1000시드·미실행/OPEN 문구도 존재했다. 원문 대조에서 바깥tick×dt 복원 가정을 하위걸음 누적 시간으로 보강했다. 이번 실행자는 지정 D03만 작성했고 게임 테스트는 실행하지 않았다. 실패 ID 없음. **5-a는 독립 정확성 승인과 다르다.**

## 9. H1 최신 사용자 선택 — 2026-10-25
