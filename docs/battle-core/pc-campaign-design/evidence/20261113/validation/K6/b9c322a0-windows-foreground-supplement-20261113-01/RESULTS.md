# K6 Windows 보조 실입력 결과

`b9c322a0`의 Windows 패키지를 새 격리 프로필에서 실행했다. 게임 클라이언트는 1600×900이었다. [실행 기록](launch.json) · [Godot 엔진 로그](engine.log)

| 실입력 | 화면 관찰 |
| --- | --- |
| 타이틀 → 서사 건너뛰기 → 적벽 → 출격 | C0에서 두 차례 틱 0을 확인했다. 각 회차에서 시작 클릭 후 틱 1을 확인하고 Return to map으로 결산 없이 돌아왔다. |
| 공개 개요 → 적벽 모의전 → 기존 카드 → 표준 자동 | 시작·건너뛰기·Stop을 두 차례 실행했다. 각 회차가 기존 카드로 돌아왔다. |
| 세 번째 표준 자동 실행 | 종료까지 진행해 조조 승리, 20분, seed 18210을 확인했다. seed는 일반 실행에서 나온 값이다. |
| Alt+F4 | 창이 닫혔고 사후 조회에서 기록된 PID 27796이 없었다. 종료 코드는 수집하지 않았다. |

종료 후 런타임 EXE와 O07 DLL의 SHA-256은 실행 기록과 일치했다. 격리 프로필에는 GLES 셰이더 캐시 6개만 남아 있었고 저장 슬롯, 결산 원장, 이전 세대 및 임시 저장 파일은 발견되지 않았다. 엔진 로그에서 EntryBoot 리소스 로드와 Godot 4.7.2를 확인했다. ERROR, WARNING, orphan, leak 검색 결과는 0건이었다. 표의 조작과 결과는 화면 관찰 기록에 근거한다.

이 증거는 현재 제품 패키지의 보조 실입력에 한정한다. 과거 고정 seed 재현과 K6 정식 실행의 전후 비교는 별도 판정이 필요하다.
