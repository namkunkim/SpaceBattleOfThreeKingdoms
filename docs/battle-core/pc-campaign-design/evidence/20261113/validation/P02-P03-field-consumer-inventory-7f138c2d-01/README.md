## 작전 간에 남은 검증

- 위 계약에서 ID는 단일 작전의 복원·리플레이에 쓰인다. 다음 작전의 공통 입력과 C0를 어떤 권한 있는 결과에서 생성하는지, 이전 정산의 어떤 상태 필드를 어떤 형태로 넘기는지, 어느 운영 Cn에서 인계가 성립하는지는 위 실행에서 확인되지 않았다.
- 한 작전의 적용·대기 prefix와 제한 호스트의 연속 순번은 확인했다. 여러 작전에 걸친 순번의 소유자와 범위, 다음 작전에서 이어받을 명령의 경계, 재개·재시도 때 중복 적용 방지의 기대값과 관측 근거가 남아 있다.
- 일반 운영 완료에는 공개 외부 저장과 독립 다중 호스트 검증도 남아 있다. 기존 차단 시험은 체크리스트의 지시대로 재실행하지 않았다.
