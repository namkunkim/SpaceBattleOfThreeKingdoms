Windows 검증 기록에는 실행 결과, 관련 화면 및 판정에 사용한 파일을 담았다. 파일 목록은 원본과 저장소 사본의 SHA-256을 각각 기록한다. 일부 사본은 로컬 경로를 가리고 Markdown 링크를 저장소 기준으로 바꿨다. 보고서에 언급된 원본 실행 폴더에는 추가 로그와 실행 산출물이 보존되어 있다.

각 기록의 실행 기준과 판정 범위는 해당 보고서를 따른다. 과거 빌드의 결과는 현재 Windows 인수 상태를 갱신하지 않는다. 남은 항목은 [캠페인 적용 체크리스트](../../SESSION-REQUIREMENTS-CHECKLIST-20261031.md)에 기록한다.
