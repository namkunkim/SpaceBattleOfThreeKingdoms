# Cross Counter 공개 슬롯 대기 명령 복원

Windows 한 대의 새 격리 프로필에서 Godot 4.7.2 헤드리스로 EntryBoot, 적벽 결과 지도, 공개 Cross Counter 호스트와 실제 네이티브 저장 슬롯을 실행했다. 소비 처리된 적벽 목표 달성 결산의 검토된 사본만 사용했다. 시험은 공개 컨트롤의 신호를 호출하고 자동 처리를 멈춰 논리 틱을 직접 진행했다.

| 별도 실행 단계 | 확인 |
| --- | --- |
| 닫기와 재시도 | 16틱에서 지도 클릭으로 이동, 정지 버튼으로 정지를 대기열에 넣었다. 백업 경로를 디렉터리로 만들어 정상 닫기 저장이 실패하도록 했을 때 이전 슬롯 바이트, 소유권과 두 대기 명령이 유지됐다. 방해 요소를 제거한 뒤 저장 재시도로 정확한 패킷을 슬롯에 기록하고 종료했다. |
| 첫 재시작 | 같은 작전의 라이브 패킷 전체가 저장 패킷과 일치했다. 대기 명령 및 사건 커서를 확인했다. 17틱에 두 명령이 순서대로 한 번씩 적용됐고, 18틱에서 명령 이력과 네이티브 명령 로그가 그대로였다. 적용된 이력을 공개 저장으로 기록했다. |
| 두 번째 재시작 | 18틱에 저장한 패킷과 빈 대기열을 복원했다. 19틱까지 명령이 재적용되지 않았다. 포기 결산, 지도 복귀, 과거 결산 재열기를 확인했다. |

세 단계 28/28. 원본 부모 결산과 격리 사본의 SHA-256은 모든 단계에서 일치했다. 테스트 소스·엔진·부모 SHA-256, 프로세스별 결과 및 진단은 [실행 기록](run.json)에 있다.
