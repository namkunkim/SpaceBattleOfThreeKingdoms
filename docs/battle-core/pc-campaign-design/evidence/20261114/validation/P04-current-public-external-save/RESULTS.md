# P04 현재 공개 외부 저장 집중 회귀

Windows 격리 헤드리스 실행에서 현재 적벽 v1 공개 경로를 따라 들어가 외부 저장 상태 지문 회귀 **37/37**을 통과했다. [테스트 경로 수정 PR #85](https://github.com/namkunkim/SpaceBattleOfThreeKingdoms/pull/85) · [집중 실행 기록](focused-result.json)

기존 시험은 서사를 건너뛴 뒤 이전의 적벽 버튼을 기다렸다. 현재 경로인 준비 화면의 이어하기, 천하 지도 브리핑, 첫 작전 정면 출격을 사용하도록 시험 진입부를 갱신했다. 제품 코드 및 외부 저장 검증 본문은 변경하지 않았다.

체크섬이 유효한 변조 후보를 격리 재생 후 상태 지문 검증에서 거부했다. 활성 소유자·브리프·체크포인트·버튼과 보호 파일 네 개가 유지됐다. 같은 호스트에서 정상 파일을 다시 불러와 소비 사건을 다시 게시하지 않고 대기 중인 정지 명령을 한 번 적용했다. 실제 Windows 파일 선택기 왕복은 기존 142틱 검증 근거를 사용했다. [기존 선택기 검증](../../../20261113/validation/P04-windows-picker-actual-65d92dea-01/RESULTS.md)
