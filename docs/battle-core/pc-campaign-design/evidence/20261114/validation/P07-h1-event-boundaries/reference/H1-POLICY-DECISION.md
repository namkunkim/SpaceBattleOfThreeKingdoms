# H1 후속 — 점령·철수·지역 집결 사용자 정책 결정

2026-10-25 / **핵심 정책 3항 선택 기록·세부 수치/사건/저장 미정**.

기록자: 지정 단일 기록 실행자. 입력은 조율자가 전달한 사용자의 D06 정책 명시 선택이다. [플레이북](../../../워크플로우-플레이북.md)의 0/5/6단계 및 [작업 분해](../PC-CAMPAIGN-WORK-BREAKDOWN-20261025.md) §4의 H1 후속·수용본·단독 파일 소유 계약을 따른다. 계획에 후속 정책 기록의 전용 파일 경로가 없어 **본 파일을 이번 3항의 단일 결정 원본**으로 둔다. [H0](H0-DECISION.md)와 [앞선 H1](H1-DECISION.md)의 선택/미정은 아래에서 명시 갱신한 부분 외에는 유지한다.

## 1. 채택된 정책

| 결정 ID | 사용자 선택 | 적용 경계 |
|---|---|---|
| H1-P01 | **최종 목표 확보 시 보급시설 최소 하나를 현재 통제·가동**, **같은 점령자·소유상태에서 중단 진행량 보존** | D06 P1 권고 방향 채택. 보급거점의 과거 확보 이력만으로 주목표 성공을 인정하지 않음. 중단 중 진행하는 것은 아니며 다른 점령자/반대 소유로 진행량을 넘기는 승인도 아님 |
| H1-P02 | **부분 생환을 주목표 성공과 별도의 철수 성과로 평가**. 보급거점 확보 이력+지휘 함대 생환+실제 투입 대비 생환 비용을 사용. **명시적 철수 때는 철수 성과만**, **목표 점령과 지휘 상실 동시에는 실패 우선** | D06 P2 권고 방향 채택. 실제 투입비용을 분모 기준으로 삼는 방향이며 살아 있는 함대만 분모에 넣어 손실을 지우지 않음. 구체 비율/시한·대상 세력/비용 상세는 미정. 기존 적벽 Q84 전원 도달 규칙을 바꾸는 것이 아님 |
| H1-P03 | **지역 집결→안전한 가동 거점에서 시간·물자를 쓰는 유한 정비→복귀**. **군 사기는 경고로 사용하고 첫 국지 패퇴만으로 작전 종료하지 않음** | D06 P3 권고 방향 채택. 같은 함대의 손상/탄약/사기를 유지하며 무적·순간이동·자동회복·파괴함 재생을 뜻하지 않음. 회복량/비용·안전 상세·재투입 자격은 후속 설계/측정 |

주목표의 **현재 보유·가동**과 철수 성과의 **보급거점 확보 이력**은 서로 다른 판정이다. 전방 목표를 확보했어도 보급시설을 잃었다면 주목표 조건의 현재 상태를 다시 확인하고, 이미 거점을 잃은 철수는 별도 이력 조건으로 평가한다. 확보 이력의 상세 상태/거래 참조는 D06/D07 계약으로 명시한다. 비율 미정 상태에서 50% 같은 이전 후보를 채택값으로 쓰지 않는다.

‘지휘 상실 실패 우선’은 **목표 점령과 동시인 경우**의 선택이다. 모든 동일 틱 사건의 전역 처리 순서를 확정한 것이 아니며 지휘 승계 허용/상실 정의 등 잔여 종료 정책도 별도다.

H0의 호송 차단·통신소 지연·재점령 설계 포함 및 제작순서 분리, H1의 효과지형 기본흐름 후 본체1~2개 비교는 유지한다. Q67은 변경 범위 대조 후 적용 시 B항 등재+1000시드 재측정, 비적용이면 근거/제외 이유를 기록한다. 이번 정책 선택으로 적용/면제를 바꾸지 않는다.

## 3. 독립 검토와 후속 인계

[REVIEW-D05.md](REVIEW-D05.md) 및 [REVIEW-D06.md](REVIEW-D06.md)를 열람하여 evidence_audit의 **독립 문서 수용**을 확인했다. 검토 당시 D06의 P1~P3 사용자 판단 대기는 위 3항 범위에서 갱신된다. IP1·잔여 O04/O05/O07 및 게임 검증은 여전히 미정/미실행이다. 기록 실행자가 자기 문서를 독립 승인한 것이 아니다.

- **D07:** 현재 가동 보급시설·유한 정비의 시간/물자 거래를 선택된 방향으로 설계한다. 경합/소유 전이·빈 재고·이동/위협·지급 중단/예약/환불, 기존 결집/수리와의 접점 및 숫자는 후보로 검토한다.
- **D08:** 주목표 현재 상태와 철수 이력을 구별하고, 명시 철수 모드 및 목표/지휘 동시 실패 우선을 입력으로 사용한다. 나머지 사건 단계 순서·예정/출발/진입/도착·시한/비율을 임의로 결정하지 않는다. PLAN상 D07 수용 전 D08 착수는 여전히 금지다.
- **D04/D10:** 현재/이력·같은 actor/소유 epoch·투입/생환 원장·집결/정비/탈출 상태 요청을 추적하되 저장 표현은 O07 미선택이다. 본 기록은 D04를 수정하지 않는다.

**비승인:** 코드/데이터 구현, 게임·AI·저장·통행·승률·1000시드·사람 플레이 테스트 실행, 브랜치 변경/병합·커밋·푸시. 기존 제안 전체와 세부 수치/동일 틱 순서도 포괄 승인하지 않았다.
