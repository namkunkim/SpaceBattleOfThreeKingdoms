# P05 Windows 1600×900 전경 진형 전환 검증

적벽 v2 출시 후보를 새 APPDATA·LOCALAPPDATA에서 실행했다. 제품 소스 `8df226bee844b29691b188b8f4e99e6e992d467f`와 시험 격리 검사 `1bbe7643e1853a545b07320e01c36bdfe7d8a1fc`은 PR #78에 포함됐다. 측정 구간의 게임 클라이언트는 1600×900이었다. [기동 및 패키지 지문](identity.json)

| 영상에서 확인한 상태 | 영상 PTS | 전투 틱 |
| --- | ---: | ---: |
| 마지막 전환 전 상태 | 60.967초 | 1068 |
| 첫 전환 진행 상태 | 60.983초 | 1069 |

| 최종 전대 영역과 동일한 첫 표본 | 66.017초 | 1119 |

전환 시작과 화면 안정화의 표본 간격을 함께 고려하면 전대 영역은 약 5.017–5.050초에 안정됐다. 최종 프레임과 직전 프레임은 한 픽셀의 두 색상 성분이 한 단계씩 달랐다. 영상의 중복 PTS와 표본 간격 때문에 개별 함선의 정확한 도착 프레임과 실제 모니터 표시 시각을 확정할 수 없다. [HUD 표본](event-hud.png) · [전대 영역 표본](endpoint-hulls.png) · [영상 PTS](frame-pts.csv) · [프레임 해시](fleet-v2.framehash)

같은 출격의 1129틱 저장본을 다시 실행해 명령 접수 1068틱과 완료 1118틱을 확인했다. 전체 저장 상태가 일치했고 전투 논리 시간은 50틱·5,000ms였다. [논리 틱 검증](native.json)

별도 출격은 전환이 0.1초 남은 91틱에 저장했다. 실행 담당자는 91틱으로 복원한 뒤 전환 완료를 확인했다. 재개 후 976틱에 다시 저장한 기록은 원래 작전 ID와 명령을 유지했다. 전체 상태를 재현한 결과 92틱에 전환이 완료됐다. [전환 중 저장](mid-native.json) · [재개 후 저장](mid-resumed-native.json)

게임 영역 영상은 로컬 시험 근거 `game-only-58-70.mkv`에 보존했다. SHA-256은 `d260a5a53a24cc3c058612ee484ec0f10511973ce779956b0780f70901cbc30a`다.

독립 검토에서 후보와 저장본의 해시, 영상 PTS, 두 출격의 논리 50틱과 재개 후 상태 일치를 확인했다. 91틱 복원과 재개 버튼 조작 순서는 실행 담당자가 화면에서 직접 확인했다. 91틱 저장본의 재현은 전체 상태 일치와 전환 미완료를 기록했다.
