# PC 캠페인 구현 인수 스펙 준비

2026-10-26 / **문서 초안·독립 검토 대기 / 게임 코드·시험 실행 미승인** / 문서 K=3.

## 1. 목적·권위·완료 정의

[H2 결정](H2-DECISION.md)의 조건부 설계 인계를 구현 가능한 작은 조각과 인수 기준으로 바꾼다. 이 문서와 [측정 계획](MEASUREMENT-PLAN-20261026.md)의 작성만 승인됐다. 코드·데이터·시험·게임 실행·브랜치/병합·커밋·푸시는 이번 작업에 포함하지 않는다.

최신 결정은 [H0](H0-DECISION.md), [시간/지형 H1](H1-DECISION.md), [작전 정책](H1-POLICY-DECISION.md), [사건 정책](H1-EVENT-DECISION.md), [H2](H2-DECISION.md) 순서의 해당 쟁점 원본이다. [D10](D10-INTEGRATED-REVIEW.md)과 [최종 독립 검토](REVIEW-D10.md), [검토 스펙](../PC-CAMPAIGN-REVIEW-SPEC-20261025.md)의 R/O를 추적한다. 옛 문서의 미채택·대기 표현은 당시 이력이며 최신 선택을 되돌리지 않는다.

완료 정의는 첫 구현 조각의 입력·수정 경계·반례·검증 이름 후보·차단 조건, 후속 두 묶음의 계약, 미정 해소 책임을 명시하고 작성 비참여 검토자에게 인계하는 것이다. **문서 수용은 코드 착수·정량 수용이 아니다.** 테스트 이름·새 모듈 경로는 앞으로 선택할 후보이며 현재 파일 존재를 주장하지 않는다.

## 2. 고정할 행동·남길 미정

단일 성계 보급로 개방, 정면/우회와 호송·통신소·재점령을 포함하되 제작을 나눈다. 효과 지형 기본 흐름 후 물리 본체1~2개를 비교한다. 게임약20분은 가설이며 조기 성공을 막지 않는다. 최종 목표와 보급시설 최소1곳의 현재 통제·가동을 함께 요구한다. 같은 점령자/소유상태의 중단 진행량은 보존하며 다른 점령자에게 승계하지 않는다.

명시 철수는 보급 확보 이력·지휘 생환·실제 투입 대비 탈출 잔존비용으로 별도 성과를 판정한다. 목표 점령과 지휘 상실이 동시면 실패 우선이다. 지역 집결과 작전 탈출은 다르며 안전 가동거점의 시간·물자 정비로 복귀한다. 군 사기는 경고로 쓰고 첫 국지 패퇴만으로 작전 전체를 끝내지 않는다.

통신소 가동 완료가 본대 출발과 같은 논리시각이면 지연을 인정하고 출발 후 소급하지 않는다. 유효 지연만큼 공개 시한을 연장하고 시한과 동시의 유효 목표/탈출을 인정한다. 유한 증원은 실제 접근하며 조작권 박탈·숨은 피해 배율을 쓰지 않는다.

H2로 전체 상태+후속 명령·초기 동일 규칙 버전 재개, 관람과 논리 재생 분리를 채택했다. 자기 시설 상실 보고·상대 마지막 확인·적 재고 비공개·필수 일정 공지를 채택했다. 저장 필드·커밋·호환 판정 기술, 전역 동시 순서와 아래 정량값은 미정이다. 6800×4600/이동30·45/15초·8/10/16/20/24분·지연2분·생환50%를 기본 확정값으로 넣지 않는다.

## 4. 첫 구현 조각 I01 — 선택 실행 프로필·공간 입력 경계

**지금 상태: 착수 차단.** 게임 코드 승인이 없고 O03/O06/O07의 해당 인수 계약이 미완료다. 준비 자료가 있다는 이유로 코드를 먼저 만들지 않는다.

I01의 목적은 별도 작전의 입력·실효 설정을 한 경로로 만들고, 화면/헤드리스/재생이 같은 정의를 쓰도록 격리하는 것이다. 이 조각만으로 작전 완주·점령·사기·저장을 제공한다고 하지 않는다. 기존 효과 종류만 사용하고 물리 장애물·병기 제한·국가 경영은 제외한다.

## 7. 문서 게이트·인계

자체 5-a: R18행/O8행/A6행/P3행·입력 링크·허용2파일·최신 H2/정량 미정·게임 미승인 경계 검사. 문서 K=3, 실패는 해당 문서 재시도·상한 보고. 작성 비참여 검토자는 원문·반례와 대조해 별도 리뷰 기록에 수용/조건부/반려를 남긴다. 5-b 반려는 2단계 스펙으로 복귀하며 작성자가 자기 정확성을 승인하지 않는다.

후속 실행자는 문서상 후보 이름·경로·게이트를 실행 전 확정한다. 코드 작업의 재시도 상한과 체크 명령은 그 루프에서 정하며 이번 문서 K를 실제 테스트 실행 이력으로 쓰지 않는다. 문서 인계 후에도 코드 착수는 별도 범위 승인과 해당 O 게이트를 요구한다. 실제 게임·저장·성능·1000시드·사람 플레이 시험은 미실행이다.
