# 그룹 지정 UI 메모 (2026-10-05)

`CHECKLIST-OPEN.md` §7은 다른 세션이 아직 커밋하지 않은 수정 중이라(원래 폴더의 작업 트리) 이 PR에서 건드리지 못했다. 아래를 §7에 옮겨 적는다. 구조 요약은 `SESSION-HANDOFF.md` "그룹 지정 UI".

## §7 4번 — 그룹 지정: 구현 완료

- `input/selection_set.gd`(선택 집합 한 곳), HUD [다중] [1]~[5], 다중 모드 범위 선택. 테스트 `tests/selection_groups.gd`.
- 남은 확인: 태블릿 실기기에서 다중 모드 탭·범위 선택·길게 눌러 저장 손맛.

## §7 6번 — 카메라가 전장 밖으로 벗어남: 원인 후보, 미수정

- `CameraRig.clamp_cam`이 카메라 중심만 `WORLD`(3400×2300) 안에 묶는다. 가장자리에서는 화면 절반이 전장 밖이고, 줌아웃(0.35)일수록 심하다. 화면 모서리의 땅 좌표(`s2w`)로 클램프하거나 여백을 둔다.
- 팬이 `화면 델타 ÷ cam_z`라 원근 투영(피치 68°)과 맞지 않아 손가락이 땅을 못 따라간다. `s2w` 차이로 바꾸면 된다.
- 허용 범위(얼마나 밖까지 볼 수 있나)가 정해지지 않아 고치지 않았다.

## §7 5번 — 함대 1개 선택 후 목표 끌기 실패: 재현 조건 후보, 미수정

- 목표 끌기는 터치 시작점이 아군 명패(`label_rect` ±4px) 또는 함대 중심 `max(28, 52·cam_z)`px 안일 때만 시작한다(`TouchController._touch`의 `_hit_fleet`). 함대가 움직여 손가락 아래를 벗어났거나 줌아웃 상태에서 명패 밖을 짚으면 팬이 된다.
- 선택된 전대가 있을 때 빈 곳 끌기를 팬으로 보는 것이 충돌의 본질이다. 정책 결정이 먼저다(예: 선택 전대 주변 판정 반경 확대, 끌기 시작 후 일정 거리 전 지연 판정). 새 다중 모드(범위 선택)와도 맞춰야 한다.
