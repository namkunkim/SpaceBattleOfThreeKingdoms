# 방공·대응 발진 검증 (2026-10-19)

작업: `feature/air-defense`, `worktrees/air-defense`. main 반영 없음.

## 사용자 결정과 동작

- 자동 편성의 특화 함대 보존은 후속. 이번에는 편성·난이도 목표를 바꾸지 않는다.
- 함재기·미사일만 방공 대상. 뇌격·전열·요격 사격은 제외한다.
- 방공 = min(1500, 유효 방공 함선 수 × 가중 bp 합 / 현재 잔존 척 수). 가중치는 요격함 4000, 강습모함 2000, 요격 장비 고속정 3000. 손상 계수를 적용한다. 수치는 본편 정본이 없는 proposed 값이다.
- 플레이어 함대별 자동 대응 기본 꺼짐, 적 기본 켜짐. 무장 탭의 자동 대응 버튼으로 선택 함대 설정을 바꾼다. 혼합 선택은 모두 켜고, 모두 켜진 선택은 모두 끈다.
- 설정은 피격 시 대응만 제어한다. 기존 60초 주기 사격은 계속된다. 대응은 다음 틱에 정상 사격 조건으로 1회 사용하고 주기를 갱신한다. 표적은 기존 표적 선택 규칙을 따른다.
- 대응 공격에는 재대응하지 않는다. 같은 틱 이미 발진했다면 추가 대응하지 않는다. 여러 동시 피격은 하나의 예약으로 합친다.
- 예약 뒤 사거리·플랫폼·자원·생존·퇴각 조건이 사라지거나 설정을 끄면 예약을 지운다. 실패한 대응은 횟수를 쓰지 않는다.
- 설정·예약·최근 발진 틱은 지문에 포함한다. 일반 명령 기록 경로를 사용한다.

## 검증

Godot 4.7.2, 헤드리스, 테스트 단독·순차 실행. 아래 **16종 모두 종료 코드 0, PASS/OK**:

`air_defense`, `salvo_rules`, `evasion`, `battle_flow`, `core_rules`, `detection_rules`, `commander_ai`, `supply_rules`, `rule_text_salvo`, `formation_ui`, `organization_rules`, `view_range`, `flip_rules`, `bundle_layout`, `weapon_charges`, `rule_text`.

- `organization_rules`: 입문 자동 편성에서 시드 1/2/3 전투 종료(720/591/782초)와 재생 지문 일치. 이 세 시드는 회귀 확인이며 승률 추정 표본이 아니다.
- `commander_ai`: 자동 해결 및 명령이 섞인 재생 지문 확인.
- 기능 변경 최종 상태에서 `air_defense` 재실행 통과.
- 로그: worktree의 `scratchpad/air-defense-<test>.log`(로컬, 커밋 제외). 여러 테스트가 종료 시 ObjectDB/resource 미해제 경고를 출력했다. 스크립트 오류는 없고, 각 테스트의 명시적 PASS/OK와 종료 코드로 판정했다.
- Python AST 설정 일치 검사 `AIR_DEFENSE_GENERATOR_SYNC_PASS`, 변경 파일 `git diff --check` 통과.

신규 `air_defense.gd`: 데이터 범주, 비율·상한·손상, 요격 장비만 방공, 명중률 감소, 양측 대응, 횟수 소비, 연쇄·동일 틱 중복 방지, 설정·혼합 선택·진영 경계, 자원/사거리/퇴각/격침/플랫폼 제한, 예약 실패 해제, 결정론.

확장 `rule_text_salvo.gd`: 실제 무장 탭 버튼 → 입력 명령 → 코어 → 투영 → 화면 모델 → 켜짐/꺼짐 표시 왕복.

JSON과 생성기의 air_defense 사전은 Python AST로 비교해 일치 확인. 기존 생성기 불일치 영역은 재생성하지 않았다.
