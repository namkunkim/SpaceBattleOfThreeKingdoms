## 1. 확정 규칙과 어긋나는 표시 (목업 v2)

> **시점 (UI-1 세션 답신 반영):** U-1·U-3은 지금 돌아가는 POC 규칙(화력 +30%/+60%, 방어진형 버튼)과는 맞는 표시다. 그래서 **코어가 확정 규칙으로 바뀌는 시점(M3·M5)에 함께 바꾼다.** 목업과 정보 설계(자리, 문구 틀)는 확정 규칙 기준으로 미리 준비해 둔다. U-2(사기 눈금)는 코어에 사기가 생길 때(M4) 처음부터 bp로 붙인다.

| # | 목업 위치 | 표시 | 어긋나는 결정 | 고칠 방향 |
|---|---|---|---|---|
| U-1 | 199, 260, 600행 근처 | "측면 공격 화력 +30%", "측면 공격 중 +30%" | Q33: 방향 효과는 피해 배율이 아니라 **명중률 보정**(표적 방어 정면 +10 / 측면 0 / 후면 −15), 사기 감소 측면 ×1.25 / 후면 ×1.5 | "측면 공격: 명중 +10%p, 적 사기 타격 ×1.25"처럼 고친다. 후면은 "+25%p, ×1.5" |
| U-2 | 200, 256행 근처 | "사기 41" | Q30: 사기 눈금은 **bp 0~10000**, 구간은 안정 6000↑ / 동요 3000~5999 / 퇴각 1~2999 | 숫자는 bp(예: 4100) 또는 백분율(41%)로 쓰고, 구간 모양(● ◐ ▽ ×, `EXPERIENCE-DESIGN.md` §6)을 함께 보여 준다. "41"만 쓰면 게이지(0~125)로 읽힌다 |
| U-3 | 280~282, 317행 근처 | "방어진형" 버튼, "돌격하면 방어진형은 풀립니다" | 제안서 v0.2 §4.15·§14: POC 방어진형 버튼은 **삭제**(방원진이 대신) | 버튼을 빼고, 진형 탭의 방원진으로 안내한다. 돌격 설명은 "열 용량의 40%를 쓰고, 사기 안정일 때만 사용 가능"(Q42)으로 고친다 |
| U-4 | v1 | CP 표시 | Q21: CP 폐지 | v2에서는 사라졌다. 확인만 한다 |

## 2. 컨셉상 확인이 필요한 점

| # | 항목 | 내용 | 권고 |
|---|---|---|---|
| C-1 | 표시 함선 수 | 전대당 50~75척을 표시한다(남은 전력 비율). 규칙상 적벽 전대는 5~26척(함종 카운터)이다 | 표현과 규칙의 분리는 괜찮다. 다만 **화면에 나오는 모든 숫자는 코어의 카운터**여야 한다. "보이는 배 = 실제 척 수"로 오해하지 않도록 정보 패널에는 카운터만 쓴다. 비율은 "실제 1척 = 표시 3척"처럼 고정 배율로 하면 손실이 직관적으로 보인다 |
| C-2 | 일제 포화 주기 | 화면은 1.5~2.3초마다 물결처럼 쏜다. 코어는 무기 범주마다 **60초에 한 번** 판정한다(Q46) | 상시 포화는 분위기 연출로 두고, 코어의 일제사격 사건이 오면 **강조 포화**(밝기·소리·화면 흔들림)를 따로 보여 준다. 그래야 "지금 포격함이 쐈다"를 읽을 수 있다 |
| C-3 | 진영 글리프 | 촉 = 사각, 위 = 마름모로 정했다. **오(손권군)가 없다** | 오의 글리프(예: 원·吳)를 정한다. 동맹은 아군과 다른 글리프와 세력명으로 구분해야 한다(제안서 §7.1). 소유 표시(● 아군 / ○ 타 세력)와 세력 글리프의 관계도 정한다 |
| C-4 | 성능 | 데스크톱 내장 GPU에서 760척 60fps. 본편 정본 목표는 204개 표시 개체다 | 모바일 실기기 측정 전에는 "표시 배율"을 설정으로 두어 낮출 수 있게 한다. 적벽 상급(172척)에 배율 4면 688척이다 |
| C-5 | 메시지 문구 | "측면을 찔러라" 같은 지휘 대사 | 좋다. 결정 카드의 참모 대사(`EXPERIENCE-DESIGN.md` §5)와 같은 목소리로 맞춘다 |

## 3. 아직 자리가 없는 확정 요소

다음은 결정됐거나 경험 설계에서 채택된 화면 요소인데, 목업 v2에 자리가 없다. 코어 값이 생기기 전이라도 **자리 설계**는 해 두기를 권한다.

| 요소 | 근거 | 자리 제안 |
|---|---|---|
| 결정 카드(참모 대사, 선택지 2~3개, 추천 배지, 시간 막대) | `EXPERIENCE-DESIGN.md` §5 | 화면 아래 중앙, 엄지 영역 |
| 정욱 의심 게이지, 기류 창 예보와 남은 시간 | §1·§2 | 상단 국면 표시 옆 또는 황개 전대 태그 위 |
| 붕괴 위기(군 사기 4500 미만) 경고, 유비 결집 버튼(1회) | §4 | 상단 군 사기 막대에 임계선과 위기 표시, 태세 탭에 결집 |
| 자동 ×4 표시, "다음 분기까지 건너뛰기"와 사유·예상 시간 | Q52, §6 U8 | 우측 상단 속도 버튼 옆 |
| 명령 되돌리기 알림(4초) | §6 U2 | 화면 아래, 결정 카드와 겹치지 않는 곳 |
| 전대 띠(아군 초상 7개) | §6 U4 | 그룹 탭 I~IV 자리를 넓혀 |
| "결정 2/5" 표시 | §5 | 상단 시계 옆 |
| 결산: "당신의 결정", 갈림길 회고, 메달판, "다음에 해볼 것", 사관 서술 | §4·§7·§9 | 결과 화면 |
| 홈: 난이도 사다리, what-if 카드, 메달판 | §9 | 타이틀(전투 허브) |
| 이어하기 상황 요약 3줄 | §7 | 이어하기 진입 시 |

## 4. 잘 맞는 점

- 코어에 없는 값(사기, 국면, 자원)을 가짜로 채우지 않고 숨긴다. 정보 경계 원칙과 맞다.
- 전투 상태를 `battle_source.gd` 어댑터 한 곳으로만 읽는다. M1 투영과 연결하기 쉽다.
- 진영을 색만으로 나누지 않고 글리프를 함께 쓴다.
- 끌기 취소(출발 함대로 되돌리기)를 넣었다. 제안서 §7.2와 같다.
- 앵커 배치(16:9·16:10·21:9)와 터치 입력이 처음부터 들어가 있다.

## 5. 전달

이 리뷰는 UI-1 세션에 전달했고, UI-1이 후속 "게임 UI 상품화 수준 개선-2" 세션에 넘겼다. 반영 시점은 사용자가 정한다. 이후 UI 의견은 UI-2 세션으로 보낸다.
