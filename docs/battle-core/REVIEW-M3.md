| ① | 주기가 찼는데 표적이 없으면 사거리 진입 즉시 쏜다 | **채택 + 문장 명시** | 주기를 "재장전 시간"으로 읽는다. 충전된 포는 표적이 확인 접촉으로 사거리·사격각에 들어오는 틱에 쏘고, 쏜 시점부터 60초다. 무장 탭 "일제사격" 버튼(다음 주기를 지금 당긴다)과 같은 모델이라 일관된다. 제안서 §4.3에 반영. 부작용은 아래 "후속 1" |
| ② | 방향 배분 60/40 정수 카운터, 작은 손실에서 40% 쪽이 먼저 갈 수 있다 | **조정(후속)** | 구조는 수용한다. 다만 작은 손실마다 반올림이 한쪽으로 치우치면 장기 비율이 60/40에서 벗어난다. **60% 몫의 소수 잔여를 전대 단위로 이월**해 합계가 60/40에 수렴하게 한다(결정론 유지). 노트의 "첫 척은 노출 묶음"과 "40% 쪽으로 먼저"가 서로 어긋나니 실제 동작을 한 문장으로 적어 달라. 테스트: 누적 손실 20척 이상에서 노출 함종 몫 60±5%. 시점은 M5 노출표 전체를 넣을 때 |
| ③ | 10~15초 주기 대안(P12) 미측정 | **보류(M4로 이월)** | 제안서가 M3에서 재자고 했으나 새 기준선(M4) 없이는 의미가 작다. `tests/salvo_compare.gd`에 `period` 인자만 지금 열어 두고, M4에서 **두 변형**을 같은 시드로 잰다: (a) 주기만 줄임, (b) 주기를 줄이고 기본 피해를 같은 비율로 줄여 총 피해를 보존. 사용자 결정 Q46(60초)을 바꾸는 일이 아니라 측정이다. 결과가 좋아도 바꾸려면 인터뷰로 묻는다 |
| ④ | 가까이서 포격함 승률 27% | **수용** | "멀리서 이기고 가까이서 진다"의 의도에 든다(승률 20~40%면 양호). 완전히 0%에 가깝거나 50%에 가까워지면 거리대 계수를 본다. 조건 B(연합 승률 √ 28%, 고정 20%, 정비례 13%)는 적 AI가 POC라 밸런스 근거로 쓰지 않는다는 구현 세션의 판단에 동의한다. √ 기본 유지(Q45) |

## 후속 (구현 세션)

1. **첫 일제의 동기화(관찰 항목):** ①에 따라 오래 접근한 전대들이 사거리 진입 틱에 한꺼번에 첫 일제를 쏜다. 초기 엇갈림(ID 유도)이 사실상 사라진다. M4 측정 항목에 **판당 첫 일제 동시 비율**(같은 진영 둘 이상이 같은 초에 쏜 비율)과 첫 일제 결과 편중을 넣는다. 편중이 크면 "첫 일제 뒤 다음 주기는 60초 + 전대 ID 유도 0~15초"를 비교한다(제안서 §4.3 후보, 지금 적용하지 않는다).
2. `tests/salvo_compare.gd`에 `period` 인자(③).
3. 방향 배분 잔여 이월과 장기 비율 테스트(②, M5).
4. 거리대별 지휘관 능력치(`might`·`intellect`)를 M4에 반영.
