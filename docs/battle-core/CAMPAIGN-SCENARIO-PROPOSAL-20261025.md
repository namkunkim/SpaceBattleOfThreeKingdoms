# 기동·조우·점령·보급 캠페인 제안 및 제미나이 안 검토

작성: 2026-10-25. 상태: **기획 제안 / 미구현 / 수치 미검증**.

후속 검토: [PC 맵 확장과의 통합·작업 분해](PC-CAMPAIGN-INTEGRATION-REVIEW-20261025.md). 시간 기준, 사기·작전 종료, 지형 도입 순서와 구현 단계는 이 후속 검토를 함께 참조한다.

사용자 요청: 적의 일제 접근 중심 전투에서 벗어나, 이동·조우·교전·행성 점령·보급·시간 경과에 따른 적 증원이 있는 캠페인을 제안한다. 사용자가 제공한 제미나이의 「가르가멜 성계 돌파 작전」도 검토 대상으로 포함한다. 기존 적벽 한정 문서의 범위와 별도로 요청된 확장 기획이며, 이 문서는 기존 적벽 규칙을 변경하지 않는다.

## 1. 권고

**20분 전후의 단일 항성계 작전**부터 만든다. 정찰하고 항로를 골라 움직이며, 적의 임무를 방해하고, 필요한 행성을 확보해 보급한 뒤 최종 목표를 달성하는 구조다. 전투 하나에서 얻은 손실·탄약·보급 재고가 작전 끝까지 유지되어야 한다.

첫 샘플은 「형주 외곽 항성계 — 강하 보급로 개방」을 제안한다. 지명은 가칭이며 기존 지도 ID에 아직 배정하지 않는다. 제미나이 안의 두 경로와 중간 보급을 살리고, 보급선 차단·증원 지연·계획된 철수를 추가한다.

20분은 목표 플레이 시간과 적 본대 도착 기준이다. 시간 초과가 곧 강제 전멸이라는 뜻은 아니다. 20분 엄수 체험판이 필요하면 별도 ‘제한시간 도전’ 규칙으로 작전 실패를 결산한다. 어느 쪽도 조작권 박탈이나 비공개 공격력 증폭을 쓰지 않는다.

## 2. 현재 게임에서 확인한 사실

| 영역 | 확인한 기반 | 캠페인에 필요한 확장 |
|---|---|---|
| 지도 | `docs/battle-core/WORLD-MAP-LINK.md`: 천하 지도→적벽 진입과 결과 연출. 소유 변화는 영속 저장하지 않음 | 이동 가능한 작전 지도, 행성 소유·시설 상태, 저장 |
| 시나리오 | `core/battle/scenario_profile.gd`: 편성·초기 위치·`deploy_delay_s` 변환 | 일반 목표·거점·항로·사건 정의. 현재 변환 결과의 `reinf`는 빈 배열 |
| 증원 | `core/battle/battle_sim.gd`: `_reinf_def`, 한 번의 `st.reinf`, 시간 조건의 생성 경로 | 복수 사건 ID, 출발→이동→도착, 취소·지연·중복 방지 |
| 탐지 | `core/battle/detection.gd`: 확인·추정·접촉 상실 | 작전 지도 접촉과 정찰 보고 연결. 적 AI도 같은 정보 제한 준수 |
| 보급 | `core/battle/supply.gd`: 정지·반경·동시 처리량·보급함 재고·손상별 처리율 | 소유권 변경 반영, 유한한 점령 기지 재고, 항로 연결 조건 |
| 수리 | 같은 파일: 중파→경파 처리, 피격 후 경파 회복. 보급은 주기 단위 | 점령 시설 기능별 처리. 파괴 함선 복구와 수리를 구분 |
| 승패 | `core/battle/victory.gd`: 적벽 인물·군 사기·손실·20분 판정 | 시나리오별 목표 판정. 적벽 승패를 새 작전에 그대로 적용할 수 없음 |
| 결과 | `scripts/world/battle_outcome.gd`: 승패·손실 비율·후일담 중심 | 함대별 실제 잔존 편성·손상·탄약·보급 재고 인계 |

현재 공급원 설명은 보급함 반경 140, 기지 180이며 실제 값은 프로필을 따른다. 기지는 현행 규칙상 재고 무한이다. 따라서 ‘유한 기지 재고·연결된 보급선’은 신규 설계다. 연료도 이번에 확인한 전투·보급 경로에 연결돼 있다고 볼 근거가 없으므로 첫 샘플에서 제외한다. 무기마다 소모 자원도 다르므로 모든 일반 공격을 탄약 100의 단일 규칙으로 바꾸지 않는다.

## 3. 제미나이 제안 평가

| 항목 | 판정 | 통합안 |
|---|---|---|
| 정찰→분기→거점→보급→최종 공격 | 채택 | 이해하기 쉬운 첫 작전의 뼈대 |
| 짧고 강한 정면로 / 길고 약한 우회로 | 조정 채택 | 이동 시간·탄약·위험·후속 이점 모두 달라야 함. 우회로에도 제한적 보급 제공 |
| 교전 손실과 탄약 유지 | 채택 | 화면 전환이나 목표 달성으로 자동 회복하지 않음 |
| 8분 호송선 출발 | 조정 | 작전 시작부터 예정된 물류 일정으로 존재. 점령 전후 어느 시점에도 실제 항로에서 발견·차단 가능 |
| 18분 후방 재점령 | 조정 | 외곽 진입점에서 접근. 아군 시작점 한가운데 즉시 생성하지 않음 |
| 보급함의 보급 반경 | 기존 규칙 활용 | 범위만 들어가면 초당 무한 회복하는 오라로 바꾸지 않음 |
| 기지 파괴 즉시 행성 소유 전환 | 수정 | 적 함대 격퇴·시설 무력화·궤도 장악·점령을 분리. 저장고까지 파괴하면 노획량 감소 |
| 행성 점령 즉시 탄약·연료 100% | 수정 | 유한 재고와 보급 주기를 적용. 획득량과 대기열을 UI로 표시 |
| 모든 함대 탄약 0이면 공격 불가 | 부적합 | 무기별 탄약·에너지·사용 횟수 규칙 유지. 남은 주포 등으로 전투·퇴각 가능 |
| HP 초당 2% 수리 | 보류 | 50초 만에 전량 복구하는 평준화보다 기존 손상·물자 규칙을 활용 |
| 저체력 함선·보급함 무조건 최우선 | 수정 | 탐지됨·도달 가능·임무 이득이 있을 때 가중. 요새 수비대가 보급함을 따라 전장을 이탈하지 않음 |
| 전원 시야 진입 전 Idle | 수정 | 순찰은 순찰하고 호송은 이동. 매복대만 대기. 플레이어가 오지 않아도 작전은 진행 |
| 3·8·12분 정각에 단계 전환 | 수정 | 목표 달성이 진행 조건. 시간은 외부 압박에 사용. 빠른 플레이어를 기다리게 하지 않음 |
| X=300 통과로 항로 선택 확정 | 부적합 | 항로 구간·진입점·거점으로 판별. 분견대 양쪽 파견·회항 허용 |
| 10분/12분에 서로 다른 증원 예고 | 정합화 | 하나의 증원 일정에서 UI와 대사를 생성 |
| 20분 조작권 상실·적 공격력 10배·전멸 | 제외 | 공지한 전력의 본대가 실제 진입. 철수·목표 돌파·항로 차단의 대응 유지 |
| 좌표·반경·척수 예시 | 참고만 | 현재 함대/전대 단위와 축척·지휘 한도·이동 속도에 맞춰 재산정 |

제미나이 상세안은 본문에서는 ‘건물 파괴 시 즉시 점령’, 체크리스트에서는 ‘기함 접근 후 점령 게이지’를 요구해 서로 충돌한다. 전쟁 안개 역시 레이더 고장을 뜻하지 않는다. ‘확인되지 않은 항적’, ‘성간 물질로 탐지 범위 감소’처럼 실제 규칙과 일치하는 대사를 쓴다.

## 4. 레퍼런스에서 가져올 작전 구조

아래의 게임 적용은 우리 게임을 위한 재해석이다. 원작 사건의 전개·승패를 그대로 재현하는 시나리오 목록이 아니다.

| 레퍼런스 | 확인한 작전 요소 | 우리 게임에 적용할 것 |
|---|---|---|
| 은영전 아스타테 | 분산한 적의 합류 전 각개격파 | 합류 예정 시각과 항로를 정찰해 한 부대씩 상대하는 ‘합류 저지전’ |
| 은영전 이젤론 공략 | 요새 정면 화력 대신 기만·내부 제어 확보 | 수비 함대 유인 후 제어 시설 점령. 전자전·강습 기능이 필요하므로 후속 |
| 은영전 제국령 침공·암릿처 | 장거리 침공과 대규모 패퇴 | 진출 거리만큼 보급 부담이 증가하고, 퇴각로 확보도 성과인 ‘원정 철수전’. 구체 보급 수치는 독자 설계 |
| 은영전 페잔 점령·라그나로크 | 다른 회랑을 통한 침공으로 방어 거점의 가치 변화 | 최강 요새를 우회해 항로 관제 행성을 확보하는 ‘우회 침공전’ |
| 은영전 연전·버밀리온 | 지휘관을 유인하고 결정적 목표로 급진, 소모 방어선과 증원 | 전멸보다 지휘 거점 무력화가 우선인 ‘지휘부 급습전’ |
| 은영전 요새 철수 | 거점 고수보다 전력 집중, 선단 철수 | 기지를 포기해도 수송선·주력 생환으로 승리하는 ‘철수 엄호전’ |
| 은영전 마르 아데타 | 좁은 회랑에서 수적 우세를 제한 | 협로 지연전과 후위 교대. 대규모 적을 전멸시킬 필요 없음 |
| Sins of a Solar Empire 계열 | 항로 연결, 천체별 역할, 위성의 병목 | 행성별 보급·수리·관제 역할과 끊을 수 있는 항로 |
| Homeworld 계열 | 함대 보존과 이동·자원 운용을 중시하는 작전 구성 | 작전 중 편성·손상·소모품 유지, 다음 교전의 준비 비용 |

은영전은 회전 자체보다 ‘왜 그 장소에서 싸워야 했는가’를 참고한다. 함대가 지켜야 할 시설·기다려야 할 호송·합류해야 할 아군이 있으면 무조건 돌진할 이유가 사라진다.

## 5. 재사용할 시나리오 유형 8개

| 시나리오 | 주목표·승리 | 적의 임무 | 시간 압박과 대응 |
|---|---|---|---|
| 보급로 개방 | 저장고 확보 + 목표 관제소 확보 | 순찰·거점 방어·호송 | 지원 본대 도착 전 개방. 통신소 확보로 지연 |
| 합류 저지 | 적 3개 부대 중 2개 전투 불능 또는 합류 항로 차단 | 정해진 지점으로 집결 | 합류 후 정면전이 어려워짐. 정찰로 시간표 확보 |
| 수송선단 호위 | 지정 수송선 3개 중 2개 탈출 | 습격·추격·퇴로 차단 | 선단 이동과 적 접근이 동시에 진행 |

| 원정 철수 | 확보한 보급으로 손상 함대·수송선 귀환 | 후퇴 유도·보급 교란·포위 | 점령 수보다 생환 전력 평가. 재고 없는 거점도 정찰로 확인 |
| 협로 지연 | 정해진 선단 탈출 완료까지 회랑 유지 | 돌파·우회 | 시간 경과가 아군에 유리. 철수 시점은 선단 진행으로 결정 |
| 지휘부 급습 | 적 지휘 거점 무력화 | 지연 방어·기함 후퇴·구원 | 부대 전멸보다 목표 도달 우선. 포위 전 철수는 제한 성과 |

첫 구현은 보급로 개방 하나다. 호위·강습·정치 사건·국가 경영까지 한 번에 넣지 않는다. 동일 목표·항로·사건 체계로 다음 작전을 제작할 수 있도록 설계한다.

## 6. 20분 샘플: 강하 보급로 개방

### 6.1 브리핑과 승패

적이 형주 외곽의 관제 행성을 점거해 강하 방향 보급 항로를 봉쇄했다. 연합 함대는 현지 보급창을 확보한 뒤 관제소를 장악해야 한다. 적 구원 본대는 약 20분 후 도착한다.

- 주목표: **주보급창 또는 우회 보급소 중 하나 확보 + 최종 관제소 확보 + 아군 지휘 전대 생존**.
- 행성 점령은 해당 행성의 군사 통제권 획득을 뜻한다. 민간 행성 지표를 파괴하는 행동은 목표가 아니다.
- 부목표: 호송 차단, 통신 중계소 확보, 점령 시설 보존, 보급함 생환.
- 제한 성과: 보급 거점을 확보했으나 최종 목표 달성이 어려울 때, 지휘 전대와 살아 있는 출전 전력 비용의 50% 이상을 탈출시켜 ‘전력 보존 철수’. **주목표 성공과 별도 결과**다.
- 패배: 지휘 전대 상실, 생환 가능한 전력 전무, 또는 철수 종료 시각까지 주목표도 철수 조건도 달성하지 못함.
- 권장 길이: 첫 성공 18~22분, 숙련 시 12~16분. 일반 모드 철수 종료는 기본 24분, 본대 지연에 따라 최대 26분. 모두 실험 시작값이다.

### 6.2 지도와 편성

```text
                          [주보급창 A] ───── [최종 관제 행성 C]
                         /        │               │
[연합 진입/탈출 E] ─ [분기 J]      │           [적 증원 진입 R]
                         \        │               │
                          [우회 보급소 B] ─ [통신 중계소 D]
```

연결: E–J, J–A, A–C, J–B, B–D, D–C, A–B, R–C, R–D。A–B는 회항·분견대 합류용이며 두 거점 전부 점령은 필수가 아니다. 각 항로의 거리와 현재 함대 기준 이동 예상 시간을 표시한다.

| 대상 | 역할과 선택 비용 |
|---|---|
| A: 주보급창 | 짧은 길. 순찰·수비와 싸워야 하지만 탄약과 물자가 충분함 |
| B: 우회 보급소 | 긴 길. 소규모 경비와 탐지 저하 지형. 탄약은 적지만 수리 물자와 D 접근성이 좋음 |
| D: 통신 중계소 | 선택 목표. 확보 시 아직 출발하지 않은 구원 본대의 출발을 2분 지연 |
| C: 관제 행성 | 궤도 방어대와 최종 수비 함대. 관제소 확보가 목표이며 수비대 전멸은 불필요 |
| R: 증원 진입점 | 작전 지도 가장자리의 고정 진입점. 정찰하면 함대 규모·진로의 추정 갱신 |

아군은 지휘·주력, 기동·정찰, 지원의 세 운용 그룹을 권고한다. 실제 함대·전대·척수는 현재 편성 한도와 비용을 기준으로 검증한다. 적은 순찰, A 수비, B 경비, C 수비, 호송, 구원 선발·본대의 고정 편성을 가진다. 전투력은 부대 이름이나 척수만으로 비교하지 않고 기존 편성 비용과 교전 실험으로 산정한다.

### 6.3 예상 진행과 실제 트리거

| 예상 시간 | 플레이 경험 | 실제 진행 조건 |
|---|---|---|
| 0~3분 | 정찰, 항로 선택, 순찰 회피 또는 차단 | 탐지·이동으로 진행. 3분까지 기다릴 필요 없음 |
| 3~7분 | A 공격 또는 B 우회 점령 | 방어 무력화 + 점령 완료 |
| 7~10분 | 재보급·수리, 호송 추격 여부 결정 | 첫 거점 점령 즉시 보급 가능. 호송은 별도 일정 |
| 10~14분 | D 확보 또는 C 직행, 공격 준비 | 플레이어 이동과 점령 상태 |
| 14~18분 | 관제 행성 교전·점령 | C 궤도 확보 및 점령. 빠르면 이보다 먼저 성공 |
| 18~20분 | 적 선발대의 재점령 시도, 돌파/방어/철수 선택 | 아래의 전역 증원 일정 |

### 6.4 적 물류·증원 일정

작전 시계는 **게임 시뮬레이션 시간**이다. 일시정지는 멈추고 배속은 같은 비율로 반영한다. 메뉴·브리핑으로 압박이 진행되지 않는다.

| 시점 | 사건 | 대응과 결과 |
|---|---|---|
| 시작 | 본대 도착 예상 약 20분을 브리핑에 공지 | 계획할 수 있는 정보 제공 |
| 8분 | 현지 호송대가 A→C 출발. A를 이미 상실했으면 R→C 예비 항로를 사용 | 일정은 사전 정의. 경로 변경도 한 번만 수행하고, 발견된 경우 보고 |
| 호송 도착 | 살아남은 화물량에 비례해 C 수비대 보급 재고 증가 | 수비대의 탄약을 즉시 무한 충전하거나 새 함대를 생성하지 않음 |
| 10분 | 적 선발대 R 진입, 재점령 목표로 이동 개시 | 도착 목표 약 18분에 맞게 실제 항로 길이·속도 설정. 공통 경보 제공 |
| 16분 | 적 본대 출발. 기본 R 진입은 20분 | D를 출발 전에 확보했다면 출발 18분·진입 22분. 이미 출발한 함대는 소급 지연하지 않음 |
| 선발대 목표 접근 | A 또는 B 중 아군이 보유한 거점 하나 공격 | 아군 보급 전력·경로 비용·알려진 정보로 선택. 현재 전투 중인 거점으로 순간 이동 금지 |
| 20분 또는 22분 | 실제 편성의 본대 R 진입 | C 구원 또는 항로 차단. 승리 미확정이면 전투 계속; 무한 반복 생성 없음 |
| 24분 또는 26분 | 일반 모드의 작전 결산 시한 | 주목표 성공·철수·실패 판정. 시한은 처음부터 표시하고 D 효과도 UI 갱신 |

승패가 확정되면 남은 사건은 중단한다. 본대는 외부 구원 전력으로 데이터에 한 번만 예약되며, 보급창 상실만으로 사라지지 않는다. 거점 점령은 현지 보급·재점령 경로를 바꾸고, 통신소 확보는 출발 시간을 바꾼다. 출발·진입·목표 도착을 서로 다른 시점으로 관리한다.

선발대를 격퇴하거나 본대를 유인할 수 있다. 증원 전력도 같은 탄약·탐지·이동·손상 규칙을 따른다. 본대 교전으로 플레이가 늘어나는 일반 모드와, 20분에 작전 실패를 결산하는 제한시간 도전은 별도 프리셋이다.

### 6.5 점령과 보급

점령 상태: `적 소유 → 방어 무력화 → 점령 진행 → 아군 통제 → 시설 가동`. 적 재접근으로 경합이 생기면 점령을 정지한다. 점령 중 매 틱 소유권을 뒤집지 않는다.

- 거점 반경 내에서 점령 가능한 전투 전대가 45초간 유지하면 통제권 획득. 정찰 전대 하나로도 가능하되 이 동안 다른 임무 수행 기회가 줄어든다. 기함만 강제하지 않는다.
- 시설 가동에는 추가 15초가 든다. 경합이나 거점 이탈 시 가동 진행은 정지한다. 시간·반경은 조정 후보값이다.
- 함선 수와 비례해 점령 속도를 무제한 올리지 않는다. 소수 분견대로 목표를 수행할 이유를 남긴다.
- 적 방어 시설을 무력화하는 것과 보급 시설을 파괴하는 것은 별개다. 방어 시설 전부 구현이 어려우면 첫 버전은 수비 전대와 거점 점령으로 표현한다.
- 현행 보급의 정지·반경·동시 처리·주기·손상 처리를 유지한다. 탄약·물자 지출은 작업 완료와 같은 트랜잭션으로 처리한다.
- 첫 샘플은 기지 재고를 유한하게 만들고, 지휘/주력 그룹과 기동 그룹이 모두 한 번은 유효한 보급을 받을 수 있는 양에서 실험한다. A는 공격 지속, B는 손상 회복에 유리하되 어느 경로도 탄약 고갈로 필패하지 않아야 한다.
- 파괴된 함선은 수리로 재생하지 않는다. 신조함 생산·보충은 첫 샘플에 넣지 않는다.
- E부터 거점까지 아군 통제 경로가 있으면 기지 재적재 가능. 경로가 끊겨도 현지 창고·보급함에 남은 재고는 사용할 수 있다. 첫 샘플은 물리 수송 재현 대신 연결된 동안의 명시된 재고 유입률을 사용하고 UI로 표시한다.
- 적이 포위했다고 이미 쌓인 탄약을 삭제하거나 수리를 즉시 취소하지 않는다. 차단 효과는 재적재 중단이다.

### 6.6 적의 임무와 정보 제한

| 임무 | 기본 행동 | 접촉 후 판단 |
|---|---|---|
| 순찰 | 지정 항로 왕복, 접촉 보고 | 유리하면 접근, 불리하면 A 수비대로 이탈. 추격 범위 제한 |
| 거점 수비 | 목표 반경 유지 | 보급함 추격보다 거점 보호 우선. 수비대 전부 유인 가능하지 않게 함 |
| 호송 | 목적지 이동 | 엄호 요청·우회·탈출. 플레이어 본대에 자살 돌격하지 않음 |
| 재점령 | 아군 보급 거점으로 접근 | 수비가 강하면 봉쇄·구원 대기. 보급 전력이 노출되면 공격 |
| 예비대 | 중요 목표 유지 | 보고된 위협과 목표 상실에 따라 재배치 |

전술 사격 대상은 확인된 적, 사거리·사선·진로·임무 위험을 반영해 선택한다. 보급함·약해진 전대에 가중치를 줄 수 있지만, 안개 너머 체력·재고를 읽거나 안전한 수비 위치를 무조건 포기하지 않는다. 목표 재선택에는 유지 시간과 거리 제한을 둔다.

### 6.7 PC 조작과 정보

- 우클릭 이동, 경유지 예약, 그룹 지정. 현재 조작 체계와 맞추되 소수 함선의 반복적인 체력 교대를 필수로 만들지 않는다.
- 상단: 주목표, 작전 경과, 본대 진입 예상, 결산 시한. 증원 시각을 ‘게임 종료까지’로 표시하지 않는다.
- 행성 카드: 소유·경합·점령 게이지·가동 상태·재고·보급 대기열·연결/고립.
- 함대 상세: 무기별 탄약, 손상, 보급함 재고. 단일 총탄약 %만으로 함대가 공격 가능한지 판단시키지 않는다.
- 접촉 정보: 확인/추정과 마지막 관측 시각. 상세 편성·목표는 정찰로 공개하고, 캠페인상 필수 경보는 공개 정보로 명시한다.
- 도착 임박 경보는 2분 전·30초 전을 기준으로 한 번씩. 같은 사건을 대사·팝업·음성으로 중복 방해하지 않는다.
- 결산은 목표, 생환 비용, 시설 보존, 호송 차단, 철수 여부를 보여 준다. 시간 점수만 과도하게 주어 보급을 건너뛰게 하지 않는다.

## 7. 구현 경계와 데이터 계약 제안

첫 샘플은 하나의 작전 인스턴스와 연속 시계를 사용한다. 여러 전투 화면을 전환하는 긴 캠페인은 후속이다. 긴 이동을 압축해도 이동 소모·적 일정·호송 진행은 같은 작전 시간으로 반영해야 한다.

권고 신규 구성요소는 `OperationState`, `ObjectiveEvaluator`, `EventScheduler`, `ControlPoint`, `MissionAI`다. 이름은 설계용이며 현재 클래스가 아니다.

- `OperationState`: 작전/스키마 버전, 시드, 시각, 함대 고유 ID별 편성·손상·탄약·보급 재고·위치·명령, 거점 소유·점령 진행·시설 상태·재고, 접촉, 호송, 예약 사건과 완료 ID, 결과.
- `ObjectiveEvaluator`: 전멸·지휘부·점령·탈출 등 목표별 판정. 최종 점령과 시한이 같은 틱이면 목표 성공을 먼저 평가하는 우선순위를 명시한다. 지휘 전대 상실과 동시 성공은 실패 우선.
- `EventScheduler`: `event_id`, `earliest_at`, 상태 조건, 실행 여부, 출발/진입 시각, 부대 편성 참조, 진입점, 임무, 취소 조건. 매 프레임 `time == 480` 대신 `time >= 480 && !fired`를 사용한다.
- `ControlPoint`: 점령·경합·가동과 보급 공급원 소유를 연결. 현행 `SupplyCore`는 초기 기지 목록을 만들기 때문에 지도 색만 바꿔서는 공급원 세력이 변경되지 않는다.
- `MissionAI`: 전략적 목적지와 교전 허용 범위를 정하고, 실제 이동·사격은 기존 전투 코어로 전달한다.

`BattleOutcome`의 손실 비율만으로 다음 교전의 편성을 재생성하지 않는다. 함대별 잔존 상태를 별도 인계해야 한다. 영속 저장은 단계 전환 시만이 아니라 작전 중에도 가능해야 하며, 완료 사건·노획 지급·결산을 재실행하지 않아야 한다.

적벽에 특화된 승패를 별도 프로필 뒤에 유지한다. 신규 작전 목표 판정기를 선택할 수 있도록 확장하되, 기존 적벽의 20분 종료를 전역에서 제거하지 않는다. 현재 한 번짜리 `st.reinf`를 그대로 다수 증원 관리에 재사용하지 않는다.

## 8. 제작 순서와 검증 기준

1. **작전 바탕:** 단일 항성계, 5개 거점과 항로, 이동·목표·순찰. 여러 함대를 전부 첫 접촉으로 모으지 않음.
2. **작전의 이유:** A/B 선택, 점령 상태, 유한 보급, 함대 손실 유지. 기존 탐지·수리·탄약 규칙 연결.
3. **적의 일정:** 호송, 통신소 지연, 선발대 재점령, 본대, 철수·결산.
4. **연속성:** 저장/불러오기·재생·배속 검증. 이후 다른 시나리오 유형 제작.

필수 검증:

- A 직행과 B 우회 모두 승리 가능. 어느 경로든 보급 한 번 이상이 유의미하고, 이동 대기만 길어지지 않는가.
- 두 거점을 모두 먹는 전략·분견대 운용이 가능하면서도 항상 최선이 되지 않는가.
- 최종 목표를 조기 달성하면 즉시 성공하고 예약 증원이 종료되는가.
- 거점을 점령하지 못한 상태의 8분 호송, D를 16분 직전에/직후에 점령한 상태, 경합·재점령이 일관적인가.
- 사거리 밖 보급함·미탐지 저체력 전대를 적 AI가 추격하지 않는가.
- 적이 약한 아군을 보고도 지켜야 할 목표를 유지할 수 있는가.
- 보급 차단 뒤 기존 재고 사용, 이동 중 보급 진행 취소, 저장/불러오기로 재고 복제가 없는가.
- 같은 시드·명령은 배속·일시정지·저장 왕복 뒤에도 같은 사건·결과를 내는가.
- 20분 이후에도 조작·철수·승리 기회가 남고, 명시한 결산 시한에 결과가 한 번만 확정되는가.

플레이테스트 기록: 경로별 이동/교전/점령/보급 시간, 첫 보급 시점, 탄약 고갈 시점, 증원 전 성공률, 철수 선택률, 유휴 시간, 손실 비용. 위의 분 단위 수치는 측정 후 조정하며 확정 난이도로 취급하지 않는다.

## 9. 참고 자료와 근거 범위

- 사용자 첨부 「붙여넣은 텍스트.txt」의 제미나이 기본안·상세안. 검토 대상이며 게임 구현 사실의 근거로 쓰지 않았다.
- [은하영웅전설 공식 본전 1기 줄거리](https://www.ginei.jp/story1.php): 1~2화 아스타테, 6~7화 이젤론, 12~16화 제국령 침공·암릿처. 원작 작전의 큰 구조 확인용이다.
- [공식 본전 2기 줄거리](https://www.ginei.jp/story2.php): 44~46화 페잔 점령·철수, 50~52화 연전·버밀리온. 우회·생환·지휘 목표 참고.
- [공식 본전 3기 줄거리](https://www.ginei.jp/story3.php): 69~71화 재탈환·협로 방어 참고.
- [Die Neue These 공식 45화](https://gineiden-anime.com/story45.html): 페잔 회랑을 통한 진공 계획 확인.
- [Sins 공식 Gameplay](https://wiki.sinsofasolarempire.com/index.php?title=Gameplay), [Stardock Gravity Well Types](https://stardock.atlassian.net/wiki/spaces/SSEFW/pages/1357119491/Gravity%2BWell%2BTypes): 연결 항로·행성 유형·병목 구조 참고. 본 제안의 보급·점령 수치는 이들 게임의 수치가 아니다.
- [Homeworld 3 공식 로드맵 설명](https://www.homeworlduniverse.com/an-update-to-homeworld-3s-roadmap/): 임무 다음 단계로 넘어가는 시점 선택의 전략적 가치와 자원 수집 함대 요소 참고. 세부 캠페인 규칙을 동일하다고 주장하지 않는다.
- [Battlefleet Gothic: Armada 공식 소개](https://www.focus-entmt.com/en/games/battlefleet-gothic-armada): 함대 전술과 스토리 캠페인 결합의 장르 비교. Armada 2의 세부 Urgency 수치는 본 제안에 사용하지 않았다.

이 문서에서 제시한 분기·점령 시간·재고·증원 일정·승패 조건은 전부 우리 게임용 제안이다. 게임 실행 코드나 기존 정본 데이터는 변경하지 않았다.
