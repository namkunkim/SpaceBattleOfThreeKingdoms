## 1. 역사 기록과 규모

| 세력 | 기록 | 출처 |
|---|---|---|
| 조조 | 자칭 "수군 80만" | 조조가 손권에게 보낸 글, 『강표전』 |
| 조조 | 실제로는 중원군 15~16만(오랜 원정으로 지침) + 형주 항복군 7~8만("아직 의심을 품고 있다") | 주유의 판단, 『강표전』 |
| 조조 | 적벽에서 불리했고, 역병이 크게 돌아 관리와 병사가 많이 죽어 군을 물렸다 | 무제기 |
| 손권 | 주유·정보가 이끈 3만 | 주유전, 『강표전』 |
| 유비 | 관우의 수군 정예 1만 + 유기가 모은 강하 병사 1만 이상 | 제갈량전 |
| 화공 | 황개: "적은 많고 우리는 적어 오래 버티기 어렵다. 조조군 배가 머리와 꼬리를 잇대었으니 불태우고 달아날 수 있다" | 주유전 |

**인원 비율:** 조조 약 22~24만 대 연합 약 5만으로, 4.4~4.8배다.

**본편 정본의 비율** (`combat.md` §4.3.3)
- 동원 국력 기준으로 조조 101 대 손유 46, 2.20배다.
- 함선으로는 2,367척 대 1,078척이다.
- 정본은 이 2.20배에서 화공 성공 확률을 27.4%로 계산한다. "적벽은 네 번에 한 번 일어날 수 있는 일"이라는 설계다.

**이 시나리오의 기준**
- 상급 난이도를 정본 2.20배에 맞춘다(실제 2.14배).
- 낮은 난이도는 조조군 규모를 줄인다(§3).
- 연합 안의 손권 대 유비는 인원 기준 3:2를 따른다(288 대 198). 정본 동원 국력은 31:15다.

## 3. 난이도

**원칙** [세션 Q44]
- 난이도는 조조군의 강함만 바꾼다. 연합 편성은 같다.
- 바꾸는 것은 네 가지다: 규모, 시작 사기(역병·원정 피로, 형주 수군의 훈련도), AI 수준, 화공 간파 속도.
- AI는 모든 난이도에서 같은 안개 속에서 싸운다. 본편 `ai-design.md` §9의 "극한 = 완전 정보"는 쓰지 않는다.

| | 입문 | 표준 | 상급 | 극한 |
|---|---|---|---|---|
| 규모 배율 (함종별 척 수) | 0.70 | 0.70 | 1.00 | 1.00 |
| 배치 전대 | 4 | 5 (+형주 을) | 7 (+조순, 조홍) | 7 |
| 조조군 코스트 / 연합 대비 | 529 / 1.09배 | 601 / 1.24배 | 1,039 / 2.14배 | 1,039 / 2.14배 |
| 조조군 함선 | 53척 | 60척 | 113척 | 113척 |
| 전장 전체 함선 | 112척 | 119척 | 172척 | 172척 |
| 시작 사기: 북방군 | 8000 | 8000 (밸런스 2차에서 8500→8000) | 9500 | 10000 |
| 시작 사기: 형주 수군 | 6000 (동요) | 6500 | 7500 | 9000 |
| AI 사고 깊이 / 실수율 / 반응 지연 | 1수 / 25% / 120초 | 2수 / 10% / 60초 | 3수 / 3% / 0 | 3수 / 0% / 0 |
| 화공 위험 대응 | 없음 (밀집 유지) | 간파 평균 60초 | 20초 | 10초 |
| 의도 | 역병과 미숙한 형주 수군. 조조는 묶은 배를 풀지 않는다 | 데모의 보통 | 정본 재현 (2.20배) | 역병 없음, 정상 훈련 |

- 규모 배율은 함종별 척 수에 곱하고 half-up으로 반올림한다. 원래 1척 이상이면 최소 1척이다.
- 입문과 표준은 배율이 같다. 차이는 채모 전대, 사기, AI다.
- 시작 사기 차등은 본편 `ai-design.md` §9(자원 보너스 없음)에 닿는다. 본편은 B7에서 시작 사기 가산을 수용하지 않았다(2026-10-04). 이 시나리오는 난이도 보너스가 아니라 역병·원정 피로·훈련도의 반영이라는 근거와 세션 Q50에 따라 유지하고, 합류 때 남는 차이로 둔다.
- 형주 수군의 낮은 시작 사기는 정본의 "훈련도 20 → 붕괴 확률 ×1.30"(`combat.md` §1.4)을 bp 체계로 옮긴 것이다.
- 화공 간파는 정본 §5.7의 "정욱의 간파"를 실시간으로 옮긴 것이다. 폭발정이 위험 거리(300) 안에 들어오면 조조 AI가 그 전대를 분산 진형으로 바꿀 확률이 초마다 생긴다. 분산 진형이 되면 화공 표적 조건(밀집)을 잃는다.

## 4. 간이 시뮬레이션 결과 (AI 대 AI, 난이도·조건마다 40시드)

> **갱신:** 아래는 초기 편성의 결과다. 투입 시차, 거리대 대기, 화공 재설계를 넣은 최신 결과(세트 RX: 표준 15~16분, 파도 3번)는 `EXPERIENCE-DESIGN.md` §8에 있다.

플레이어 개입 없이 연합도 AI가 지휘한다(방어형). "화공 시도"는 황개 화공대가 밀집 조조 전대에 접근해 연쇄 폭발을 노리는 경우다.

| 난이도 | 화공 | 조조 승률 | 길이 중앙값 | 주된 종료 |
|---|---|---|---|---|
| 입문 | 없음 | 5% | 6분 17초 | 조조 군 사기 붕괴 |
| 입문 | 시도 | 0% | 4분 24초 | 조조 군 사기 붕괴 |
| 표준 | 없음 | 62% | 7분 43초 | 양쪽 군 사기 붕괴 |
| 표준 | 시도 | 32% | 7분 09초 | 양쪽 군 사기 붕괴 |
| 상급 | 없음 | 100% | 6분 56초 | 연합 군 사기 붕괴 |
| 상급 | 시도 | 85% | 6분 41초 | 연합 군 사기 붕괴 |
| 극한 | 없음 | 100% | 6분 50초 | 연합 군 사기 붕괴 |
| 극한 | 시도 | 95% | 6분 51초 | 연합 군 사기 붕괴 |

**읽는 법**
- **상급은 정본과 같은 구도다.** 화공 없이는 연합이 진다. 화공을 시도해도 조조가 간파하면 진다. 성공한 15%에서만 이긴다(정본 27.4%).
- **표준은 화공이 승부를 가른다.** 화공 없이 조조 62%, 시도하면 32%다.
- **입문은 화공 없이도 이긴다.**
- 위 수치는 플레이어가 없는 기준선이다. 플레이어가 직접 지휘하면(측면 기동, 진형 전환, 집중 사격, 화공 시점 선택) 연합 승률이 올라간다. 실제 목표 승률은 M4·M7에서 사람의 플레이로 다시 잡는다.

**한계**
- 간이 모델이다. 진형 전환, 보급, 선회, 위장 항복, 플레이어 개입이 없고, AI가 단순하다.
- 화공의 기류 조건(성운 통과)은 "운용 전대에서 표적이 동쪽 ±60°"로 단순화했다.
- 표본이 40판이라 ±8%p 정도의 흔들림이 있다.
- **전투 길이가 4~8분으로 대회전 목표(15~30분)보다 짧다.** 교전이 시작되면 사기가 2~3분 안에 무너진다. M4에서 사기 감소량, 접근 거리, 일제사격 주기를 함께 조정해야 한다.
