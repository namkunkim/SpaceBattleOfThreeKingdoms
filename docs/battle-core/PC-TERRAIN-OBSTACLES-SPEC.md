# PC 전투 지형·장애물 상세안

2026-10-24 / `codex/pc-ten-minute-battle-review` / 제안 상태, 런타임 미구현.

상위 설계: [10분 전투 검토](PC-TEN-MINUTE-BATTLE-REVIEW.md). 6800×4600 전장에서 이동 경로 선택·엄폐·측면 공격·보급 복귀를 만들기 위한 상세안이다. 현재 `BattleTerrain`의 사각형 효과 구역에 더해 실제 이동과 사격을 차단하는 장애물을 요구한다. 단순 배경 장식만으로는 이 요구를 충족하지 못한다.

추가 사용자 제안인 항행 자격·레이저 차단·강습 전용 구역은 [SF 지형 사례 리뷰 및 병기별 규칙안](SF-SPACE-TERRAIN-REVIEW.md)에 상세화했다. 이 문서의 '첫 버전은 모든 병기 직선 차단' 규칙은 물리적 본체에 적용하며, 별도 효과 구역의 병기별 차단은 해당 규칙표를 따른다.

## 지형별 전술 규칙

| 지형 | 함대 이동 | 직접 사격·뇌격 | 탐지 | 플레이 역할 |
|---|---|---|---|---|
| 성운 | 통과, 기존 비용 1.3333배 | 기존 사거리 ×0.85·사격각 감소 | 기존 관측 센서 감소·표적 은폐 증가 | 위험을 감수하고 우회·접촉 단절 |
| 성긴 잔해대 | 통과, 기존 비용 1.5385배 | 기존 사거리 ×0.9·사격각 감소 | 약한 센서 감소·은폐 증가 | 빠른 개활 항로와 느린 은폐 항로 선택 |
| 행성 그림자 | 통과, 기존 비용 1.1111배 | 기존 사거리 ×0.8·사격각 감소 | 기존 센서 감소·은폐 증가 | 행성 주변 측면 기동. 그림자 자체는 물리적 벽이 아님 |
| 밀집 소행성 군집 | 본체 통과 불가 | 사격선 차단 | 본체를 가로지르는 직접 탐지 차단 | 접근 항로 분기·교전 분리 |
| 대형 난파선·잔해 덩어리 | 본체 통과 불가 | 사격선 차단 | 본체를 가로지르는 직접 탐지 차단 | 국지 엄폐·후퇴 엄호 |
| 행성 본체의 전술 단면 | 원 내부 통과 불가 | 사격선 차단 | 본체를 가로지르는 직접 탐지 차단 | 중앙 직행을 나누는 큰 기준점 |

성운·성긴 잔해·그림자는 기존 효과를 재사용한다. 통과 불가 3종은 새 코어 규칙이며 기존 효과 수치로 흉내 내지 않는다. 지형으로 인한 충돌 피해·파괴·추가 체력 시스템은 첫 버전에 넣지 않는다.

전투는 2D 평면이므로 행성 본체는 해당 평면의 원형 차단 영역으로 정의한다. 화면에서 위·아래로 넘어갈 수 있어 보이는 연출을 피하고, 수직 우회는 지원하지 않는다. 외형은 부드럽게 만들되 판정 경계와 표시 경계는 일치시킨다.

### 미사일·함재기

- 첫 버전에서는 모든 무기 범주가 발사 지점→대상 사이의 차단 여부를 확인한다. 미사일·함재기도 장애물 너머의 적을 직선으로 공격할 수 없다. 엄폐 너머 공격은 실제 우회 항로와 비행시간 구현 후 별도 확장한다.
- 지속 중인 미사일·함재기 공격에서 대상이 엄폐 뒤로 이동하면 이후 명중·피해 판정마다 다시 확인한다. 차단 중에는 피해를 주지 않으며 소모한 자원을 환급하지 않는다. 복귀·수명 만료 규칙은 별도로 유지한다.
- 별도 관측 함대가 적을 탐지했더라도 사격 함대의 사격선이 막혔으면 발사는 불가하다. 탐지 공유와 사격 가능 여부를 분리한다.
- 장애물 뒤의 적은 새 직접 탐지 갱신을 받지 않는다. 기존 마지막 접촉은 전쟁 안개 만료 규칙대로 남으며, 차단됐다는 이유로 적이 지도에서 즉시 삭제되거나 위치가 새로 공개되지 않는다.
- `Detection.in_view()`의 거리 기반 직접 가시 경로에도 장애물 검사를 적용한다. 센서 점수에만 차폐를 반영하면 직접 가시 경로가 이를 우회한다. 다른 관측자의 차단 없는 탐지는 진영에 공유되지만 막힌 사격선은 열리지 않는다. 정찰·특기 등의 일시 공개 효과는 첫 버전에서 마지막 접촉/추정 정보만 제공하고 본체 차폐를 무시한 실시간 확인 접촉을 부여하지 않는 정책을 우선한다. 기존 특기와 충돌하는 경우 PC 프로필 예외로 명시하고 검증한다.

## 장애물 6개 배치 초안

좌표는 전장 기준. 원은 `[중심 x, 중심 y, 반지름]`, 사각형은 `[x, y, 폭, 높이]`다. 소행성은 첫 버전에서 원, 난파선은 축 정렬 사각형 판정으로 시작한다. 복잡한 시각 메시의 개별 돌마다 충돌을 만들지 않는다.

| ID | 장애물·형상 | 좌표 | 의도 |
|---|---|---|---|
| OBS-P01 | 중앙 행성 / 원 | [3350, 2400, 380] | 중앙 교전을 북·남으로 분리, 주변에서 재접적 |
| OBS-A01 | 북서 소행성 군집 / 원 | [2100, 1050, 220] | 북측 선봉이 개활·성운 항로 중 선택 |
| OBS-A02 | 북동 소행성 군집 / 원 | [4550, 1050, 240] | 적 북측 지원의 직선 합류 지연 |
| OBS-A03 | 남측 소행성 군집 / 원 | [3650, 3550, 250] | 남측 우회에 방향 전환 요구 |
| OBS-W01 | 서측 대형 난파선 / 사각형 | [1700, 2350, 360, 200] | 아군 전선 교대·후퇴 엄호 |
| OBS-W02 | 동측 대형 난파선 / 사각형 | [4900, 2500, 360, 200] | 적 후방 접근 전에 교전 방향 선택 |

효과 구역과 장애물은 겹칠 수 있다. 예를 들어 성운 속 소행성 본체는 이동 차단하고 본체 밖 성운은 통과 비용만 적용한다. 행성 그림자와 본체의 범위·UI는 독립적이다. 이 배치는 예시 좌표이며 모든 진형의 통행 가능성을 보장한 완성 맵은 아니다.

북측 경로는 y≈700~1300, 중앙은 행성의 북·남 가장자리를 돌아가는 두 갈래, 남측은 y≈3300~4100에서 설계한다. 북↔중앙, 중앙↔남의 횡단 연결을 각각 2곳 이상 확보하여 한 장애물로 전체 전장이 단절되지 않게 한다. 보급·탈출 지점은 장애물 반대편의 막힌 주머니에 두지 않는다.

### 통로·배치의 치수 규칙

- `R`은 현재 진형의 함대 중심에서 가장 먼 실제 렌더 함선 외곽까지의 보수적 반경이다. 표시 밀도가 낮아도 생략된 함선의 논리 외곽을 포함한다. 코어와 렌더가 같은 진형 치수 데이터를 사용해야 한다.
- `s`는 안전 여유 40좌표를 시작값으로 한다. 한 함대의 통행 폭은 최소 `2 × (R + s) + 120`, 두 함대의 병행 통행은 각 함대 폭의 합에 추가 여유를 둔다. 면적이 넓은 진형에 대해서는 600~900 폭도 부족할 수 있으므로 고정 통로 폭만으로 통행을 보장하지 않는다.
- 진형 유지로 통행할 수 없으면 UI에서 차단된 진형과 가능한 우회 경로를 안내한다. 자동으로 함선을 장애물 안에 집어넣거나, 예고 없이 진형을 바꾸지 않는다. 플레이어가 종진 전환을 선택하면 전환 과정까지 안전한 위치에서 수행한다.
- 스폰·초기 배치·증원·탈출 판정 원·보급 서비스 영역과 그 접근 경로 모두를 검사한다. 최대 진형을 유지한 채 갈 수 있는 경로가 하나 이상 있어야 한다. 불가능하면 장애물 위치·크기를 바꾼다.

## 이동과 우회 경로

권위 있는 장애물 판정과 경로 선택은 시뮬레이션 코어에서 수행한다. Godot 화면 충돌체만 추가하면 헤드리스·리플레이와 실제 화면이 서로 다른 전투를 계산하므로 완료로 보지 않는다.

1. 원·사각형 장애물을 `R+s`만큼 팽창시켜 함대 중심의 안전 영역을 계산한다. 수동 이동, AI, 후퇴·강제 퇴각, 돌격, 집결, 보급 복귀에 같은 규칙을 적용한다. 특기 질주도 통과 불가 본체를 관통하지 않는다.
2. 고정 격자 A*를 첫 구현 후보로 사용한다. 격자 간격 40좌표는 실험값이다. 노드·변 전체의 충돌을 확인하고 대각선 코너 통과를 금지한다. 효과 구역 이동 비용을 경로 비용에 포함한다.
3. 시뮬레이션 내부 경로는 기존 사용자 경유점 수 제한과 분리한다. 사용자가 찍은 경유점 사이에 필요한 우회 노드가 많다는 이유로 정상 명령을 거절하지 않는다. 가시선으로 안전한 구간만 경로를 단순화한다.
4. 각 틱의 출발점→다음 위치를 swept-circle 방식으로 검사한다. 끝점만 검사하지 않는다. 빠른 돌격·큰 틱 이동에서 얇은 난파선을 관통하는 문제를 막는다.
5. 진형 전환·전대 간 밀어내기·후퇴 전환 후에도 외곽을 재검증한다. 넓어지는 진형을 그 자리에서 수용할 수 없으면 거절 사유를 제공하고 안전한 장소를 안내한다.
6. 본체 안에 찍은 목적지에는 '장애물 내부에는 이동할 수 없습니다'를 표시한다. 도달 불가 경로는 명시적으로 거절하고 기존 유효 명령을 유지한다. 지도 지형은 공개 정보이므로 거절이 미탐지 적을 노출하지 않는다.
7. A* 동점 처리, 장애물 순서, 좌표 양자화, 경로 재계산 틱을 고정한다. 벽시계 시간·프레임 순서·화면 물리 결과에 따라 경로를 달리하지 않는다.

경로 재탐색은 명령·진형 크기·목표의 유효 경로가 바뀔 때 수행하고, 프레임마다 전 함대에 반복하지 않는다. 장애물은 첫 버전에서 고정하며 파괴·이동 장애물은 이후 범위다.

## 사격·탐지 판정과 AI

- 사격선은 공격자 논리 위치에서 표적 논리 위치까지의 선분으로 판정한다. 접선과 경계 접촉은 차단으로 처리하고 공통 epsilon을 사용한다. 함선별 메시·발사구 차이는 시각 연출에만 사용한다.
- 물리적 장애물에 막히면 기존 성운 사거리 배율보다 차단 판정이 우선한다. 차단되지 않은 선분에만 효과 구역 배율을 적용한다. 탐지에서도 본체 차단을 확인한 다음 센서·은폐·신뢰도 계산을 적용한다.
- AI는 공개 장애물과 자신이 아는 접촉만 이용한다. 미탐지 적 위치를 이용한 최단 우회는 금지한다.
- 공격 AI는 차단 뒤에서 사격 명령을 반복하는 대신 사격선이 열리는 도달 가능한 후보점으로 기동한다. 우회 거리, 성운·잔해 비용, 알려진 적 사거리, 보급 접근을 평가한다. 후보점 평가 순서도 고정한다.
- 후퇴 AI는 탈출·보급 목적지까지의 실제 경로를 사용한다. 장애물 코너에서 공격 목표와 후퇴 목표 사이를 왕복하지 않게 목표 유지·재평가 간격을 둔다.
- 전선별 경유점을 갖는 초기 배치·증원 목표를 사용하여 전군이 중앙 행성 한쪽에 뭉치지 않게 한다. 지형상 유효한 이동과 기존 교전 거리 유지 규칙이 서로 막는 경우를 별도 검증한다.

## 플레이어에게 보일 정보

- 통과 불가 본체는 밝은 윤곽·사선 채움, 통과 가능한 효과 구역은 반투명 면으로 구별한다. 색상만으로 구분하지 않는다.
- 호버/선택 정보에 '이동 불가 / 사격 차단 / 직접 탐지 차단' 또는 '통과 가능 / 이동 속도 감소 / 탐지·사거리 감소'를 표시한다.
- 이동 미리보기는 실제 코어의 우회 경로·예상 도착 시간·막힌 구간을 표시한다. ETA에 선회·지형 비용이 포함되지 않았다면 근사치임을 알린다.
- 공격 미리보기는 사거리 부족과 장애물 차단을 서로 다른 사유로 표시한다. 미탐지 적이나 적의 숨은 이동 경로는 표시하지 않는다.
- 미니맵에도 동일한 본체·통로를 표시하며, 장식용 작은 돌은 전술 장애물과 혼동되지 않게 한다. 확대·축소 시 윤곽이 선택 입력을 가리지 않게 한다.

## 구현 순서와 검증

1. 장애물 데이터·공통 기하 판정·진형 외곽 데이터를 먼저 만든다. 효과 구역과 독립적으로 로드하며 PC 프로필·프로필 해시·재생 입력에 포함한다.
2. 이동 충돌·우회·강제 퇴각을 연결한 뒤 사격·탐지 차단을 연결한다. 데이터만 읽고 실제로 관통하는 상태는 플레이 가능한 완료로 표시하지 않는다.
3. AI의 사격 위치 선택·후퇴 경로와 UI·미니맵을 연결한다. 그다음 6개 장애물과 10개 효과 구역을 모두 켜고 전투 시간·재접적·정체 구간을 측정한다.

필수 검증 사례:

- 원/사각형 내부·바깥·접선, 0길이 선분, 겹침, 경계 epsilon에서 이동·사격·탐지가 일관적이다.
- 최대 속도 돌격·특기 질주·틱 한 번의 긴 이동도 본체를 관통하지 않는다. 수동·AI·후퇴·집결·증원 배치 모두 같은 조건을 만족한다.
- 큰 진형·작은 진형·회전·진형 전환·분리 보정 후 실제 함선 외곽이 본체와 겹치지 않는다.
- 모든 초기 배치에서 최소 2개 전선에 접근 가능하고 아군 탈출·보급으로 복귀할 수 있다. 도달 불가 목적지 거절 후 기존 명령이 유지된다.
- 장애물 뒤 표적에게 직접·지속 피해가 들어가지 않는다. 다른 아군이 발견한 적이라도 엄폐 너머 사격은 불가하며, 마지막 접촉은 기존 안개 규칙대로 만료된다.
- 알려진 적이 본체 뒤로 이동하면 AI가 가능한 사격 위치를 찾고, 도달 불가 시 사격 명령만 반복하지 않는다. 10초 이상 이동·유효 사격·정당한 대기가 없는 함대를 진단한다.
- 같은 시드·프로필·명령을 헤드리스 및 재생에서 돌리면 경로·결과 지문이 일치한다. 정상 함대 수·전장 전체 화면에서 프레임·틱 시간과 경로 탐색 비용을 측정한다.

이 상세안은 장애물 시스템의 신규 작업 범위를 포함한다. 현재 게임에 이미 구현된 기능으로 안내하지 않으며, 10분 플레이 달성 여부는 상위 검토안의 비교 실험과 실제 플레이로 별도 판정한다.
