화면 흐름: 천하도에서 상세 전투로, 다시 천하도로

홈은 따로 있는 메뉴 화면이 아니라 천하도 자체다. 적벽은 지도 위 같은 좌표에서 생기고, 같은 좌표로 확대해 들어가 상세 전투가 되고, 결과를 지도에 남긴 채 돌아온다. 위 시안의 상태 ①~④가 이 순서를 따른다.

① 개전 전개전 조건 5종을 소식 줄에 표시. 미래 전투는 지도에 예약 표시하지 않는다.
→
② 적벽 개전pending→active 전이 뉴스 1회, 시각 바 아래 1행 배너, 구지 궤도에 교전 표식.
→
③ 전투 진입 시트지도를 가리지 않는 우측 시트. 출진·위임·나중에. 기한은 게임 시간으로 흐른다.
→
상세 전투같은 battle_id·시드·참가 함대 ID로 실시간 전투(mockup-battle-v2). 지도를 Z4까지 이어서 확대한 뒤 HUD로 넘긴다.
→
④ 결과 복귀결과를 정확히 한 번 적용. 퇴각 경로·권역 변화를 1.5초 강조, 배너는 브리핑 로그로 내려간다.

공용 토큰 제안 — 홈과 전투가 같은 색을 쓴다

지금 세력 색이 세 곳에서 다르다. galaxy.json은 위 청·촉 녹·오 적, 본편 ui_palette.gd는 조조 청·손권 녹(유비 없음), 전투 factions.gd는 촉 청록·위 주황·오 보라다. 같은 세력이 홈과 전투에서 다른 색이면 화면 전환 순간 피아 판독이 끊긴다. 아래 표를 두 화면의 정본으로 제안한다. 녹색 계열은 지형 장애물 색과 겹치므로 세력 색에서 뺐다.

서체

본문 Noto Sans KR 400/700(본편 정본, 임베드 OFL), 제목 Noto Serif KR 700(전투 HUD의 본명조와 같은 글꼴 계열). 전투 HUD의 Pretendard는 Noto Sans KR로 맞추는 것을 제안한다. 숫자는 모두 고정폭 숫자.

결정이 필요한 것

  • 1. 홈의 플레이어 세력본편 홈은 손권 시점, 1차 데모와 상세 전투는 유비 시점이다. 시안은 전투와 맞춰 유비로 그렸다.
  • 2. 공용 세력 색위 제안표를 채택하면 전투 HUD의 위(주황)·오(보라)를 바꿔야 한다. 피아 상대색(아군 청록·적 주황)은 세력색과 별개 층으로 둘지 정한다.
  • 3. 세력 문장의 한자전투 HUD는 蜀·魏·吳 인장을 쓰고, 본편 가이드는 아이콘 안 한자를 금지한다. 시안은 형태(사각·마름모·원)+한글 세력명으로 그렸다.
  • 4. 데모와 캠페인의 종료점DEMO-RC-05는 결과 화면에서 끝나고 홈으로 돌아오지 않는다. 상품 홈은 ④ 결과 복귀까지 다룬다. 데모 빌드에서는 ③의 진입점만 쓴다.
  • 5. 진입 기한 동안의 시간screens §1.4가 열어 둔 문제다. 시안은 기한이 게임 시간으로 흐르고, 일시정지하면 기한도 멈춘다.

시안에 쓴 값

지도(권역 경계·항로·회랑·성계·지형 밀도·태양계권 천체)는 본편 정본 데이터다. 소유 상태, 자원, 함대 위치, 시각, 결과는 예시로 표시한 설계용 값이다. 참가 전대·지휘관은 이 저장소의 data/scenarios/red_cliffs_208_realtime.json을 따랐다. 재생성: python tools/ui/build_home_mockup.py [본편 경로].
