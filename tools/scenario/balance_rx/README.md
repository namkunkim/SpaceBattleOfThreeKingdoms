# 밸런스 2차 기록 (세트 RX, 2026-10-03)

`EXPERIENCE-DESIGN.md` §8의 결과를 낸 밸런스 에이전트의 스크립트다. **기록 보존용**이다.

- `sim2.py`: 1차(세트 R). 투입 대기, 거리대 대기, 손권 지원 AI, 사건 기록, 진영 공유 탐지(선택)
- `mk3.py` → `sim3.py`: 2차(세트 RX). 연환·역병, 위장 항복과 의심 게이지, 화공 위력·번짐, 폭발정 2회, 기류 창, 사건 회복과 결집
- `final3.py`: 최종 표 실행기 (`python final3.py`, 조건마다 40시드)
- `tl3.py`: 한 판의 사건 타임라인 출력

**주의:** 이 스크립트는 시나리오 데이터를 갱신하기 전의 상태를 가정한다. 갱신 전 데이터는 조조군 x에 +150을 스스로 더하고, 투입 대기를 스크립트 안에서 정했다. 지금의 `data/scenarios/red_cliffs_208_realtime.json`은 이미 x +150, `deploy_delay_s`, 표준 북방군 8000을 반영했다. 그대로 다시 돌리면 위치가 두 번 밀린다. 재현하려면 오프셋을 0으로 고친다. 실제 수치는 M3·M4 코어에서 다시 잰다.
