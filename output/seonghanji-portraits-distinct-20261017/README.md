- 서방권 13명은 서구·지중해계 6명, 아랍계 7명으로 재제작했다(2026-10-18 최신 지시). 그 외 488명은 동아시아계.
- 여성 20명은 20~30대(20~39세)의 미인.

- SF 군사 초상, 글자 없는 561×701 PNG. 이름·소속·역할·식별 태그는 `tags.json` / `tags.csv`에 분리한다.
- `index.html`은 생성 완료 이미지와 별도 이름을 검색하는 목록이다. 실제 완료 수는 `manifest.json` / `generation-status.json`을 따른다.

## 반복 얼굴 수정

이전 방식은 단일 조조 이미지를 반복 참고했고 얼굴형·헤어 배정도 종속되어 조합이 24명마다 반복됐다. 특수 인물 설정과 추가 수염 지시가 충돌하는 경우도 있었다. 이 버전은 프롬프트를 처음부터 다시 작성하며, 조조 얼굴 이미지 참조를 사용하지 않는다. 501명 모두 개별 얼굴 설계를 기록했다. 실제 구별 여부는 생성 이미지로 확인한다.

초기 새 버전 중 조홍·순욱·순유·곽가·전위는 후속 미남형/단정한 머리 지시에 따라 `-v2.png`로 교체했다. 조비·만총은 젊은 얼굴과 긴 흰 수염의 부조화를 수정했다. 이전 파일은 보존하고 현행 `filename` 연결은 manifest와 태그에만 기록한다. images 폴더 파일 개수를 완료 인원으로 해석하면 안 된다.

## 복구와 검증

- 서방권 교체 내역과 제작 프롬프트는 `western-revision.json`에 기록했다. `images/<ID>-western-v2.png`가 새 현행 파일이며, 이전 동아시아계 초상은 보존했다. 새 태그·갤러리·manifest의 연결은 교체본을 가리킨다. 인종 배정은 사용자 요청에 따른 창작 설정이며 역사적 인물의 실제 혈통을 단정하지 않는다.

- 2026-10-18 재개 시 이전 `output` 폴더가 없었다. 내장 생성 도구의 원본 PNG와 이 대화의 성공한 저장 기록을 대조해 434명과 수정 전 파일 7개를 복원했다. 남은 67명은 새로 생성했다.
- 복구 증거는 `../portrait-recovery/restored-mappings.json`에 ID·이름·당시 파일명·원본 경로·시각으로 남겼다. 복구 스크립트는 기존 파일이 있으면 중단하며, 완료 폴더에 재실행하지 않는다.

- 이전 버전의 조사 문서 일부는 대화에서 복구했으나, 이전 버전 전체의 이미지·메타데이터를 복구했다고 간주하지 않는다. 현재 납품 대상은 이 폴더의 501명이다.

## 생성 및 재개

imagegen 스킬과 내장 image_gen 도구를 사용한다. `prompts.jsonl`은 현재 인물별 프롬프트다. `next.cjs 1`로 다음 대기 인물을 읽고, 한 인물씩 생성한 뒤 `resize.ps1`로 최종 크기를 저장하고 `save-result.cjs`로 등록한다. 마지막에 `verify.ps1`로 파일·규격·태그 연결을 검사한다. 미완료 상태를 완료했다고 표시하지 않는다.
