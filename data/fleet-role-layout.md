# 함종별 함대 진형 배치

이 문서는 Godot 실행 시 `FleetRenderer`가 읽는 배치 기준이다. 아래 `fleet-role-layout` JSON 블록을 수정하고 게임을 다시 실행하면 초기 배치와 진형 전환 배치에 적용된다. 전투 피해·사거리·진형 계수는 기존 시나리오 데이터를 따른다.

## 함종별 역할

| 함종 ID | 함종 | 위치 | 역할 |
|---|---|---|---|
| SHP-01 | 강습모함 | 중앙 후방 | 보호받으며 함재기·강습정 운용 |
| SHP-02 | 공성함 | 후방 화력선 | 방어망 관통 사격 |
| SHP-03 | 포격함 | 중후방 양측 | 장거리 포화 지원 |
| SHP-04 | 전열함 | 전방 중앙 | 정면 교전·돌파 |
| SHP-05 | 보급함 | 후방 안쪽 | 수리·보급 |
| SHP-06 | 전자전함 | 전열 뒤 양측 | 탐지·교란 |
| SHP-07 | 요격함 | 양익 외곽 | 고속 요격·호위 |
| SHP-08 | 고속정 | 전방 양익 | 정찰·연락·기습 |

## 진형별 운용

| 진형 ID | 진형 | 배치 방향 |
|---|---|---|
| FRM-01 | 어린진 | 중앙 돌파. 전열 선두, 뒤쪽에 화력·지원 전력 배치 |
| FRM-02 | 학익진 | 양익 포위. 요격함·고속정을 양익에 전개 |
| FRM-03 | 방원진 | 종심 방어. 모함·지원함을 후방 안쪽에 두고 외곽을 호위 |
| FRM-04 | 안행진 | 사격 전개. 포격함·공성함을 중후방 사격 구역에 분산 |
| FRM-05 | 봉시진 | 축차 투입. 전열 선봉 뒤에 강습·화력 전력 배치 |
| FRM-06 | 장사진 | 종렬 항진. 좁은 대열 폭을 지키며 앞쪽 초계·후미 지원 |
| FRM-07 | 팔진 | 가변 대응. 전열·화력·호위를 방형 대열 내 구역별로 배치 |

진형의 점 좌표·모양·척 수는 유지한다. 함종별 선호 구역에 가장 가까운 빈자리를 순서대로 배정하고, 같은 함종은 좌우 균형을 고려한다. 편성 비율이나 좁은 진형 때문에 선호 구역을 모두 확보하지 못할 수 있다. 격침된 슬롯도 진형 전환 배정에 포함하여 빈자리를 유지한다. 편성이 비공개인 적 접촉과 편성 없는 POC는 기존 표시를 따른다.

## 실행 설정

`order`는 자리 확보 우선순위다. 8개 함종 ID를 각각 한 번씩 적는다. `targets`의 두 값은 `[전후 위치, 양익 위치]`다. 전후 위치는 0=후방, 1=전방이며 양익 위치는 0=중앙, 1=외곽이다. 모든 값은 0~1 범위의 유한한 숫자여야 한다. 아래 식별자의 JSON 블록은 문서에 하나만 둔다.

```fleet-role-layout
{
  "version": 1,
  "order": ["SHP-05", "SHP-01", "SHP-06", "SHP-07", "SHP-08", "SHP-04", "SHP-02", "SHP-03"],
  "targets": {
    "SHP-01": [0.32, 0.18],
    "SHP-02": [0.25, 0.35],
    "SHP-03": [0.45, 0.65],
    "SHP-04": [0.90, 0.30],
    "SHP-05": [0.08, 0.05],
    "SHP-06": [0.58, 0.48],
    "SHP-07": [0.55, 1.00],
    "SHP-08": [1.00, 0.85]
  }
}
```

파일이 없거나 설정이 잘못되면 경고를 남기고 내장 기본 배치를 사용한다. 한 번 생성한 렌더러는 같은 설정을 계속 사용하며, 문서 수정은 다음 실행부터 반영한다. Android 배포 파일에도 이 문서를 포함한다.

## 함선 이미지와 배치도

Godot에서 타이틀 **진형 배치도** 또는 전투 중 **진형 → 배치도 보기**를 누르면 함선 이미지로 배치를 확인할 수 있다. 7종 진형과 예시 편성·실제 아군 편성을 선택하며, 이 문서의 현재 설정으로 배치도를 그린다. 열람 중 전투는 정지하고 돌아가기·Esc로 원래 상태에 복귀한다.

[7개 진형의 함선 이미지 배치도 (HTML)](../docs/ui/fleet-formations.html)를 스펙 시각 자료로 함께 기록한다. 전체 비교 및 개별 확대가 가능하다. HTML은 2026-10-18 설정의 기록이며 실행 시 설정을 읽는 파일은 이 Markdown 문서다. 설정 변경 후에는 HTML도 다시 생성해야 한다. 자세한 연결은 [진형 탭 스펙](../docs/ui/FORMATION-TAB-SPEC.md)을 참조한다.

게임의 이미지 경로는 `assets/ships/silhouette/`다. 전열함 0.png, 포격함 1.png, 공성함 2.png, 보급함 3.png, 전자전함 4.png, 요격함 5.png, 강습모함 6.png를 사용한다. 고속정은 현재 같은 요격함 모델을 사용하되 배치 역할은 별도 함종 ID로 구분한다. 비교 배치도에서는 고속정을 작게 표시한다.

비교 예시는 동일한 56척(강습모함 6, 공성함 4, 포격함 8, 전열함 14, 보급함 4, 전자전함 4, 요격함 10, 고속정 6)을 사용하고 위쪽을 전방으로 표시한다. 실제 게임은 시나리오 편성을 사용한다.
