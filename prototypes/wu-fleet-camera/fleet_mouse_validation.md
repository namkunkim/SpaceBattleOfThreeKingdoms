# 오국 함대 마우스 검증 씬

Godot 4.7에서 이 폴더의 `project.godot`를 열고 `fleet_mouse_validation.tscn`을 현재 씬으로 실행한다. PowerShell에서도 실행할 수 있다.

```powershell
& 'C:/Tools/Godot/Godot_v4.7.2-stable_win64.exe' --path 'F:/WorkSpace/.codex/worktree/wu-fleet-camera/prototypes/wu-fleet-camera' --resolution 1280x720 res://fleet_mouse_validation.tscn
```

- 시작 화면에서 10개 함대와 600척이 정지한다. 휠로 확대·축소한다. 휠 버튼을 누른 채 끌면 지도 위치를 옮긴다.
- 함대군 메뉴의 함대 번호, 개별 표식, 또는 확대 화면에서 모든 함선의 투영 범위를 감싼 사각형을 왼쪽 클릭해 선택한다. 범위가 겹치면 표식을 우선하고, 표식이 없으면 클릭 지점에 중심이 가장 가까운 범위를 선택한다.
- 왼쪽 버튼을 누르고 드래그해 선택 상자에 걸친 함대를 함께 선택한다. Shift+왼쪽 클릭으로 개별 함대를 추가하거나 뺀다. Shift를 누른 채 드래그하면 기존 선택에 상자 안의 함대를 추가한다. 여러 함대를 선택한 상태에서 이동을 명령하면 패널에 표시된 기준 함대가 클릭 지점으로 이동하고 나머지는 현재 상대 간격을 유지하는 목적지를 받는다.
- 지도를 우클릭하면 해당 위치로 이동한다. 우버튼을 누른 채 끌면 버튼을 누른 위치가 목적지가 되고 화살표가 도착 후 함수 방향을 표시한다. 버튼을 놓아 명령을 확정한다. 선택된 함대의 남은 경로, 목적지, 도착 후 함수 방향은 명령 확정 후에도 표시된다. 짧은 우클릭은 이동 방향을 표시하며, 도착 후 선회가 완료되거나 정지 명령을 내리면 표시가 사라진다.
- 패널의 **이동**, **방향 전환**, **정지**도 사용할 수 있다. Space는 전 함대의 일시 정지와 재개를 전환한다. Esc는 선택과 입력 중인 명령을 해제하며 이미 내린 이동 명령은 계속 실행된다.
- 이동 명령을 내린 뒤 휠로 깊게 확대하면 선택 함대의 기함을 따라가며 선체와 후미 분사를 확인할 수 있다. 축소하면 함대군을 다시 볼 수 있다.
- 기존 GLB의 청동색 선체와 청록색 선체 라인을 사용한다. 배기는 기존 이온 노즐에서 세력색으로 점등한다. 위는 `#74bdff`, 촉은 `#85d9ab`, 오는 `#ff938b`다. 이 씬에는 오국만 배치한다.

## 기동 기준

`fleet_poc_motion.gd`는 언리얼 함대 제어 POC의 `Source/ShuFleet/BattleFormation.cpp`에서 기준점 이동·선회, 함급별 함선 회전·가감속, 8개 편대 평균 오차 보정, 근접 분리, 슬롯 복귀 계산을 옮긴다. 거리는 POC의 전함 길이 440을 이 씬의 전함 길이 0.75로 환산했다. 이 씬의 60척 대형을 유지하며, POC에 프로필이 없는 공성함에 포격전함 프로필을 사용한다.

## 검증

Godot 4.7.2 헤드리스 실행에서 시작 상태, 광역·개별 선택과 패널 배치, 줌 전후 10개 함대 위치, 지점 방향 전환, 선택 함대의 가속과 개별 함선 슬롯 추적, 다른 9개 함대 정지 유지, 전함의 6개 노즐과 오국 분사색, 정지 시 분사 소등을 확인했다. 이 검증은 Godot의 입력 처리기에 마우스 이벤트를 전달했다. 최종 씬의 실제 Windows 마우스 조작은 사용자 확인 단계다.

추가 컨트롤도 헤드리스에서 확인했다. 전체 함선의 투영 범위와 패널 비겹침, 중간 버튼 드래그 시 커서 아래 지도 위치 유지, 우클릭과 우드래그 구분, 도착 뒤 지정 방향 선회, 두 함대 동시 일시 정지·재개, Esc 선택 해제 후 기존 명령 유지가 모두 통과했다.
