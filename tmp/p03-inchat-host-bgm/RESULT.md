# P03 BGM 포함 종료 진단 결과

| 시도 | 범위 | 결과 |
| --- | --- | --- |
| 01 | 실제 BGM 로드만 하는 독립 플레이어 | CLEAN, 실제 exit 0 |
| 02 | 같은 독립 플레이어의 실제 BGM 재생 | CLEAN, 실제 exit 0 |
| 03 | 단일 실제 호스트 | FAIL, 실제 exit 1. process disable 후 playing을 검사한 오라클 순서 오류 |
| 04 | 단일 실제 호스트, disable 전 재생 확인 | CLEAN, 실제 exit 0 |
| 05 | BGM이 있는 실제 호스트 네 개와 기능 검증 | CLEAN, 실제 exit 0, 잔여 프로세스 0, BGM 재생 4/4, 기능 4/4, 예상 진단 2개, 그 외 진단 0 |

신규 K6는 5회 사용했다. 사전등록된 06 ordered 조건인 기존 누수의 정확한 재현이 05에서 발생하지 않아 06을 실행하지 않았다. 기존 호스트 시계 K6와 해당 실패 기록은 별개다.

실제 BGM을 포함한 격리 검증에서 정상 종료를 관측했다. 과거 누수 실행과 신규 05의 runner 정리 순서가 달라 누수 원인과 수정 효과는 미확정이다. 생산 파일에 변경을 적용하지 않았다. 실행 차이 및 다음 실험 가설은 `DIFFERENCE-ANALYSIS.md`에 기록했다.
