# 직접 출격 전환 거절 전달 독립 closeout

판정: 명시한 legacy 즉시 전환 거절 조각의 전달을 수용한다. 전체 P02/첫 PC operation은 NOT_READY이며 실제 GUI 입력·자연 종료 및 장면 수락 뒤 준비 실패나 복귀 전환은 이 인수 범위가 아니다. PC0 2/2 소진, 별도 여덟째 K6 미사용은 유지한다. 실제 모델 ID는 이 런타임에서 검증되지 않아 추정하지 않는다.

전달 ZIP SHA 491a6d55c2bd870c4f7b3f82b2913a0acf771baf4fe4768a93bd9d0473b1c7bd, manifest SHA eeb2287b65e06797b5cba4dc36f3d87e2cdafcf03a77fb782189a2455d8924fe를 대조했다. ZIP 216개는 manifest 수록 payload 215개와 manifest 자신 1개이고 중복 이름·CRC 오류가 없다. 215개 모두 크기·SHA·현재 동일 경로 파일을 재대조해 일치했다. ZIP은 curated evidence이며 전체 원본·전체 사용자 데이터를 포함한다고 주장하지 않는다.

현재 source 1480개는 두 승인 적용 후보 및 나머지 동결 closure와 일치한다. 별도 5-b와 적용 후 심사의 14 lane 원문, 실제 로더 오류 4쌍·45행 및 root/Job 증거가 전달 목록에 있다. source 테스트 원본은 overlay로 덮지 않았다. HEAD 0be09755, index 6980bad4…, staged 비어 있음. baseline에 기록된 기존 ZIP/HTML 62개도 현재 해시와 일치한다. 이전 전체 baseline은 수집 중 변경된 비원자적 표본이므로 다른 모든 경로의 무변이를 뜻하지 않는다.

진행표 변경은 보존한 before에서 직접 전환 거절 구간 하나만 추가한 것임을 실제 텍스트 대조했다. 문서는 최초 두 실패, 세 번째 격리 통과, 이후 원본 바이트 반영 및 원본 적용 후 Godot 미실행을 구분한다. 직접 재진입 테스트는 OS 입력이 아니며 강제 sim._end는 자연 종료가 아니다. P03 채팅의 idle 관측은 표본 시점 상태이지 향후 쓰기 잠금이 아니다. 독립 closeout은 ZIP 외부에 남기므로 이미 동결된 전달물의 자기참조 변경을 만들지 않는다.
