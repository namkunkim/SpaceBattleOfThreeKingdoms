## 실제 연결과 호환 경계

`operation_runtime_adapter.gd`는 명시 runtime-ready 입력의 검증·한 번 JSON 정수 정규화·원자적 fresh private 구축을 담당하는 static factory다. owner public read2개와 기존 queue/advance/drain/close를 실제 `tests/autoresolve.gd --operation-input <JSON> --out <새경로>`가 소비한다. opt-in 기본값은 꺼짐이다. 입력/지원밖/출력 실패는 명시 exit1이며 legacy fallback·모듈/증원 임의 제거가 없다. no-clobber 출력과 close-before-write 계약은 결과 문서를 따른다.

초기 controls []와 명시 delegate 배열·정확 Variant/키/순서/typed identity 계약을 완화하지 않았다. private 추가 read 때문에 code SHA가 바뀌었으며 과거 packet 호환 보증은 없다. I01a synthetic geometry 설정을 runtime 입력으로 승격하지 않았고 source→effective 변환·전체 K02/hash/ID/cursor 계약은 미완료다. stock POC 전체/실제 적벽/다른 활성 모듈을 지원한다고 가정하지 않는다.

정책은 public projection만 본다. none 즉시 반환, attack5는 copied 정책뷰의 confirmed/estimated contact에 현재 Detection.foes 의미로 dead=false만 보완하고 lost를 제외한다. 기존 legacy 정책/play/play_rc/통계 본문은 추가 hunk 역제거 시 사전 바이트와 같다. 실제 UI host의 G/vm/clock/선택/카메라/trace 및 worker thread에 동기 owner를 공유하는 통합은 구현하지 않았다.
