# V2 검증기 수정 및 격리 2회차 준비

독립 실행 승인 대기. 1/6 사용, 2회차 엔진 실행 0. 제품 후보와 원본 제품 바이트는 1회차와 같다.

준비 단계에서 `G.has("state")`와 존재 시 Variant 값을 분리한다. 최초 준비 실패에서는 키 부재와 빈 Dictionary, 결과·일시정지에서는 각각 키 존재와 `"end"`·`"pause"`를 확인한다. 거절 때마다 키 존재와 값 보존을 두 ID로 판정한다. 값이 없는 최초 준비 실패에서는 Dictionary가 여전히 비어 있어야 한다. 실제 버튼, sim·화면·라우팅·대기 Outcome, WorldMap 복구와 기존 진단 검사는 유지한다.

매니페스트는 이전 고정 자료와 원문 로그를 포함해 38개 파일 및 원본 closure 1,480개와 보호 표본 26개를 대조한다. 20개 명령과 개별 상한 합계 1,950초는 이전 계획과 같다. 예상 검증 행은 기준선 거절 각 17, 후보 거절 결과 29와 일시정지·준비 각각 28, 정상 결과 각 13과 정상 일시정지·준비 각 12다. 1회차와 별도 경로 및 승인 파일을 사용한다.

준비 시 C: 여유 5,019,762,688바이트, 이전 같은 규모의 import 완료 프로젝트 실측 약 1.004GB였다. 두 프로젝트의 신규 복제를 사용해 1회차 캐시와 증거를 보존한다. 시작 직전 4,000,000,000바이트 미만이면 복제를 시작하지 않는다. 절대적인 실행 중 디스크 사용 상한을 의미하지 않는다. 원본·이전 실행에서 삭제한 경로는 없다.
