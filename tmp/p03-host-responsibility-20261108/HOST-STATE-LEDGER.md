## 반례 3개와 증거 범위

- **A 준비 실패와 운영 복원 실패.** P02의 벤치용 patch가 빈 프로필이나 비배열 roster를 만든 입력은 새 sim 생성 전 반환한다. 기존 실행에서는 지정 동기 호출 실패/정상 복구 및 정상 start→close trace 비교를 수용했다. 반면 운영 중 packet 오류는 코어 [restore_completed](../../core/battle/operation_private_state.gd:354) 및 향후 host 재결합이 관여한다. 준비 실패에서 기존 sim 동일성만 확인해도 restore 실패 후 선택·FX·trace·소비가 보존된다는 결론은 나오지 않는다.
- **B 논리 시간과 프레임 잔여.** P03 terminal 관측에서 tick2/clock150을 보존했다. 같은 논리 checkpoint의 두 host 인스턴스에서 acc를 서로 다른 소수로 둔 뒤 같은 frame delta를 공급하면 정수 tick 문턱을 한쪽만 넘을 수 있다. 이는 TickClock 계산에서 도출한 미실행 반례다. 두 host clock이나 종료 HUD 지연의 복원은 terminal 실행 범위 밖이었다.
- **C 큐 drain과 별개 소비.** P03 viewer 관측은 같은 tick의 pre/post-filter core queue와 restore를 확인했다. 같은 post-drain packet에서 trace/FX 통지가 실행된 호스트와 아직 실행 전인 호스트를 대조하는 재현은 미실행이다. WorldLink outcome 슬롯이 비었다고 외부 게시/지급 완료 또는 내구성 있는 ack를 추론할 수 없다. [replay 책임표](../p03-progress-20261108/REPLAY-SUFFIX-RESPONSIBILITY.md)는 consumed를 해당 replay의 지역 변수로 분리한다.

P02 실제 마감은 제한된 동기 준비·게시 및 정상 흐름 비교에 적용된다. HUD 상호작용, timer/callback, thread/await 및 외부 ack의 운영 복원은 이번 조사에서 실행하지 않았다. 전체 P03/I01/I01b/A04~A06 NOT_READY, O07 OPEN, 외부 save schema UNCLASSIFIED.
