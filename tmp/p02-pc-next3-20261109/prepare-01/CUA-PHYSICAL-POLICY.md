# 실제 Windows 입력 행 보류

실제 입력은 문서화된 CUA 앱 동작으로만 검증한다. 현재 runner는 승인 범위를 headless-28-only로 제한하며 물리 행을 시작하지 않는다. Windows 입력도 0건으로 기록한다. 물리 전장 관측 코드는 수동 입력을 기다리고 이벤트·제품 viewport를 기록한다. 이것만으로 OS 입력 주체를 입증할 수 없다.

별도 독립 승인에는 CUA 표면에서 Job의 PID와 창 소유권, foreground, 실제 클릭 대상 화면과 좌표의 연결을 문서화된 방법으로 증명할 수 있어야 한다. 어느 연결이든 확인할 수 없다면 GUI는 미검증 상태로 둔다. 제품 장면 전환 이후의 viewport 및 엔진 입력 사실은 OS 캡처와 CUA 동작 기록과 구분한다. 생성된 Brief seed와 host seed를 비교하며 고정 seed 주입은 없다.

기존 PC0 결과의 분모는 이 항목과 별개다. 스크립트 신호를 물리 입력 결과로 세지 않는다.
