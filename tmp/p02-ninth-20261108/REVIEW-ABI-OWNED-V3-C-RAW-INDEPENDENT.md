# ABI owned v3 및 C raw 매핑 독립 심사

판정: **source-only·합성 보강 수용, 실제 실행 manifest는 반려.** `ABI-OWNED-V3-AND-C-RAW-REVIEW.md` SHA `ddc21e16b0be39788c33be0e1a02cfefa0c24f8e4f7742946797612066309382`, SHA 목록 `3438d1906ebee43369e651d19a0f46b1106786fc6dafa8720187cbf0c0b1013b`, runner `a97490e99029e9e46a2ff91ba3e233553ebad4420f907093ab27112e4de85381`, C mapping `f16966ad47957548bdafc1282e8a8e5c59ba23f6c714270884da2f084679b1a0` 확인. 심사 모델 gpt-6.1-terra. 실제 Godot·Job·제품·GUI 실행 없음.

ABI runner는 broker HANDLE 할당·membership 확인 뒤 barrier를 해제하고 Job process list를 통해 retained HANDLE, creation time, image path와 종료 상태를 수집하려 한다. 20초 inner/35초 outer, 제한 output 및 owned drain 구조는 필요한 요소다. 다만 **정적 판독과 합성 로그는 실제 Windows nested Job·wrapper spawn·short-lived process 관측·cleanup을 입증하지 않는다.** 프로세스 image는 허용 경로와 비교하고 실행 전후 파일을 hash하지만, 실제 열린 image의 바이트 identity와 중간 교체를 직접 증명하지 않는다. 정확 engine/broker/launcher inputs, 실제 observed image path·creation time 및 hash 한계, per-handle membership, PID 재사용·짧은 프로세스 미관측의 실패를 확인해야 한다.

독립 manifest 수용 전 다음의 유한 단계를 요구한다. (1) 우선 동일 nested 소유 코드로 무해한 Python child의 정상·timeout·출력 초과·할당 실패/관측 실패를 전용 scratch에서 검증하고 retained HANDLE·active 0 및 별도 owned sentinel의 생존/정상 종료를 기록한다. 이는 Godot ABI 자체나 실제 engine child 관측을 대신하지 않는다. (2) supervisor의 `release` 및 setup, `drain_and_confirm`, 최종 `fsync`가 각자의 deadline 밖에서 막힐 가능성을 외부 tool/supervisor의 유한 stop 및 owned Job 정리로 다룬다. 강제 종료 후 journal 누락은 실패다. (3) 실제 argv/env, 승인 pin, 입력/출력 SHA 및 expected scratch list, protected HEAD resolved ref/index/P03/worker의 관측 범위를 확정하고 재심한다. 예기치 않은 scratch 파일은 실패이지만 workspace 전체 외부 쓰기나 전후 샘플 사이 변경은 증명하지 못한다. reviewed engine·최소 source를 쓰는 위험 기반 접근으로 한정하며 해당 한계를 명시한다. (4) 짧은 engine이 membership 관측 전 종료되면 PASS로 바꾸지 않고 실패로 둔다. 권한 상승·사용자/타 세션 프로세스 조작은 하지 않는다.

C mapping은 파일 SHA·line offset/hash, ordinal 및 nondecreasing microsecond를 기록하고 다섯 call의 source/target raw 순서·typed packet·outside·repeat no-op을 비교한다. 동시 microsecond를 인위 증가시키지 않는 판단은 옳다. 그러나 `restore_pairs`의 seed/tick/sim_id 등에는 exact int 검사가 없고 Python의 `True == 1` 같은 타입 동등성을 이용한 잘못된 ID/tick/seed가 허용될 수 있다. actor/lane/phase/seed/tick/sim token의 정확한 타입·범위와 유일성, 시각 동률·회귀 및 raw event 누락/혼입 반례를 추가한다. Mapping은 일부 사건만 필터하므로 원본 전 event의 총 순서와 예기치 않은 행, initial/eval/scope 및 20개 segment를 전체 판정기가 별도로 검증해야 한다. packet을 Variant로 decode한 typed 값은 재직렬화 bytes가 아니다. approved pin/v4 geometry/v7 original packet/v9 phase/alias/detach/suffix 연결 및 실제 producer 영향·출력량/시간 상한은 미완료다.

제안된 Python 자손 시험과 검토된 최소 ABI 실행은 제품 fixture/project/cache를 읽지 않으면 K6 제품 소진점이 아니며, GUI·21행의 증거로 합산하지 않는다. 실제 제품 import 또는 검증 spawn 시 마지막 K6이 소진된다. 현재 review-only status를 유지하고 실행하지 않는다. P03 활성 변경과 worker·기존 원문/K1~K5를 보호하며 HEAD lane의 P03 결합은 미검증으로 남긴다.
