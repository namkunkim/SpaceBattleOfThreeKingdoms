# 캡처 계측 및 비제품 watchdog 준비 결과

제품 실행·import·Godot 파싱·GUI 입력·Job 실제 시험은 각각 0회다. 원본 변경 없이 새 evidence만 생성했다. K6 한 회가 남아 있다.

- 행 19 Q. `capture-overlays-review/p02_headless_adapter.gd`와 정규화 diff는 제품 정책 command sequence와 raw BattleSim reference sequence를 각각 캡처한다. 정책 함수와 queue 호출은 각각 한 번이다. 전체 ordered command Dictionary를 var_to_bytes hex로 표현하므로 JSON은 typed payload 자체를 변환하지 않는다. Raw fixture의 기존 terminal ticks에서 유도한 2,164개의 case/seed/tick 키를 `qc_capture_streams.py`가 검사하고 양쪽의 동일 누락도 거부한다. 해당 tick vector는 수용된 관측 fixture에 한정되며 final lane의 fixture 일치가 필요하다.
- 행 19 C. `capture-overlays-review/i01b_service_state.gd`는 _restore 전에 직접 생성·진행된 native source의 양쪽 contacts, 복원 직후 target의 양쪽 contacts를 동일 typed encoding으로 캡처한다. _restore의 원래 detached identity 및 불변 단언은 유지한다. 10 seed×2 상태×2 복원×2 side = 80개 키를 검사한다. 양쪽 records 개수는 결과에서 관측하며 역사 단언 합계로 계산하지 않는다.
- 행 21 B. `b-capture-review/world_link.gd`의 expected는 dynamic node 이름을 임의 예측하는 대신 constructor가 저장한 직접 참조, frozen difficulty keys와 특정 child slots에서 기대 object를 찾는다. 실제은 원래 _buttons의 재귀 목록이다. 두 목록의 runtime absolute NodePath와 device-major 순서를 맞춘다. 4/10/2/6개의 stage 버튼 기대, 3개 device, static 43을 합쳐 109를 제안한다. 이 수는 fixture visibility를 전제로 한 정적 산출이며 실제 WorldLink 파싱·실행은 독립 심사 후 단일 K6 범위다.
- Python 합성 판정은 Q/C 2 정상 +8 반례, B 1 정상 +4 반례다. 같은 누락을 양쪽에 넣는 경우, duplicate, 순서 교체, raw Variant hex 부적합, button path 및 device type 변형을 거부했다. Hex 형식 검사는 payload 전체의 Godot 역직렬화나 타입 의미의 외부 증명은 아니다. B의 예상 경로 노드가 현장 expected/live 어느 쪽에서도 확인되지 않으면 미완료다. 출력을 추가한 GDScript parser, 런타임 영향, 통합 assert ordinal/diff, 21행 최종 manifest 모두 미검증이다.
- Computer Use SKILL과 docs/api.md에서 Sky의 opaque Window.id, capture/targeting, click/press_key의 Promise<void>, Window 자동 활성화를 확인했다. 클릭·키 입력에 OS hook에서 대조할 nonce/표식 파라미터나 per-request OS receipt, 입력 이벤트 스트림 계약은 문서에 없다. Sky가 SendInput을 사용한다는 설명과 실제 요청별 provenance 입증은 별개다. 앱 선택·입력·hook을 호출하지 않았다. 15/16과 전체 K6은 해당 경계가 남아 대기한다.
- `watchdog-review/WATCHDOG-DRAFT-INPUTS.json`은 최소 프로젝트/스크립트, 실제 Python·엔진·V5 broker의 SHA와 W1~W5 engine argv, per-case profile/cache roots, 예상 user dir, hard/inner/cleanup timer를 고정한 review-only 자료다.
