# P03 fresh replay 부분 처리 경계 독립 5-b

2026-11-08. **변경 요청.** 대상 실행의 동작 관측은 보존한다. 승인 v2의 필수 5-a 조건 두 가지를 충족하지 않아 독립 최종 수용은 보류한다.

`/root/p03_review`가 구현 담당과 별도로 심사했다. 사용자가 인정한 모델 배정 근거는 `spawn_agent`의 명시적 `gpt-6.1-sol` 지정과 별개 에이전트 ID다. 실제 서빙 모델은 별도 검증하지 못했다. 심사 중 추가 엔진 실행과 구현 변경은 없었다.

## 원문 대조

- 승인 v2 SHA-256 `186D68D56785176DBF19AEC9A4CD3A851623759E8F073B876400D7963B92786A` 일치. 심사 manifest 13/13, 조사 입력 19/19, P02 원본 fixture·oracle 6/6을 각각 재해시했다. 기록상 입력 SHA와 크기의 전후 일치는 첫 oracle 51/51, 수정 oracle 51/51, probe 53/53이다. 첫 시도와 현재의 차이는 `oracle_a.gd`와 `launch.py`다. 두 성공 시도의 동결 목록은 현재 파일과 일치했다. 첫 시도 소스 바이트는 전용 폴더에서 별도 발견하지 못해 당시 소스 대조는 해시·stderr에 한정된다.
- 첫 oracle은 타입 추론 parse error 2건과 ERROR 1건, 실제 exit 1이다. 수정 oracle은 직접 BattleSim을 구동하고 replay/owner 호출 없이 예상 summary를 구성한다. 대상과 BattleSim 본체를 공유하므로 replay 조율 경로를 검증하는 독립 대조다. 실제 exit 0, 종료 tick/end_tick 1221, clock/end_ms 122050, `no_selection`과 terminal event를 원문과 코드에서 확인했다. oracle native SHA가 대상의 실행 전 입력에 일치한다. K=6 안에서 oracle 2회와 대상 1회를 사용했다.
- probe 원문에서 네 이름의 ID 1–8이 순서대로 각 한 번씩 등장하며 32개 모두 PASS다. 소스의 검사 조건을 승인표와 대조했다. 대상 실제 exit 0, 진단 0, Job active 0/total 2, 콘솔과 본체 PID 분리 및 경로 일치다. timeout 경로는 이번에 발생하지 않았다. 결과는 선행 A log와 terminal 실패, 무효 B의 선행 검증, A 단독의 ordered raw events와 summary, 내부 helper의 닫힘 범위에 한정된다.
- 현재 HEAD는 시작 `fb660cea69207fd332e26128643007694910a253`와 일치한다. STATUS-DELTA에 보이는 295행은 P02 215, 전용 29, 기타 P03 폴더 51의 신규 미추적 경로다. tracked 표시의 상태 변화는 관측되지 않았다. status는 이미 dirty였던 파일의 내용 변경을 입증할 수 없고 양쪽 긴 경로 경고로 완전한 스냅샷도 아니다. P02와 다른 P03 파일을 이번 실행 산출물로 집계하지 않는다.

## 변경 요청

1. **필수 실행 마커와 판정 불일치.** 승인 v2는 검사별 시작/종료 마커와 정확한 네 이름별 8개 고유 PASS를 외부 게이트 조건으로 등록했다. `probe.gd`와 stdout에는 CHECK 행 및 최종 PROBE_RESULT만 있으며 CASE_START/CASE_END가 없다. `launch.py`는 총수와 유일성만 검사하고 정확한 이름·ID 집합과 마커를 강제하지 않는다. 사후 대조는 원문 32 PASS를 뒷받침한다. `gate_passed=true`는 승인 게이트의 판정과 불일치한다. 대상 runner와 외부 판정에 등록된 검사를 반영하고 기존 원문을 보존한다.
2. **동결 입력 누락.** `project.godot`의 WorldLink autoload는 `scripts/world_link.gd`를 참조하며 스크립트는 BattleBrief와 BattleOutcome 타입을 참조한다. `launch.py`와 실행별 목록에는 이 스크립트와 해당 클래스 파일이 없다. 정본 문서도 별도의 조사 해시 목록에 있고 실행 전후 목록에 포함되지 않는다. 현 resource_path 가드는 oracle의 BattleSim, probe의 Replay와 Private를 확인한다. 누락은 현재 해시를 소급 채워 해소할 수 없으므로 다음 실행이 승인되면 autoload·타입 및 정본을 포함한 의존성 목록과 경로 검증 범위를 확정하고 실행 전후 기록을 확보한다.

워크플로우에 따라 5-b 반려를 스펙 단계로 돌린다. 기록된 실행은 관측으로 보존하며 이번 심사에서 재실행하지 않았다. P03/I01/I01b/A04–A06 NOT_READY, O07 OPEN, 외부 저장 스키마 UNCLASSIFIED를 유지한다.
