# FX-S A06 증거 매핑 인계

독립 수용된 계획에 따라 A06 요구 7개와 과대 집계 반례 3개를 정리했다. 정적 5-a에서 원문 위치 불일치 0, 입력 16개의 정확한 경로·SHA·크기 전후 일치를 확인했다. 역사 제한 실행, 정적 관측 및 가상 효과의 증거 분류를 유지한다. 별도 Terra 5-b 대기다. Godot은 실행하지 않았고 공유 파일과 P02 파일은 읽기만 했다.

운영 인수의 외부 차단은 제품 효과 완료의 권위 있는 소유자/결과 기록, 제품 명령 및 epoch, ST·활성 host 보존, durable 커밋과 실패 복구 계약이다. 다음 최소 결정은 대표 제품 효과 하나와 해당 효과 완료를 증명할 소유자·기록을 지정하는 것이다. 결정 후에만 그 결과를 관측하는 처리 표식만 남음·효과만 남음·재시도 계획을 별도 등록한다. 가상 실험을 반복해 외부 권위를 대체하지 않는다. 전체 P03/I01/I01b/A04–A06 NOT_READY, O07 OPEN, 외부 저장 schema UNCLASSIFIED.
