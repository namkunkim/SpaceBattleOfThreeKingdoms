# P03 cursor/drain 보존 판정 개정안

Terra 계획 승인 대기. 기존 PLAN.md의 네 명명, 32개 단언, fixture·oracle·엔진·Job 게이트는 유지한다. 실제 실행 3회/K=6, 잔여 3회다. 04 preflight에서 엔진을 시작하지 않았다. 이후에는 상위 조율이 지정한 1회만 별도 승인 후 실행한다. 실제 사용량 제한과 승인 밖 변화는 즉시 중단·보고하며 자동 반복하지 않는다.

## 사전 고정

- 계획과 runner/launcher/Job helper, console/엔진 본체, 프로젝트·class map의 모든 해석 경로, 생산 코드·데이터·설정 및 정본을 확정된 경로, SHA-256 및 크기로 고정한다. 기존 135개를 최소 비교 분모로 삼는다. 목록 재해시 불일치, 누락, 해석 오류, 링크·경로 탈출은 엔진 실행 전 중단 사유다.
- 보호 파일은 기존 실행 입력, 생산 경로의 기존 파일, 조율자가 명시한 P02 소유 경로의 기존 파일, 아래 허용 디렉터리에 이미 있던 모든 파일이다. P02 코드·정본·전용 작업 폴더를 manifest로 명시하고 status와 별개로 실물 열거하여 ignored/장경로도 포함한다. 경로별 존재·SHA·크기를 전후 비교한다. 보호 범위가 불분명하거나 읽기·열거에 실패하면 미실행 중단한다.
- 자체 출력은 전용 조각 아래 다음 미사용 attempt 폴더와 예약된 새 감사 파일에만 쓴다. 기존 시도의 원문이나 계획을 덮어쓰지 않는다. stdout/stderr와 Godot 사용자 데이터 및 임시 파일은 해당 attempt 아래로 격리한다. attempt 디렉터리와 새 감사 파일은 각각 원자적 독점 생성으로 예약한다. 기존 경로 또는 예약 실패 시 실행하지 않는다. 전후 실제 출력 경계·최종 실경로 및 각 구성 요소의 링크·재분석점을 검사한다. 충돌 또는 탈출이 관측되면 hard stop이다. 실행 전 예약 목록, 실행 후 실제 생성 목록과 PID를 기록한다. 이 예약은 제3자의 동시 변경 가능성을 제거하지 않는다. P02 중지를 요청하지 않는다.

## 외부 신규 허용 범위

다음 패턴의 한 단계 아래 새 일반 파일만 허용한다. 허용 trace의 부모 디렉터리는 실행 전에 존재하고 실경로가 확정돼야 한다. 신규 디렉터리 및 링크는 허용하지 않는다. 같은 패턴의 기존 파일은 보호 대상이다.

- tmp/p02-eighth-20261108/gate-k1/before-world-clean/roaming/Godot/app_userdata/SpaceBattleOfThreeKingdoms/battle_traces/battle-*.jsonl
- tmp/p02-eighth-20261108/gate-k1/before-world-returning/roaming/Godot/app_userdata/SpaceBattleOfThreeKingdoms/battle_traces/battle-*.jsonl

허용 신규의 경로, 발견 시각, 크기, 가능한 SHA와 외부 출처 근거를 별도 기록한다. P02 실행 기록의 경로·시간·프로세스 등 독립 증거로 해당 파일을 P02에 귀속할 수 없거나 자체 출력 가능성을 배제할 수 없으면 hard stop이다. 이름만으로 출처를 판정하지 않는다. 작성 중인 파일의 두 표본이 달라지면 차이를 신규 파일의 속성으로 기록하고 가능한 경우 후속 안정 표본도 보존한다. 두 표본만으로 출처나 최종 내용이 확정되었다고 주장하지 않는다. 링크, 형식 변경 또는 사전 예약된 자체 출력과 겹치면 허용하지 않는다. 패턴 확대는 별도 사전 심사 대상이다.

## 종료 판정

같은 고정 집합을 재해시하고 HEAD, porcelain·stderr, 보호·P02·생산·자체 출력·허용 디렉터리별 전후 재귀 실물 인벤토리와 자체 및 외부 출력 차이를 대조한다. 이 인벤토리에는 ignored 여부와 무관하게 새 파일, 디렉터리, 링크를 분류하며 열거 실패는 실행 전 중단 또는 종료 게이트 실패다. 그 외 영역은 porcelain이 실제로 관측한 범위만 비교한다. 기존 보호 파일의 삭제·이동·내용 변경, 허용 목록 밖의 신규 경로, HEAD 변화, timeout, Job 종료 실패는 hard stop이다. 사전 보호 목록은 종료까지 고정한다. 기존 trace append나 기존 보호 파일 갱신은 정당한 P02 작업이어도 이번 시도의 hard stop이며 그 결과를 새 기준선으로 자동 재분류하지 않는다. 경고는 원문으로 남기고 보호 영역의 열거를 가린 경고는 실패 처리한다.

반례: before-world-clean의 새로운 일치 trace는 외부 출처와 함께 기록한다. 기존 trace가 한 바이트만 바뀌어도 실패다. 다른 실행 모드의 새 trace, 별도 P03 suite.json, 새 생산 파일도 실패다. 허용 신규 trace와 동시에 owner나 class map이 바뀌면 실패다. 자체 runner가 P02 경로를 출력으로 사용해도 실패다.

이 gate는 동결 입력 및 정의된 보호 범위의 관측된 전후 일치와 자체 출력 한정을 판정한다. 전체 트리 무변이, 실행 중 변경 후 원복의 부재, 미관측 경로의 완전한 열거는 입증 범위 밖이다. 독립 5-b는 보호 목록·재해시·예외·반례와 원문을 다시 대조한다. Terra가 이 개정안을 승인하기 전 구현·실행을 시작하지 않는다. 전체 P03/I01/I01b/A04–A06 NOT_READY, O07 OPEN, 외부 저장 schema UNCLASSIFIED.
