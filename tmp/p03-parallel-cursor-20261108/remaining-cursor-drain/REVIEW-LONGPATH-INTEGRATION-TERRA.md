# 긴 경로 및 종료·출처 통합 독립 검토 — 미수용

대상 PLAN-LONGPATH-EXIT-INTEGRATION.md SHA-256 `894076F3AEC482687E093916DA0C938FD5F1933B65F3D84D2AF750BB060EC652`. 엔진 실행 없이 검토했다.

긴 경로 진단은 명령 단위 longpaths status exit 0 및 stderr 빈 기록, 두 경고 대상의 확장 경로상 빈 디렉터리 열거를 포함한다. 선언 범위 요약은 29 roots, 고유 파일 79,647, 디렉터리 2,980, 잔여 오류 0으로 기록하고 다섯 ZIP을 최초 디렉터리 열거 오류에서 별도 정규 파일 SHA·크기로 보충한다. 원래 SUMMARY의 오류를 지우지 않고 MERGED 및 scope audit에서 회복 경위를 기록한 점은 유용하다. 서로 다른 시점의 열거이므로 단일 원자 스냅샷이나 실제 실행의 전후 무변이를 입증하지 않는다. 확정 실행 분모의 완전성·재해시는 향후 preflight와 종료 감사에서 다시 확인해야 한다.

단독 helper의 8개 합성 검사 결과는 파일 변경·삭제, 허용·미귀속, 잘못된 경로, 디렉터리·링크를 다루지만 실제 종료 경로와 출처 어댑터를 통한 통합 검증이 아니다. Sol 확인에 따르면 런타임 격리·종료 판정·실제 출처 어댑터는 아직 계획 단계다. 따라서 **종료/출처 게이트 통합 수용 불가**, 실행 재개 불가다. P02 기록 파일 자체가 창 중 생성·변경되면 현재 허용 범위 밖이므로 별도 hard stop이며 이름·시간만으로 허용할 수 없다.

후속 독립 심사에 통합 코드 및 SHA, 실제 실행 경로에서 호출되는 엔진 없는 합성 반례 결과(보호 파일 변경/삭제, 허용·미귀속, 잘못된 모드, 링크/새 디렉터리, 자체 경로 충돌, 누락·예외, 종료 상태 및 기록), 원자 예약·격리 및 양방향 실경로 검증, P02 출처 기록 연결과 그 기록 자체 보호 규칙, 새 전후 인벤토리 및 오류 처리를 제출해야 한다. 원문 보존과 상위의 별도 실행 승인도 필요하다. 5-a 미통과, 실제 Godot 실행 3회/K=6 유지.
