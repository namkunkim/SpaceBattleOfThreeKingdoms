# P02 재개 계획 독립 심사

판정: **준비 작업에 한해 수용; K6 실행은 반려**. 심사 대상 RESUME-PLAN.md SHA-256 `381096045a7dc5c392fc2a948ad07b4698fd957781534ba9415c23c3c4bb824f`. 이 판정은 제품 코드 적용이나 P02 인수가 아니다. 심사 turn의 권위 있는 request metadata: model `gpt-6.1-terra`, reasoning_effort `low`.

후보 patch는 세 승인 파일에 국한되고 native 생성과 기존 지휘 정책을 공통 함수로 옮긴다. direct 거절은 게시 전, auto 거절은 thread 시작 전이다. 이 경계는 게시 중 예외 전체의 원자성을 뜻하지 않는다. 기존 제한 adapter/worker/replay와 적벽 private owner 제품 연결은 별도다. 원본 `_reinf_def` 참조 및 combat 전달을 확인했으며 이 변경의 alias 보존은 실제 실행 증거가 아직 필요하다. P03 변경은 시점별로만 구분한다.

실행 반려 이유: 계획 자체가 행 5·12·15·16 등 구체 명령과 fixture가 아직 없음을 밝히며, 행별 입력·예상·관측 파일·전체 단언, 복제 차이 및 SHA가 최종 동결되지 않았다. K6 잔여 한 회를 소진하기 전에 완성된 manifest와 실행 가능한 프로브 전체를 별도 독립 재심해야 한다. 21행 전부가 분모이고 K3/K4 부분 관측이나 K5 출처 불명 입력으로 대체할 수 없다. 각 lane과 전체 시간 상한의 합도 사전에 계산해야 한다. WorldMap 600초는 종료 보장이 아니며 만료는 실패/미검증이다. K1~K5 기록을 보존하고 한도를 재설정하지 않는다.

GUI 제안의 Win32 비대상 창 조회는 API 확인만 증명한다. 실제 실행 PID·생성 시각·이미지 SHA와 OS HWND 소유 PID, 전경·client 좌표 및 Sky 창의 고유 대응을 실행별로 확인해야 한다. 매 입력 전후 기록만으로 중간 전경과 입력 출처를 증명할 수 없다는 제약을 계획이 인정한다. 이를 해소하는 관찰·중단·입력 상관 절차가 실행 전 구체화되고 독립적으로 심사되어야 한다. 확인 실패 또는 입력 혼재 시 성공 집계 금지. GUI 조작은 computer-use 절차를 따른다.

준비 단계에서 기존 증거/원본 checkout, Git metadata, HTML 및 P03을 변경하지 말고 새 경로에만 프로브와 manifest를 작성한다. 실행 직전 모든 의존 입력과 승인 hunk를 대조하고 drift 또는 미귀속 변경은 보류한다. 최종 실행 결과의 독립 5-b 수용 전 원본 제품 적용과 마감은 금지한다. 본 심사는 테스트 실행이나 GUI 입력을 수행하지 않았다.
