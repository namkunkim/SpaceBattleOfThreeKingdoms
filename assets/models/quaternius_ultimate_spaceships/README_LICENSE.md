# 성한지 SF 우주함대 3D 함선 우선 후보 번들

이 폴더에는 Quaternius의 `Ultimate Spaceships Pack`에서 선별한 7개 모델이 들어 있습니다.

- 원 배포 페이지: https://opengameart.org/content/lowpoly-spaceships-pack
- 직접 다운로드: https://opengameart.org/sites/default/files/ultimate_spaceships_-_may_2021.zip
- 제작자: Quaternius
- 배포 라이선스: CC0 1.0 Universal
- CC0 안내: https://creativecommons.org/publicdomain/zero/1.0/
- 확보일: 2026-09-12

## 포함 모델과 제안 용도

| 모델 | 함종 제안 | 상태 |
|---|---|---|
| Imperial | 전열함 | 채택 |
| Executioner | 화력함 | 채택 |
| Insurgent | 공성함 | 개조용 |
| Omen | 보급함 | 개조용 |
| Pancake | 전자전함 | 개조용 |
| Dispatcher | 요격함 | 채택 |
| Challenger | 요격함 대안 | 개조용 |

각 모델 폴더에는 FBX, OBJ/MTL, BLEND 원본과 2048×2048 PNG 텍스처가 있습니다. 이 배포 ZIP에는 배포 페이지의 설명과 달리 glTF 파일이 들어 있지 않았습니다. Godot 4.7.2에서 FBX 임포트 성공 여부를 별도로 확인했습니다.

CC0는 상업적 이용·수정·재배포를 허용하지만, Creative Commons는 권리 상태나 제3자 권리에 관해 보증하지 않습니다. 원 출처 URL과 이 문서를 프로젝트의 서드파티 에셋 기록에 보존하는 것을 권장합니다.
