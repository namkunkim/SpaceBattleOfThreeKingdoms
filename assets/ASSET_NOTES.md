# POC 생성 자산 기록

두 자산은 OpenAI 내장 ImageGen으로 2026-09-12 생성한 독자 POC 자산이다. 원작 게임의 함선, 인물 초상, UI 자산을 입력 이미지로 사용하거나 복제하지 않았다.

## `ships/fleet_ship_sheet_v1.png`

- 용도: 탑다운 함대전용 함선 스프라이트 시트
- 프롬프트: 투명 배경의 2행 3열 구성으로 아군 청색과 적군 적색의 전열함·순양함·구축함을 각각 한 척씩 배치한다. 모든 함선은 오른쪽을 향한 정투영 탑다운 시점이며, 장갑판·함교·포탑·엔진 발광이 48~96픽셀에서도 읽히는 독자적인 레트로 미래 우주 오페라 디자인으로 만든다. 문자·로고·워터마크·기존 저작물의 식별 가능한 함선은 배제한다.

## `portraits/commanders_sheet_v1.png`

- 용도: 함대 명패와 하단 지휘 HUD용 지휘관 초상 시트
- 프롬프트: 동일한 암청색 함교 배경의 엄격한 3열 2행 칸에 유비·관우·제갈량·손권·조조·조인에서 영감을 받은 독자적인 반신 지휘관 초상 여섯 명을 배치한다. 공공영역 역사 인물의 특징과 절제된 SF 함대 제복을 결합하되, 특정 애니메이션·게임 인물과 닮지 않게 한다. 문자·로고·휘장·워터마크는 배제한다.

## `backgrounds/red_cliffs_starfield_v1.png`

- 용도: 조작 가능한 전술 객체 아래에 배치하는 우주 전장 배경
- 프롬프트: 중앙 전술 영역은 어둡고 읽기 쉽게 비우며 가장자리에 청록 성운, 황금 성간 먼지, 우측의 절제된 적색 위험 지대, 소행성 파편과 깊이 단서를 배치한다. 함선·UI·문자·격자·로고·워터마크·기존 저작물은 포함하지 않는 독자적인 고품질 3D 전략 게임용 배경으로 만든다.

## `vfx/fleet_combat_vfx_sheet_v1.png`

- 용도: 사격 이벤트의 탄체, 보호막 피격, 폭발과 잔해 표현
- 프롬프트: 실제 투명 배경의 엄격한 4열 2행 칸에 청색 포구 화염·광자탄·보호막 충격·보호막 파동, 주황 폭발·적색 장갑 피격·반응로 폭발·연기 잔해를 각각 하나씩 배치한다. 32~128픽셀에서 읽히는 고명암 3D VFX로 만들고 함선·UI·문자·테두리·로고·워터마크는 제외한다.

현재 자산은 POC용이며 상품화 승인 자산이 아니다. 실제 제품 단계에서는 아트 디렉션, 라이선스, 인물 고증, 개별 원본 파일과 애니메이션 가능 여부를 별도로 검토해야 한다.

## Quaternius 3D 함선 7종

- 위치: `models/quaternius_ultimate_spaceships/`
- 제작자: Quaternius
- 원 팩: `Ultimate Spaceships Pack` (2021)
- 라이선스: CC0 1.0 Universal
- 출처: https://opengameart.org/content/lowpoly-spaceships-pack
- 반입일: 2026-09-12
- 런타임 형식: FBX를 Godot 4.7.2가 직접 임포트
- 원본·라이선스 상세: `models/quaternius_ultimate_spaceships/README_LICENSE.md`

함급 대응은 Imperial=전열함, Executioner=화력함, Insurgent=공성함, Omen=보급/수리함, Pancake=전자전함, Dispatcher=요격함이다. 전용 항모 모델이 없는 현재 POC에서는 Challenger를 강습항모의 임시 대역으로 사용한다. 현재 3D POC는 원본 형상을 그대로 사용하고 팀별 색조, 금속 재질, 엔진광만 런타임에서 적용한다. 전용 강습항모 제작, 개조용 모델의 구조 수정과 GLB 표준화는 아직 수행하지 않았다.

## 사용자 제공 ver3 GLB

- 원본 보존: `models/user_ver3/` (15종)
- 전투 런타임: `models/user_ver3_runtime/` (7종)
- 사용자 확인 라이선스: 사용 가능, 별도 제한 없음
- 적용 함급: 전열함, 화력함, 항모, 공성함, 전자전함, 보급/수리함, 호위함
- 최적화: 원본 약 197만~307만 삼각형을 함급별 2.5만~6만 삼각형 LOD0로 축소
- 재질 정책: GLB 내장 PBR 재질 보존, 기존 Quaternius 런타임 재질 오버라이드 제거
- 축 정책: 원본 선수 `+X`를 게임 전방 `-Z`로 Y축 90도 보정

`전열함_기함급`은 과도한 기함 강조를 피하기 위해 현재 204척 편제에는 사용하지 않는다. 원본 15종은 수정하지 않았으며 Blender 최적화 스크립트는 `tools/blender/optimize_user_ver3_models.py`에 보존한다.

## 사용자 제공 함선 컨셉과 v0.9 런타임 자산

- 원본 보존 위치: `concepts/user-provided/`
- 통일 시점: 정투영 상면도
- 통일 방향: 함수는 오른쪽, 엔진은 왼쪽
- 함급 정책: `보급함` 유지, 별도 `수송함`은 사용하지 않고 `수송기`로 통합
- 대형함 v2: `ships/concept_runtime/battleship_top_v2.png`, `fire_support_top_v2.png`, `siege_ship_top_v2.png`, `assault_carrier_top_v2.png`
- 지원함 묶음: `ships/concept_atlases/support_ships_v1.png` — 보급함·전자전함·요격함
- 소형기 묶음: `ships/concept_atlases/small_craft_v1.png` — 고속정·수송기·전투기

대형함 네 척은 각각 해당 사용자 제공 컨셉 한 장을 권위 참조로 사용해 내장 ImageGen으로 별도 생성했다. 공통 프롬프트는 원본 함형·무장·갑판·엔진 배치를 보존한 고해상도 정투영 상면도, 실제 투명 배경, 함수 오른쪽, 배경·문자·번호·휘장·UI 제거였다. 공성함은 첫 결과의 관통포가 3문이어서 선체를 유지하고 선수 관통포를 정확히 4문으로 수정한 두 번째 결과만 채택했다.
