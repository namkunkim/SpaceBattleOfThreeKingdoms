# 배경음악

퍼블릭 도메인 고전. `ui_sound.gd`가 `Music` 버스로 순서대로 반복 재생한다. 음량은 설정의 "배경음악".

| 파일 | 곡 / 연주 | 출처·라이선스 |
|---|---|---|
| `mars.ogg` | Holst 〈행성〉 중 "Mars, the Bringer of War" / 미 공군 밴드(1998) | [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Holst-_mars.ogg) — 연주는 미 정부 직원 저작물, 곡은 작곡가 1934년 사망으로 PD |
| `overture_1812.ogg` | 차이콥스키 〈1812 서곡〉 / 스키드모어 칼리지 오케스트라(Musopen) | [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Pyotr_Ilyich_Tchaikovsky_-_1812_overture.ogg) — 연주자가 PD로 공개. Musopen이 사용처 표기를 요청함 → 크레딧에 "Music: Musopen / Skidmore College Orchestra" 넣을 것 |
| `mountain_king.ogg` | Grieg 〈페르귄트〉 중 "산왕의 동굴에서" / Musopen Symphony(체코 국립 교향악단) | [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Musopen_-_In_the_Hall_Of_The_Mountain_King.ogg) — Musopen이 전 세계 PD로 공개, 표기 요구 없음(그래도 크레딧에 Musopen 표기). **교전 중 반복 재생**, 평시 곡 목록(`MUSIC`)에는 없음 |
| `stars_stripes.ogg` | Sousa 〈Stars and Stripes Forever〉 / Sousa's Band, Edison 녹음(1909.11) — 2MB, 4분 28초, 옛 음질 | [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Sousa's_band.stars_stripes_forever.EDIS-SRP-0194-20.ogg) — 미 국립공원관리청 보관 자료, 미국 PD. 업로더도 저작권 포기 선언. 평시 첫 곡 |
